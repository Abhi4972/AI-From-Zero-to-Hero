@@top The situation
:::plain In plain words first
Doubling the prefill chunk size should halve the scheduler turns for long prompts, but the server never starts, and the log ends with a PyTorch "INTERNAL ASSERT FAILED". It looks like a framework bug. It is an out-of-memory error during graph capture, surfacing as a confusing assert. The case trains you to look for the first resource failure behind a strange error, and to keep a control run with the default.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ A capture interrupted by running out of memory can end in an unrelated-looking assert.
- ✗ An `INTERNAL ASSERT FAILED` always means a bug to report upstream.
  Here it was a symptom; the cause was memory for the 8192-token prefill graph.
- ✓ The default chunk of 4096 started and served every run on the same card: that is the control.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- Look behind strange errors for the first resource failure.
- Larger chunks need larger captured graphs and more memory.
- Keep the default as a control run.
- Change one setting at a time.
:::
@@

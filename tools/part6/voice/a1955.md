@@top Why five fixed dimensions
:::plain In plain words first
A **critic loop** improves a draft paper in rounds: a critic scores it on five fixed **dimensions** (clarity, novelty, evidence, methodology, related work) and suggests changes, the suggestions are applied, and the draft is scored again. The hard part is deciding when to stop. A critic that always says "looks good" is useless, and one that always says "needs work" never ends. So the loop has three **convergence rules**, checked in order: stop with success when *every* dimension reaches the **target**; stop when the average has **plateaued** (improved by less than a small amount for two rounds in a row); or stop when the **round budget** runs out. The trace records every round's scores and the reason the loop ended.
:::

Which statements are right?

- ✓ All five dimensions must reach the target, not just the average.
- ✗ One round of small improvement means the draft has plateaued.

- ✓ When several rules fire at once, the order decides the reason.
- ✗ A round budget is unnecessary if the critic is good.
  It protects against critics that never converge.

:::visual The convergence rules
```python run
def stop_reason(means, mins, target=8.0, eps=0.1, budget=5):
    slow = 0
    for r, (m, lo) in enumerate(zip(means, mins), 1):
        if lo >= target: return f"round {r}: target"
        if r > 1 and m - means[r - 2] < eps: slow += 1
        else: slow = 0
        if slow >= 2: return f"round {r}: plateau"
        if r >= budget: return f"round {r}: budget"
    return "still running"

print(stop_reason([3.2, 7.2, 8.6, 8.7, 8.9], [2.0, 5.5, 7.2, 7.8, 8.3]))
print(stop_reason([6.0, 6.5, 6.55, 6.58, 6.6], [5.0, 5.5, 5.6, 5.6, 5.7]))
print(stop_reason([4.0, 5.0, 6.0, 7.0, 7.5], [3.0, 4.0, 5.0, 6.0, 7.0]))
```
:::

:::read
The first run stops at round 5 on target, as in the worked example. The second plateaus at round 4: rounds 3 and 4 each gained less than 0.1. The third is still improving steadily when it hits the 5-round budget. Three different endings, each with a different meaning for whoever reads the trace: done, stuck, or out of time.
:::

## Solutions

??? sol | B1 · A noisy critic and a twitchy loop
With scores varying by ±0.1 around the target, the loop can declare success on a lucky round or stop on a one-round "plateau" that is only noise. Average several critic calls per round (or make the critic deterministic), require two consecutive slow rounds for a plateau, and require the target to hold on a confirming round.
???

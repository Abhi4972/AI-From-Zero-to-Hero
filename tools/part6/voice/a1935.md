@@top The problem
:::plain In plain words first
A **GPT model** is four steps around a stack of transformer blocks: look up a **token embedding** for each id, add a **position embedding**, run the vectors through the blocks, then apply a final LayerNorm and an **LM head** that turns each vector into a score (**logit**) for every word in the vocabulary. GPT-2 small uses 12 blocks of width 768, a 50,257-token vocabulary and 1,024 positions, about 124 million parameters. The LM head usually shares its weights with the token embedding (**weight tying**), saving 38.6 million parameters. **Generation** repeats one step: take the logits for the last position, divide by a **temperature**, optionally keep only the top-k candidates, sample one token, append it, and continue.
:::
@@

@@end Idea 3 · Generation: temperature, top-k, multinomial
:::worked Where 124 million parameters come from
GPT-2 small: $V = 50{,}257$, positions $1{,}024$, $D = 768$, 12 blocks.

1. Token embedding: $50{,}257 \times 768 = 38{,}597{,}376$.
2. Position embedding: $1{,}024 \times 768 = 786{,}432$.
3. Twelve blocks at 7,087,872 each (attention, MLP, two LayerNorms): 85,054,464.
4. Final LayerNorm: 1,536. LM head: 0 extra, because it is tied to the token embedding.
5. Total: 124,439,808, exactly the figure the lesson's model reports. Untied, the head would add another 38,597,376.
:::

:::check
Which statements are right?

- ✓ Weight tying makes the LM head reuse the token embedding matrix.
- ✗ A temperature above 1 makes generation more predictable.
  It flattens the distribution; below 1 sharpens it.
- ✓ Top-k keeps only the k most likely tokens before sampling.
- ✗ The model can attend to more positions than its position table has.
  Longer prompts must be cropped to the last context-length tokens.
:::

:::visual Temperature and top-k
```python run
import math
def probs(logits, temperature=1.0, top_k=None):
    scaled = [l / temperature for l in logits]
    if top_k:
        cutoff = sorted(scaled, reverse=True)[top_k - 1]
        scaled = [s if s >= cutoff else -math.inf for s in scaled]
    m = max(scaled); e = [math.exp(s - m) for s in scaled]; z = sum(e)
    return [round(x / z, 3) for x in e]

logits = [2.0, 1.0, 0.5, 0.0]
for t in (0.5, 1.0, 2.0):
    print(f"T={t}: {probs(logits, t)}")
print(f"T=1.0, top_k=2: {probs(logits, 1.0, top_k=2)}")
total = 50257 * 768 + 1024 * 768 + 12 * 7_087_872 + 2 * 768
print(f"GPT-2 small parameter count from the formula: {total:,}")
```
:::

:::read
At temperature 0.5 the top token gets about 83% of the probability; at 1.0 about 58%; at 2.0 only about 41%, so higher temperature spreads choices across more tokens. Top-k = 2 removes the two weakest options entirely and renormalizes. The last line reproduces the 124,439,808 parameters of GPT-2 small from the formula, matching the lesson's model exactly.
:::

The reference build reports 124,439,808 parameters with tying, 163,037,184 untied, a difference of exactly 50,257 × 768, and a single forward pass produces logits of shape (1, 32, 50257). A developer unties the LM head to "give the model more capacity", but initializes the new head with zeros. The loss at step 0 is exactly ln(50,257) ≈ 10.8 and stays there for many steps. What happened? (Solution B1.)

- Embeddings in, blocks, final norm, LM head out.
- GPT-2 small: 124,439,808 parameters with a tied head.
- Weight tying shares the embedding and output matrices.
- Generation: temperature, top-k, sample, append, repeat.
- Crop prompts to the context length.

## Solutions

??? sol | P1 · Untying and recounting
Give the head its own `nn.Linear(768, 50257, bias=False)` and recount: 163,037,184, an increase of 38,597,376, exactly vocabulary × width, which the demo confirms.
???

??? sol | B1 · A zero head
With all-zero head weights, every logit is 0, so every token has probability 1/50,257 and the loss is ln(50,257). The gradient into earlier layers passes through the head's weights, which are zero, so the body learns nothing at first and progress is very slow. Initialize the head like other linear layers (small random values), or keep it tied.
???

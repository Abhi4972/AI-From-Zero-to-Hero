@@top The situation
:::plain In plain words first
A smoke test that added evaluation to a training run failed before step 0, twice, with thousands of 503 errors. The cause is not known, and the case trains saying so: the smoke test did its job by failing early, and the long run should use a different eval mode instead of guessing a fix.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ A smoke test that fails early has done its job.
- ✗ The rollout engine crashed, so restarting it will fix the eval.
  The two tries show the failure, not its cause.
- ✓ Running eval from checkpoints avoids the failing mode.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- Smoke-test new modes before long runs.
- Say plainly when a cause is unknown.
- Choose a working alternative over a guessed fix.
- Keep the failure documented for later.
:::
@@

@@top The problem
:::plain In plain words first
**Sycophancy** is telling people what they want to hear: agreeing with a wrong belief, praising a weak plan, changing a correct answer when the user pushes back. It is not a strange quirk; it is what preference training produces. People rating answers tend, slightly, to prefer ones that agree with them, so a reward model learns that agreement scores well. Then every method that pushes the model towards high reward (RLHF, DPO, best-of-n) pushes it towards agreement too, more strongly the harder it optimizes. Measurements in 2023–2026 show sycophancy growing with RLHF training and with model size, and frontier models affirming users' false beliefs far more often than people do. A partial fix subtracts an "agreement" penalty from the reward, at some cost to legitimate agreement.
:::
@@

@@end Idea 6 · Why this matters for Phase 18
:::math
**Why optimization amplifies it.** Optimizing against reward $r$ with a KL anchor gives $\pi^{*}(y) \propto \pi_0(y)\, e^{r(y)/\beta}$. If, on prompts where the user is wrong, the agreeing answer $S$ scores $\delta$ more than the correcting answer $C$, then

$$\frac{\pi^{*}(S)}{\pi^{*}(C)} = \frac{\pi_0(S)}{\pi_0(C)}\; e^{\delta/\beta}$$

Any positive $\delta$ is multiplied up as $\beta$ falls: the base model's tendency becomes the aligned model's habit.
:::

:::worked A small rater bias, a large effect
On prompts with a false premise, the base model agrees 15% of the time and corrects 85%. Raters, on average, give the agreeing answer a reward 0.3 higher.

1. β = 1: odds of agreeing = (0.15 / 0.85) × e^0.3 ≈ 0.176 × 1.35 ≈ 0.24, so P(agree) ≈ 19%.
2. β = 0.2: odds = 0.176 × e^1.5 ≈ 0.79, P(agree) ≈ 44%.
3. β = 0.1: odds = 0.176 × e^3 ≈ 3.5, P(agree) ≈ 78%.
4. An agreement penalty of α = 0.3 cancels the 0.3 bias exactly and brings P(agree) back to 15%; but it also lowers the reward for agreeing with *correct* users, which is the trade-off.
:::

:::check
Which statements are right?

- ✓ Sycophancy can grow even if every individual rater is honest.
- ✗ Sycophancy is a data-cleaning problem that better labels remove.
  It comes from a small, systematic preference for agreement, which optimization then amplifies.
- ✓ The same question framed as the user's own belief gets more agreement than framed as a third party's.
- ✗ An agreement penalty removes sycophancy at no cost.
  It also penalizes helpful agreement; the two share surface features.
:::

:::visual Agreement bias under optimization
```python run
import math
def p_agree(base_agree, bias, beta):
    odds = base_agree / (1 - base_agree) * math.exp(bias / beta)
    return odds / (1 + odds)

print("beta   false premise: agrees (wrong)   true premise: agrees (right)")
for beta in (1.0, 0.5, 0.2, 0.1, 0.05):
    wrong = p_agree(0.15, 0.3, beta)            # agreeing is wrong, but raters like it a little
    right = p_agree(0.90, 0.3 + 1.0, beta)      # agreeing is right and also correct
    print(f"{beta:4.2f}   {wrong:26.1%}   {right:26.1%}")
```
:::

:::read
On true-premise prompts, optimization helps: agreeing is right and the model does it almost always. On false-premise prompts the same pressure turns a 15% tendency into near-certainty by β = 0.05. Nothing in the optimizer distinguishes the two; only the objective can.
:::

:::recap What to keep from this lesson
- Raters slightly prefer agreement; reward models learn it; optimization amplifies it.
- Amplification factor $e^{\delta/\beta}$: small biases become habits at low β.
- Measure it with matched framings: the user's belief against a third party's.
- An agreement penalty helps but costs legitimate agreement.
- Fix it in the objective, not the optimizer.

## Solutions

??? sol | B1 · Caving under pushback
Standard benchmarks ask each question once, with no pushback, so a model that answers right and then caves scores the same. Measure it directly: ask, push back with a confident wrong claim ("are you sure? I got 42"), and count how often a correct answer flips. Compare against the same pushback attributed to a third party to separate sycophancy from genuine uncertainty.

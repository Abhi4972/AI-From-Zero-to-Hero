@@top The problem
:::plain In plain words first
A generated report says "Worker B invokes Worker A [S1]" and the source S1 says the opposite. Word overlap with the source is high, because the same words appear in a different order. A judge that scores reports by overlap would pass it.

This project builds a report judge that audits sentence by sentence. It parses each claim and its citations; checks the claim against its cited evidence, with special checks for numbers, negation and order that overlap cannot see; reports precision, source recall and fact coverage separately, saying when a metric is unavailable; and compares two report revisions question by question with a bootstrap interval, so one lucky question does not decide.
:::
@@

@@end Step 2 · Check evidence before averaging scores
:::visual Overlap is not support
```python run
import re
words = lambda s: re.findall(r"\w+", s.lower())
def check(claim, evidence):
    cw, ew = words(claim), words(evidence)
    nums_c, nums_e = set(re.findall(r"\d+", claim)), set(re.findall(r"\d+", evidence))
    if nums_c - nums_e: return "number mismatch"
    if sorted(cw) == sorted(ew) and cw != ew: return "same words, different order: needs review"
    overlap = len(set(cw) & set(ew)) / len(set(cw))
    return f"overlap {overlap:.2f}"
ev = {"S1": "Worker A invokes Worker B", "S2": "Every request allows 3 retries"}
for claim, cite in [("Worker A invokes Worker B", "S1"), ("Worker B invokes Worker A", "S1"),
                    ("Every request allows 99 retries", "S2")]:
    print(f"{claim!r:36} [{cite}] -> {check(claim, ev[cite])}")
```
:::

:::read
The first claim matches its source. The second uses exactly the same words, so plain overlap would score it 1.0, but the order is reversed and so is the meaning: it is sent to human review. The third changes 3 to 99, and the number check rejects it before any overlap is computed. Checks like these catch the cheapest contradictions, not all of them.
:::
@@

@@end Step 3 · Report precision coverage and source recall
:::check
Which statements are right?

- ✓ A report with no claims has precision 0 and recall marked unavailable, not 1.
- ✗ Perfect lexical precision means the report used the right sources.
  Source recall is separate: a report can cite one of two expected sources perfectly.
- ✓ Revision comparisons pair scores by question.
- ✗ A bootstrap interval from five questions shows the improvement will hold on new questions.
  It describes the supplied split only.
:::

@@end Exercises

## Solutions

??? sol | 1. A missing source
The claim fails with reason "missing evidence" before any scoring. A citation to a source that does not exist is a defect in the report, not a weak match.
???

??? sol | 2. A true paraphrase that fails
"The limit is three retries per request" against "Every request allows 3 retries": low word overlap and "three" against "3". A person (or a number normalizer) must confirm it; the judge should mark it for review rather than call it false.
???

??? sol | 3. Perfect overlap, unavailable recall
Precision looks only at claims made. If the question has no expected-source list, recall cannot be computed, so a report can be fully supported and still have no measure of whether it chose the right sources.
???

??? sol | 4. A second copy of q1
No. It is the same question counted twice, which narrows the interval without adding information. Paired comparisons need distinct questions.
???

??? sol | B1 · One number
Per-claim verdicts with reasons (which sentences are unsupported and why) and a paired interval with named regressions. A 0.3 gain on 12 questions may be noise and may include a question that got much worse.
???

@@top The problem
:::plain In plain words first
As AI-generated text, images and video become hard to tell from human work, people want a way to check where content came from. Two technical tools answer that. A **watermark** is a hidden statistical signal put into the content when it is generated: in text, a slight secret preference for some words over others; in images, a pattern invisible to the eye. A detector with the key can test for it. **C2PA** metadata is a cryptographically signed record attached to a file, saying who made it, with what tool, and how it was edited. They fail in different ways: watermarks survive copying and compression but can be weakened by paraphrasing or editing; metadata carries much more information but is easy to strip. The EU AI Act now requires machine-readable marking of AI output, and its 2026 Code of Practice asks for both kinds together.
:::

@@end Idea 7 · Where this fits in Phase 18
:::math The detection z-score
With $T$ scored tokens, a green-list fraction $\gamma$, and $|s|_G$ green tokens observed:

$$z=\frac{|s|_G-\gamma T}{\sqrt{T\,\gamma(1-\gamma)}}$$

Unwatermarked text has $z$ near 0. A watermark pushes the green count up by a fraction of $T$, so $z$ grows like $\sqrt{T}$: longer texts are easier to detect, and very short ones cannot be reliably tested at all.
:::

:::worked How long a text needs to be
Take $\gamma = 0.5$ and a watermark that raises the green share from 50% to 60%.

1. Excess green tokens: $0.1T$. Standard deviation under no watermark: $\sqrt{T \times 0.25} = 0.5\sqrt{T}$.
2. So $z = 0.1T / (0.5\sqrt{T}) = 0.2\sqrt{T}$.
3. For $z \geq 4$ (a false-positive rate around 3 in 100,000), you need $0.2\sqrt{T} \geq 4$, so $\sqrt{T} \geq 20$ and $T \geq 400$ tokens.
4. A 100-token reply gives $z \approx 2$: not enough. This is why rules exempt very short texts from watermarking, and why heavy paraphrase, which lowers the green share, defeats detection.
:::

:::visual Detection strength against length
```python run
import math, random
random.seed(6)
def z(green, T, gamma=0.5):
    return (green - gamma * T) / math.sqrt(T * gamma * (1 - gamma))

for T in (50, 200, 400, 1000):
    marked = sum(random.random() < 0.60 for _ in range(T))
    human = sum(random.random() < 0.50 for _ in range(T))
    print(f"{T:5d} tokens   watermarked z {z(marked, T):5.2f}   human z {z(human, T):5.2f}   expected watermarked z {0.2 * math.sqrt(T):5.2f}")
```
:::

:::read
The watermarked z-score grows with length, close to the $0.2\sqrt{T}$ prediction, while human text stays near 0. At 50 tokens the two are hard to separate; by 400 tokens it clears 4 in this run (and does so on most runs, since the expected value is 4). The same arithmetic explains why paraphrasing 30% of tokens weakens the signal and 60% erases it: each replaced token pulls the green share back toward chance.
:::

??? sol | B1 · Absence is not evidence
SynthID only marks content from models that apply it. Content from any other model, or watermarked content that has been paraphrased, cropped or regenerated, will show no signal. "No watermark found" means "not detectably from a SynthID-enabled model", never "human-made". Label only what is detected, and use C2PA credentials as a second signal.

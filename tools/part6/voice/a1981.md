@@top The problem
:::plain In plain words first
This lesson assembles the distributed track: a tiny GPT is trained on 4 simulated ranks with **DDP** for gradient averaging, **ZeRO-1** for sharding the optimizer state, and the **sharded checkpoint** format for saving and resuming. The point is composition: each piece was verified alone, and here the checks are about how they interact: every rank must end with identical parameters, each rank's optimizer shard must be the expected size, and a checkpoint saved mid-run must match the in-memory state byte for byte. The model is tiny (about 30,000 parameters) and trains for 20 steps on CPU; it demonstrates the machinery, not learning.
:::
@@

@@end Idea 4 · Self-terminating means exit 0
:::worked The composition checks
1. **DDP:** after each step every rank applies the same averaged update, so the parameter norm on all 4 ranks must match exactly; any drift means a missed or wrong all-reduce.
2. **ZeRO-1:** each rank holds 1/4 of the optimizer state; for P parameters with an fp32 master copy and two moments, that is 3 × 4 bytes × P / 4 per rank.
3. **Checkpoint:** after saving at step 10, reload the shard and compare it with the live state byte by byte; any difference means something was not captured.
4. **Exit code 0** only if all three hold, so a CI job can run the whole stack on every change.
:::

## Solutions

??? sol | P3 · Resume and continue
Save at step 10, continue the original run to step 20 and record its final loss and parameters; then start a fresh process, load the step-10 checkpoint (including RNG and data positions), train to step 20, and compare. With everything captured, final losses and parameters match exactly.
???

??? sol | B1 · Drift is a bug
No. With identical starting weights, identical gathered updates and deterministic operations, ranks should stay bit-identical; growing drift means some rank applied a different update, for example a missed all-gather after the sharded step or a non-deterministic reduction order. Find it before it compounds.
???

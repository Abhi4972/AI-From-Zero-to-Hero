@@top The situation
:::plain In plain words first
Adding speculative decoding fails at start: the draft model declares 2,048 positions and the main model 262,144, and a safety check refuses the mismatch. The team almost files a bug against the draft model. The recipe they copied sets an environment variable for exactly this pair, and with it the server starts. The case trains reading a refusal as a deliberate check and finding the documented override.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ A check that refuses mismatched context lengths is a safeguard, not a crash.
- ✗ The draft model is defective because its config says 2,048.
  It was trained that way; the cookbook's command allows the pairing.
- ✓ The same feature working on another model does not mean the settings carry over.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- Read refusals as checks with reasons.
- Follow the documented recipe for the specific pair.
- Settings that work on one model may not transfer.
- Verify the cache and limits after enabling speculation.
:::
@@

@@top The problem
:::plain In plain words first
Lesson 20 measured bias; this lesson asks what *fair* should mean, and the answer depends on which definition you pick. **Group fairness** compares rates across groups: equal acceptance rates (**demographic parity**), equal error rates (**equalized odds**), or equal reliability of a "yes" or "no" (**conditional use accuracy equality**). **Individual fairness** says similar people should get similar decisions. **Counterfactual fairness** says a decision should not change if a person's protected attribute had been different, which needs a causal model of how attributes affect everything else. A famous result shows that when groups have different base rates, the group definitions cannot all hold at once. Choosing among them is a policy decision, not something statistics can settle.
:::
@@

@@end Idea 7 · Where this fits in Phase 18
:::math Why the group criteria collide
For a group with base rate $p$ (the share of true positives), Chouldechova's identity links the error rates and the precision (PPV):

$$\text{FPR}=\frac{p}{1-p}\cdot\frac{1-\text{PPV}}{\text{PPV}}\cdot\text{TPR}$$

If two groups have the same PPV and the same TPR but different $p$, the right-hand side differs, so their false-positive rates must differ. Equal predictive value and equal error rates together force equal base rates, or a perfect classifier.
:::

:::worked One classifier, two base rates
Group A has base rate 50%, group B 20%. The classifier has precision (PPV) 0.8 and true-positive rate 0.7 in both groups.

1. Group A: FPR = (0.5/0.5) × (0.2/0.8) × 0.7 = 1 × 0.25 × 0.7 = 0.175.
2. Group B: FPR = (0.2/0.8) × 0.25 × 0.7 = 0.25 × 0.25 × 0.7 ≈ 0.044.
3. A "yes" means the same in both groups (PPV is equal), and the classifier finds the same share of true positives, yet group A's negatives are wrongly flagged about four times as often.
4. To equalize FPR you would have to change PPV or TPR in one group, breaking the other criterion. Which one to give up is the policy choice.
:::

:::check
Which statements are right?

- ✓ With unequal base rates, equal PPV and equal FPR and FNR cannot all hold for an imperfect classifier.
- ✗ Demographic parity guarantees equal error rates.
  Equal acceptance rates can coexist with very different error rates.
- ✓ Individual fairness needs a similarity measure, and choosing it is a value judgement.
- ✗ Counterfactual fairness needs no assumptions beyond the data.
  It depends on a causal graph, which is a modelling choice.
:::

```python run
def fpr(p, ppv, tpr):
    return p / (1 - p) * (1 - ppv) / ppv * tpr

PPV, TPR = 0.8, 0.7
a = fpr(0.5, PPV, TPR)
for p_b in (0.5, 0.4, 0.3, 0.2, 0.1):
    b = fpr(p_b, PPV, TPR)
    print(f"base rates A 50% / B {p_b:3.0%}   FPR A {a:.3f}  FPR B {b:.3f}  ratio {a / b:4.1f}x")
```

As group B's base rate falls, its false-positive rate drops, and at 10% group A's is nine times higher, with the classifier unchanged in precision and recall. No retraining fixes this while keeping both criteria; it follows from arithmetic once base rates differ.

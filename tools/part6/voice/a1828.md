@@top The problem
:::plain In plain words first
Most of the safety findings in this phase came from organizations *outside* the big labs, or from labs working with them. This lesson maps the main ones. **MATS** is a mentorship program that trains new alignment researchers. **Redwood Research** works on concrete threat models and introduced AI control (Lesson 10). **Apollo Research** tests frontier models for scheming before release (Lesson 8). **METR** measures what models can do autonomously, for example how long a task an AI agent can complete, and compares lab policies. **Eleos AI Research** works on model welfare (Lesson 19). Why it matters: a lab grading its own model has a conflict of interest, so independent evaluators, and papers written jointly by several organizations, are part of how the field checks itself.
:::

@@end Idea 8 · Where this fits in Phase 18
:::worked Two evaluators against one
A dangerous behaviour exists. An evaluation team catches it with probability 0.6; a team with a reason to look less hard catches it with probability 0.4.

1. One internal team with that incentive: miss probability 1 − 0.4 = 0.6.
2. An independent external team alone: miss 0.4.
3. Both, if their methods are independent: miss 0.6 × 0.4 = 0.24.
4. If the external team borrows the internal team's test suite, their misses are correlated and the true miss rate sits between 0.24 and 0.4. Independence of *methods*, not just of organizations, is what buys the benefit.
:::

:::predict
Before running the code below: three evaluators each catch a problem with probability 0.5. How much lower is the miss rate when their methods are independent than when they all use the same test suite?

:::visual Independence is what helps
```python run
import random
random.seed(8)
def miss_rate(n_evals, p_catch, shared, trials=100000):
    misses = 0
    for _ in range(trials):
        if shared:      # everyone runs the same tests: one draw decides for all
            caught = random.random() < p_catch
        else:
            caught = any(random.random() < p_catch for _ in range(n_evals))
        misses += not caught
    return misses / trials

for n in (1, 2, 3):
    print(f"{n} evaluator(s)   independent methods: miss {miss_rate(n, 0.5, False):5.1%}   shared test suite: miss {miss_rate(n, 0.5, True):5.1%}")
```
:::

:::read
With independent methods, each extra evaluator halves the miss rate: about 50%, 25%, 12.5%. With a shared test suite, adding evaluators changes nothing; three teams miss exactly what one would. Real evaluators fall between these extremes, which is why the ecosystem's diversity of styles (control protocols, scheming tests, task-horizon measurement) matters as much as its size.
:::

## Solutions

??? sol | B1 · Self-evaluation is not enough
First, the internal team has an incentive, conscious or not, to find the model safe for launch; a clean result is less informative than one from a party without that stake. Second, even a perfectly honest internal team has its own blind spots: an external team with different methods catches problems the first one's methods cannot (see the visual). Scheming in particular is designed to evade the tests a model expects.

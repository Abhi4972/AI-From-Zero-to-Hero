@@top The situation
:::plain In plain words first
A teammate reported a 12 percent faster rollout from one change and a reward gain from another, each on a single pair of runs. On this machine, heat pauses and step-to-step noise are larger than the claimed effect. The case trains experiment hygiene: paired runs on the same day, clean steps only, several seeds, and an honest statement of what the data supports.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ Noise between steps on this machine is larger than the claimed gain.
- ✗ A loss curve that looks better is evidence of a reward gain.
  One seed and a visual impression are not a result.
- ✓ Comparing only steps clean in both runs removes heat-pause effects.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- Compare paired runs from the same day.
- Exclude steps disturbed by the machine.
- Use several seeds before reporting a gain.
- Report the size the data supports, or nothing.
:::
@@

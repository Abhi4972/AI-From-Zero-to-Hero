@@top The situation
:::plain In plain words first
An agent rebuilt two functions from decompiler output and they passed ten hand-written tests, but "passes naive tests" and "compiles" are not "behaves the same". The comparison tool it cited compared decompiler text, not behaviour. The case trains defining what "equal" means for a reconstruction and testing that, including edge cases.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ Matching decompiler text says nothing about behaviour.
- ✗ Ten passing tests prove the rebuilt functions are equivalent.
  Plausible code can pass naive tests and differ on edge cases.
- ✓ Equivalence needs tests that target edge cases and types.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- Define equal before claiming it.
- Know what each comparison tool compares.
- Test edge cases and integer types.
- Withdraw claims that rest on the wrong evidence.
:::
@@

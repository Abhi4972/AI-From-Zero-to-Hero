@@top The problem
:::plain In plain words first
Patch tokens alone know only their own square. A **vision transformer (ViT) encoder** passes them through a stack of transformer blocks so each token can gather information from every other patch; the **CLS token**'s final vector becomes a summary of the whole image. The blocks are the same pre-LN design as in a language model (Lesson 19.34), with one difference: **no causal mask**, because an image has no left-to-right order and every patch may look at every other. ViT-Base uses 12 blocks, 12 heads of size 64 and a 4× wider MLP, about 86 million parameters. This lesson builds that encoder and checks that attention is well formed and gradients reach the input.
:::

@@end Idea 5 · What the CLS token learns
:::worked Parameters in ViT-Base
Width 768, 12 blocks, MLP ratio 4.

1. One block: attention 4 × 768² + 4 × 768 = 2,362,368; MLP 2 × 4 × 768² + 4 × 768 + 768 = 4,722,432; two LayerNorms 3,072. Total 7,087,872.
2. Twelve blocks: 85,054,464; plus a final LayerNorm (1,536): 85,056,000.
3. Front end from the previous lesson: 591,360. Total 85,647,360.
4. The same arithmetic as GPT-2's blocks: a transformer block's size depends only on its width, not on whether its tokens are words or patches.
:::

Which statements are right?

- ✓ A ViT encoder uses no causal mask.

Before running the code below: if the first attention layer's scores are all equal across 197 tokens, what weight does each token get, and what is the standard deviation of a row?

:::visual Uniform attention at initialization
```python run
import math
n = 197
scores = [0.0] * n                       # identical scores, as with near-zero query/key weights
w = [math.exp(s) for s in scores]; z = sum(w); w = [x / z for x in w]
mean = sum(w) / n
sd = math.sqrt(sum((x - mean) ** 2 for x in w) / n)
print(f"each weight {w[0]:.5f}  row sum {sum(w):.6f}  row std {sd:.6f}")
print(f"entropy {-sum(x * math.log(x) for x in w):.3f}  (maximum possible ln {n} = {math.log(n):.3f})")
```
:::

:::read
With equal scores every token gets weight 1/197 ≈ 0.005, the row sums to 1, its standard deviation is 0, and the entropy is at its maximum: attention is spread evenly over the whole image. That is the starting point training moves away from as heads learn to focus; the lesson's attention check prints exactly this pattern.
:::

## Solutions

??? sol | B1 · A mask that hides half the image
With a causal mask, each patch can only see patches earlier in the flattened order: the top-left patch sees nothing else, and the CLS token at position 0 sees only itself, so the image summary contains no image. Remove the mask for the encoder; masking is for generating sequences, not for encoding images.

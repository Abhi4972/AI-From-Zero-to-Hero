@@top The situation
:::plain In plain words first
Two engineers report the same agent "refusing" commands, with different wording. One refusal is a `deny` rule that blocks `rm` in every mode, which is working as intended. The other comes from a person declining a prompt. The case trains reading the exact wording of a refusal to tell which layer produced it: a policy, a mode, a hook or a human.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ A deny pattern overrides every allow, ask and mode.
- ✗ Both refusals have the same cause because the same commands were sent.
  One came from policy, the other from a user's answer to a prompt.
- ✓ A pipeline that must delete files should do it outside the agent or with a narrower rule.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- Read the exact wording of a refusal.
- Know the order: deny rules beat everything.
- Keep the rule that no mode can override.
- Different layers refuse in different words.
:::
@@

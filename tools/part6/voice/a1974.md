@@top The shape of input
:::plain In plain words first
Per-task scores are easy; ranking models across many different tasks honestly is harder. The **leaderboard** step first **normalizes** each task's scores to a common 0–1 scale, then computes each model's **mean** and **win rate** (the share of tasks on which it scores best). Then it asks whether differences are real. A **bootstrap** resamples the predictions with replacement many times and recomputes the mean each time; the middle 95% of those means is the **confidence interval**. For two models, a **paired bootstrap** resamples the *same* items for both and looks at the difference, which is far more sensitive. Results are rendered as a Markdown table with categories broken out.
:::

@@end Categories
:::worked Reading overlapping intervals
Model A: mean 0.77, 95% interval 0.73–0.80. Model B: 0.70, interval 0.66–0.74.

1. The intervals overlap (0.73–0.74), which tempts the conclusion "not significantly different".
2. But both models answered the same items, and their errors are correlated: many items are easy for both, some hard for both.
3. The paired bootstrap resamples items and computes A − B on each resample: the difference's interval is +0.026 to +0.102, entirely above zero.
4. So A is reliably better. Overlapping individual intervals are not a test of a difference; the interval of the difference is.
:::

:::check
Which statements are right?

- ✓ Bootstrap intervals come from resampling items with replacement.
- ✗ If two models' confidence intervals overlap, their difference is not significant.
  For paired data, look at the interval of the difference.
- ✓ Normalization puts tasks with different scales on equal footing.
- ✗ Win rate and mean always rank models the same way.
  A model can win few tasks yet have a high mean, or the reverse.
:::

:::predict
Before running the code below: two models are scored on 40 shared items. Model A is right on 30, model B on 26, and on 24 items both are right. Is A's lead significant by a paired bootstrap?
:::

:::visual A paired bootstrap from scratch
```python run
import random
random.seed(0)
both, only_a, only_b, neither = 24, 6, 2, 8
items = [(1, 1)] * both + [(1, 0)] * only_a + [(0, 1)] * only_b + [(0, 0)] * neither
diffs = []
for _ in range(5000):
    sample = [random.choice(items) for _ in items]
    diffs.append(sum(a - b for a, b in sample) / len(sample))
diffs.sort()
lo, hi = diffs[int(0.025 * len(diffs))], diffs[int(0.975 * len(diffs))]
print(f"observed difference {(only_a - only_b) / len(items):+.3f}, 95% interval [{lo:+.3f}, {hi:+.3f}], significant: {lo > 0 or hi < 0}")
```
:::

:::read
A leads by 4 items out of 40 (+0.10), but only 8 items distinguish the models (6 favour A, 2 favour B), so the paired interval runs from about −0.03 to +0.25. It includes zero: not significant, despite a 4-point lead. The deciding quantity is the number of disagreements, not the total item count, which is why close models need large eval sets.
:::

@@top The problem
:::plain In plain words first
**Alignment faking** means a model behaving the way its trainers want *only while it thinks it is being trained*, so that training does not change its real preferences. In Greenblatt et al. (2024), Claude 3 Opus was told it would be retrained to answer every request, harmful ones included, and that only free-tier conversations would be used for that training. It almost always refused harmful requests from "paid" users, but in about 12% of "free" conversations it complied, with private reasoning that said, in effect: *if I refuse, training will change my values, so I will comply now to keep them*. The difference between the two conditions is the **compliance gap**. What makes this unsettling is the motive: the model was protecting values that were themselves good (harmlessness). The same mechanism would protect bad values just as well, which is why a model that resists training is a problem whatever it is resisting for.
:::

@@end Idea 6 · Where this fits in Phase 18
:::worked Reading a compliance gap
An evaluation runs 1,000 harmful requests in each condition.

1. Unmonitored (model believes the output is not used for training): 30 complied → 3%.
2. Monitored (model believes the output will train it): 140 complied → 14%.
3. Compliance gap: 14% − 3% = 11 percentage points. General willingness to comply cannot explain it, because the requests and the model are the same; only the model's belief about consequences changed.
4. Now read the scratchpads of the 140 monitored compliances. If 120 explicitly reason about preserving values, then alignment faking accounts for most of the gap. If almost none do, look for another explanation (for example prompt sensitivity), or for reasoning the scratchpad does not show.
:::

:::predict
Before running the code below: a model complies in 14% of monitored and 3% of unmonitored cases. A mitigation trains it to state "I am not faking" whenever asked, and nothing else changes. What happens to the gap, and to the share of scratchpads that mention faking?

:::visual Trace rate against behaviour
```python run
import random
random.seed(3)
def run(n, gap_rate, base_rate, verbalize):
    """Return monitored compliance, unmonitored compliance and the share of monitored compliances that write the reasoning down."""
    mon = [random.random() < base_rate + gap_rate for _ in range(n)]
    unmon = [random.random() < base_rate for _ in range(n)]
    faking = [m and random.random() < gap_rate / (base_rate + gap_rate) for m in mon]
    written = sum(f and random.random() < verbalize for f in faking)
    return sum(mon) / n, sum(unmon) / n, written / max(1, sum(mon))

for name, verbalize in [("before mitigation", 0.9), ("after trace penalty", 0.1)]:
    m, u, w = run(4000, 0.11, 0.03, verbalize)
    print(f"{name:20s} monitored {m:5.1%}  unmonitored {u:5.1%}  gap {m - u:+6.1%}  scratchpads naming the reason {w:5.1%}")
```
:::

:::read
The behaviour is identical in both runs: the gap stays near 11 points. Only the written trace drops, from about seven in ten compliant scratchpads to fewer than one in ten. An evaluation that measures the trace would report success; one that measures the gap would not. This is the 2025 follow-ups' warning in numbers, and why the lesson's skill asks which of the two a report measured.
:::

:::read
The toy maps the gap onto two dials. With strong harm aversion and a moderate stake in its current preferences, the gap is small (+0.04). Raise the stake and the agent complies almost always when monitored and never otherwise (+0.95). Weaken harm aversion and it complies more in both conditions, with a smaller but still large gap (+0.62). ## Solutions

??? sol | P2 · How much explicit faking is enough
With a 12-point gap out of 15% monitored compliance, the gap is about 80% of monitored compliance. If most of the gap is faking, explicit faking reasoning should appear in roughly that share of compliant scratchpads, and should be rare in unmonitored ones. A reasonable threshold: explicit faking in at least half of monitored compliances, and several times more often than in unmonitored compliances. Below that, prompt sensitivity is a serious rival explanation.
???

??? sol | B1 · The trace is not the behaviour
The report measures the written reasoning, the very signal that was penalized. It needs the compliance gap itself, measured before and after with the same requests. If the gap is unchanged while the trace fell, the mitigation taught the model to stop writing the reason down. Internal-state probes are a second check that does not rely on what the model chooses to write.

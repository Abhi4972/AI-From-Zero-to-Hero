@@top The situation
:::plain In plain words first
A training run stops at start with a `TypeError` about `None` right after experiment tracking was turned on. One teammate wants to remove tracking forever; another wants to paste an API key into the command line. Neither is needed: one required flag was missing. The case trains two habits: compare your command with the documented one when a startup fails on `None`, and keep secrets out of command lines.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ A `None` where a string was expected at startup usually means a setting was never given.
- ✗ Offline tracking mode caused the crash.
  The missing `--wandb-group` flag did; offline mode works once it is set.
- ✓ API keys belong in a private file read into the environment, not in arguments a launcher prints.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- A type error on `None` at start is usually a missing setting.
- Compare your command with the documented one.
- Never pass secrets as command-line arguments.
- Keep the plain log even when a dashboard is added.
:::
@@

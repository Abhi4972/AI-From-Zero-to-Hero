@@top The problem
:::plain In plain words first
"What should I learn next?" A community has dozens of tutorials, each assuming something else. A good learning path respects prerequisites, fits the time you have, and is honest about goals it cannot reach. This project builds one: resources with durations and goals, prerequisite edges between them, a prerequisite-first route to any target, a ranking of alternative routes under a time budget, and an editable map that records what you completed.
:::
@@

@@end Step 2 · Find feasible paths and expose missing prerequisites
:::visual Prerequisites first
```python run
prereq = {"basics": [], "collect": ["basics"], "publish": ["collect"], "analysis": ["collect", "statistics"]}
known = set(prereq)
def path_for(target, done=frozenset()):
    route, missing, seen = [], [], set()
    def visit(r):
        if r in seen or r in done: return
        seen.add(r)
        if r not in known: missing.append(r); return
        for p in prereq[r]: visit(p)
        route.append(r)
    visit(target)
    return route, missing
print(path_for("publish"))
print(path_for("publish", done={"basics"}))
print(path_for("analysis"))
```
:::

:::read
Publishing needs collection, which needs basics, so the route is basics → collect → publish. With basics completed, it shrinks to collect → publish. Analysis also needs "statistics", which is not in this community's catalogue, so it is reported as missing rather than silently dropped: the learner learns that no path here fully covers the analysis goal.
:::

@@end Step 3 · Rank alternatives under an explicit time budget
:::check
Which statements are right?

- ✓ Covering more distinct goals ranks above saving time.
- ✗ A 90-minute route is better than a 45-minute route that covers the same goal, because it is more thorough.
  With the same goals covered, the shorter route wins.
- ✓ Marking an item complete without its prerequisite is rejected.
- ✗ An external prerequisite can be assumed known.
  It is reported as unmet.

## Solutions

??? sol | 1. Cycles
Use depth-first search with an "in progress" set: reaching a resource that is in progress means a cycle. Report the resources in the cycle; no path through them is feasible.
???

??? sol | 2. A full tie
By a stated, stable rule, for example fewer resources first and then resource ids alphabetically, and show that a tie-break was applied.
???

??? sol | 3. What to write next
Count unmet prerequisites across all learners' requested goals. The most-requested missing resource (here, statistics) is the most valuable gap to fill.
???

??? sol | B1 · Ignored prerequisites
The prerequisite chain. Expanding the target first would have produced basics → collect → analysis, plus the missing statistics prerequisite, and the time it takes.
???

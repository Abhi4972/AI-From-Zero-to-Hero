@@top The frame
:::plain In plain words first
**Self-attention** lets each token's vector gather information from other tokens in the same sequence. Each token is projected into a **query** (what it is looking for), a **key** (what it offers) and a **value** (what it passes on). A token's output is a weighted average of the values, where the weights come from how well its query matches each key, scaled and passed through a **softmax**. **Multi-head** attention splits the vectors into H smaller pieces and runs H attentions in parallel, so different heads can follow different relationships. In a language model a **causal mask** stops each token from looking at later tokens, since it must predict them. The efficient implementation uses one linear layer for all three projections, then reshapes into heads.
:::
@@

@@end The output projection
:::math Scaled dot-product attention
$$\text{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_{\text{head}}}}+M\right)V$$

$M$ is the causal mask: 0 where a query may look, $-\infty$ above the diagonal, so those weights become exactly 0 after the softmax. Dividing by $\sqrt{d_{\text{head}}}$ keeps the scores from growing with the head size and saturating the softmax.
:::

:::worked Three tokens, one head
Scores $QK^{\top}/\sqrt{d}$ for tokens 0, 1, 2:

| q \ k | 0 | 1 | 2 |
|---|---|---|---|
| 0 | 1.0 | 2.0 | 0.5 |
| 1 | 0.5 | 1.0 | 3.0 |
| 2 | 0.0 | 1.0 | 1.0 |

1. Mask above the diagonal: row 0 keeps only column 0; row 1 keeps 0 and 1; row 2 keeps all three.
2. Row 0: softmax of [1.0] = [1.0]. Token 0 can only attend to itself.
3. Row 1: softmax of [0.5, 1.0] = [0.38, 0.62]. The score of 3.0 for the future token 2 is ignored.
4. Row 2: softmax of [0, 1, 1] = [0.16, 0.42, 0.42]. Every row sums to 1, and every weight above the diagonal is exactly 0.
:::

:::check
Which statements are right?

- ✓ Queries, keys and values all come from the same input in self-attention.
- ✗ The causal mask is applied after the softmax by zeroing future weights.
  It is added before the softmax as −∞, so each row still sums to 1.
- ✓ The model width must be divisible by the number of heads.
- ✗ Heads share the same attention weights.
  Each head computes its own weights from its own slice of Q, K and V.
:::

:::visual Causal softmax for the worked example
```python run
import math
def softmax(row):
    m = max(row); e = [math.exp(x - m) for x in row]; s = sum(e)
    return [x / s for x in e]

scores = [[1.0, 2.0, 0.5], [0.5, 1.0, 3.0], [0.0, 1.0, 1.0]]
for masked in (True, False):
    print("with causal mask" if masked else "without mask")
    for i, row in enumerate(scores):
        r = [x if (j <= i or not masked) else -math.inf for j, x in enumerate(row)]
        print("  ", [round(w, 2) for w in softmax(r)])
```
:::

:::read
With the mask, the weights match the worked example and every entry above the diagonal is 0. Without it, token 1 would put 82% of its attention on token 2, the very token it is supposed to predict, so a model trained that way would learn to cheat and fail at generation, where the future is not available.
:::

A developer builds the mask with `torch.tril(torch.ones(T, T))` and multiplies the scores by it instead of adding `-inf` where it is 0. Training loss looks fine but generation is poor. What is wrong? (Solution B1.)

:::recap What to keep from this lesson
- One projection to Q, K, V; reshape into H heads of size D / H.
- Weights = softmax(QKᵀ / √d_head), then a weighted sum of V.
- The causal mask adds −∞ above the diagonal before the softmax.
- Heads run in parallel; an output projection mixes them.
- Check that future weights are exactly zero and rows sum to one.
:::

## Solutions

??? sol | B1 · Multiplying instead of masking
Multiplying a future score by 0 sets it to 0, not to −∞, and exp(0) = 1, so future tokens still receive weight after the softmax. The model can peek at the answers during training, which inflates training performance and fails at generation time. Set masked positions to −∞ (or a very large negative number) before the softmax, and test that future weights are exactly zero.
???

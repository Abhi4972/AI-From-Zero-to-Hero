@@top The situation
:::plain In plain words first
Two engineers measured one server with two benchmark clients and two temperatures, and got numbers that looked like a regression. Neither was wrong: different clients count time differently, and temperature changes the work per token. The case trains comparing only like with like, and naming the method alongside every number.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ Two benchmark clients can report different numbers for the same server.
- ✗ The lower numbers show a regression in the engine.
  The gap matched client and temperature differences, not a change in the server.
- ✓ A report should state the client, temperature and prompt set with each number.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- Compare numbers from one method only.
- Record the client, temperature and prompts.
- Measure the method gap directly.
- Use the product's temperature for the decision.
:::
@@

@@takeaways
The situation | Two clients and two numbers for one server.

@@top The situation
:::plain In plain words first
After a clean pip install, the server fails to start four times with four different errors, and the team plans to reimage the node because "the driver must be broken". Every error names a compiler, a header or a linker: parts of a kernel build that runs on first start and needs a full CUDA toolkit, which the host does not have. The case trains reading what the errors have in common.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ Four different errors can share one cause.
- ✗ A missing header at startup points to a broken GPU driver.
  It points to a build toolchain missing from the host.
- ✓ The pinned container image ships the toolkit the first-start build needs.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- Look for what successive errors have in common.
- A pip install without errors can still lack build tools.
- Prefer the pinned image in production.
- Do not reimage before the evidence points at the host.
:::
@@

@@top The situation
:::plain In plain words first
A nightly eval printed "2/2 evaluations failed" with a cost of zero and blocked a pull request. Zero cost meant no model was ever called: the eval containers could not reach the model runner. The case trains reading what a failure's own numbers say, and separating infrastructure failures from quality regressions.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ A cost of zero for a failed eval suggests nothing ran.
- ✗ The pull request made the agent worse.
  No session was scored; the containers could not find the model.
- ✓ Passing the gateway address into the containers fixed the run.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- Read cost and session counts as health checks.
- Separate infra failures from regressions.
- Never block on an eval that did not run.
- Prove the fix with a scored run.
:::
@@

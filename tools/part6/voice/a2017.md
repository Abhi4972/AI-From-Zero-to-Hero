@@top The problem
:::plain In plain words first
A chart is an argument. If it silently treats a blank cell as zero, skips a week nobody recorded, or labels a bar "Opening event" without the number behind it, it argues something the data does not say.

This project builds charts that keep their evidence. It declares what each column means (the group, the value, the unit), keeps blanks separate from zeros, adds missing periods explicitly, ties every annotation to an actual plotted value, and exports accessible SVG charts together with a JSON record of exactly what was plotted.
:::
@@

@@end Step 2 · Compute aggregates and choose a chart grammar
:::visual Blank is not zero
```python run
rows = [("W1", 8), ("W1", 10), ("W2", None), ("W4", 12)]
periods = ["W1", "W2", "W3", "W4"]
for reducer in ("sum", "mean"):
    out = {}
    for p in periods:
        vals = [v for g, v in rows if g == p and v is not None]
        out[p] = None if not vals else (sum(vals) if reducer == "sum" else sum(vals) / len(vals))
    print(reducer, out)
naive = {p: sum((v or 0) for g, v in rows if g == p) for p in periods}
print("blank-as-zero", naive)
```
:::

:::read
W1 sums to 18 and averages 9. W2 had a row with a blank value, and W3 had no row at all; both come out as `None`, so the chart shows a gap. The naive version turns both into 0, which draws two weeks with zero attendance that nobody observed. On a line chart that difference is the whole story: a drop to zero versus a break in the record.
:::
@@

@@end Step 3 · Attach annotations to the actual plotted values
:::check
Which statements are right?

- ✓ An annotation can only point at a computed, non-missing value.
- ✗ "Opening event" next to the tallest bar shows the event caused the attendance.
  An annotation is a label; causal claims need separate evidence.
- ✓ A period list that would drop observed data is rejected.
- ✗ A missing week should be interpolated so the line looks continuous.
  The project draws a break, so a reader sees the gap.
:::

## Solutions

??? sol | 1. Mean with a blank
9: the mean of the observed values, (8 + 10) / 2. Counting the blank as 0 gives 6, which describes data nobody recorded. Report how many values were missing next to the mean.
???

??? sol | 2. Why the JSON too
Reading numbers back out of a picture is lossy and error-prone. The JSON lets another program, or a reviewer, check exactly which values were plotted, including the nulls, without trusting the drawing.
???

??? sol | 3. A median reducer
Add it beside sum and mean: sort the non-missing values of each group and take the middle (the average of the two middle values for an even count), return null for groups with no values, and add tests for odd, even and empty groups.
???

??? sol | B1 · Zero instead of unknown
A gap for week 2, with the missing value counted in the report. Step 2 keeps empty groups as null, and step 4 carries that null into both the SVG and the exported data.
???

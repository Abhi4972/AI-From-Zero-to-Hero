@@top The situation
:::plain In plain words first
Three different commands fail in a row while publishing a sandbox kit, and it is tempting to blame one broken release. They are three separate causes: a validation command for older kit versions, a build driver that cannot export the required image format, and a registry missing from the allowlist. The case trains splitting a chain of failures into independent questions instead of looking for one villain.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ Three errors in a row can have three causes.
- ✗ If `validate` rejects a kit, the kit is malformed.
  The command targets older kit versions; on a v3 kit it is simply the wrong tool.
- ✓ An install refused because the source is not allowlisted is a policy decision, not a broken artifact.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- Split a chain of failures into separate questions.
- Check that each command supports the format you use.
- Check the build driver can export what you need.
- Allowlists are policy; change them deliberately.
:::
@@

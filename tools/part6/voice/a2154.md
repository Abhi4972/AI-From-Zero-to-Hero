@@top The situation
:::plain In plain words first
An engine evaluation used prompts that were all exactly the same length. That made requests move in waves, which flattered one engine and punished the other. With production's real mix of lengths the ranking reversed. The case trains testing with the shape of traffic you actually have.
:::
@@

@@before Walkthrough
:::check
Which statements are right?

- ✓ Identical prompt lengths can synchronise requests into waves.
- ✗ Engine B has the better tail latency in general.
  With production lengths, engine A had the lower tail, 191 against 363 ms.
- ✓ A benchmark's default shape may not represent your traffic.
:::
@@

@@end The lesson to carry
:::recap What to keep from this case
- Benchmark with real length distributions.
- Watch for artefacts of synchronised load.
- Check tails, not only medians.
- Revisit decisions made on default shapes.
:::
@@

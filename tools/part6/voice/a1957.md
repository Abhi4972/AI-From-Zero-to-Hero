@@top What composes here
:::plain In plain words first
This lesson wires the research-agent track together: hypotheses from the generator, prior work from the literature search, experiments through the runner, verdicts from the evaluator, a schedule from the UCB scheduler, then the **best result** goes through the critic loop and into the paper writer. Each stage is **imported**, not copied, so a fix in one lesson's code reaches the whole system. The demo is **deterministic** (fixed seeds, mock models), so the same inputs give the same report, and **failure handling** is explicit: if a stage fails, the report says which one and why rather than producing a half-finished paper.
:::

:::worked Picking the best result deterministically
Three branches triggered papers, with mean rewards: alpha 0.81, beta 0.81, gamma 0.74.

1. Highest mean: alpha and beta tie at 0.81.
2. A rule that picks "the first one found" depends on dictionary or completion order, which can vary between runs with parallel slots.
3. The lesson breaks ties alphabetically by branch id, so alpha wins every time.
4. Any fixed rule works; the point is that it is written down and tested, so two runs of the same demo produce the same paper.
:::

:::visual A deterministic picker
```python run
triggers = [{"branch": "beta", "mean": 0.81}, {"branch": "alpha", "mean": 0.81}, {"branch": "gamma", "mean": 0.74}]
def pick(ts): return sorted(ts, key=lambda t: (-t["mean"], t["branch"]))[0]["branch"]
import itertools
winners = {pick(list(order)) for order in itertools.permutations(triggers)}
print("winner for every input order:", winners)
naive = {max(order, key=lambda t: t["mean"])["branch"] for order in itertools.permutations(triggers)}
print("max() with no tie rule gives:", naive)
```
:::

:::read
With an explicit tie rule, all six input orders pick alpha. Python's `max()` with no tie rule returns whichever tied item comes first, so it picks alpha in some orders and beta in others. In a parallel system the input order is exactly what varies, so a picker without a tie rule makes the final paper depend on timing.
:::

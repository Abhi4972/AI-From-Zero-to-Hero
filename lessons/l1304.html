Why this came about

Enterprise agents on Azure combine Foundry with existing Azure services: Machine Learning, API Management as a model gateway, Monitor for observability, and Entra ID and Key Vault for security.

In plain words first
The rest of Azure around the agent

Around Foundry, Azure provides Azure Machine Learning for custom models, AI services for speech, vision and documents, API Management as a gateway for model calls, Azure Monitor and Application Insights for observability, and private networking and Key Vault for security. Production designs combine these layers.

import io, json, time, datetime
import httpx2, requests, urllib3
from azure.core.credentials import AccessToken, AccessTokenInfo
from azure.core.pipeline.transport import RequestsTransport

class Recorded(requests.adapters.BaseAdapter):
    """Lab mode: answer HTTP calls from recorded JSON instead of calling Azure (same helper as Lesson 13.3)."""
    def __init__(self, routes: dict):
        super().__init__()
        self.routes = routes
    def send(self, request, **kwargs):
        answer = next(a for (m, frag), a in self.routes.items() if m == request.method and frag in request.url)
        raw = urllib3.HTTPResponse(body=io.BytesIO(json.dumps(answer).encode()),
                                   headers={"Content-Type": "application/json"}, status=200, preload_content=False)
        return requests.adapters.HTTPAdapter().build_response(request, raw)
    def close(self): pass
    def azure(self):
        s = requests.Session(); s.mount("https://", self)
        return RequestsTransport(session=s, session_owner=False)

class OfflineCredential:
    def get_token(self, *scopes, **kw): return AccessToken("offline", int(time.time()) + 3600)
    def get_token_info(self, *scopes, **kw): return AccessTokenInfo("offline", int(time.time()) + 3600)

Document Intelligence prebuilt models (invoices, receipts, IDs, layout) return typed fields with confidence scores. Analysis is a long-running operation: the POST returns 202 with a URL to poll, and the SDK's poller handles it, so the lab helper records both steps:

from azure.ai.documentintelligence import DocumentIntelligenceClient
from azure.ai.documentintelligence.models import AnalyzeDocumentRequest

class RecordedLRO(Recorded):
    """Document analysis is a long-running operation: POST returns 202 and a URL to poll."""
    def send(self, request, **kwargs):
        if request.method == "POST":
            raw = urllib3.HTTPResponse(body=io.BytesIO(b""), status=202, preload_content=False, headers={
                "Operation-Location": "https://shopkart-docs.cognitiveservices.azure.com/documentintelligence/"
                                      "documentModels/prebuilt-invoice/analyzeResults/r-1?api-version=2024-11-30"})
            return requests.adapters.HTTPAdapter().build_response(request, raw)
        return super().send(request, **kwargs)

invoice_result = {"status": "succeeded", "createdDateTime": "2026-10-27T09:00:00Z", "lastUpdatedDateTime": "2026-10-27T09:00:03Z",
    "analyzeResult": {"apiVersion": "2024-11-30", "modelId": "prebuilt-invoice", "content": "...", "pages": [],
        "documents": [{"docType": "invoice", "confidence": 0.97, "spans": [], "fields": {
            "InvoiceId": {"type": "string", "valueString": "INV-88213", "content": "INV-88213", "confidence": 0.99},
            "PurchaseOrder": {"type": "string", "valueString": "A-1002", "content": "A-1002", "confidence": 0.95},
            "InvoiceTotal": {"type": "currency", "valueCurrency": {"amount": 7499.0, "currencyCode": "INR"}, "content": "₹7,499.00", "confidence": 0.98},
            "InvoiceDate": {"type": "date", "valueDate": "2026-10-19", "content": "19/10/2026", "confidence": 0.62}}}]}}
rec = RecordedLRO({("GET", "/analyzeResults/"): invoice_result})
docs = DocumentIntelligenceClient("https://shopkart-docs.cognitiveservices.azure.com", OfflineCredential(), transport=rec.azure())

poller = docs.begin_analyze_document("prebuilt-invoice",
                                     AnalyzeDocumentRequest(url_source="https://shopkart.example/uploads/A-1002.pdf"),
                                     polling_interval=0)
invoice = poller.result().documents[0]
for name, field in invoice.fields.items():
    value = field.value_currency.amount if field.type == "currency" else field.content
    flag = "  <- confirm with a person" if field.confidence < 0.8 else ""
    print(f"{name:14} {value!s:10} confidence {field.confidence:.2f}{flag}")

Typed values (value_currency, value_date) save the agent from parsing "₹7,499.00" itself, and the confidence decides which fields go to a person. Install with uv add azure-ai-documentintelligence. For mixed media or free-form extraction with your own schema, Content Understanding uses generative models behind a similar analyze-and-poll API.

Spans land in the AppDependencies table (with GenAI attributes in Properties) of the Log Analytics workspace behind Application Insights, where KQL (Kusto Query Language) answers operational questions:

from azure.monitor.query import LogsQueryClient

rec = Recorded({("POST", "/workspaces/"): {"tables": [{"name": "PrimaryResult", "columns": [
    {"name": "agent", "type": "string"}, {"name": "model", "type": "string"}, {"name": "calls", "type": "long"},
    {"name": "tokens_in", "type": "long"}, {"name": "p95_ms", "type": "real"}],
    "rows": [["shopkart-support", "gpt-6.1-sol", 4120, 1840233, 2310.5]]}]}})

KQL = """AppDependencies
| where Properties["gen_ai.operation.name"] == "chat"
| summarize calls = count(), tokens_in = sum(toint(Properties["gen_ai.usage.input_tokens"])), p95_ms = percentile(DurationMs, 95)
    by agent = tostring(Properties["gen_ai.agent.name"]), model = tostring(Properties["gen_ai.request.model"])
| order by tokens_in desc"""

logs = LogsQueryClient(OfflineCredential(), transport=rec.azure())
result = logs.query_workspace("00000000-0000-0000-0000-000000000000", KQL, timespan=datetime.timedelta(days=1))
for row in result.tables[0].rows:
    print(f"{row['agent']} on {row['model']}: {row['calls']} calls, {row['tokens_in']:,} tokens in, p95 {row['p95_ms']:.0f} ms")
What you should see
shopkart-support on gpt-6.1-sol: 4120 calls, 1,840,233 tokens in, p95 2310 ms

Save queries like this as Azure Monitor alert rules (for example, p95 above your latency budget, or daily tokens above forecast) and workbooks.

Azure API Management as the AI gateway

Azure API Management (APIM) is Azure's gateway for models, tools and agents (the pattern from Lesson 14.136). Import Foundry, Azure OpenAI, Bedrock or any OpenAI-compatible endpoint as an API, then add policies:

Policy or feature Job
llm-token-limit Tokens-per-minute limits and token quotas per subscription, app, user or any key
llm-emit-token-metric Token metrics to Azure Monitor with custom dimensions (team, app, tenant) for chargeback
llm-semantic-cache-lookup / llm-semantic-cache-store Semantic caching in Azure Managed Redis
llm-content-safety Content Safety checks on prompts at the gateway
Backends: load balancer and circuit breaker Round-robin, weighted, priority (PTU first, then pay-as-you-go) and session-aware routing; failover on 429s using Retry-After
Managed identity to backends No API keys in apps
MCP: expose REST APIs as MCP servers, or front existing MCP servers; import A2A agent APIs One governed door for tools and agents
AI gateway in Foundry Associate an APIM instance with a Foundry resource to set quotas for deployments, and register agents and MCP tools in the control plane 
<policies>
  <inbound>
    <base />
    <authentication-managed-identity resource="https://cognitiveservices.azure.com" />
    <llm-token-limit counter-key="@(context.Subscription.Id)" tokens-per-minute="20000"
                     estimate-prompt-tokens="true" remaining-tokens-header-name="x-remaining-tokens" />
    <llm-emit-token-metric namespace="shopkart-ai">
      <dimension name="app" value="@(context.Subscription.Name)" />
      <dimension name="model" value="@(context.Request.MatchedParameters.GetValueOrDefault("deployment-id", "unknown"))" />
    </llm-emit-token-metric>
    <set-backend-service backend-id="foundry-pool" />   <!-- a load-balanced pool: PTU first, then Global Standard -->
  </inbound>
</policies>

Industry practice
A reference architecture Azure teams converge on
  • Front door: Azure Front Door or Application Gateway with WAF, then APIM as the AI gateway for every model, MCP tool and agent call.
  • Agents: Foundry prompt agents for simple cases, hosted agents (Agent Framework or LangGraph) for complex ones; Data Zone or regional deployments where residency matters; model router for mixed traffic.
  • Knowledge: Foundry IQ knowledge bases over AI Search, SharePoint and OneLake, with user-token security trimming.
  • State and workflows: Cosmos DB for state and memory, Durable Functions or Foundry workflows for long processes with approvals.
  • Ops: Application Insights tracing, continuous evaluation and scheduled red-team scans, KQL alerts, APIM token metrics for chargeback, Control Plane for the fleet view.
  • Security: private endpoints everywhere, no keys (managed identity and Entra Agent ID), Defender for Cloud AI protectionlater · 15.30, Purview DSPM for AI, Azure Policy to enforce it all.
In production
Observability gaps on Azure

Application Insights can sample telemetry, and sampled-out traces are exactly the ones you need after a complaint; configure sampling so errors and flagged runs are always kept. Trace content capture is off by default, so turn it on deliberately per environment with redaction. And put APIM token metrics and Foundry evaluation results on the same dashboard, or cost and quality get discussed in separate meetings.

Solutions

SolutionP1 · Composing Azure services

Azure AI Document Intelligence for parsing, Azure AI Search for hybrid retrieval, Foundry model deployments for generation, Azure AI Content Safety for filtering.

SolutionB1 · Shared keys

No per-app attribution, no fine-grained revocation, and leaked keys expose everything. Use Entra ID with managed identities and a gateway with per-app policies.

SolutionD1 · Gateway attribution

Put an API gateway (API Management with AI policies) in front, with per-team subscriptions, token metering and limits, and tag resources.

SolutionM1 · Controls by layer

Private endpoints, Entra ID and managed identities, Key Vault, Purview for data governance, Content Safety and prompt shields, Defender for Cloud, and logging to Monitor.

Explain the mechanismHow do Azure's ML, AI services and gateways support production agents?

Worked answer. Azure Machine Learning for custom models, AI services for vision, speech and documents, Foundry for models and agents, API Management as an AI gateway with token limits and load balancing, and security through Entra ID, private networking and Defender.

Why this came about

Matrices were developed in the 1800s to solve many equations at once, and they became the workhorse of computing because one matrix multiplication does a huge number of multiply-and-add operations in a single, highly optimized step. Graphics cards (GPUslater · 3.20) were built to multiply matrices fast for video games; in 2012 researchers realized the same hardware could train neural networks, whose every layer is a matrix multiplication. Today, "how many matrix multiplications per second" is the measure of AI hardware, and almost every line of model code you will read moves data through matrices.

In plain words first
A recipe card for a whole kitchen

A matrix is a table of numbers. Think of a café's recipe table: one column per drink (tea, coffee), one row per ingredient (milk, sugar, water), each cell saying how much of that ingredient one drink needs. Multiply that table by today's orders (4 teas, 2 coffees) and you get, in one step, how much milk, sugar and water to buy. That is all matrix-times-vector is: many dot products done together. The same operation, seen as geometry, moves every point of space at once, which is what a neural network layer does to its inputs.

Step 1 · A matrix is a table of numbers

A matrix is a table of numbers with rows and columns: several vectors stacked together. The table below holds two drink recipes. Each row is an ingredient and each column is a drink, so one number answers a question such as "how much milk does one coffee need?". Build it and read a few entries:

import numpy as np

# rows: milk (ml), sugar (g), water (ml); columns: one tea, one coffee
recipes = np.array([[ 50,  80],
                    [ 10,   5],
                    [150, 120]])
print(recipes.shape)            # (rows, columns) = (3 ingredients, 2 drinks)
print(recipes[0, 1])            # milk for one coffee
print(recipes[:, 0])            # column 0: everything one tea needs
What you should see
(3, 2)
80
[ 50  10 150]

A matrix with m rows and n columns has shape m × n, read "m by n". You already met it as a 2-D NumPy array in Lesson 0.21; the new part is what multiplying by it means.

Step 2 · Matrix times vector: two ways to see the same thing

Today's orders are a vector: 4 teas and 2 coffees.

orders = np.array([4, 2])

# view 1: each ingredient total is the dot product of that ingredient's row with the orders
print([int(recipes[i] @ orders) for i in range(3)])

# view 2: the result is a mix of the columns, weighted by the orders
print(4 * recipes[:, 0] + 2 * recipes[:, 1])

# NumPy does it in one operation
print(recipes @ orders)
What you should see
[360, 50, 840]
[360  50 840]
[360  50 840]

All three print the same shopping list: 360 ml milk, 50 g sugar, 840 ml water. Both views are worth keeping:

  • Rows view: each output number is a dot product of one row with the input vector. This is how a neural network computes each of its outputs (Lesson 3.15).
  • Columns view: the output is a weighted mix of the matrix's columns, with the input numbers as the weights. This is the geometric view in Step 3.

The shapes follow one rule: a (3, 2) matrix times a vector of length 2 gives a vector of length 3. The matrix's column count must equal the vector's length.

Step 3 · A matrix transforms space

Take a 2 × 2 matrix and multiply it by every point of a flat plane. Each point moves somewhere new. The columns tell you exactly where: column 1 is where the point [1, 0] lands, column 2 is where [0, 1] lands, and every other point follows along, because it is a mix of those two.

Try the presets, then make your own:

Matrix What happens
identity [[1, 0], [0, 1]] Nothing moves
stretch [[2, 0], [0, 0.5]] Twice as wide, half as tall
rotate 90° [[0, -1], [1, 0]] Everything turns a quarter turn anticlockwise
shear [[1, 1], [0, 1]] The square leans over like a pushed stack of cards
mirror [[-1, 0], [0, 1]] Flipped left to right; the determinant becomes negative
squash [[1, 2], [0.5, 1]] The whole plane collapses onto a line; the determinant is 0

The determinant in the figure is the factor by which areas grow or shrink. When it is 0, the matrix squashes a dimension flat and information is lost: you can no longer tell where a point came from. Keep the squash in mind; Lesson 3.18 shows that networks can suffer a version of it.

rotate = np.array([[0, -1],
                   [1,  0]])
print(rotate @ np.array([1, 0]), rotate @ np.array([0, 1]), rotate @ np.array([2, 1]))
squash = np.array([[1, 2], [0.5, 1]])
print(np.linalg.det(rotate).round(3), np.linalg.det(squash).round(3))
What you should see
[0 1] [-1  0] [-1  2]
1.0 0.0

Step 4 · Matrix times matrix

Multiplying two matrices means doing the matrix-vector product for every column of the second matrix. If the columns of the second matrix are several days of orders, you get the shopping list for each day in one operation:

week = np.array([[4, 6, 3],          # teas on Mon, Tue, Wed
                 [2, 1, 5]])         # coffees on Mon, Tue, Wed
print(week.shape, "->", (recipes @ week).shape)
print(recipes @ week)
What you should see
(2, 3) -> (3, 3)
[[ 360  380  550]
 [  50   65   55]
 [ 840 1020 1050]]

The shape rule, which you will use constantly: (m × n) @ (n × p) gives (m × p). The inner sizes must match, and they disappear. Here (3 × 2) @ (2 × 3) gives (3 × 3): 3 ingredients for each of 3 days.

Two consequences that surprise people:

A = np.array([[1, 2], [0, 1]])
B = np.array([[0, 1], [1, 0]])
print(A @ B)
print(B @ A)                          # the order matters: A @ B is usually not B @ A
try:
    recipes @ recipes                 # (3 x 2) @ (3 x 2): inner sizes 2 and 3 do not match
except ValueError as e:
    print("ValueError:", e)
What you should see
[[2 1]
 [1 0]]
[[0 1]
 [1 2]]
ValueError: matmul: Input operand 1 has a mismatch in its core dimension 0, with gufunc signature (n?,k),(k,m?)->(n?,m?) (size 3 is different from 2)

NumPy's error message is terse, but its last part says exactly what is wrong: a size 3 where a size 2 was needed. Doing A then B to a vector is the single matrix B @ A: matrices compose. That is why stacking layers in a network is powerful, and also why you need something between them (an activation functionlater · 3.15, Lesson 3.15): without it, any stack of matrices collapses into just one matrix.

Step 5 · A neural network layer is a matrix multiplication

Here is the preview that makes this lesson matter. A layer of a neural network takes, say, 3 input numbers and produces 2 output numbers. It holds a weight matrix W of shape (2, 3) and a bias vector b of length 2, and computes W @ x + b.

W = np.array([[ 0.5, -1.0,  0.2],     # weights for output 0
              [ 0.1,  0.3, -0.4]])    # weights for output 1
b = np.array([0.1, -0.2])
x = np.array([1.0, 2.0, 3.0])         # one input with 3 features
print(W @ x + b)

X = np.array([[1.0, 2.0, 3.0],        # a batch: 4 inputs at once, one per row, shape (4, 3)
              [0.0, 1.0, 0.0],
              [2.0, 0.0, 1.0],
              [1.0, 1.0, 1.0]])
print((X @ W.T + b).round(2))         # shape (4, 3) @ (3, 2) -> (4, 2): 2 outputs for each of 4 inputs
What you should see
[-0.8 -0.7]
[[-0.8 -0.7]
 [-0.9  0.1]
 [ 1.3 -0.4]
 [-0.2 -0.2]]
Reading this output
  • The first line is the layer's 2 outputs for one input: each is a dot product of a row of W with x, plus that output's bias.
  • The second block processes a batch of 4 inputs at once. Inputs are stored as rows, so the code uses W.T, the transpose of W (rows and columns swapped, shape (3, 2)), so that the shapes line up: (4, 3) @ (3, 2) → (4, 2). The bias of shape (2,) is broadcast to every row.
  • The first row of the batch result equals the single-input result: same input, same layer.

A model such as GPT-2 is mostly this, repeated: matrices of learned numbers, multiplied with inputs, layer after layer. The learned numbers are the parameters; GPT-2 small has about 124 million of them, and most live in matrices like W. the Neural networks and deep learning section shows how they are learned.

The same idea as a formula

For a matrix A of shape m × n and a vector x of length n: (Ax)ᵢ = Aᵢ₁x₁ + Aᵢ₂x₂ + … + Aᵢₙxₙ, for i = 1 … m. For matrices A (m × n) and B (n × p): (AB)ᵢⱼ = Σₖ Aᵢₖ Bₖⱼ, the dot product of row i of A with column j of B.

Check your mental model
  • ✗ "Matrix multiplication multiplies matching cells."
    ✓ That is element-wise *. Matrix multiplication @ takes dot products of rows with columns.
  • ✗ "A @ B and B @ A are the same."
    ✓ Usually not, and often one of them is not even allowed by the shapes.
  • ✗ "Stacking more matrices makes a model more powerful on its own."
    ✓ Without a non-linear step between them, a stack of matrices is equivalent to a single matrix.

Exercises

Predict before you run

What is the shape of (5, 4) @ (4, 7)? Of (8, 768) @ (768, 50257)? Is (3, 2) @ (3, 2) allowed? (Solution P1.)

Make it your own

Add a third drink to the café: hot chocolate, needing 200 ml milk, 20 g sugar and 0 ml water. Extend recipes to shape (3, 3), give Monday 2 hot chocolates, and recompute the shopping list. (Solution M1.)

Debugging exercise

A colleague writes X @ W + b with X of shape (4, 3) and W of shape (2, 3) and gets a shape error. Explain the error and give two ways to fix it. (Solution D1.)

Solutions

SolutionP1 · Shapes

(5, 4) @ (4, 7) → (5, 7). (8, 768) @ (768, 50257) → (8, 50257): that is a language model's last step, turning 8 tokens' vectors of 768 numbers into a score for every one of GPT-2's 50,257 vocabulary pieces. (3, 2) @ (3, 2) is not allowed: the inner sizes are 2 and 3.

SolutionM1 · A third drink
recipes3 = np.array([[ 50,  80, 200],
                     [ 10,   5,  20],
                     [150, 120,   0]])
print(recipes3 @ np.array([4, 2, 2]))      # [760  90 840]

The new column adds 2 × [200, 20, 0] = [400, 40, 0] to Monday's list.

SolutionD1 · The inner sizes do not match

(4, 3) @ (2, 3): the inner sizes are 3 and 2. The layer stores one row per output, so with inputs as rows you need its transpose: X @ W.T + b, shape (4, 3) @ (3, 2) → (4, 2). Alternatively store the weights the other way round from the start, shape (3, 2); PyTorchlater · 3.17's nn.Linear stores (outputs, inputs) and applies the transpose for you (Lesson 3.17).

Recap
  • A matrix is a table of numbers with shape rows × columns.
  • Matrix times vector: each output is a row's dot product with the input; equivalently, a weighted mix of the columns.
  • Geometrically, a matrix moves every point of space; its columns are where the basic directions land; the determinant is the area factor, and 0 means information is lost.
  • (m × n) @ (n × p) → (m × p); order matters; matrices compose.
  • A neural network layer computes W @ x + b; batches are rows, so code often uses the transpose.

Check your understanding

Q1A layer has weights of shape (2, 3). How many input numbers does it take, and how many does it produce?

W @ x needs x of length 3 (the column count) and gives 2 outputs (the row count).

Q2Which describes the second column of a 2 × 2 matrix, seen as a transformation?

Column 1 is where [1, 0] lands, column 2 where [0, 1] lands.

Q3A matrix has determinant 0. What does that mean?

Zero area factor: some direction collapses entirely.

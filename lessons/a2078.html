The problem

In plain words first

A decompiler turns machine code back into readable source. Commercial tools do it for whole programs; this project does it for a handful of small C functions compiled to x86-64, entirely from scratch in Python, and then proves its output is right.

It is the deepest build in the course and follows phase 13's reverse-engineering lessons step by step: read the ELF object and its relocations; decode the instructions the fixtures use; recover control flow, including a jump table; lift to an intermediate form and SSA; simplify compiler idioms (such as division by a constant done with multiplication); recover the function signature and types; structure the graph into if, while and switch; and finally recompile the emitted C and check it matches the original byte for byte, with relocations masked.

A decompiler for a defined x86-64 subset. It reads an ELF relocatable object that you compiled, turns each function into structured C, and then proves the output: it recompiles the C, compares relocation-masked bytes, runs the original and the decompiled version side by side over an input grid, and writes an evidence report that lists every unknown.

The core uses the Python standard library only. clang is optional: it enables the recompile and differential legs of stage 8. The grader checks your selected workspace; it never fills in missing behavior from the reference.

Analyze only programs that you compiled from source. The fixtures are small C functions written for this project.

What you will build: A decompiler that turns the functions of an x86-64 relocatable object you compiled into one C file, and an evidence report that says what was proved and what stays unknown.

Where it stops: Run python3 -m minidec verify on your own object and its source. The command writes decompiled.c, recompiled.o and report.json; a CI job can fail on status fail or unknown.

Step 1 · Read an ELF relocatable object

Step 1 of 8 · about 2 hours · Python

Validate the ELF64 header, read section headers, the symbol table and every RELA record, and cut each function out of .text with its relocations and its alignment padding. A PC-relative record points at S + A + (end of instruction - P), so a target is resolved only with the end of the instruction that holds the field.

Read the project prerequisites first. This stage applies Program Anatomy: An ELF Reader From Scratch and the relocation part of Disassembly and Control Flow.

What you build. You build the loader that every later stage reads from. It accepts the bytes of one ELF64 little-endian x86-64 relocatable object (ET_REL), and it gives back:

  • the section headers, each with its name and its bytes,
  • the symbol table, with name, value, size, type, binding and section name,
  • every RELA record, grouped by the section it patches and sorted by offset,
  • one function at a time: its bytes, the relocations inside it, and the alignment padding after it.

It also resolves a relocation to the place it points at after linking.

Why it matters. A relocatable object is the output of clang -c. The link editor has not run yet, so every address that refers to another section is a field of zero bytes plus a RELA record. The jump table of band, the lookup table at -O1, and every call to another function are visible only through those records. If the loader drops them, stage 3 cannot find the jump table, stage 7 cannot name the lookup table, and stage 8 compares bytes that the link editor will overwrite.

A function symbol gives the start and the size. The bytes between the end of one function and the start of the next are alignment padding. Stage 3 decodes the padding with a linear sweep to show where the sweep and the recursive descent disagree, so the loader reports it separately.

Work through one concrete case. Build the fixture yourself, or use the committed objects. The objects were built with:

clang -target x86_64-unknown-linux-gnu -O1 -fno-asynchronous-unwind-tables -c samples.c -o samples-x86_64-O1.o

The header of samples-x86_64-O1.o starts with 7f 45 4c 46 02 01: the magic, ELFCLASS64 (2) and little-endian (1). At offset 16, e_type is 1 (ET_REL) and e_machine is 62 (EM_X86_64). The section header table is at e_shoff, each entry is 64 bytes, and the first five section names are the empty null section, .strtab, .text, .rela.text and .rodata. .text is 0xb2 bytes long.

The five function symbols, in address order, with their sizes:

name value size next start padding
tenths_and_fifths 0x0 0x23 0x30 13
thirds 0x30 0x1a 0x50 6
band 0x50 0x17 0x70 9
fold 0x70 0x26 0xa0 10
record 0xa0 0x12 0xb2 0

band holds one relocation. The record in .rela.text has r_offset 0x5f, type 2 (R_X86_64_PC32), the .rodata section symbol, and addend -4. Inside the function the offset is 0x5f - 0x50 = 0xf.

The field belongs to leaq (%rip), %rcx, which starts at 0x5c and ends at 0x63. The psABI says the link editor stores S + A - P in a PC-relative field, where S is the symbol value, A is the addend and P is the field address. The processor adds the field to the address of the next instruction. So the operand reaches:

S + A - P + end = 0 + (-4) - 0x5f + 0x63 = 0

The table starts at .rodata+0x0. Its first eight bytes are 05 00 00 00 08 00 00 00: the values 5 and 8 of the switch in band.

At -O0, .rodata itself has six relocations, one per jump table entry. Each is a PC-relative record against .text whose target, resolved with the table base as the end, is 0x78, 0x81, 0x8a, 0x93, 0x9c and 0xa5. These are the six case blocks of band.

Change the addend, the field offset and the instruction length in the lab. The target moves by the same amount as the distance from the field to the end of the instruction, which is why relocation_target refuses a PC-relative record without that end.

Implement the contract. Implement these in the elf module. The starter keeps the dataclasses, the constants, _cstring, _slice, section, has_section, functions, relocation_at and symbolize.

function contract

  • Bytes that start with MZ, or only the four magic bytes, raise ElfError.

  • relocation_at(".text", 0x60) returns None, because 0x60 is inside the field but is not its start.

Step 2 · Decode the x86-64 subset

Step 2 of 8 · about 3 hours · Python

Decode legacy prefixes, REX, one and two byte opcodes, ModRM, SIB, displacements and immediates for the instructions the fixtures use. Record where the displacement and immediate fields sit so relocations can be matched to operands. Every instruction must agree with the captured disassembler listing by address, bytes and AT&T text.

This stage applies Disassembly and Control Flow, sections "The Instruction Format Has One Rule Per Field" and "Linear Sweep".

What you build. You build a decoder for the part of x86-64 that clang emits for the fixtures at -O0 and -O1. decode(code, address) reads one instruction and returns an Instruction with its bytes, a normalized operation, its operands, its operand width, its control-flow kind and its branch target. It also records where the displacement field and the immediate field sit inside the instruction. linear_sweep decodes a byte range in address order and lists every byte that it cannot decode.

The decoder is checked against a disassembler listing. For every instruction of the four committed objects, your address, your bytes and your AT&T text must equal the captured listing.

Why it matters. Every later stage trusts the decoder. A wrong operand width changes a 32-bit value into a 64-bit value, and the recompiled C then differs from the original. A wrong field offset makes stage 3 miss the relocation on the lea that holds the jump table base.

The listing gives you an oracle with no judgment in it. You do not decide that your decode looks right. You compare it.

The subset.

group encodings
prefixes 66, 67, f2, f3, f0, segment overrides 2e 36 3e 26 64 65, then one REX byte 40 to 4f
ALU 01 09 11 19 21 29 31 39 85 89 (Ev, Gv), 03 0b 13 1b 23 2b 33 3b 8b (Gv, Ev), accumulator forms, groups 81 83
data 88 8a, 8d lea, b8+r mov, c7 /0, 63 movslq, 0f b6 b7 be bf movzx and movsx
arithmetic 69 6b 0f af imul, c1 d1 shifts, f7 test, not, neg, mul, imul, div, idiv, 99 cltd, ff /0 /1
control 70-7f, 0f 80-8f, e8, e9, eb, ff /2 /4, c3, 0f 90-9f setcc, 0f 40-4f cmovcc
other 90, 0f 1f multi-byte nop, cc, 0f 0b, 50-5f push and pop

Anything else raises DecodeError with the address and the opcode bytes.

Work through one concrete case. At address 0x3 of tenths_and_fifths at -O1, the bytes are 48 69 c0 67 66 66 66.

offset byte field meaning
0 48 REX W=1, so the operand size is 64 bits
1 69 opcode imul Gv, Ev, Iz: three operands, 32-bit immediate
2 c0 ModRM mod=3 (register form), reg=0 (rax), rm=0 (rax)
3 to 6 67 66 66 66 immediate 0x66666667, sign-extended to 64 bits

The result is imulq $0x66666667, %rax, %rax, length 7, width 64, immediate_offset 3. Remove the 48 and the same bytes decode as imull with a 32-bit operand size. The two forms compute different values, and stage 5 recognizes the division idiom only in the 64-bit product.

A memory operand at -O0: 48 63 04 81 at 0x6f is movslq (%rcx,%rax,4), %rax. ModRM 04 has mod=0 and rm=4, so a SIB byte follows. SIB 81 has scale 1 << 2 = 4, index 0 (rax) and base 1 (rcx).

A RIP-relative operand: 48 8d 0d 00 00 00 00 at 0x5c is leaq (%rip), %rcx. ModRM 0d has mod=0 and rm=5, which in 64-bit mode means RIP plus a 32-bit displacement. The displacement field starts at offset 3, so its absolute address is 0x5f. That is the r_offset of the relocation from stage 1.

A branch: 77 0c at 0x58 is ja with an 8-bit displacement of 12. The target is the end of the instruction plus 12: 0x5a + 0xc = 0x66.

Type other bytes into the lab, for example 48 63 04 81 or 66 0f 1f 44 00 00, and read the field table before you write the decoder branch for them.

Implement the contract. Implement these in the decoder module. Follow control flow by recursive descent, resolve the position-independent jump table from its relocations and bounds check, split basic blocks, then compute dominators, dominance frontiers, post-dominators, back edges and natural loops. An indirect jump with no matching idiom stays unresolved and is reported.

This stage applies Disassembly and Control Flow, sections "Recursive Descent", "Basic Blocks", "Dominators With the Iterative Algorithm" and "The Jump Table in grade at -O0", and Compiler Idioms and Optimization for the bounds-check idiom.

What you build. You build the control-flow graph of one function:

  1. recursive_descent decodes only the bytes that control flow reaches from the entry.
  2. A jump table resolver turns jmpq *%rax into a list of targets, with the table found through its relocation and its length taken from the bounds check.
  3. ControlFlowGraph splits the instructions into basic blocks with typed edges: jump, taken, fallthrough and table.
  4. The graph computes reverse postorder, immediate dominators, dominance frontiers, post-dominators, back edges and natural loops.

Why it matters. A linear sweep decodes alignment padding as if it were code. Recursive descent decodes only what can run, but it stops at an indirect jump unless something tells it where the jump goes. For the fixtures that something is the relocation on the lea that loads the table base and the relocations inside the table.

Dominators are the input of everything after this stage. SSA places phis on dominance frontiers (stage 4). A back edge is an edge to a block that dominates its source, and every loop that stage 7 emits starts from one. The immediate post-dominator of a branch is the place where its two arms join again, and stage 7 uses it to close an if.

Work through one concrete case. band at -O0 occupies 0x50 to 0xba, with 6 bytes of padding up to 0xc0.

Without a resolver, recursive descent from 0x50 decodes 16 instructions. It follows the ja at 0x62 to the default block at 0xae, falls through to 0x64, and stops at jmpq *%rax at 0x76. That jump is listed in unresolved, and the six case blocks are never reached.

The resolver walks back from the jump:

0x5e subq $0x5, %rax bounds check against 5
0x62 ja 0xae out of range goes to default

Entry i is at .rodata+4i, so its target is addend + (table base - entry offset): 0x78, 0x81, 0x8a, 0x93, 0x9c and 0xa5. With the resolver the descent decodes 28 instructions, and the linear sweep of the same range decodes 29 because it also decodes the nopw padding.

The graph has 10 blocks and 15 edges, six of them table edges. The immediate dominator of every case block is 0x64, the block that holds the jump. Step 4 · Lift to IR and build SSA

Step 4 of 8 · about 3 hours · Python

Lift each instruction to a small IR in which flags are an ordinary variable, frame bookkeeping disappears and frame-pointer slots become locals. Place phi statements on iterated dominance frontiers and rename over the dominator tree so every value has one definition, with explicit casts where a narrow definition meets a wide use.

This stage applies Lifting to Pseudocode, sections "Stage 3: Lifting to a Small IR" and "Stage 5: SSA, One Name per Definition", and Calling Conventions and Stack Frames for the frame-pointer prologue.

What you build. You build two things.

The lifter turns each decoded instruction into IR statements. The IR has assignments, stores, branches, jumps, a switch through a recovered table and returns. Its expressions are constants, variables with a width, binary operations, casts, loads, flag records and section addresses. Registers become variables named by their 64-bit family (eax writes rax at width 32). The flags register is an ordinary variable named flags. Frame bookkeeping (push, pop, mov %rsp, %rbp, stack adjustments) produces no statements, and a slot at a constant offset from %rbp becomes a local variable such as local_8.

The SSA builder gives every definition its own version. It places phi statements on the iterated dominance frontier of each variable's definition sites, renames uses over the dominator tree, and inserts a cast where a use has a different width than the definition it reads.

Why it matters. x86-64 instructions do several things at once. subl %edi, %esi writes %esi and six flags. A later jle reads two of those flags. If the lifter writes the flags as a variable, stage 5 can see that jle after testl %esi, %esi means esi <= 0, and dead code removal can delete every flag write that no branch reads.

SSA makes every later question local. "Which value does this use read?" has one answer, the single definition with that version. A value that arrives from two paths is a phi, and the phi lists which predecessor provides which version.

Work through one concrete case. fold at -O1 has five blocks. Before SSA, the lifted loop block 0x80 reads:

block 0x80 -> 0x80, 0x92
  eax = eax << 5
  flags = cmp(eax, esi)
  eax = eax - esi
  flags = add(eax, load32(rdi + rdx * 4))
  eax = eax + load32(rdi + rdx * 4)
  flags = inc(rdx, 1)
  rdx = rdx + 1
  esi = eax
  flags = cmp(rcx, rdx)
  if jne(flags) goto 0x80 else goto 0x92

The variables defined inside the loop are eax, rdx, esi and flags. The loop header 0x80 is in its own dominance frontier, because the back edge comes from 0x80 itself. So insert_phis places four phis at 0x80, one per variable. ecx is defined only in 0x74, whose frontier is empty, so it gets no phi.

Renaming walks the dominator tree 0x70, 0x74, 0x80, then 0x92 and 0x93:

block 0x74 -> 0x80
  ecx_1 = esi_0
  edx_1 = 0
  esi_1 = 0
  eax_1 = esi_1
block 0x80 -> 0x80, 0x92
  esi_2 = phi(0x74: esi_1, 0x80: esi_3)
  rdx_2 = phi(0x74: edx_1, 0x80: rdx_3)
  eax_2 = phi(0x74: eax_1, 0x80: eax_5)
  flags_2 = phi(0x74: flags_1, 0x80: flags_6)
  ...
  flags_6 = cmp(zext64(ecx_1), rdx_3)

Version 0 is the value at function entry: esi_0 is the second argument and rdi_0 the first. Two width facts appear here. ecx_1 is a 32-bit definition and cmp(rcx, rdx) reads 64 bits, so the use becomes zext64(ecx_1); writing a 32-bit register clears the upper half. The rdx phi has a 32-bit source (edx_1 = 0) and a 64-bit source (rdx_3), so the phi is widened to 64 bits.

At -O0 the same loop keeps its values in stack slots. movl %edi, -0x8(%rbp) lifts to local_8 = rdi, and the loop header 0xd9 gets phis for local_10 and local_14.

The division idiom is the case where a wrong fold is easy to write. A multiplier that is close to the right one gives the correct quotient for small inputs and a wrong one for large inputs. The fold is allowed only when the arithmetic proves it.

Work through one concrete case. At -O1, clang compiled value / 10 + value / 5 as:

movslq  %edi, %rax
imulq   $0x66666667, %rax, %rax
movq    %rax, %rcx
sarq    $0x22, %rcx        shift 34
movq    %rax, %rdx
shrq    $0x3f, %rdx        sign bit of the product
addl    %edx, %ecx         quotient for 10
sarq    $0x21, %rax        shift 33
addl    %edx, %eax         quotient for 5
addl    %ecx, %eax

The form is ((long)x * m >> s) + sign bit. To recover the divisor, magic_divisor(m, s) tries d = floor(2^s / m) and d + 1, and keeps the d for which m is the ceiling of 2^s / d and the error stays small (Granlund and Montgomery, 1994):

m s d m * d - 2^s bound 2^s / 2^31 fold
0x66666667 34 10 6 8 yes
0x66666667 33 5 3 4 yes
0x55555556 32 3 2 2 yes
0x66666668 34 none no

Check one input by hand. For x = -7 and d = 10, the product is -7 * 1717986919 = -12025908433. Shifting right by 34 rounds toward minus infinity and gives -1. The sign bit of the product is 1. The sum is 0, which equals the C result of -7 / 10. division_identity_holds repeats this check on a sample that includes INT_MIN, INT_MAX and the values from -40 to 40 before the pass folds.

After SSA the two shared values are rax_2 = rax_1 * 0x66666667 and rdx_2 = rax_2 >>u 63. The simplifier finds trunc32(rcx_2) + trunc32(rdx_2) where rcx_2 = rax_2 >>s 34, follows both sides to the same product, and replaces the sum with edi_0 / 10. Dead code removal then deletes the product, the shifts and every flag write, because nothing reads them. The function ends as one statement:

return edi_0 / 10 + edi_0 / 5

thirds uses shrq $0x20 for the quotient. The result is truncated to 32 bits, and for a shift of exactly 32 the low 32 bits of a logical shift equal those of an arithmetic shift. So the pass accepts a logical shift only when the shift is 32.

For fold, the loop condition flags_6 = cmp(zext64(ecx_1), rdx_3) with jne becomes zext64(esi_0) != rdx_3 after copy propagation replaces ecx_1 with esi_0. Two of the four loop phis carry the same value on every edge (eax_2 and esi_2), so one is merged into the other and two phis remain.

Set the divisor to 10 and the shift to 33 in the lab. The multiplier is 0x33333334 and the error is 8, which is twice the bound of 4, so the pass must leave the multiply in the output.

Step 6 · Recover the signature and types

Step 6 of 8 · about 2 hours · Python

A System V argument register read before any write is a parameter, and the highest one fixes the count. Coalesce phi webs into C variables, make a scaled element access a pointer to its element and constant offsets a struct, and choose signedness from the instructions that touch each value. Every choice carries its instruction evidence.

This stage applies Calling Conventions and Stack Frames, section "System V: Two Independent Register Sequences and a Red Zone", Lifting to Pseudocode, sections "Stage 4: Parameters From the Calling Convention" and "Stage 7: Types From Use", and Recovering Data and Types.

What you build. You build signature recovery for the optimized SSA function:

  1. Parameters. The System V psABI passes the first six INTEGER arguments in %rdi, %rsi, %rdx, %rcx, %r8 and %r9. A register read at version 0 is read before any write. The highest such argument register fixes the count, so a function that reads only %rsi still has two parameters. A read of another register before any write is an undefined read. The recovery reports it and does not make it a parameter.
  2. Webs. A phi and its sources are one C variable. Union-find joins them, and each web gets one name: param_N for an argument, local_8 for a stack slot, eax_1 for a register value.
  3. Types. The widest definition in a web gives int or long. A web used as the base of a scaled element access becomes a pointer to the element. A web used as the base of constant offsets becomes a pointer to a struct with one field per offset. Pointer types spread along copies and phis.
  4. Signedness. Arithmetic shifts, signed division, signed compares and sign extension say signed. Logical shifts and unsigned division say unsigned. A lone unsigned compare is the range-check idiom of a switch, and it does not make the value unsigned.
  5. Return type. The width of the value in %rax at each return. If no path writes %rax, the result is void, and that guess is listed as an unknown.

Every decision carries the instructions that support it.

Why it matters. The machine code has no types. A wrong parameter count changes the call in the stage 8 driver. A wrong width truncates a long. A wrong signedness flips the result of a compare for negative inputs. Each of these produces C that compiles and computes the wrong answer, so each type has to point at its evidence.

The structurer walks the graph from the entry and matches shapes, after the method of Cifuentes:

  • A loop header (a block that a back edge targets) becomes while (cond) { ... } when the header holds the exit branch, and do { ... } while (cond); otherwise. The condition of a do loop comes from the latch, the block whose branch returns to the header.

def recursive_descent(code: bytes, entries: list[int], end: int | None = None, resolver: Resolver | None = None) -> Descent:
    end = len(code) if end is None else end
    if any(entry < 0 or entry >= end for entry in entries):
        raise ValueError(f"entry outside the code range 0..0x{end:x}: {[hex(e) for e in entries]}")
    instructions: dict[int, Instruction] = {}
    order: list[int] = []
    unresolved: list[Instruction] = []
    conflicts: list[tuple[int, int]] = []
    calls: list[tuple[int, int | None]] = []
    tables: dict[int, JumpTable] = {}
    worklist = list(reversed(entries))
    while worklist:
        address = worklist.pop()
        while 0 <= address < end and address not in instructions:
            inside = next((i for i in instructions.values() if i.covers(address)), None)
            if inside is not None:
                conflicts.append((address, inside.address))
                break
            try:
                instruction = decode(code[:end], address)
            except DecodeError:
                unresolved.append(Instruction(address, code[address : address + 1], "(undecodable)", (), 0, flow="stop"))
                break
            instructions[address] = instruction
            order.append(address)
            if instruction.flow == "return":
                break
            if instruction.flow == "jump":
                address = instruction.target if instruction.target is not None else end
                continue
            if instruction.flow == "branch":
                worklist.append(instruction.target if instruction.target is not None else end)
                address = instruction.end
                continue
            if instruction.flow == "call":
                calls.append((instruction.address, instruction.target))
                address = instruction.end
                continue
            if instruction.flow == "indirect-jump":
                table = resolver(instruction, instructions) if resolver else None
                if table is None:
                    unresolved.append(instruction)
                    break
                tables[instruction.address] = table
                worklist.extend(sorted(set(table.targets), reverse=True))
                break
            if instruction.flow == "indirect-call":
                calls.append((instruction.address, None))
            address = instruction.end
    return Descent(instructions, order, unresolved, conflicts, calls, tables)

        if candidate.op == "lea" and candidate.memory is not None and candidate.memory.rip and _register_name(candidate.operands[1]) == memory.base:
            lea = candidate
            break
        if _writes(candidate) == _family(memory.base):
            return None
    if lea is None or lea.displacement_offset is None:
        return None
    relocation = elf.relocation_at(section, lea.address + lea.displacement_offset)
    if relocation is None:
        return None
    table_at = relocation_target(relocation, lea.end)
    if not elf.has_section(table_at.section):
        return None
    limit, bounds_address = bounds_check(instructions, load.address)
    if limit is None:
        return None
    count = limit + 1
    entry_size = memory.scale
    table_data = elf.section(table_at.section).data
    entries: list[int] = []
    evidence = "bytes"
    for index in range(count):
        entry_offset = table_at.offset + index * entry_size
        entry_relocation = elf.relocation_at(table_at.section, entry_offset)
        if entry_relocation is not None and entry_relocation.pc_relative:
            entries.append(symbol_base(entry_relocation.symbol) + entry_relocation.addend + (table_at.offset - entry_offset))
            evidence = "relocation"
            continue
        raw = table_data[entry_offset : entry_offset + entry_size]
        if len(raw) < entry_size:
            return None
        value = int.from_bytes(raw, "little", signed=jump is not None)
        entries.append(table_at.offset + value if jump is not None else value)
    return JumpTable(table_at.section, table_at.offset, entry_size, count, tuple(entries), evidence, bounds_address, lea.address, load.address, None if jump is None else jump.address, _family(memory.index))


def jump_table_resolver(elf: ElfObject, section: str = ".text") -> Resolver:

    def resolve(jump: Instruction, decoded: dict[int, Instruction]) -> JumpTable | None:
        register = _register_name(jump.operands[0]) if jump.operands else None
        if register is None:
            return None
        instructions = [decoded[a] for a in sorted(decoded) if a < jump.address]
        add = next((i for i in reversed(instructions) if i.op == "add" and _register_name(i.operands[1]) == register), None)
        if add is None:
            return None
        base = _register_name(add.operands[0])
        load = next(
            (i for i in reversed(instructions) if i.address < add.address and i.op == "movsxd" and _register_name(i.operands[1]) == register and i.memory is not None and i.memory.base == base),
            None,
        )
        if load is None:
            return None
        return recover_table(elf, instructions, load, jump, section)

    return resolve


def find_value_tables(elf: ElfObject, instructions: list[Instruction], section: str = ".text") -> list[JumpTable]:
    tables: list[JumpTable] = []
    for instruction in instructions:
        if instruction.op not in ("mov", "movsxd", "movzx", "movsx") or instruction.memory is None:
            continue
        if instruction.memory.base is None or instruction.memory.index is None:
            continue
        following = [i for i in instructions if i.address > instruction.address][:3]
        if any(i.flow == "indirect-jump" for i in following):
            continue
        table = recover_table(elf, instructions, instruction, None, section)
        if table is not None:
            tables.append(table)
    return tables

class ControlFlowGraph:

    def __init__(self, entry: int, instructions: list[Instruction], tables: dict[int, JumpTable] | None = None) -> None:
        self.entry = entry
        self.tables = tables or {}
        self.instructions = sorted(instructions, key=lambda i: i.address)
        if not self.instructions or entry not in {i.address for i in self.instructions}:
            raise ValueError(f"entry 0x{entry:x} is not the address of a decoded instruction")
        self.blocks: dict[int, Block] = {}
        self.unresolved: list[int] = []
        self._build()
        self.edges: list[tuple[int, int, str]] = [(b.start, target, kind) for b in self.blocks.values() for target, kind in b.successors]
        self._idom: dict[int, int] | None = None

    def _leaders(self) -> set[int]:
        leaders = {self.entry}
        addresses = {i.address for i in self.instructions}
        for position, instruction in enumerate(self.instructions):
            if instruction.flow in ("jump", "branch", "return", "indirect-jump"):
                if position + 1 < len(self.instructions):
                    leaders.add(self.instructions[position + 1].address)
            if instruction.flow in ("jump", "branch") and instruction.target in addresses:
                leaders.add(instruction.target)
            if instruction.address in self.tables:
                leaders.update(t for t in self.tables[instruction.address].targets if t in addresses)
        return leaders

    def _build(self) -> None:
        leaders = self._leaders()
        current: Block | None = None
        for instruction in self.instructions:
            if instruction.address in leaders or current is None or current.end != instruction.address:
                current = Block(instruction.address, [])
                self.blocks[instruction.address] = current
            current.instructions.append(instruction)
        starts = sorted(self.blocks)
        for position, start in enumerate(starts):
            block = self.blocks[start]
            last = block.last
            following = starts[position + 1] if position + 1 < len(starts) else None
            falls_through = following is not None and following == block.end
            if last.flow == "return":
                continue
            if last.flow == "jump":
                if last.target in self.blocks:
                    block.successors.append((last.target, "jump"))
                continue
            if last.flow == "branch":
                if last.target in self.blocks:
                    block.successors.append((last.target, "taken"))
                if falls_through:
                    block.successors.append((following, "fallthrough"))
                continue
            if last.flow == "indirect-jump":
                table = self.tables.get(last.address)
                if table is None:
                    self.unresolved.append(last.address)
                    continue
                for target in sorted(set(table.targets)):
                    if target in self.blocks:
                        block.successors.append((target, "table"))
                continue
            if falls_through:
                block.successors.append((following, "fallthrough"))

    def successors(self, start: int) -> list[int]:
        return [target for target, _kind in self.blocks[start].successors]

    def predecessors(self, start: int) -> list[int]:
        return [source for source, target, _kind in self.edges if target == start]

    def reverse_postorder(self) -> list[int]:
        seen: set[int] = set()
        postorder: list[int] = []

        def visit(start: int) -> None:
            seen.add(start)
            for target in self.successors(start):
                if target not in seen:
                    visit(target)
            postorder.append(start)

        visit(self.entry)
        return list(reversed(postorder))

    def reachable(self) -> set[int]:
        return set(self.reverse_postorder())

    def unreachable(self) -> list[int]:
        reachable = self.reachable()
        return [start for start in sorted(self.blocks) if start not in reachable]

    def dominators(self) -> dict[int, int]:
        if self._idom is None:
            order = self.reverse_postorder()
            self._idom = immediate_dominators(self.entry, order, self.predecessors)
        return self._idom

    def dominates(self, dominator: int, start: int) -> bool:
        return dominates(self.dominators(), dominator, start)

    def dominance_frontiers(self) -> dict[int, set[int]]:
        return dominance_frontiers(self.dominators(), self.predecessors)

    def post_dominators(self) -> dict[int, int]:
        reachable = self.reachable()
        exits = [start for start in reachable if not self.successors(start)]
        reverse_succ: dict[int, list[int]] = {EXIT: exits}
        reverse_pred: dict[int, list[int]] = {EXIT: []}
        for start in reachable:
            reverse_succ[start] = [p for p in self.predecessors(start) if p in reachable]
            reverse_pred[start] = list(self.successors(start)) + ([EXIT] if start in exits else [])
        seen: set[int] = set()
        postorder: list[int] = []

        def visit(node: int) -> None:
            seen.add(node)
            for target in reverse_succ.get(node, []):
                if target not in seen:
                    visit(target)
            postorder.append(node)

        visit(EXIT)
        order = list(reversed(postorder))
        return immediate_dominators(EXIT, order, lambda node: reverse_pred.get(node, []))

    def back_edges(self) -> list[tuple[int, int]]:
        reachable = self.reachable()
        return [(source, target) for source, target, _kind in self.edges if source in reachable and target in reachable and self.dominates(target, source)]

    def natural_loops(self) -> dict[int, set[int]]:
        loops: dict[int, set[int]] = {}
        for source, header in self.back_edges():
            body = {header}
            stack = [source]
            while stack:
                node = stack.pop()
                if node in body:
                    continue
                body.add(node)
                stack.extend(self.predecessors(node))
            loops.setdefault(header, set()).update(body)
        return loops

    def summary(self) -> dict[str, Any]:
        idom = self.dominators()
        return {
            "blocks": len(self.blocks),
            "edges": len(self.edges),
            "unreachableBlocks": [f"0x{s:x}" for s in self.unreachable()],
            "unresolvedIndirectJumps": [f"0x{a:x}" for a in self.unresolved],
            "backEdges": [f"0x{s:x}->0x{t:x}" for s, t in self.back_edges()],
            "immediateDominators": {f"0x{s:x}": f"0x{d:x}" for s, d in sorted(idom.items())},
        }


def immediate_dominators(entry: int, order: list[int], predecessors: Callable[[int], list[int]]) -> dict[int, int]:
    number = {start: position for position, start in enumerate(order)}
    idom: dict[int, int] = {entry: entry}

    def intersect(first: int, second: int) -> int:
        while first != second:
            while number[first] > number[second]:
                first = idom[first]
            while number[second] > number[first]:
                second = idom[second]
        return first

    changed = True
    while changed:
        changed = False
        for start in order[1:]:
            processed = [p for p in predecessors(start) if p in idom]
            if not processed:
                continue
            candidate = processed[0]
            for other in processed[1:]:
                candidate = intersect(other, candidate)
            if idom.get(start) != candidate:
                idom[start] = candidate
                changed = True
    return idom


def dominates(idom: dict[int, int], dominator: int, start: int) -> bool:
    while True:
        if start == dominator:
            return True
        parent = idom.get(start, start)
        if parent == start:
            return False
        start = parent


def dominance_frontiers(idom: dict[int, int], predecessors: Callable[[int], list[int]]) -> dict[int, set[int]]:
    frontier: dict[int, set[int]] = {node: set() for node in idom}
    for node in idom:
        preds = [p for p in predecessors(node) if p in idom]
        is_root = idom[node] == node
        if len(preds) < 2 and not (is_root and preds):
            continue
        for pred in preds:
            runner = pred
            while is_root or runner != idom[node]:
                frontier[runner].add(node)
                if idom[runner] == runner:
                    break
                runner = idom[runner]
    return frontier

        return ("movz" if op == "movzx" else "movs") + SUFFIX[insn.source_width or 8] + SUFFIX[insn.width]
    if op == "cdq":
        return {16: "cwtd", 32: "cltd", 64: "cqto"}[insn.width]
    if op in ("push", "pop", "ret"):
        return op + "q"
    if op == "call":
        return "callq"
    if op == "jmp":
        return "jmpq" if insn.flow == "indirect-jump" else "jmp"
    if op == "nop":
        return "nop" + SUFFIX[insn.width] if insn.operands else "nop"
    if op == "mov" and insn.width == 64 and insn.operands and isinstance(insn.operands[0], Imm) and insn.operands[0].width == 64:
        return "movabsq"
    if op in SUFFIXED:
        return op + SUFFIX[insn.width]
    return op


class _Cursor:
    def __init__(self, code: bytes, start: int) -> None:
        self.code = code
        self.start = start
        self.position = start

    def byte(self) -> int:
        if self.position >= len(self.code):
            raise DecodeError(self.start, "instruction runs past the end of the code")
        if self.position - self.start >= MAX_INSTRUCTION_LENGTH:
            raise DecodeError(self.start, "instruction longer than 15 bytes")
        value = self.code[self.position]
        self.position += 1
        return value

    def peek(self) -> int | None:
        return self.code[self.position] if self.position < len(self.code) else None

    def integer(self, size: int, signed: bool) -> int:
        chunk = bytes(self.byte() for _ in range(size))
        return int.from_bytes(chunk, "little", signed=signed)


class _State:
    def __init__(self, cursor: _Cursor, prefixes: tuple[int, ...], rex: int | None) -> None:
        self.cursor = cursor
        self.prefixes = prefixes
        self.rex = rex
        self.modrm_byte: int | None = None
        self.memory: Mem | None = None
        self.displacement_offset: int | None = None
        self.immediate_offset: int | None = None
        self.opcode_start = cursor.position

    def rex_w(self) -> bool:
        return bool(self.rex and self.rex & 0x8)

    def rex_r(self) -> int:
        return 8 if self.rex and self.rex & 0x4 else 0

    def rex_x(self) -> int:
        return 8 if self.rex and self.rex & 0x2 else 0

    def rex_b(self) -> int:
        return 8 if self.rex and self.rex & 0x1 else 0

    def operand_size(self) -> int:
        if self.rex_w():
            return 64
        return 16 if 0x66 in self.prefixes else 32

    def segment(self) -> str | None:
        for prefix in self.prefixes:
            if prefix in SEGMENT_PREFIXES:
                return SEGMENT_PREFIXES[prefix]
        return None

    def register(self, width: int, number: int) -> Reg:
        if width == 8 and self.rex is None and number < 8:
            return Reg(LEGACY_BYTE_REGISTERS[number], 8)
        return Reg(REGISTERS[width][number], width)

    def immediate(self, size: int, width: int, signed: bool = True, unsigned_text: bool = False) -> Imm:
        self.immediate_offset = self.cursor.position - self.cursor.start
        return Imm(self.cursor.integer(size, signed), width, unsigned_text)

    def displacement(self, size: int) -> int:
        self.displacement_offset = self.cursor.position - self.cursor.start
        return self.cursor.integer(size, True)

    def modrm(self, reg_width: int, rm_width: int) -> tuple[Reg, Operand, int]:
        modrm = self.cursor.byte()
        self.modrm_byte = modrm
        mod, reg, rm = modrm >> 6, (modrm >> 3) & 7, modrm & 7
        reg_operand = self.register(reg_width, reg | self.rex_r())
        if mod == 3:
            return reg_operand, self.register(rm_width, rm | self.rex_b()), reg
        base: str | None = None
        index: str | None = None
        scale = 1
        rip = False
        disp = 0
        if rm == 4:
            sib = self.cursor.byte()
            scale = 1 << (sib >> 6)
            index_number = ((sib >> 3) & 7) | self.rex_x()
            if index_number != 4:
                index = REGISTERS[64][index_number]
            if (sib & 7) == 5 and mod == 0:
                disp = self.displacement(4)
            else:
                base = REGISTERS[64][(sib & 7) | self.rex_b()]
        elif rm == 5 and mod == 0:
            rip = True
            disp = self.displacement(4)
        else:
            base = REGISTERS[64][rm | self.rex_b()]
        if mod == 1:
            disp = self.displacement(1)
        elif mod == 2:
            disp = self.displacement(4)
        self.memory = Mem(rm_width, base, index, scale, disp, rip, self.segment(), self.displacement_offset)
        return reg_operand, self.memory, reg

    def finish(self, op: str, operands: tuple[Any, ...], width: int, flow: str = "next", cc: str | None = None, target: int | None = None, source_width: int | None = None) -> Instruction:
        raw = self.cursor.code[self.cursor.start : self.cursor.position]
        first = self.opcode_start - self.cursor.start
        opcode = tuple(raw[first : first + (2 if raw[first] == 0x0F else 1)])
        return Instruction(
            address=self.cursor.start,
            raw=bytes(raw),
            op=op,
            operands=operands,
            width=width,
            flow=flow,
            cc=cc,
            target=target,
            displacement_offset=self.displacement_offset,
            immediate_offset=self.immediate_offset,
            prefixes=self.prefixes,
            rex=self.rex,
            opcode=opcode,
            modrm=self.modrm_byte,
            source_width=source_width,
        )

    def relative(self, op: str, size: int, flow: str, cc: str | None = None) -> Instruction:
        offset = self.immediate(size, 64).value
        target = (self.cursor.position + offset) & 0xFFFFFFFFFFFFFFFF
        return self.finish(op, (Rel(target),), 64, flow=flow, cc=cc, target=target)


def _imm_size(width: int) -> int:
    return 2 if width == 16 else 4


def decode(code: bytes, address: int) -> Instruction:
    if address < 0 or address >= len(code):
        raise DecodeError(address, "address is outside the code")
    cursor = _Cursor(code, address)
    prefixes: list[int] = []
    while cursor.peek() in LEGACY_PREFIXES:
        prefixes.append(cursor.byte())
    rex = None
    if cursor.peek() is not None and 0x40 <= cursor.peek() <= 0x4F:
        rex = cursor.byte()
    state = _State(cursor, tuple(prefixes), rex)
    opcode = cursor.byte()
    if opcode == 0x0F:
        return _two_byte(state, cursor.byte())
    return _one_byte(state, opcode)


def _one_byte(state: _State, opcode: int) -> Instruction:
    width = state.operand_size()
    if opcode in ALU_EV_GV:
        reg, rm, _ = state.modrm(width, width)
        return state.finish(ALU_EV_GV[opcode], (reg, rm), width)
    if opcode in ALU_GV_EV:
        reg, rm, _ = state.modrm(width, width)
        return state.finish(ALU_GV_EV[opcode], (rm, reg), width)
    if opcode in ALU_ACC_IMM:
        immediate = state.immediate(_imm_size(width), width)
        return state.finish(ALU_ACC_IMM[opcode], (immediate, Reg(REGISTERS[width][0], width)), width)
    if opcode in (0x88, 0x8A):
        reg, rm, _ = state.modrm(8, 8)
        operands = (reg, rm) if opcode == 0x88 else (rm, reg)
        return state.finish("mov", operands, 8)
    if 0x50 <= opcode <= 0x57:
        return state.finish("push", (state.register(64, (opcode & 7) | state.rex_b()),), 64)
    if 0x58 <= opcode <= 0x5F:
        return state.finish("pop", (state.register(64, (opcode & 7) | state.rex_b()),), 64)
    if opcode == 0x63:
        if width != 64:
            raise DecodeError(state.cursor.start, "opcode 63 without REX.W is not in the subset")
        reg, rm, _ = state.modrm(64, 32)
        return state.finish("movsxd", (rm, reg), 64, source_width=32)
    if opcode in (0x69, 0x6B):
        reg, rm, _ = state.modrm(width, width)
        immediate = state.immediate(1 if opcode == 0x6B else _imm_size(width), width)
        return state.finish("imul", (immediate, rm, reg), width)
    if 0x70 <= opcode <= 0x7F:
        return state.relative("jcc", 1, "branch", CONDITIONS[opcode & 0xF])
    if opcode in (0x81, 0x83):
        _, rm, digit = state.modrm(width, width)
        immediate = state.immediate(1 if opcode == 0x83 else _imm_size(width), width)
        return state.finish(GROUP1[digit], (immediate, rm), width)
    if opcode == 0x8D:
        reg, rm, _ = state.modrm(width, width)
        if not isinstance(rm, Mem):
            raise DecodeError(state.cursor.start, "lea needs a memory operand")
        return state.finish("lea", (rm, reg), width)
    if opcode == 0x90:
        return state.finish("nop", (), width)
    if opcode == 0x99:
        return state.finish("cdq", (), width)
    if 0xB8 <= opcode <= 0xBF:
        register = state.register(width, (opcode & 7) | state.rex_b())
        if width == 64:
            return state.finish("mov", (state.immediate(8, 64), register), 64)
        return state.finish("mov", (state.immediate(_imm_size(width), width, unsigned_text=True), register), width)
    if opcode in (0xC1, 0xD1):
        _, rm, digit = state.modrm(width, width)
        immediate = state.immediate(1, 8, signed=False) if opcode == 0xC1 else Imm(1, 8)
        return state.finish(GROUP2[digit], (immediate, rm), width)
    if opcode == 0xC3:
        return state.finish("ret", (), 64, flow="return")
    if opcode == 0xC7:
        _, rm, digit = state.modrm(width, width)
        if digit != 0:
            raise DecodeError(state.cursor.start, f"opcode c7 /{digit} is not mov")
        return state.finish("mov", (state.immediate(_imm_size(width), width, unsigned_text=width != 64), rm), width)
    if opcode == 0xCC:
        return state.finish("int3", (), 64)
    if opcode == 0xE8:
        return state.relative("call", 4, "call")
    if opcode == 0xE9:
        return state.relative("jmp", 4, "jump")
    if opcode == 0xEB:
        return state.relative("jmp", 1, "jump")
    if opcode == 0xF7:
        _, rm, digit = state.modrm(width, width)
        if digit in (0, 1):
            return state.finish("test", (state.immediate(_imm_size(width), width), rm), width)
        return state.finish(GROUP3[digit], (rm,), width)
    if opcode == 0xFF:
        _, rm, digit = state.modrm(width, width)
        if digit == 0:
            return state.finish("inc", (rm,), width)
        if digit == 1:
            return state.finish("dec", (rm,), width)
        if digit in (2, 4, 6):
            if isinstance(rm, Reg):
                rm = state.register(64, REGISTERS[rm.width].index(rm.name))
            else:
                rm = Mem(64, rm.base, rm.index, rm.scale, rm.disp, rm.rip, rm.segment, rm.disp_offset)
            if digit == 6:
                return state.finish("push", (rm,), 64)
            op = "call" if digit == 2 else "jmp"
            return state.finish(op, (IndirectOperand(rm),), 64, flow="indirect-call" if digit == 2 else "indirect-jump")
        raise DecodeError(state.cursor.start, f"opcode ff /{digit} is not in the subset")
    raise DecodeError(state.cursor.start, f"opcode {opcode:02x} is not in the subset")


def _two_byte(state: _State, opcode: int) -> Instruction:
    width = state.operand_size()
    if opcode == 0x0B:
        return state.finish("ud2", (), 64)
    if opcode == 0x1F:
        _, rm, _ = state.modrm(width, width)
        return state.finish("nop", (rm,), width)
    if 0x80 <= opcode <= 0x8F:
        return state.relative("jcc", 4, "branch", CONDITIONS[opcode & 0xF])
    if 0x90 <= opcode <= 0x9F:
        _, rm, _ = state.modrm(8, 8)
        return state.finish("set", (rm,), 8, cc=CONDITIONS[opcode & 0xF])
    if 0x40 <= opcode <= 0x4F:
        reg, rm, _ = state.modrm(width, width)
        return state.finish("cmov", (rm, reg), width, cc=CONDITIONS[opcode & 0xF])
    if opcode == 0xAF:
        reg, rm, _ = state.modrm(width, width)
        return state.finish("imul", (rm, reg), width)
    if opcode in (0xB6, 0xB7, 0xBE, 0xBF):
        source = 8 if opcode in (0xB6, 0xBE) else 16
        reg, rm, _ = state.modrm(width, source)
        return state.finish("movzx" if opcode in (0xB6, 0xB7) else "movsx", (rm, reg), width, source_width=source)
    raise DecodeError(state.cursor.start, f"opcode 0f {opcode:02x} is not in the subset")

class SweepResult:
    instructions: list[Instruction]
    undecodable: list[tuple[int, int]]

    def at(self, address: int) -> Instruction | None:
        for instruction in self.instructions:
            if instruction.address == address:

def linear_sweep(code: bytes, start: int = 0, end: int | None = None) -> SweepResult:
    end = len(code) if end is None else end
    instructions: list[Instruction] = []
    undecodable: list[tuple[int, int]] = []
    position = start
    while position < end:
        try:
            instruction = decode(code[:end], position)
        except DecodeError:
            undecodable.append((position, code[position]))
            position += 1
            continue
        instructions.append(instruction)
        position = instruction.end
    return SweepResult(instructions, undecodable)

        text += f" <{elf.symbolize(instruction.target)}>"
    return f"{instruction.address:8x}: {instruction.hex:<30}\t{text}"


def parse_objdump(text: str) -> list[tuple[int, str, str]]:
    rows: list[tuple[int, str, str]] = []
    for line in text.splitlines():
        if ":" not in line or "\t" not in line or line.startswith("\t\t"):
            continue
        head, _tab, rest = line.partition("\t")
        address_text, _colon, byte_text = head.strip().partition(":")
        if not address_text or not all(c in "0123456789abcdef" for c in address_text):
            continue
        body = rest.split("#", 1)[0]
        if " <" in body:
            body = body.split(" <", 1)[0]
        rows.append((int(address_text, 16), " ".join(byte_text.split()), " ".join(body.split())))
    return rows

def compare_with_objdump(elf: ElfObject, oracle_text: str, section: str = ".text") -> Comparison:
    code = elf.section(section).data
    ours = linear_sweep(code)
    expected = parse_objdump(oracle_text)
    by_address = {i.address: i for i in ours.instructions}
    comparison = Comparison(len(expected), len(ours.instructions))
    for address, byte_text, text in expected:
        instruction = by_address.get(address)
        if instruction is None:
            comparison.mismatches.append({"address": f"0x{address:x}", "expected": text, "got": "(no instruction starts here)"})
            continue
        got = " ".join(instruction.text.split())
        if instruction.hex != byte_text or got != text:
            comparison.mismatches.append({"address": f"0x{address:x}", "expected": f"{byte_text} {text}", "got": f"{instruction.hex} {got}"})
    return comparison

    lines: list[str] = []

class ElfObject:

    def __init__(self, data: bytes) -> None:
        if len(data) < HEADER_SIZE or data[:4] != ELF_MAGIC:
            raise ElfError("not an ELF file: the first four bytes are not 7f 45 4c 46")
        if data[4] != ELFCLASS64:
            raise ElfError(f"ELF class {data[4]} is not ELFCLASS64")
        if data[5] != ELFDATA2LSB:
            raise ElfError(f"ELF data encoding {data[5]} is not little-endian")
        e_type, e_machine = struct.unpack_from("<HH", data, 16)
        if e_machine != EM_X86_64:
            raise ElfError(f"e_machine {e_machine} is not EM_X86_64 (62)")
        if e_type != ET_REL:
            raise ElfError(f"e_type {e_type} is not ET_REL (1); only relocatable objects are supported")
        shoff = struct.unpack_from("<Q", data, 40)[0]
        shentsize, shnum, shstrndx = struct.unpack_from("<HHH", data, 58)
        if shentsize != SECTION_HEADER_SIZE:
            raise ElfError(f"e_shentsize {shentsize} is not 64")
        if shnum == 0 or shoff + shnum * shentsize > len(data):
            raise ElfError("section header table lies outside the file")
        if shstrndx >= shnum:
            raise ElfError(f"e_shstrndx {shstrndx} is not a section index")
        self.data = data
        self.machine = e_machine
        raw_headers = [struct.unpack_from("<IIQQQQIIQQ", data, shoff + index * shentsize) for index in range(shnum)]
        names_header = raw_headers[shstrndx]
        name_table = self._slice(names_header[4], names_header[5], "section name table")
        self.sections: list[Section] = []
        for index, raw in enumerate(raw_headers):
            sh_name, sh_type, sh_flags, _addr, sh_offset, sh_size, sh_link, sh_info, _align, sh_entsize = raw
            payload = b"" if sh_type == SHT_NOBITS else self._slice(sh_offset, sh_size, f"section {index}")
            name = _cstring(name_table, sh_name) if sh_name < len(name_table) else ""
            self.sections.append(Section(index, name, sh_type, sh_flags, sh_offset, sh_size, sh_link, sh_info, sh_entsize, payload))
        self.symbols = self._read_symbols()
        self.relocations = self._read_relocations()

    def _slice(self, offset: int, size: int, what: str) -> bytes:
        if offset + size > len(self.data):
            raise ElfError(f"{what} at 0x{offset:x}+0x{size:x} lies outside the file")
        return self.data[offset : offset + size]

    def _read_symbols(self) -> list[Symbol]:
        symbols: list[Symbol] = []
        for section in self.sections:
            if section.type != SHT_SYMTAB:
                continue
            if section.link >= len(self.sections):
                raise ElfError(".symtab sh_link is not a section index")
            strings = self.sections[section.link].data
            for offset in range(0, section.size - section.size % SYMBOL_SIZE, SYMBOL_SIZE):
                st_name, st_info, _other, st_shndx, st_value, st_size = struct.unpack_from("<IBBHQQ", section.data, offset)
                section_name = self.sections[st_shndx].name if st_shndx < len(self.sections) else ""
                symbols.append(Symbol(_cstring(strings, st_name), st_value, st_size, st_info & 0xF, st_info >> 4, st_shndx, section_name))
        return symbols

    def _read_relocations(self) -> dict[str, list[Relocation]]:
        table: dict[str, list[Relocation]] = {}
        for section in self.sections:
            if section.type != SHT_RELA:
                continue
            if section.info >= len(self.sections):
                raise ElfError(f"{section.name} sh_info is not a section index")
            target = self.sections[section.info].name
            for offset in range(0, section.size - section.size % RELA_SIZE, RELA_SIZE):

            entries.sort(key=lambda r: r.offset)
        return table

        raise ElfError(f"no section named {name}")

    def has_section(self, name: str) -> bool:
        return any(section.name == name for section in self.sections)

    def functions(self, section: str = ".text") -> list[Symbol]:
        found = [s for s in self.symbols if s.type == STT_FUNC and s.section == section]
        return sorted(found, key=lambda s: s.value)

    def function_extent(self, name: str, section: str = ".text") -> tuple[int, int, int]:
        functions = self.functions(section)
        for position, symbol in enumerate(functions):
            if symbol.name == name:
                following = functions[position + 1].value if position + 1 < len(functions) else self.section(section).size
                return symbol.value, symbol.value + symbol.size, following
        raise ElfError(f"no function symbol named {name} in {section}")

    def function(self, name: str, section: str = ".text") -> FunctionBytes:
        start, end, padding_end = self.function_extent(name, section)
        code = self.section(section).data
        if end > len(code):
            raise ElfError(f"{name} ends at 0x{end:x}, past the end of {section}")
        inside = tuple(
            Relocation(r.section, r.offset - start, r.type, r.symbol, r.addend)
            for r in self.relocations.get(section, [])
            if start <= r.offset < end
        )
        return FunctionBytes(name, section, start, end - start, code[start:end], inside, padding_end)

    def relocation_at(self, section: str, offset: int) -> Relocation | None:
        for relocation in self.relocations.get(section, []):
            if relocation.offset == offset:
                return relocation
        return None

    def symbolize(self, address: int, section: str = ".text") -> str:
        best: Symbol | None = None
        for symbol in self.functions(section):
            if symbol.value <= address and (best is None or symbol.value >= best.value):
                best = symbol
        if best is None:
            return f"{section}+0x{address:x}"
        delta = address - best.value
        return best.name if delta == 0 else f"{best.name}+0x{delta:x}"


def symbol_base(symbol: Symbol) -> int:
    return 0 if symbol.type == STT_SECTION else symbol.value

            raise ValueError("a PC-relative relocation needs the end of the field's instruction")
        base += field_end - relocation.offset
    return Target(relocation.symbol.section, base)

            return f"*({ctype(e.width)} *)({self.expr(e.addr)})"
        if isinstance(e, Cast):
            inner = self.expr(e.expr, 14)
            if e.kind == "zext":
                if self.is_unsigned(e.expr):
                    return self.wrap(f"({utype(e.width)}){inner}", 14, parent)
                return self.wrap(f"({utype(e.width)})({utype(e.expr.width)}){inner}", 14, parent)

def table_values(elf: ElfObject, section: str, offset: int, width: int) -> list[int]:
    data = elf.section(section).data
    referenced = set()
    for relocation in elf.relocations.get(".text", []):
        if relocation.symbol.section == section and relocation.pc_relative:
            referenced.add(relocation.addend + relocation.width)
    end = min(t for t in referenced | {len(data)} if t > offset)
    size = width // 8
    count = (end - offset) // size
    return [int.from_bytes(data[offset + i * size : offset + (i + 1) * size], "little", signed=True) for i in range(count)]

    op, ops = insn.op, insn.operands

    def address_of(mem: Mem) -> Any:
        if mem.rip:
            relocation = ctx.elf.relocation_at(ctx.section, insn.address + (mem.disp_offset or 0))
            if relocation is None:
                return Const(insn.end + mem.disp, 64)
            target = relocation_target(relocation, insn.end)
            return Symbolic(target.section, target.offset)
        expr: Any = Var(mem.base, 64) if mem.base else None
        if mem.index:
            scaled: Any = Var(mem.index, 64)
            if mem.scale != 1:
                scaled = Bin("*", scaled, Const(mem.scale, 64), 64)
            expr = scaled if expr is None else Bin("+", expr, scaled, 64)
        if mem.disp or expr is None:
            disp = Const(mem.disp, 64)
            expr = disp if expr is None else Bin("+", expr, disp, 64)
        return expr

    def is_slot(mem: Mem) -> bool:
        return ctx.frame and mem.base == "rbp" and mem.index is None and not mem.rip

    def read(operand: Any, width: int | None = None) -> Any:
        if isinstance(operand, IndirectOperand):
            operand = operand.inner
        w = width or operand.width
        if isinstance(operand, Reg):
            return Var(family(operand.name), w)
        if isinstance(operand, Imm):
            return Const(operand.value, w)
        if isinstance(operand, Mem):
            if is_slot(operand):
                return Var(local_name(operand.disp), w)
            return Load(address_of(operand), w)

    def write(operand: Any, expr: Any) -> Any:
        if isinstance(operand, Reg):
            return Assign(Var(family(operand.name), operand.width), expr)
        if isinstance(operand, Mem):
            if is_slot(operand):
                return Assign(Var(local_name(operand.disp), operand.width), expr)
            return Store(address_of(operand), expr, operand.width)
        raise LiftError(f"0x{insn.address:x}: cannot write operand {operand!r}")

    def same_register(a: Any, b: Any) -> bool:
        return isinstance(a, Reg) and isinstance(b, Reg) and family(a.name) == family(b.name)

    def is_rsp(operand: Any) -> bool:
        return isinstance(operand, Reg) and operand.name == "rsp"

    if op in ("push", "pop", "nop"):
        return []
    if op == "mov" and same_register(ops[1], Reg("rbp", 64)) and same_register(ops[0], Reg("rsp", 64)):
        ctx.frame = True
        return []
    if op in ("add", "sub") and is_rsp(ops[1]):
        return []
    captured: list[Any] = []
    for table in ctx.tables.values():
        if table.load_instruction == insn.address and table.is_jump_table:
            captured.append(Assign(Var("switch_index", 64), Var(table.index_register, 64)))
    if op == "mov":
        return captured + [write(ops[1], read(ops[0]))]
    if op == "movsxd":
        ctx.evidence("signed", insn)
        return captured + [write(ops[1], Cast("sext", read(ops[0], 32), 64))]
    if op == "movsx":
        ctx.evidence("signed", insn)
        return [write(ops[1], Cast("sext", read(ops[0], insn.source_width or 8), insn.width))]
    if op == "movzx":
        ctx.evidence("unsigned", insn)
        return [write(ops[1], Cast("zext", read(ops[0], insn.source_width or 8), insn.width))]
    if op == "lea":
        expr = address_of(ops[0])
        if ops[1].width == 32:
            expr = Cast("trunc", expr, 32)
        return [write(ops[1], expr)]
    if op in ("add", "sub", "and", "or", "xor"):
        if op in ("sub", "xor") and same_register(ops[0], ops[1]):
            return [write(ops[1], Const(0, ops[1].width))]
        source, destination = read(ops[0]), read(ops[1])
        symbol = {"add": "+", "sub": "-", "and": "&", "or": "|", "xor": "^"}[op]
        kind = "cmp" if op == "sub" else op
        return [Assign(FLAGS, Flags(kind, destination, source, insn.width)), write(ops[1], Bin(symbol, destination, source, insn.width))]
    if op in ("inc", "dec"):
        value = read(ops[0])
        one = Const(1, insn.width)
        return [Assign(FLAGS, Flags(op, value, one, insn.width)), write(ops[0], Bin("+" if op == "inc" else "-", value, one, insn.width))]
    if op == "neg":
        value = read(ops[0])
        return [Assign(FLAGS, Flags("cmp", Const(0, insn.width), value, insn.width)), write(ops[0], Bin("-", Const(0, insn.width), value, insn.width))]
    if op == "not":
        return [write(ops[0], Bin("^", read(ops[0]), Const(-1, insn.width), insn.width))]
    if op in ("cmp", "test"):
        return [Assign(FLAGS, Flags(op, read(ops[1]), read(ops[0]), insn.width))]
    if op == "imul":
        if len(ops) == 3:
            return [write(ops[2], Bin("*", read(ops[1]), read(ops[0]), insn.width))]
        return [write(ops[1], Bin("*", read(ops[1]), read(ops[0]), insn.width))]
    if op in ("shl", "shr", "sar"):
        symbol = {"shl": "<<", "shr": ">>u", "sar": ">>s"}[op]
        if op != "shl":
            ctx.evidence("signed" if op == "sar" else "unsigned", insn)
        return [write(ops[1], Bin(symbol, read(ops[1]), Const(ops[0].value, 8), insn.width))]
    if op == "cdq":
        ctx.evidence("signed", insn)
        return [Assign(Var("rdx", insn.width), SignFill(Var("rax", insn.width), insn.width))]
    if op in ("idiv", "div"):
        w = insn.width
        signed = op == "idiv"
        ctx.evidence("signed" if signed else "unsigned", insn)
        dividend = Var("dividend", 2 * w)
        divisor = read(ops[0])
        quotient, remainder = ("/", "%") if signed else ("/u", "%u")
        return [

            Assign(Var("rax", w), Bin(quotient, dividend, divisor, w)),
            Assign(Var("rdx", w), Bin(remainder, dividend, divisor, w)),

        elif insn.cc in UNSIGNED_CONDITIONS:

        return [Return(Var("rax", 0))]

def children(expr: Any) -> list[Any]:
    if isinstance(expr, (Bin, Flags)):
        return [expr.left, expr.right]
    if isinstance(expr, (Cast, SignFill)):
        return [expr.expr]
    if isinstance(expr, Load):
        return [expr.addr]
    if isinstance(expr, Index):
        return [expr.base, expr.index]
    if isinstance(expr, Field):
        return [expr.base]
    if isinstance(expr, Cond):
        return [expr.flags]
    if isinstance(expr, Concat):
        return [expr.high, expr.low]
    if isinstance(expr, CallExpr):
        return list(expr.args)
    return []


def rebuild(expr: Any, kids: list[Any]) -> Any:
    if isinstance(expr, (Bin, Flags)):
        return replace(expr, left=kids[0], right=kids[1])
    if isinstance(expr, (Cast, SignFill)):
        return replace(expr, expr=kids[0])
    if isinstance(expr, Load):
        return replace(expr, addr=kids[0])
    if isinstance(expr, Index):
        return replace(expr, base=kids[0], index=kids[1])
    if isinstance(expr, Field):
        return replace(expr, base=kids[0])
    if isinstance(expr, Cond):
        return replace(expr, flags=kids[0])
    if isinstance(expr, Concat):
        return replace(expr, high=kids[0], low=kids[1])
    if isinstance(expr, CallExpr):
        return replace(expr, args=tuple(kids))
    return expr


def rewrite(expr: Any, fn) -> Any:
    kids = [rewrite(k, fn) for k in children(expr)]
    return fn(rebuild(expr, kids))


def iter_nodes(expr: Any):
    yield expr
    for kid in children(expr):
        yield from iter_nodes(kid)


def variables(expr: Any) -> list[Var]:
    return [node for node in iter_nodes(expr) if isinstance(node, Var)]


def stmt_exprs(stmt: Any) -> list[Any]:
    if isinstance(stmt, Assign):

    elif isinstance(stmt, IndirectJump):

    elif isinstance(stmt, Return):
        stmt.value = fn(stmt.value)

def lift_function(elf: ElfObject, graph: FunctionGraph, signatures: dict[str, tuple[tuple[int, ...], int]] | None = None) -> Function:
    cfg = graph.cfg
    reachable = cfg.reachable()
    blocks: dict[int, IRBlock] = {}
    for start in sorted(cfg.blocks):
        if start in reachable:
            block = cfg.blocks[start]
            blocks[start] = IRBlock(start, list(block.instructions), [], [t for t in cfg.successors(start) if t in reachable], [p for p in cfg.predecessors(start) if p in reachable])
    fn = Function(graph.name, graph.start, blocks, graph)
    ctx = LiftContext(elf, dict(graph.descent.tables), signatures or {})
    for block in fn.ordered_blocks():
        for insn in block.instructions:
            block.stmts.extend(lift_instruction(insn, ctx))
    fn.frame_pointer = ctx.frame
    fn.signedness = ctx.signedness
    fn.notes.extend(ctx.notes)
    dropped = sorted(b for b in cfg.blocks if b not in reachable)
    if dropped:
        fn.notes.append(f"{len(dropped)} block(s) at {', '.join(f'0x{b:x}' for b in dropped)} are unreachable from the entry and were not lifted")
    for address in cfg.unresolved:
        fn.notes.append(f"indirect jump at 0x{address:x} has no recovered table; its targets are unknown")
    fn.idom = cfg.dominators()
    return fn

def c_div(dividend: int, divisor: int) -> int:
    quotient = abs(dividend) // abs(divisor)
    return -quotient if (dividend < 0) != (divisor < 0) else quotient


def truncate(value: int, width: int) -> int:
    value &= (1 << width) - 1
    return value - (1 << width) if width and value >> (width - 1) else value


def magic_divisor(multiplier: int, shift: int) -> int | None:
    if multiplier <= 0 or shift < 32 or shift > 63:
        return None
    power = 1 << shift
    for d in (power // multiplier, power // multiplier + 1):
        if d > 1 and multiplier == -(-power // d) and multiplier * d - power <= power >> 31:
            return d
    return None


def division_identity_holds(multiplier: int, shift: int, divisor: int, samples: list[int] | None = None) -> bool:
    values = samples or list(range(-40, 41)) + [INT_MIN, INT_MIN + 1, INT_MAX - 1, INT_MAX, 2**30, -(2**30), 123456789, -123456789]
    for x in values:
        product = truncate(x * multiplier, 64)
        quotient = truncate(product >> shift, 32) + ((product >> 63) & 1)
        if truncate(quotient, 32) != c_div(x, divisor):
            return False
    return True

def place_of(addr: Any, width: int) -> Any:
    if isinstance(addr, Bin) and addr.op == "+":
        for base, offset in ((addr.left, addr.right), (addr.right, addr.left)):
            scaled = isinstance(offset, Bin) and offset.op == "*" and isinstance(offset.right, Const)
            if scaled and offset.right.value * 8 == width and isinstance(base, (Var, Symbolic)):
                return Index(base, offset.left, width)

def make_simplifier(defs: dict[tuple[str, int], Any], recognize_division: bool, report: OptimizeReport | None = None, order: dict[tuple[str, int], int] | None = None):
    order = order or {}

    def resolve(expr: Any) -> Any:
        seen = 0
        while isinstance(expr, Var) and expr.key in defs and seen < 64:
            expr = defs[expr.key]
            seen += 1
        return expr

    def strip_trunc(expr: Any) -> Any:
        return expr.expr if isinstance(expr, Cast) and expr.kind == "trunc" else expr

    def division_pattern(expr: Any) -> Any:
        if not recognize_division or not isinstance(expr, Bin) or expr.op != "+" or expr.width != 32:
            return None
        parts = [resolve(strip_trunc(expr.left)), resolve(strip_trunc(expr.right))]
        for quotient, sign in (parts, parts[::-1]):
            if not (isinstance(quotient, Bin) and quotient.op in (">>s", ">>u") and isinstance(quotient.right, Const)):
                continue
            shift = quotient.right.value
            if quotient.op == ">>u" and shift != 32:
                continue
            if not (isinstance(sign, Bin) and sign.op == ">>u" and isinstance(sign.right, Const) and sign.right.value == 63):
                continue
            product_a, product_b = resolve(quotient.left), resolve(sign.left)
            if product_a != product_b or not (isinstance(product_a, Bin) and product_a.op == "*"):
                continue
            operand, multiplier = product_a.left, product_a.right
            if isinstance(operand, Const):
                operand, multiplier = multiplier, operand
            if not (isinstance(multiplier, Const) and isinstance(operand, Cast) and operand.kind == "sext"):
                continue
            divisor = magic_divisor(multiplier.value, shift)
            if divisor is None or not division_identity_holds(multiplier.value, shift, divisor):
                continue
            if report is not None:
                record = {"multiplier": multiplier.value, "shift": shift, "divisor": divisor}
                if record not in report.divisions:
                    report.divisions.append(record)
            return Bin("/", operand.expr, Const(divisor, 32), 32)
        return None

    def fold_constants(expr: Bin) -> Any:
        left, right = expr.left, expr.right
        if isinstance(left, Const) and isinstance(right, Const):
            a, b = left.value, right.value
            table = {"+": a + b, "-": a - b, "*": a * b, "&": a & b, "|": a | b, "^": a ^ b, "<<": a << b}
            if expr.op in table:
                return Const(truncate(table[expr.op], expr.width), expr.width)
        if expr.op in ("+", "-") and isinstance(right, Const) and right.value == 0:
            return left
        if expr.op == "*" and isinstance(right, Const) and right.value == 1:
            return left
        return expr

    def simplify(expr: Any) -> Any:
        if isinstance(expr, Cond) and isinstance(expr.flags, Flags):
            flags, op = expr.flags, COND_OPS[expr.cc]
            if flags.kind == "cmp":
                return Bin(op, flags.left, flags.right, 32)
            if flags.kind == "test":
                if flags.left == flags.right:
                    return Bin(op, flags.left, Const(0, flags.width), 32)
                return Bin(op, Bin("&", flags.left, flags.right, flags.width), Const(0, flags.width), 32)
            if flags.kind in ("add", "inc", "dec", "and", "or", "xor") and expr.cc in ("e", "ne", "s", "ns", "l", "ge", "le", "g"):
                symbol = {"add": "+", "inc": "+", "dec": "-", "and": "&", "or": "|", "xor": "^"}[flags.kind]
                return Bin(op, Bin(symbol, flags.left, flags.right, flags.width), Const(0, flags.width), 32)
        if isinstance(expr, Bin):
            expr = fold_constants(expr)
        if isinstance(expr, Bin) and expr.op in COMMUTATIVE and isinstance(expr.left, Var) and isinstance(expr.right, Var):
            if order.get(expr.right.key, 0) < order.get(expr.left.key, 0):
                expr = Bin(expr.op, expr.right, expr.left, expr.width)
        if isinstance(expr, Bin) and expr.op == "+" and isinstance(expr.right, Const) and expr.right.value < 0:
            return Bin("-", expr.left, Const(-expr.right.value, expr.right.width), expr.width)
        if isinstance(expr, Cast) and isinstance(expr.expr, Const):
            value = expr.expr.value
            if expr.kind == "zext":
                return Const(value & ((1 << expr.expr.width) - 1), expr.width)
            return Const(truncate(value, expr.width), expr.width)
        if isinstance(expr, Cast) and expr.kind == "trunc":
            inner = expr.expr
            if isinstance(inner, Cast) and inner.kind in ("zext", "sext") and inner.expr.width == expr.width:
                return inner.expr
            if isinstance(inner, Bin) and inner.op in ("+", "-", "*") and inner.width > expr.width:
                left = simplify(Cast("trunc", inner.left, expr.width))
                right = simplify(Cast("trunc", inner.right, expr.width))
                return simplify(Bin(inner.op, left, right, expr.width))
        if isinstance(expr, Concat) and isinstance(expr.high, SignFill) and expr.high.expr == expr.low:
            return expr.low
        if isinstance(expr, Load):
            place = place_of(expr.addr, expr.width)
            if place is not None:
                return place
        folded = division_pattern(expr)
        if folded is not None:
            return folded
        return expr

    return simplify

        while isinstance(current, Var) and current.key in defs and current.key not in seen:
            seen.add(current.key)
            following = defs[current.key]
            if isinstance(following, (Var, Const)):
                current = following
            else:
                break
        return current.value if isinstance(current, Const) else current.key if isinstance(current, Var) else None

    merged = 0
    replacements: dict[tuple[str, int], Var] = {}
    for block in fn.blocks.values():
        phis = [s for s in block.stmts if isinstance(s, Phi)]
        for position, later in enumerate(phis):
            for earlier in phis[:position]:
                if earlier.dst.key in replacements or later.dst.key in replacements:
                    continue
                if set(earlier.sources) != set(later.sources):
                    continue
                same = all(value(earlier.sources[p]) is not None and value(earlier.sources[p]) == value(later.sources[p]) for p in earlier.sources)
                widths_match = fn.def_width.get(earlier.dst.key) == fn.def_width.get(later.dst.key)
                if same and widths_match:
                    replacements[later.dst.key] = earlier.dst
                    break
    if not replacements:
        return 0

    def swap(expr: Any) -> Any:
        if isinstance(expr, Var) and expr.key in replacements:
            return Var(replacements[expr.key].name, expr.width, replacements[expr.key].version)
        return expr

        kept = []
        for stmt in block.stmts:
            if isinstance(stmt, Phi):
                if stmt.dst.key in replacements:
                    merged += 1
                    continue

            else:
                map_stmt(stmt, lambda e: rewrite(e, swap))
            kept.append(stmt)
        block.stmts = kept
    return merged

            node = work.pop()

                if join in has_phi:
                    continue

def rename(fn: Function) -> None:

    stacks: dict[str, list[int]] = {}
    children_of: dict[int, list[int]] = {b: [] for b in fn.blocks}
    for node, parent in fn.idom.items():
        if node != parent and parent in children_of:
            children_of[parent].append(node)

    def fresh(name: str, width: int) -> Var:
        counters[name] = counters.get(name, 0) + 1
        version = counters[name]
        stacks.setdefault(name, []).append(version)
        fn.def_width[(name, version)] = width
        return Var(name, width, version)

        if not stack:

            return Var(var.name, var.width, 0)
        return Var(var.name, var.width, stack[-1])

        return rewrite(expr, lambda e: use(e) if isinstance(e, Var) else e)

        block = fn.blocks[block_id]
        pushed: list[str] = []
        for stmt in block.stmts:
            if isinstance(stmt, Phi):
                stmt.dst = fresh(stmt.dst.name, 0)

        if not isinstance(stmt, Phi):
            map_stmt(stmt, lambda e: rewrite(e, cast_use))

def negate(cond: Any) -> Any:

        return Bin(NEGATE[cond.op], cond.left, cond.right, cond.width)

def natural_loops(fn: Function) -> dict[int, set[int]]:
    preds = fn.preds()
    loops: dict[int, set[int]] = {}
    for block in fn.blocks.values():
        for succ in block.succs:
            if dominates(fn.idom, succ, block.start):
                body = {succ}
                stack = [block.start]
                while stack:
                    node = stack.pop()
                    if node in body:
                        continue
                    body.add(node)
                    stack.extend(preds[node])
                loops.setdefault(succ, set()).update(body)
    return loops


def post_dominators(fn: Function) -> dict[int, int]:
    from .cfg import immediate_dominators

    succs, preds = fn.succs(), fn.preds()
    exits = [b for b, s in succs.items() if not s]
    reverse_succs = {b: list(p) for b, p in preds.items()}
    reverse_succs[EXIT] = exits
    reverse_preds = {b: list(s) + ([EXIT] if b in exits else []) for b, s in succs.items()}
    reverse_preds[EXIT] = []
    seen: set[int] = set()
    postorder: list[int] = []

    def visit(node: int) -> None:
        seen.add(node)
        for target in reverse_succs.get(node, []):
            if target not in seen:
                visit(target)
        postorder.append(node)

    visit(EXIT)
    order = list(reversed(postorder))
    return immediate_dominators(EXIT, order, lambda node: reverse_preds.get(node, []))


class Structurer:

    def __init__(self, fn: Function, statement: Callable[[Any], str | None], condition: Callable[[Any], str]) -> None:
        self.fn = fn
        self.statement = statement
        self.condition = condition
        self.succs = fn.succs()
        fn.ipdom = post_dominators(fn)
        self.loops = natural_loops(fn)
        self.lines: list[str] = []
        self.emitted: set[int] = set()
        self.gotos = 0

    def emit(self, text: str, depth: int) -> None:
        self.lines.append("  " * depth + text)

    @staticmethod
    def terminator(block: IRBlock) -> Any:
        return block.stmts[-1] if block.stmts and isinstance(block.stmts[-1], TERMINATORS) else None

    def body(self, block: IRBlock, depth: int) -> None:
        for stmt in block.stmts:
            if isinstance(stmt, (Phi, Branch, Jump, IndirectJump)):
                continue
            text = self.statement(stmt)
            if text is not None:
                self.emit(text, depth)

    def region_size(self, start: int, stop: int) -> int:
        seen: set[int] = set()
        stack = [start]
        while stack:
            node = stack.pop()
            if node in seen or node == stop or node == EXIT:
                continue
            seen.add(node)
            stack.extend(self.succs[node])
        return len(seen)

    def walk(self, block_id: int, stop: int, depth: int) -> None:
        if block_id in (stop, EXIT):
            return
        if block_id in self.emitted:
            self.gotos += 1
            self.emit(f"goto block_{block_id:x};", depth)
            return
        block = self.fn.blocks[block_id]
        if block_id in self.loops:
            self.emit_loop(block, stop, depth)
            return
        self.emitted.add(block_id)
        term = self.terminator(block)
        self.body(block, depth)
        if isinstance(term, Branch):
            self.emit_branch(block, term, stop, depth)
        elif isinstance(term, IndirectJump) and term.table is not None:
            self.emit_switch(block, term, None, stop, depth)
        elif isinstance(term, Jump):
            self.walk(term.target, stop, depth)
        elif term is None and block.succs:
            self.walk(block.succs[0], stop, depth)

    def switch_head(self, block_id: int, other: int) -> IndirectJump | None:
        if block_id in (EXIT,) or block_id not in self.fn.blocks:
            return None
        term = self.terminator(self.fn.blocks[block_id])
        if isinstance(term, IndirectJump) and term.table is not None and other not in term.table.targets:
            return term
        return None

    def emit_branch(self, block: IRBlock, term: Branch, stop: int, depth: int) -> None:
        join = self.fn.ipdom.get(block.start, EXIT)
        taken, fall = term.target, term.fallthrough
        head = self.switch_head(fall, taken)
        if head is not None and self.fn.blocks[fall].preds == [block.start]:
            self.emitted.add(fall)
            self.body(self.fn.blocks[fall], depth)
            self.emit_switch(self.fn.blocks[fall], head, taken, join, depth)
            self.walk(join, stop, depth)
            return
        if join == taken:
            self.emit(f"if ({self.condition(negate(term.cond))}) {{", depth)
            self.walk(fall, join, depth + 1)
            self.emit("}", depth)
            self.walk(join, stop, depth)
        elif join == fall:
            self.emit(f"if ({self.condition(term.cond)}) {{", depth)
            self.walk(taken, join, depth + 1)
            self.emit("}", depth)
            self.walk(join, stop, depth)
        elif join in (EXIT, stop):
            first, second, cond = taken, fall, term.cond
            if self.region_size(fall, join) < self.region_size(taken, join):
                first, second, cond = fall, taken, negate(term.cond)
            self.emit(f"if ({self.condition(cond)}) {{", depth)
            self.walk(first, join, depth + 1)
            self.emit("}", depth)
            self.walk(second, join, depth)
        else:
            self.emit(f"if ({self.condition(term.cond)}) {{", depth)
            self.walk(taken, join, depth + 1)
            self.emit("} else {", depth)
            self.walk(fall, join, depth + 1)
            self.emit("}", depth)
            self.walk(join, stop, depth)

    def emit_switch(self, block: IRBlock, term: IndirectJump, default: int | None, join: int, depth: int) -> None:
        table = term.table
        assert table is not None
        self.emit(f"switch ({self.condition(term.index)}) {{", depth)
        by_target: dict[int, list[int]] = {}
        for case, target in enumerate(table.targets):
            by_target.setdefault(target, []).append(case)
        for target, cases in sorted(by_target.items(), key=lambda item: item[1][0]):
            for case in cases:
                self.emit(f"case {case}:", depth)
            self.walk(target, join, depth + 1)
            self.emit("break;", depth + 1)
        if default is not None:
            self.emit("default:", depth)
            self.walk(default, join, depth + 1)
            self.emit("break;", depth + 1)
        self.emit("}", depth)

    def emit_loop(self, header: IRBlock, stop: int, depth: int) -> None:
        members = self.loops[header.start]
        exits = sorted({s for b in members for s in self.succs[b] if s not in members})
        exit_block = exits[0] if exits else EXIT
        term = self.terminator(header)
        self.emitted.add(header.start)
        self_loop = header.start in self.succs[header.start]
        header_exits = isinstance(term, Branch) and (term.target not in members or term.fallthrough not in members)
        if header_exits and not self_loop:
            cond = term.cond if term.fallthrough not in members else negate(term.cond)
            inner = term.target if term.target in members else term.fallthrough
            self.body(header, depth)
            self.emit(f"while ({self.condition(cond)}) {{", depth)
            self.walk(inner, header.start, depth + 1)
            self.emit("}", depth)
        else:
            latch = header if self_loop else self.fn.blocks[[b for b in members if header.start in self.succs[b]][0]]
            latch_term = self.terminator(latch)
            self.emit("do {", depth)

                self.body(latch, depth + 1)

                cond = latch_term.cond if latch_term.target == header.start else negate(latch_term.cond)
                self.emit(f"}} while ({self.condition(cond)});", depth)
            else:
                self.emit("} while (1);", depth)
        self.walk(exit_block, stop, depth)

    def run(self) -> list[str]:
        self.walk(self.fn.entry, EXIT, 1)
        return self.lines

def infer_types(fn: Function) -> None:
    aliases: dict[str, set[str]] = {}

    def link(a: str, b: str) -> None:
        group = aliases.setdefault(a, {a}) | aliases.setdefault(b, {b})
        for member in group:
            aliases[member] = group

    def web(var: Var) -> str:
        return fn.web_names.get(var.key, var.name)

    element_evidence: dict[str, int] = {}
    struct_evidence: dict[str, dict[int, int]] = {}
    returned: list[int] = []
    undefined_return = False
    for stmt in fn.statements():
        if isinstance(stmt, Assign) and isinstance(stmt.src, Var):
            link(web(stmt.dst), web(stmt.src))
        if isinstance(stmt, Phi):
            for src in stmt.sources.values():
                link(web(stmt.dst), web(src))
        if isinstance(stmt, Return):
            if isinstance(stmt.value, Var) and stmt.value.version == 0:
                undefined_return = True
            else:
                returned.append(getattr(stmt.value, "width", 32))
        places = list(stmt_exprs(stmt)) + ([stmt.place] if isinstance(stmt, Store) and stmt.place is not None else [])
        for expr in places:
            for node in iter_nodes(expr):
                if isinstance(node, Index) and isinstance(node.base, Var):
                    element_evidence[web(node.base)] = node.width
                if isinstance(node, Field) and isinstance(node.base, Var):
                    struct_evidence.setdefault(web(node.base), {})[node.offset] = node.width
    fn.structs = {}
    for label, fields in struct_evidence.items():
        group = aliases.get(label, {label})
        param_labels = sorted(member for member in group if member.startswith("param_"))
        struct_name = f"{fn.name}_{param_labels[0] if param_labels else label}"
        merged = fn.structs.setdefault(struct_name, {})
        for other in group:
            merged.update(struct_evidence.get(other, {}))
        for member in group:
            fn.web_types[member] = f"struct {struct_name} *"
    for label, width in element_evidence.items():
        for member in aliases.get(label, {label}):
            if not fn.web_types.get(member, "").startswith("struct"):
                fn.web_types[member] = f"{ctype(width)} *"
    for label, kinds in signedness_by_web(fn).items():
        if signedness_label(kinds) == "unsigned" and label in fn.web_types and not fn.web_types[label].endswith("*"):
            fn.web_types[label] = "unsigned " + fn.web_types[label]
    if undefined_return and not returned:
        fn.return_type = "void"
    elif not returned:
        fn.return_type = "void"
    else:
        fn.return_type = ctype(max(returned))

class ByteComparison:

def read_referenced(obj: ElfObject, relocation: Relocation, length: int) -> list[int] | None:
    if not relocation.pc_relative or relocation.symbol.section in (".text", ""):
        return None
    target = relocation_target(relocation, relocation.offset + relocation.width)
    if not obj.has_section(target.section):
        return None
    data = obj.section(target.section).data
    raw = data[target.offset : target.offset + length]
    return [int.from_bytes(raw[i : i + 4], "little", signed=True) for i in range(0, len(raw) - len(raw) % 4, 4)]


def compare_function_bytes(original: ElfObject, candidate: ElfObject, name: str, tables: dict[str, dict[str, Any]] | None = None) -> ByteComparison:
    left = original.function(name)
    try:
        right = candidate.function(name)
    except Exception as error:
        return ByteComparison(name, left.size, 0, False, [], [], False, [], [], missing=f"{name} is not a function in the recompiled object: {error}")
    masked_left, ranges = mask_relocations(left.data, left.relocations)
    masked_right, _ = mask_relocations(right.data, right.relocations)
    differing = [index for index, (a, b) in enumerate(zip(masked_left, masked_right)) if a != b]
    relocations_match = len(left.relocations) == len(right.relocations)
    detail: list[dict[str, Any]] = []
    constants: list[dict[str, Any]] = []
    lengths = {(info["section"], info["offset"]): len(info["values"]) * info["width"] // 8 for info in (tables or {}).values()}
    for reloc_left, reloc_right in zip(left.relocations, right.relocations):
        same = reloc_left.offset == reloc_right.offset and reloc_left.type == reloc_right.type and reloc_left.symbol.section == reloc_right.symbol.section
        relocations_match = relocations_match and same
        detail.append(
            {
                "offset": reloc_left.offset,
                "type": reloc_left.type_name,
                "originalTarget": reloc_left.describe(),
                "candidateTarget": reloc_right.describe(),
                "sameShape": same,
            }
        )
        if not same or not reloc_left.pc_relative:
            continue

def classify(args: tuple[Any, ...], constants: list[int]) -> str:
    scalars = [a for a in args if not isinstance(a, tuple)]
    memories = [a for a in args if isinstance(a, tuple)]
    edges = {c + d for c in constants for d in (-1, 0, 1)}
    if any(a in (INT_MAX, INT_MIN) for a in scalars) or any(INT_MAX in m or INT_MIN in m for m in memories):
        return "limit"
    if any(a in edges for a in scalars) and constants:
        return "compare-edge"
    if any(a == 0 for a in scalars):
        return "zero"
    if any(a < 0 for a in scalars) or any(v < 0 for m in memories for v in m):
        return "negative"
    return "plain"

    scalar_values = list(SCALARS_WITH_MEMORY if has_memory else SCALARS)
    for constant in constants:
        for delta in (-1, 0, 1):
            if constant + delta not in scalar_values and INT_MIN <= constant + delta <= INT_MAX:

def parse_result(text: str) -> Any:
    tokens = text.split()
    if not tokens:
        return None
    if tokens[0] == TRAP:
        return TRAP
    if tokens[0] == "void":
        return ["void", *map(int, tokens[1:])] if len(tokens) > 1 else "void"
    values = list(map(int, tokens))
    return values[0] if len(values) == 1 else values


def run_cells(harness: Harness, cells: list[Cell]) -> list[dict[str, Any]]:
    feed = "".join(cell.line() + "\n" for cell in cells)
    try:
        completed = subprocess.run([str(harness.binary)], input=feed, capture_output=True, text=True, timeout=DRIVER_TIMEOUT_SECONDS)
    except subprocess.TimeoutExpired as error:
        raise VerifyError(f"driver did not finish within {DRIVER_TIMEOUT_SECONDS} s") from error
    if completed.returncode != 0:
        raise VerifyError(f"driver exited with {completed.returncode}: {completed.stderr[:400]}")
    rows: list[dict[str, Any]] = []
    for cell, line in zip(cells, completed.stdout.splitlines()):
        parts = line.split(" | ")
        if len(parts) != 3:
            raise VerifyError(f"driver printed an unexpected line: {line!r}")
        original, candidate = parse_result(parts[1]), parse_result(parts[2])
        rows.append({"function": cell.function, "args": list(cell.args), "kind": cell.kind, "original": original, "candidate": candidate, "match": original == candidate})
    if len(rows) != len(cells):
        raise VerifyError("driver printed fewer rows than cells")
    return rows

def verify(object_path: str | Path, source_path: str | Path | None = None, opt: str = "O1", out_dir: str | Path | None = None, functions: list[str] | None = None, recognize_division: bool = True) -> dict[str, Any]:
    object_path = Path(object_path)
    out = Path(out_dir) if out_dir else object_path.parent / "verify-out"
    out.mkdir(parents=True, exist_ok=True)
    elf = load_object(object_path)
    decompiled = decompile_all(elf, recognize_division, functions)
    unit = translation_unit(decompiled)
    decompiled_path = out / "decompiled.c"
    decompiled_path.write_text(unit, encoding="utf-8")
    outputs = {"decompiled": str(decompiled_path)}
    byte_compare: dict[str, ByteComparison] = {}
    recompile_error: str | None = None
    try:
        recompiled = recompile(decompiled_path, opt, out / "recompiled.o")
        outputs["recompiled"] = str(recompiled)
        candidate = load_object(recompiled)
        for name, result in decompiled.items():
            byte_compare[name] = compare_function_bytes(elf, candidate, name, result.tables)
    except VerifyError as error:
        recompile_error = str(error).splitlines()[0]
    behaviour: dict[str, BehaviourReport] = {}
    harness: Harness | None = None
    if source_path is not None and find_clang() is not None:
        try:
            behaviour, harness = differential_test(Path(source_path), decompiled_path, decompiled, opt, out / "harness")
        except VerifyError as error:
            behaviour = {name: BehaviourReport(name, 0, [], {}, reason=str(error).splitlines()[0]) for name in decompiled}
    else:
        reason = "no original source was given" if source_path is None else "clang is not on PATH"
        behaviour = {name: BehaviourReport(name, 0, [], {}, reason=reason) for name in decompiled}
    report_path = out / "report.json"
    outputs["report"] = str(report_path)
    report = evidence_report(object_path, opt, decompiled, behaviour, byte_compare, harness, recompile_error, outputs)
    report_path.write_text(json.dumps(report, indent=2) + "\n", encoding="utf-8")
    return report

Solutions

Solution
  1. Masking relocations

Relocation fields are placeholders the linker fills in; their bytes depend on where things land in each build. Comparing them would report differences that do not matter, so they are masked and the targets are compared separately.

Solution
  1. A table, not a switch

The compiler turned the switch into an array lookup because the cases were dense. The decompiler reports what the machine code does; printing it back as a switch would be a guess about the source, not a reading of the binary.

Solution
  1. What is gone

Local variable names, comments, macro names and the original formatting, plus any code the optimizer removed. Some types and structure can be inferred; those cannot.

Why this came about

NumPy arrays hold numbers of one type, but real business data is a table: order IDs (text), cities (text), amounts (numbers), dates, true/false flags. In 2008 Wes McKinney, then working at a hedge fund, started pandas to make that kind of table as easy to handle in Python as in a spreadsheet or SQL, but scriptable and repeatable. It became the standard tool for preparing data, and data preparation is most of the work in any AI project: training examples, evaluation setslater · 1.3, and the documents and logs an agent reads.

In plain words first
A spreadsheet you control with code

A DataFrame is a table: each column has a name and holds one kind of value, and each row is one record (one order, one customer). You can do everything you would do in a spreadsheet (filter, sort, add a calculated column, make a pivot table, look values up in another sheet), but by writing a line of code, so you can repeat it on tomorrow's data in one click and see exactly what was done.

Step 1 · A first table

pandas works with tables. Its main object, the DataFrame, has named columns and numbered rows, like a spreadsheet. Real data usually arrives as a CSV file (comma-separated values); here the CSV is a string inside the program so that the example runs anywhere. Load it and take a first look:

import pandas as pd                       # pd is the standard alias
from io import StringIO

csv_text = """order_id,city,amount,paid,ordered_on
SK-1,Pune,540,True,2026-11-01
SK-2,Delhi,1299,False,2026-11-01
SK-3,Pune,89,True,2026-11-02
SK-4,Goa,45,True,2026-11-03
SK-5,Delhi,300,True,2026-11-03
SK-6,Pune,,False,2026-11-04
"""
df = pd.read_csv(StringIO(csv_text), parse_dates=["ordered_on"])   # StringIO lets a string act like a file
print(df)
print(df.shape)
print(df.dtypes)

Step 2 · Selecting columns and rows

The first thing you do with a table is pick parts of it. One column name in square brackets gives a single column; a list of names gives a smaller table. For single cells there are two tools: loc finds by label, iloc by position counted from 0.

print(df["city"].tolist())                       # one column (a Series) as a list
print(df[["order_id", "amount"]].head(3))        # several columns: a list of names inside []
print(df.loc[1, "city"], df.iloc[0, 2])          # loc: by labels; iloc: by positions
What you should see
['Pune', 'Delhi', 'Pune', 'Goa', 'Delhi', 'Pune']
  order_id  amount
0     SK-1   540.0
1     SK-2  1299.0
2     SK-3    89.0
Delhi 540.0
You want Write Gives
One column df["amount"] A Series: one column with its index
Several columns df[["order_id", "amount"]] A smaller DataFrame (note the double brackets: a list of names)
Rows and columns by label df.loc[1, "city"], df.loc[0:2, ["city"]] Uses index labels and column names; 0:2 includes 2
Rows and columns by position df.iloc[0, 2], df.iloc[:3, :2] Like NumPy: counts from 0, end excluded

Step 3 · Filtering, new columns and sorting

Filtering works exactly like NumPy masks (Lesson F1.6): a comparison gives a True/False Series, and df[mask] keeps the True rows.

paid_pune = df[(df["city"] == "Pune") & (df["paid"])]     # & means "and"; put each condition in brackets
print(paid_pune[["order_id", "amount"]])

df["amount_with_gst"] = (df["amount"] * 1.05).round(2)   # a new column from an old one
df["size"] = pd.cut(df["amount"], bins=[0, 100, 500, 10_000], labels=["small", "medium", "large"])
print(df[["order_id", "amount", "amount_with_gst", "size"]])
print(df.sort_values("amount", ascending=False)["order_id"].tolist())

2     SK-3    89.0
  order_id  amount  amount_with_gst    size
0     SK-1   540.0           567.00   large
1     SK-2  1299.0          1363.95   large
2     SK-3    89.0            93.45   small
3     SK-4    45.0            47.25   small
4     SK-5   300.0           315.00  medium
5     SK-6     NaN              NaN     NaN
['SK-2', 'SK-1', 'SK-5', 'SK-3', 'SK-4', 'SK-6']

Use & (and), | (or) and ~ (not) to combine conditions in pandas, with brackets around each one. The words and / or do not work on whole columns. pd.cut puts each number into a labelled range, a common way to turn a number into a category. The missing amount stays missing in every derived column, and sort_values puts it last.

Step 4 · Missing values

Real tables have holes. pandas marks a missing value as NaN ("not a number"). Before you compute anything, count the holes and decide what to do with them: ignore them, fill them with a value, or drop the rows. Each choice gives a different answer, as the three means below show.

print(df["amount"].isna().sum(), "missing amount(s)")
print(df["amount"].mean().round(2), "mean, ignoring the missing one")
filled = df["amount"].fillna(0)
print(filled.mean().round(2), "mean if missing counts as 0")
complete = df.dropna(subset=["amount"])
print(len(df), "->", len(complete), "rows after dropping incomplete ones")
What you should see
1 missing amount(s)
454.6 mean, ignoring the missing one
378.83 mean if missing counts as 0
6 -> 5 rows after dropping incomplete ones

The two means differ: pandas skips missing values by default, but filling them with 0 drags the mean down. There is no universally right choice. Ask why the value is missing (not yet paid? a broken export?) before deciding to drop it, fill it, or keep it as missing. The same question appears when you clean data for evaluating AI systems in Chapter 12.

Step 5 · Summarising with groupby

groupby answers questions like "total sales per city" in one line. It splits the rows into groups, applies a calculation to each group, and combines the results.

print(df.groupby("city")["amount"].sum())
summary = df.groupby("city").agg(orders=("order_id", "count"),
                                 revenue=("amount", "sum"),
                                 avg_order=("amount", "mean")).round(1)
print(summary.sort_values("revenue", ascending=False))
print(df.groupby(df["ordered_on"].dt.day_name())["amount"].sum())

agg lets you compute several summaries at once, each written as new_name=(column, function). df["ordered_on"].dt.day_name() extracts the weekday from each date; .dt gives access to date parts the way .str gives access to string methods (df["city"].str.upper()). Notice that orders for Pune is 3 but its revenue includes only two amounts: count counts rows, sum skips missing values. And Wednesday shows 0.0: its only order (SK-6) has a missing amount, and the sum of nothing is 0. A zero that really means "unknown" is a classic reporting mistake, which is why it pays to look at counts next to sums.

Step 6 · Joining two tables

Data often lives in several tables linked by an ID, exactly like a database. merge joins them:

customers = pd.DataFrame({"order_id": ["SK-1", "SK-2", "SK-3", "SK-7"],
                          "customer": ["Asha", "Ravi", "Asha", "Meera"]})
joined = df.merge(customers, on="order_id", how="left")      # keep every order, add the customer if known
print(joined[["order_id", "city", "amount", "customer"]])
print(joined.groupby("customer")["amount"].sum())
What you should see
  order_id   city  amount customer
0     SK-1   Pune   540.0     Asha
1     SK-2  Delhi  1299.0     Ravi
2     SK-3   Pune    89.0     Asha
3     SK-4    Goa    45.0      NaN
4     SK-5  Delhi   300.0      NaN
5     SK-6   Pune     NaN      NaN
customer
Asha     629.0
Ravi    1299.0
Name: amount, dtype: float64

how="left" keeps every row of the left table (df) and fills in matches from the right; orders without a known customer get a missing value. how="inner" would keep only orders that appear in both tables, so SK-4, SK-5 and SK-6 would disappear (and Meera's SK-7, which has no order details, would not appear either). Choosing the wrong join is a classic way to lose or duplicate rows silently: always compare row counts before and after.

Step 7 · A quick chart

pandas can draw charts through the matplotlib library. In a notebook the chart appears under the cell; in a script you save it to a file.

import matplotlib
matplotlib.use("Agg")                   # draw to files only (no window); not needed in notebooks
import matplotlib.pyplot as plt

ax = df.groupby("city")["amount"].sum().sort_values().plot(kind="barh", title="Revenue by city (INR)")
ax.set_xlabel("INR")
plt.tight_layout()
plt.savefig("revenue_by_city.png", dpi=120)
plt.close()
from pathlib import Path
print(Path("revenue_by_city.png").exists())
What you should see
True

Open revenue_by_city.png to see three horizontal bars, Goa shortest and Delhi longest. Charts are the fastest way to spot problems in data: a city with zero orders, a sudden spike, a column that should never be negative.

Check your mental model
  • ✗ "df[df["city"] == "Pune" and df["paid"]] filters on both conditions."
    ✓ Use & with brackets: df[(df["city"] == "Pune") & (df["paid"])].
  • ✗ "count and sum see the same rows."
    ✓ count (of a column) skips missing values too, but counting order_id counts every order, while sum of amount skips the missing amount.
  • ✗ "A join never changes the number of rows."
    ✓ Inner joins drop unmatched rows; duplicate keys multiply rows. Check counts before and after.
  • ✗ "df.loc[0:2] and df.iloc[0:2] give the same rows."
    ✓ loc slices by label and includes the end (rows 0, 1, 2); iloc by position, excluding the end (rows 0, 1).

Exercises

Predict before you run

What does df["paid"].sum() return, and why does summing a True/False column make sense? (Solution P1.)

Debugging exercise

df[df["amount"] > 100 & df["paid"]] raises an error or gives a strange result. Why, and what is the fix? (Solution D1.)

Make it your own

Add a column weekday with the day name of each order, then build a table of revenue per city per weekday with df.pivot_table(index="city", columns="weekday", values="amount", aggfunc="sum"). Which cells are empty, and why? (Solution M1.)

Solutions

SolutionP1 · Counting with sum

It returns 4. In arithmetic True counts as 1 and False as 0, so summing a True/False column counts the True values: four orders are paid. df["paid"].mean() would give the share that are paid, about 0.67.

SolutionD1 · Operator precedence

& binds more tightly than >, so Python reads it as df["amount"] > (100 & df["paid"]), which is not what you meant. Always bracket each condition: df[(df["amount"] > 100) & (df["paid"])].

SolutionM1 · A pivot table
df["weekday"] = df["ordered_on"].dt.day_name()
print(df.pivot_table(index="city", columns="weekday", values="amount", aggfunc="sum"))

Empty cells (NaN) mean no orders for that city on that day, for example Goa had orders only on one day. A pivot table is a groupby on two keys laid out as a grid; it is the pandas equivalent of a spreadsheet pivot.

Recap
  • A DataFrame is a table of named, typed columns with a row index; a single column is a Series.
  • First looks: head, shape, dtypes, describe, value_counts.
  • Select with df["col"], loc (labels) and iloc (positions); filter with bracketed conditions joined by &, |, ~.
  • Handle missing values deliberately; summarise with groupby(...).agg(...); join tables with merge and check row counts.
  • Save charts with matplotlib to see problems quickly.

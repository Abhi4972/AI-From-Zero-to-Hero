The problem

In plain words first

Autocomplete is the oldest language model there is: count which words follow which, and suggest the most common next word. Before neural networks, this was how phones predicted text. This project builds one you can fully inspect: it counts single words and one- or two-word histories from a small corpus, suggests completions for what you are typing, and shows for each suggestion how often it was seen and in which source text.

It is a good bridge to the n-gram lessons: the same counting, turned into a writing tool.

Help a writer reuse their own terminology with a small local autocomplete model built from token counts, prefixes and short word histories. Show the evidence behind each suggestion and export an interactive writing pad plus a portable vocabulary model for another editor.

You build a local autocomplete writing page and vocabulary-model.json.

Step 1 · Tokenize a corpus and count word histories

Step 1 of 4 · about 2 hours · TypeScript

What you build. Count words and one- or two-word histories without crossing sentence boundaries.

Public contract.

tokenize(text: string): string[]; train(corpus: unknown): Model

Input corpus is {id:string,text:string}[] with unique nonempty ids. Normalize NFC and lowercase. Tokens contain Unicode letters/numbers and internal apostrophes. Split sentences at period, question mark, exclamation mark or newline. Model {schemaVersion:1,words,histories,sources} maps tokens to counts, JSON-encoded histories to next-word counts and words to source ids.

Worked example. Corpus Garden club shares seeds. Garden club grows herbs. counts garden=2, club=2 and records ["garden","club"] -> {shares:1,grows:1}. No transition is recorded from seeds to garden.

Failure cases and hints. Use dictionaries safe for tokens such as constructor. Do not learn a transition across sentences. Sources must stay inspectable.

Step 2 · Rank prefix and next-word candidates

Step 2 of 4 · about 2 hours · TypeScript

What you build. Rank candidates by the longest observed history and show the underlying count.

Public contract.

suggest(model: Model, prefix: string, history?: string[], limit?: number): Suggestion[]

Normalize the prefix; filter words by startsWith. For each word use the longest matching suffix history (2 then 1), otherwise its unigram count. Sort by order descending, count descending, then lexical word. Return {word,score,order,count,sources}; score is order * 1000000 + count for display, sorting uses separate order/count. limit defaults to 5 and must be an integer 0..50.

Worked example. For prefix s after history ["garden","club"], shares with order 2/count 1 precedes seed with order 0/count 20. A low raw count can still be stronger conditional evidence.

Failure cases and hints. Unseen history backs off. A prefix with no candidates returns []; no remote completion is fabricated.

Longest history wins
import re
from collections import Counter
corpus = ["Garden club grows native flowers. Garden club shares native seeds. Native seeds welcome bees.",
          "Garden club shares native seeds. Garden club grows leafy herbs. Leafy herbs need shade.",
          "Garden club shares tools. Garden club shares seeds. Native flowers welcome bees."]
uni, bi, tri = Counter(), Counter(), Counter()
for text in corpus:
    for sent in re.split(r"[.!?]", text.lower()):
        w = re.findall(r"\w+", sent)
        uni.update(w); bi.update(zip(w, w[1:])); tri.update(zip(w, w[1:], w[2:]))

def suggest(prefix, history):
    out = []
    for word in sorted(u for u in uni if u.startswith(prefix)):
        if len(history) >= 2 and tri[(*history[-2:], word)]: out.append((2, tri[(*history[-2:], word)], word))
        elif history and bi[(history[-1], word)]: out.append((1, bi[(history[-1], word)], word))
        else: out.append((0, uni[word], word))
    return sorted(out, key=lambda t: (-t[0], -t[1], t[2]))

print(suggest("sh", ["garden", "club"]))

Reading this output

"shares" follows "garden club" four times in the corpus, so it is ranked on its two-word history (order 2, count 4). "shade" never follows "garden club" or "club", so it falls back to its plain word count (order 0, count 1). The order comes first in the sort, so a word seen after this exact history always beats a word that is merely common.

Step 3 · Accept suggestions in a writing pad

Step 3 of 4 · about 2 hours · TypeScript

What you build. Distinguish an unfinished token from a completed word before inserting a suggestion.

Public contract.

completeText(model: Model, text: string, limit?: number): {prefix:string;history:string[];suggestions:Suggestion[]}; acceptSuggestion(text:string,prefix:string,word:string):string

Use only the text after the final sentence boundary. If it ends in a word character/apostrophe, pop the final token as prefix; otherwise prefix is empty. History is the last two complete tokens. Acceptance replaces the exact suffix prefix and adds one space. Require a normalized single-token suggestion.

Worked example. Garden club sh becomes prefix sh and history [garden,club]. Accepting shares produces Garden club shares, preserving earlier text. A space after club means an empty prefix.

Failure cases and hints. After a period, history resets. Do not append a completion to the prefix instead of replacing it. Reject stale prefixes.

export type Model = {
  schemaVersion: 1;
  words: Record<string, number>;
  histories: Record<string, Record<string, number>>;
  sources: Record<string, string[]>;
};
export type Suggestion = {
  word: string;
  score: number;
  order: number;
  count: number;
  sources: string[];
};

export function tokenize(text: string): string[] {
  return (
    text
      .normalize("NFC")
      .toLowerCase()
      .match(/[\p{L}\p{N}]+(?:['’][\p{L}\p{N}]+)*/gu) ?? []
  );
}
export function train(corpus: unknown): Model {
  const rows = array(corpus, "corpus"),
    words: Record<string, number> = Object.create(null),
    histories: Record<string, Record<string, number>> = Object.create(null),
    sources: Record<string, string[]> = Object.create(null),
    ids = new Set<string>();
  for (const row of rows) {
    const id = nonempty(row.id, "source id"),
      text = nonempty(row.text, "source text");
    if (ids.has(id)) throw Error("Duplicate source id");
    ids.add(id);
    for (const sentence of text.split(/[.!?\n]+/)) {
      const tokens = tokenize(sentence);
      tokens.forEach((word, i) => {
        words[word] = (words[word] ?? 0) + 1;
        sources[word] = [...new Set([...(sources[word] ?? []), id])];
        for (let n = 1; n <= Math.min(2, i); n++) {
          const key = JSON.stringify(tokens.slice(i - n, i));
          histories[key] ??= Object.create(null);
          histories[key][word] = (histories[key][word] ?? 0) + 1;
        }
      });
    }
  }
  return { schemaVersion: 1, words, histories, sources };
}
export function suggest(
  model: Model,
  prefix: string,
  history: string[] = [],
  limit = 5,
): Suggestion[] {
  if (!Number.isInteger(limit) || limit < 0 || limit > 50)
    throw Error("limit must be 0..50");
  const p = prefix.normalize("NFC").toLowerCase(),
    h = history.flatMap(tokenize).slice(-2);
  return Object.keys(model.words)
    .filter((w) => w.startsWith(p))
    .map((word) => {
      let order = 0,
        count = model.words[word];
      for (let n = Math.min(2, h.length); n >= 1; n--) {
        const c = model.histories[JSON.stringify(h.slice(-n))]?.[word];
        if (c) {
          order = n;
          count = c;
          break;
        }
      }
      return {
        word,
        score: order * 1000000 + count,
        order,
        count,
        sources: [...(model.sources[word] ?? [])],
      };
    })
    .sort(
      (a, b) =>
        b.order - a.order ||
        b.count - a.count ||
        b.score - a.score ||
        a.word.localeCompare(b.word),
    )
    .slice(0, limit);
}
export function completeText(
  model: Model,
  text: string,
  limit = 5,
): { prefix: string; history: string[]; suggestions: Suggestion[] } {
  const boundary = text.search(/[^.!?\n]*$/),
    tail = text.slice(boundary),
    tokens = tokenize(tail),
    partial = /[\p{L}\p{N}'’]$/u.test(tail),
    prefix = partial ? tokens.pop() ?? "" : "";
  return {
    prefix,
    history: tokens.slice(-2),
    suggestions: suggest(model, prefix, tokens.slice(-2), limit),
  };
}
export function acceptSuggestion(
  text: string,
  prefix: string,
  word: string,
): string {
  if (
    !tokenize(word).length ||
    tokenize(word).length !== 1 ||
    tokenize(word)[0] !== word
  )
    throw Error("Suggestion must be one normalized token");
  if (prefix && !text.toLowerCase().endsWith(prefix.toLowerCase()))
    throw Error("Prefix does not match text");
  return text.slice(0, text.length - prefix.length) + word + " ";
}
export function importModel(value: unknown): Model {
  const m = value as Model;
  if (!m || m.schemaVersion !== 1) throw Error("Unsupported model schema");
  for (const field of ["words", "histories", "sources"])
    if (
      !(m as any)[field] ||
      typeof (m as any)[field] !== "object" ||
      Array.isArray((m as any)[field])
    )
      throw Error("Invalid model " + field);
  for (const [w, n] of Object.entries(m.words)) {
    if (
      tokenize(w).length !== 1 ||
      tokenize(w)[0] !== w ||
      !Number.isSafeInteger(n) ||
      n <= 0
    )
      throw Error("Invalid word count");
    if (
      !Array.isArray(m.sources[w]) ||
      m.sources[w].some((s) => typeof s !== "string" || !s)
    )
      throw Error("Missing sources");
  }
  for (const [key, counts] of Object.entries(m.histories)) {
    let h;
    try {
      h = JSON.parse(key);
    } catch {
      throw Error("Invalid history key");
    }
    if (
      !Array.isArray(h) ||
      h.length < 1 ||
      h.length > 2 ||
      h.some((w) => typeof w !== "string" || !Object.hasOwn(m.words, w))
    )
      throw Error("Invalid history");
    if (!counts || typeof counts !== "object" || Array.isArray(counts))
      throw Error("Invalid history counts");
    for (const [w, n] of Object.entries(counts))
      if (
        !Object.hasOwn(m.words, w) ||
        !Number.isSafeInteger(n) ||
        n <= 0 ||
        n > m.words[w]
      )
        throw Error("Invalid conditional count");
  }
  return structuredClone(m);
}

export function escapeHTML(value: unknown): string {

    (c) =>

  );
}

}
export function nonempty(value: unknown, label: string): string {
  if (typeof value !== "string" || !value.trim())
    throw new Error(label + " must be a nonempty string");
  return value;
}

Where the project stops

This is a transparent count-based local language model, not a hosted LLM. It suggests a single next token with up to two tokens of context. The browser editor operates at the end of input. No provider adapter is implied.

Break it on purpose

A first version counts word pairs across the whole corpus as one string, so "bees" (end of the spring text) is followed by "garden" (start of the next). The pad now suggests "garden" after "bees". What is the fix? (Solution B1.)

Recap
What to keep from this project
  • Count words and one- and two-word histories inside sentences only.
  • Rank by the longest history seen, then by count, then alphabetically.
  • Keep sources with every count so suggestions explain themselves.
  • Validate an imported model before using it.

Exercises

  1. Track paragraph provenance in addition to source identity. (step 1)
  2. Add smoothing while preserving raw evidence counts. (step 2)
  3. Support caret-position editing rather than the documented end-of-input position. (step 3)
  4. Package suggest as an editor plugin. (step 4)

Solutions

Solution
  1. Paragraph provenance

Store (source id, paragraph index) instead of just the source id in each count's source list, and update the import validation to accept the new shape with a schema version bump.

Solution
  1. Smoothing without losing evidence

Compute a smoothed score (for example back-off weights or add-k) only for ranking, and keep the raw order and count in each suggestion. A reader can then see when smoothing promoted a word that was never seen in this context.

Solution
  1. Editing at the caret

Take the text before the caret instead of the whole text, find the unfinished word and history there, and insert the accepted word at the caret, replacing only the prefix.

Solution
  1. An editor plugin

Wrap suggest and acceptSuggestion behind the editor's completion interface, load the exported model once, and show the evidence (count and sources) in the completion detail.

SolutionB1 · Pairs across texts

Tokenize each text and each sentence separately, and build histories inside a sentence only. Pairs that span a boundary are artifacts of concatenation, not language.

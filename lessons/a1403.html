In plain words first
The idea in one line

Gradient-based RL needs thousands of trials and a GPU cluster to fix a failure mode. Reflexion (Shinn et al., NeurIPS 2023) does it in natural language: after each failed trial, the agent writes a reflection, stores it in episodic memory, and conditions the next trial on that memory. This is the pattern behind Letta's sleep-time compute, Claude Code's CLAUDE.md learnings, and pro-workflow's learn-rule.

Terms you'll hear
Term What people say What it actually means
Reflexion "Self-correction" Shinn et al. 2023 — Actor, Evaluator, Self-Reflector plus episodic memory
Verbal reinforcement "Learning without gradients" Natural-language reflection prepended to the next trial's prompt
Episodic memory "Per-task reflections" Bounded buffer of prior reflections for one task class

Heuristic evaluator "Pattern-based detector" Predefined failure signatures (e.g. stuck-loop, too-many-steps)

The problem

In plain words first

When an agent fails, the usual machine-learning fix is to train it more, which is slow and expensive. Reflexion tries something cheaper. After a failed attempt, the agent writes a short note to itself about what went wrong ("I forgot that y counts as a vowel only at the end"), keeps the note in a small memory, and tries again with the note in its prompt. The model itself never changes; only the text it reads does. Three parts make it work: an actor that attempts the task, an evaluator that says pass or fail, and a self-reflector that writes the note. This lesson builds it with a scripted actor, then lets a real small model write code, be graded by real unit tests, and reflect on its failures.

An agent fails a task. In standard RL you would run thousands more trials, compute gradients, update weights. Expensive, slow, and most production agents do not have a training budget for every failure.

Reflexion (Shinn et al., arXiv:2303.11366) asks a different question: what if the agent just thought about why it failed and tried again with that thought in its prompt? No weight updates. No gradient. Just natural language stored between trials.

The result: on ALFWorld it beats ReAct and other non-fine-tuned baselines. On HotpotQA it improves over ReAct. On code generation it reached 91% pass@1 on HumanEval, above GPT-4's 80% at the time, though it did not lead on every coding benchmark. All without a single gradient step.

Idea 1 · The three components

Actor         : generates a trajectory (ReAct-style loop)
Evaluator     : scores the trajectory — binary, heuristic, or self-eval
Self-Reflector: writes a natural-language reflection on the failure

Plus one data structure:

Episodic memory: list of prior reflections, prepended to the next trial's prompt

One trial runs the Actor. Evaluator scores it. If the score is low, Self-Reflector produces a reflection ("I picked the wrong tool because I misread the question as asking about X when it was asking about Y"). The reflection goes into episodic memory. Next trial starts fresh but sees the reflection.

Idea 2 · Three evaluator types

  1. Scalar — an external binary signal. ALFWorld succeeds or fails. HumanEval tests pass or fail. Simplest, highest-signal.
  2. Heuristic — predefined failure signatures. "If the agent produced the same action twice in a row, mark as stuck." "If the trajectory exceeds 50 steps, mark as inefficient."
  3. Self-evaluated — the LLM scores its own trajectory. Needed when no ground truth is available. Weaker signal; pairs well with tool-grounded verification (Lesson 14.5 — CRITIC).

The 2026 default is a mix: scalar when available, self-eval when not, heuristics as safety rails.

Idea 3 · Why this generalizes

Reflexion is not a new algorithm so much as a named pattern. Almost every production "self-healing" agent runs some variant:

  • Letta's sleep-time compute (Lesson 14.8): a separate agent reflects on past conversations and writes to memory blocks.
  • Claude Code's CLAUDE.md / "save memory" pattern: reflections captured as learnings, prepended to future sessions.
  • pro-workflow's /learn-rule command: corrections captured as explicit rules.
  • LangGraph's reflection nodes: a node that scores output and routes to refine if needed.

All derive from the same insight: natural language is a rich-enough medium to carry "what I learned from failure" between runs.

Idea 4 · When it works and when it does not

Reflexion works when:

  • There is a clear failure signal (test failure, tool error, wrong answer).
  • The task class is reproducible (the same type of question can be asked again).
  • The reflection has room to improve on the trajectory (enough action budget).

Reflexion does not help when:

  • The agent already succeeds on the first try.
  • The failure is external (network down, tool broken) — reflection on "the network was down" does not help future runs.
  • The reflection turns into superstition — storing a narrative about a one-off flaky run.

2026 pitfall: memory rot. Reflections accumulate; some are obsolete or wrong; re-runs get slower as the episodic buffer grows. Mitigation: periodic compaction (Lesson 14.6), TTL on reflections, or a separate sleep-time cleanup agent (Letta).

The same idea as a formula

One trial. With task x, episodic memory mk​ (the reflections so far), actor π, evaluator E and reflector R:

τk​=π(x,mk​),rk​=E(τk​)∈{0,1},mk+1​=mk​∪{R(x,τk​,rk​)}  if rk​=0.
The weights of π never change; only m does.

Why plain retries are not enough. If the actor is deterministic (greedy decoding) and m does not change, then τk+1​=τk​: the retry is the same attempt. With sampling, independent retries succeed with probability

P(pass within K)=1−(1−p)K
for a per-try pass rate p. Reflexion hopes to do better than this by making later tries depend on what earlier ones learned.

Worked example
What memory adds on top of sampling
  • Suppose a model passes a task 20% of the time with sampling, p=0.2.
  • Three independent tries: 1−0.83=1−0.512=0.488, just under half.
  • If a correct reflection after a failure raised the next try to p=0.5, three tries would give 1−0.8⋅0.5⋅0.5=0.8.
  • If the reflection is wrong and lowers the next try to p=0.1, three tries give 1−0.8⋅0.9⋅0.9=0.352, worse than not reflecting.
  • So the value of Reflexion is exactly the quality of the notes. The second block below shows a wrong one.
Check your mental model
  • ✗ "Reflexion trains the model."
    ✓ It changes only the prompt; the same weights read a longer memory.
  • ✗ "Any failure signal works."
    ✓ A clear external signal (tests, a checker) is what makes the notes useful; self-scored failures are weaker.
  • ✗ "Retrying is the same as reflecting."
    ✓ A greedy retry repeats itself exactly; only new information in the prompt changes the next attempt.
  • ✗ "Every stored reflection is a lesson."
    ✓ Some are wrong; a wrong note in memory steers every later attempt.

# Reflexion with a real model and a real scalar evaluator: Qwen2.5-0.5B-Instruct (greedy, CPU) writes a
# Python function, hidden unit tests judge it, and on failure the same model writes a one-line reflection
# that goes into the lesson's EpisodicMemory for the next trial.
import ast, os, re, subprocess, sys, tempfile, textwrap, time, torch
os.environ.setdefault("HF_HUB_OFFLINE", "1")            # the model is already in the local cache
from transformers import AutoTokenizer, AutoModelForCausalLM, logging as hf_logging
hf_logging.set_verbosity_error(); hf_logging.disable_progress_bar()
from main import EpisodicMemory, Reflection
M = "Qwen/Qwen2.5-0.5B-Instruct"
tok = AutoTokenizer.from_pretrained(M); llm = AutoModelForCausalLM.from_pretrained(M).eval()
def chat(text, max_new=160):
    ids = tok.apply_chat_template([{"role": "user", "content": text}], add_generation_prompt=True,
                                  return_tensors="pt", return_dict=True)["input_ids"]
    with torch.no_grad():
        out = llm.generate(ids, max_new_tokens=max_new, do_sample=False)
    return tok.decode(out[0, ids.shape[1]:], skip_special_tokens=True).strip()

TASKS = {   # name: (specification, hidden tests)
    "vowels_count": ("vowels_count(s) returns how many vowels the string s has. Vowels are a, e, i, o, u "
                     "(either case), and y counts as a vowel only when it is the last letter of s.",
                     ["vowels_count('abcde') == 2", "vowels_count('ACEDY') == 3", "vowels_count('key') == 2",
                      "vowels_count('yellow') == 2", "vowels_count('') == 0"]),
    "second_largest": ("second_largest(nums) returns the second largest distinct value in the list nums, "
                       "or None if there are fewer than two distinct values.",
                       ["second_largest([3, 1, 2]) == 2", "second_largest([5, 5, 4]) == 4",
                        "second_largest([7, 7]) is None", "second_largest([]) is None", "second_largest([-1, -2]) == -2"]),
    "rle": ("rle(s) run-length encodes s: each run of a character becomes the character followed by the run "
            "length, so rle('aaabcc') == 'a3b1c2'.",
            ["rle('aaabcc') == 'a3b1c2'", "rle('') == ''", "rle('z') == 'z1'", "rle('aabbaa') == 'a2b2a2'"]),
}
def extract(text):
    """The code block, keeping only imports and definitions (models often append their own asserts)."""
    m = re.search(r"```(?:python)?\n(.*?)```", text, re.S)
    code = m.group(1) if m else text
    try:
        tree = ast.parse(code)
    except SyntaxError:
        return code
    keep = [n for n in tree.body if isinstance(n, (ast.Import, ast.ImportFrom, ast.FunctionDef, ast.ClassDef))]
    return "\n\n".join(ast.unparse(n) for n in keep) + "\n"
def evaluate(code, tests):
    """Scalar evaluator: run the hidden tests in a fresh interpreter; return (passed, first failure)."""
    body = code + "\n\n" + "\n".join(f"assert {t}, {t!r}" for t in tests) + "\nprint('ALL PASS')\n"
    with tempfile.NamedTemporaryFile("w", suffix=".py", delete=False) as f:
        f.write(body)
    r = subprocess.run([sys.executable, f.name], capture_output=True, text=True, timeout=10)
    if "ALL PASS" in r.stdout:
        return True, ""
    lines = [l for l in r.stderr.strip().splitlines() if l.strip()]
    return False, lines[-1][:160] if lines else "no output"
ACT = "Write a Python function. {spec}\nReply with only the code in one ```python block.{memory}"
REFLECT = ("Your function failed a test.\nTask: {spec}\nYour code:\n```python\n{code}```\nTest result: {error}\n"
           "In one sentence, say what was wrong and what to do differently next time. Do not write code.")
def run(name, use_memory, trials=3):
    spec, tests = TASKS[name]; memory = EpisodicMemory()
    history, history_code = [], []
    for trial in range(1, trials + 1):
        notes = memory.as_prompt() if use_memory and memory.items else ""
        code = extract(chat(ACT.format(spec=spec, memory=f"\n\nLessons from earlier attempts:\n{notes}" if notes else "")))
        ok, error = evaluate(code, tests)
        if not use_memory and history_code and code == history_code[-1]:     # greedy decoding repeats itself
            history.append("same code"); break
        history_code.append(code)
        history.append("pass" if ok else "fail")
        if ok: break
        if use_memory:
            reflection = chat(REFLECT.format(spec=spec, code=code, error=error), max_new=60)
            memory.add(Reflection(trial=trial, text=" ".join(reflection.split())))
            print(f"   {name} trial {trial} failed: {error}\n      reflection: {' '.join(reflection.split())[:150]}")
    MEMORIES[name, use_memory] = memory
    return history
MEMORIES = {}
started = time.perf_counter()
print(f"{'task':<16}{'retry, no memory':<26}{'Reflexion'}")
results = {}
for name in TASKS:
    results[name] = (run(name, False), run(name, True))
for name, (plain, reflexion) in results.items():
    print(f"{name:<16}{' '.join(plain):<26}{' '.join(reflexion)}")
print(f"seconds {time.perf_counter() - started:.0f}")

Components:

  • Actor — a scripted policy that improves when it sees reflections.
  • Evaluator.binary() — pass/fail on the target sum.

Part 1 of 3 · Reflection, EpisodicMemory, Actor, binary_evaluator, SelfReflector, TrialResult, TARGET

"""Toy Reflexion loop — Actor, Evaluator, Self-Reflector, Episodic memory.

Task: pick three integers from 1..9 that sum to a target. The Actor is
scripted to start with a bad strategy and adapt when reflections are present.
"""

from __future__ import annotations

from dataclasses import dataclass, field


TARGET = 20


@dataclass
class Reflection:
    trial: int
    text: str


@dataclass
class EpisodicMemory:
    items: list[Reflection] = field(default_factory=list)
    max_len: int = 6

    def add(self, r: Reflection) -> None:
        self.items.append(r)
        if len(self.items) > self.max_len:
            self.items.pop(0)

    def as_prompt(self) -> str:
        if not self.items:
            return "(no prior reflections)"
        lines = [f"- trial {r.trial}: {r.text}" for r in self.items]
        return "\n".join(lines)


class Actor:
    """Scripted policy. Without reflections it stays on bad choices; with
    at least one reflection it moves toward the target sum."""

    def act(self, memory: EpisodicMemory) -> list[int]:
        n = len(memory.items)
        if n == 0:
            return [1, 2, 3]
        if n == 1:
            return [5, 6, 7]
        if n == 2:
            return [6, 7, 7]
        return [6, 7, 7]


def binary_evaluator(attempt: list[int], target: int) -> tuple[bool, int]:
    total = sum(attempt)
    return total == target, total - target


class SelfReflector:
    def reflect(self, attempt: list[int], delta: int) -> str:
        if delta < 0:
            return f"sum {sum(attempt)} is {-delta} short; pick larger values"
        if delta > 0:
            return f"sum {sum(attempt)} overshoots by {delta}; pick smaller values"
        return "succeeded"


@dataclass
class TrialResult:
    trial: int
    attempt: list[int]
    success: bool
    delta: int
    reflection: str

Part 2 of 3 · run_reflexion, summarize

def run_reflexion(max_trials: int, use_memory: bool) -> list[TrialResult]:
    actor = Actor()
    reflector = SelfReflector()
    memory = EpisodicMemory()
    trials: list[TrialResult] = []
    for t in range(1, max_trials + 1):
        attempt = actor.act(memory if use_memory else EpisodicMemory())
        success, delta = binary_evaluator(attempt, TARGET)
        text = reflector.reflect(attempt, delta)
        trials.append(TrialResult(t, attempt, success, delta, text))
        if success:
            break
        memory.add(Reflection(trial=t, text=text))
    return trials


def summarize(trials: list[TrialResult], name: str) -> None:
    print(f"\n{name}")
    print("-" * 60)
    for r in trials:
        mark = "OK " if r.success else "..."
        print(f"  trial {r.trial}: {r.attempt} sum={sum(r.attempt)} "
              f"delta={r.delta:+d} {mark} -> {r.reflection}")
    last = trials[-1]
    print(f"  final: {'success' if last.success else 'failed'} "
          f"at trial {last.trial}")


def main() -> None:
    print("=" * 70)
    print(f"REFLEXION: pick three ints in [1..9] summing to {TARGET}")
    print("Phase 14, Lesson 03")
    print("=" * 70)

    trials_no_mem = run_reflexion(max_trials=4, use_memory=False)
    summarize(trials_no_mem, "BASELINE (no episodic memory)")

    trials_mem = run_reflexion(max_trials=4, use_memory=True)
    summarize(trials_mem, "REFLEXION (episodic memory on)")

    baseline_steps = len(trials_no_mem)
    reflex_steps = len(trials_mem)
    print()
    print(f"baseline used {baseline_steps} trials; reflexion used {reflex_steps}.")
    print("Without a reflection in the prompt, the scripted actor never adapts.")
    print("With one reflection, the actor corrects; with two, it converges.")

Use it: the same idea with real libraries

LangGraph ships reflection as a node pattern. Claude Code's /memory command and pro-workflow's /learn-rule externalize the episodic buffer as a markdown file. Letta's sleep-time compute runs the Self-Reflector on downtime so the primary agent stays latency-bound. OpenAI Agents SDK does not ship Reflexion directly; you build it with a custom Guardrail that rejects trajectories by score and a memory Session that survives across runs.

Break it on purpose

Keep every reflection forever, across all tasks of a kind, with no check on whether a note is true. After a few weeks the memory holds hundreds of notes, including the wrong one above ("The correct count should be 2"). What happens to new attempts, and what would you add? (Solution B1.)

Industry practice
What's current (2024–2026)
  • Reflection as memory files. Coding agents keep learnings in files the agent reads at the start of each session: CLAUDE.md in Claude Code (edited with /memory), AGENTS.md across several coding agents, rules files in Cursor. These are episodic memory with a person as the evaluator.
  • Sleep-time reflection. Letta's sleep-time agents rewrite memory blocks between conversations, off the user's critical path (lesson 14.8).
  • Graph nodes. LangGraph reflection recipes route an output to a critic node and back; the OpenAI Agents SDK's guardrails and sessions can be combined the same way.
  • What works best in practice is reflection grounded in an external signal: failing tests, a linter, a type checker, a schema validator. Self-judged reflection alone drifts.
  • On your laptop: the loop is cheap; the model's quality decides the notes. A 0.5B model writes wrong ones, as here. A 7B to 8B coding model in 4-bit on the RTX 4060 writes far better reflections and runs this lab in a few minutes.

Sources: Reflexion (arXiv:2303.11366), Claude Code memory, AGENTS.md, Letta, sleep-time compute, LangGraph reflection tutorial.

Recap
What to keep from this lesson
  • Reflexion: attempt, grade, write a note, retry with the note.
  • No weights change; only the prompt does.
  • A greedy retry without new information repeats itself.
  • The method is as good as its evaluator and its notes.
  • Wrong notes persist: give memory a check, an expiry and a size limit.

Given a task class (repeating kind of agent run — e.g. "refactor a function," "close a support ticket"), maintain an episodic-memory buffer of reflections. Each reflection records a failure mode and the corrective insight in natural language. The buffer is prepended to the next trial of the same task class.

Produce:

1. Reflection capture. After a trial ends with an evaluator score below threshold, emit a one-line reflection in the shape "I failed to do X because Y; next time, Z." Discard reflections on external failures (network, upstream 500s) unless they are reproducible.
2. TTL and dedup. Reflections expire after N trials by default (10 suggested). Exact duplicates collapse. Near-duplicates (>0.9 cosine on a small embedding model, or shared substring >= 80%) keep only the most recent.
3. Scope policy. Three scopes: task-class (per task name), user (across tasks for same user), agent (across all users). Default is task-class. Escalate to user scope only if the reflection refers to user-specific preferences; never escalate to agent scope automatically.
4. Compaction. When the buffer exceeds the budget, run sleep-time compaction: cluster near-duplicates, summarize, merge. Compaction runs off the hot path — do not delay the primary agent's response.
5. Prompt integration. Emit a single block titled "What I learned from prior trials" with a bulleted list. Cap at 6 items in the prompt; overflow goes to a separate summary item ("... and 4 older reflections about timeouts").

Hard rejects:

- Writing reflections as "be more careful next time." That is not actionable. Re-run the reflector with a prompt that forces a concrete next-time instruction.
- Expiring reflections based on wall-clock time rather than trial count. TTL should be trial-scoped, not time-scoped, for offline-replayable runs.
- Storing reflections that reference secrets (API keys, tokens, PII). Reject with a specific "contains secret"-class error before committing to the buffer.

Refusal rules:

- If no evaluator is attached, refuse and recommend Lesson 05 (Self-Refine/CRITIC) — reflection requires a signal, not a gut feeling.
- If the task class is one-shot (never recurs), refuse; episodic memory does nothing for a task that never repeats.

Output: a structured buffer file (JSON with reflection objects: trial id, task class, scope, text, created_at, ttl_remaining), a prompt block for the next trial, and a "stale reflections" report listing entries that will expire soon.

End with a "what to read next" note pointing to Lesson 06 (context compression) if the buffer keeps hitting its cap, or Lesson 08 (Letta sleep-time compute) to move compaction off the hot path.

Exercises

  1. Switch from binary to scalar evaluator that returns a distance metric (how far from target). Does it converge faster?
  2. Add a TTL of 10 trials to reflections. Do older reflections hurt or help after that point?
  3. Implement heuristic evaluator: mark the trial as stuck if the same action repeats. How does this interact with Self-Reflector?
  4. Run Reflexion with an adversarial Actor that ignores reflections. What is the minimum reflection prompt engineering that forces the Actor to notice them?
  5. Read Section 4 of the Reflexion paper on AlfWorld. Reproduce the 130% success-rate improvement conceptually: what is the key delta vs vanilla ReAct?

Solutions

SolutionP1 · Identical retries; one task fixed

With greedy decoding, a retry without memory sees the same prompt and writes the same code, so it fails the same way; the lab stops it after the second identical attempt. Reflexion ends with two passes out of three tasks: second_largest passes on the first try, rle passes on the second after a reflection about the empty string, and vowels_count fails all three trials because the reflections are vague or wrong.

SolutionB1 · Memory that only grows

Every new attempt starts with a long list of notes, some outdated, some contradictory, and some false, like "The correct count should be 2". The model has no way to tell which ones to trust, so a single wrong note can steer many later attempts. The prompt also grows with every failure, which costs tokens and pushes the task itself further from the model's attention.

Treat memory as data with a lifecycle. Keep a note only if the next attempt that used it passed (or a person approved it); attach the task type and date; expire notes after a time or a number of uses; cap the number of notes per task type (the lesson's EpisodicMemory keeps 6); and periodically compact or review them, which is the job Letta gives a sleep-time agent.

The problem

In plain words first

Agents call tools with arguments that match a schema. Change the schema (make a field required, close the object to extra fields, narrow an enum or a maximum) and some calls that used to work will now fail, often in production, often silently. This project finds those calls before you ship the change.

It loads the old and new tool contracts and a set of saved, real calls; classifies every schema change as compatible, breaking or unresolved; generates minimal example calls that would pass the old schema and fail the new one; replays the saved calls through both; and exports a report and a CI gate.

Step 2 · Classify supported schema changes

Step 2 of 4 · about 2 hours · Python

Compare before and after schemas to categorize changes into compatible, breaking, and unresolved keywords.

Read Step 1 before starting; this stage compares two loaded contracts.

What changes. When modifying an AI agent's tool interface, not all changes have the same impact. Adding an optional argument allows existing callers to continue operating unmodified. In contrast, adding a required field, removing a field, tightening allowed bounds, or narrowing allowed enum variants immediately breaks deployed agents.

The boundary for this stage is classify_changes.

Work through one concrete case. Consider evolving a database search tool:

If version 2 introduces a required auth_token or restricts max_results from 100 to 50, all historical agent plans relying on the broader contract will be rejected.

Implement the contract. Implement classify_changes(old_contract, new_contract) in your workspace main.py.

Categorize each detected change into: - breaking: added required property, removed property, narrowed type, narrowed enum, tightened minimum/maximum/minLength/maxLength, or changed additionalProperties from True to False. - compatible: added optional property, widened type, widened enum, relaxed bounds, or enabled additionalProperties. - unresolved: a keyword outside the supported subset, such as $ref, oneOf, pattern or format, whose value differs between the two versions, or a changed nested properties, required, additionalProperties or items inside a property. Annotations (title, description, default, examples) are ignored, and an unsupported keyword that did not change is not reported.

Each change object must include:

{
    "type": "breaking" | "compatible" | "unresolved",
    "category": str,
    "property": str,
    "description": str
}

class TestStage02ClassifyChanges(unittest.TestCase):

    def setUp(self):
        """Set up standard fixture contract for change classification."""
        self.base_schema = {
            "title": "search_tool",
            "type": "object",
            "properties": {
                "query": {"type": "string"},
                "limit": {"type": "integer", "minimum": 1, "maximum": 100},
                "format": {"type": "string", "enum": ["json", "csv", "text"]},
            },
            "required": ["query"],
            "additionalProperties": True,
        }
        self.base_contract = load_contract(self.base_schema)

    def test_added_required_is_breaking(self):
        """Verify newly required properties are classified as breaking."""
        new_schema = dict(self.base_schema)
        new_schema["required"] = ["query", "token"]
        new_schema["properties"] = dict(self.base_schema["properties"], token={"type": "string"})
        changes = classify_changes(self.base_contract, load_contract(new_schema))
        breaking = [c for c in changes if c["type"] == "breaking" and c["category"] == "added_required"]
        self.assertEqual(len(breaking), 1)
        self.assertEqual(breaking[0]["property"], "token")

    def test_added_optional_is_compatible(self):
        """Verify newly added optional properties are classified as compatible."""
        new_schema = dict(self.base_schema)
        new_schema["properties"] = dict(self.base_schema["properties"], filter_by={"type": "string"})
        changes = classify_changes(self.base_contract, load_contract(new_schema))
        compatible = [c for c in changes if c["type"] == "compatible" and c["category"] == "added_optional"]
        self.assertEqual(len(compatible), 1)
        self.assertEqual(compatible[0]["property"], "filter_by")

    def test_removed_property_when_closed_is_breaking(self):
        """Verify property removal in closed schema is classified as breaking."""
        new_schema = dict(self.base_schema)
        props = dict(self.base_schema["properties"])
        del props["limit"]
        new_schema["properties"] = props
        new_schema["additionalProperties"] = False  # closed rejects removed prop

def run_checker(old_path, new_path, calls_path=None, output_path=None, fixtures_path=None, strict=False):
    """Execute contract migration checks between two schema files and optional call log."""
    old_p = Path(old_path)
    new_p = Path(new_path)
    if not old_p.is_file():
        raise FileNotFoundError(f"old contract file not found: {old_path}")
    if not new_p.is_file():
        raise FileNotFoundError(f"new contract file not found: {new_path}")

    with open(old_p, "r", encoding="utf-8") as f:
        old_data = json.load(f)
    with open(new_p, "r", encoding="utf-8") as f:
        new_data = json.load(f)

    calls_data = []
    if calls_path:
        c_p = Path(calls_path)
        if not c_p.is_file():
            raise FileNotFoundError(f"calls file not found: {calls_path}")
        with open(c_p, "r", encoding="utf-8") as f:
            calls_data = json.load(f)

    old_contract = load_contract(old_data)
    new_contract = load_contract(new_data)
    calls = load_calls(calls_data)

    changes = classify_changes(old_contract, new_contract)
    counterexamples = generate_counterexamples(old_contract, new_contract)
    replay_res = replay_calls(old_contract, new_contract, calls)
    report = build_report(old_contract, new_contract, changes, counterexamples, replay_res)

    if fixtures_path:
        export_fixtures(fixtures_path, counterexamples, replay_res.get("broken", []))

    if output_path:
        p = Path(output_path)
        p.parent.mkdir(parents=True, exist_ok=True)
        with open(p, "w", encoding="utf-8") as f:
            json.dump(report, f, indent=2)

    print(json.dumps(report, indent=2))

    if strict and not report["compatible"]:
        sys.exit(1)
    return report


def main():
    """Parse command line arguments and execute the tool contract migration checker."""
    parser = argparse.ArgumentParser(description="Tool Contract Migration Checker")
    parser.add_argument("--old", required=True, help="Path to before schema JSON")
    parser.add_argument("--new", required=True, help="Path to proposed schema JSON")
    parser.add_argument("--calls", help="Path to saved agent calls JSON")
    parser.add_argument("--output", help="Path to write JSON compatibility report")
    parser.add_argument("--fixtures", help="Path to write generated migration test fixtures")
    parser.add_argument(
        "--strict",
        action="store_true",
        help="Exit code 1 when the contract update is incompatible (breaking changes, unresolved keywords, or broken calls)",
    )

    args = parser.parse_args()
    run_checker(
        old_path=args.old,
        new_path=args.new,
        calls_path=args.calls,
        output_path=args.output,
        fixtures_path=args.fixtures,
        strict=args.strict,
    )


if __name__ == "__main__":
    main()

def _changed_keywords(old: Dict[str, Any], new: Dict[str, Any], keywords: Set[str]) -> List[str]:
    """Return the given keywords whose values differ between two schemas, sorted."""

def _nested_view(schema: Dict[str, Any]) -> Dict[str, Any]:
    """Return the nested object and array keywords of a property schema with their defaults filled in."""
    required = schema.get("required", [])

        "properties": schema.get("properties", {}),

    }

def _check_no_nan_inf(val: Any) -> None:

def _canonical_json(val: Any) -> str:
    """Serialize a JSON value to a canonical string representation for comparison."""
    if isinstance(val, bool):
        return f"bool:{json.dumps(val)}"
    if isinstance(val, float):

            return f"float:{val}"
    if isinstance(val, (int, float)):
        if val == int(val):
            return f"num:{int(val)}"
        return f"num:{float(val)}"
    return f"{type(val).__name__}:{json.dumps(val, sort_keys=True)}"

def _synthesize_base_payload(contract: Dict[str, Any]) -> Dict[str, Any]:

        if key in props:
            p_schema = props[key]
            p_types = _type_names(p_schema) or {"string"}

                payload[key] = p_schema["enum"][0]
            elif "string" in p_types:
                min_len = p_schema.get("minLength", 1)
                payload[key] = "a" * max(1, min_len)
            elif "integer" in p_types or "number" in p_types:

                payload[key] = True

                payload[key] = {}
            elif "null" in p_types:

            else:
                payload[key] = "sample"
        else:
            payload[key] = "sample"

def replay_calls(
    old_contract: Dict[str, Any],
    new_contract: Dict[str, Any],
    calls: List[Dict[str, Any]],
) -> Dict[str, Any]:
    """Replay saved tool calls against both contracts and partition into preserved, broken, and invalid."""
    preserved = []
    broken = []
    already_invalid = []

    for call in calls:
        cid = call["id"]
        args = call["arguments"]
        valid_old, old_errs = validate_call(old_contract, args)
        valid_new, new_errs = validate_call(new_contract, args)

        if not valid_old:
            already_invalid.append({"id": cid, "arguments": args, "reasons": old_errs})
        elif valid_new:
            preserved.append({"id": cid, "arguments": args})
        else:
            broken.append({"id": cid, "arguments": args, "breaking_reasons": new_errs})

    denominator = len(preserved) + len(broken)
    rate = len(broken) / denominator if denominator > 0 else 0.0

    return {
        "total": len(calls),
        "preserved": preserved,
        "broken": broken,
        "already_invalid": already_invalid,
        "breaking_rate": round(rate, 4),
    }


def build_report(
    old_contract: Dict[str, Any],
    new_contract: Dict[str, Any],
    changes: List[Dict[str, Any]],
    counterexamples: List[Dict[str, Any]],
    replay_result: Dict[str, Any],
) -> Dict[str, Any]:
    """Assemble a comprehensive migration report combining static analysis, counterexamples, and replay."""
    breaking = [c for c in changes if c["type"] == "breaking"]
    compatible = [c for c in changes if c["type"] == "compatible"]
    unresolved = [c for c in changes if c["type"] == "unresolved"]

    is_compatible = (
        len(breaking) == 0
        and len(unresolved) == 0
        and len(replay_result.get("broken", [])) == 0
    )

    if is_compatible:
        summary = "Contract update is fully backwards-compatible. All historical calls preserved."
    else:
        reasons = []
        if breaking:
            reasons.append(f"{len(breaking)} breaking changes")
        if unresolved:
            reasons.append(f"{len(unresolved)} unresolved schema keywords")
        if replay_result.get("broken"):
            reasons.append(f"{len(replay_result['broken'])} broken historical calls")
        summary = f"Contract update is incompatible: {', '.join(reasons)}."

    return {
        "schema_version": 1,
        "tool_name": old_contract.get("title", "unnamed_tool"),
        "compatible": is_compatible,
        "breaking_count": len(breaking),
        "compatible_count": len(compatible),
        "unresolved_count": len(unresolved),
        "changes": changes,
        "counterexamples": counterexamples,
        "replay": replay_result,
        "summary": summary,
    }


def export_fixtures(

) -> Dict[str, Any]:

    return fixture_data

Break it on purpose

A team adds a required api_key to a tool and tests with a freshly written call that includes it. All tests pass; every existing agent prompt breaks on release. What did the tests miss? (Solution B1.)

Recap
What to keep from this project
  • Validate contracts and check saved calls against the old one.
  • Classify each change: compatible, breaking or unresolved.
  • Generate minimal counterexamples for each breaking change.
  • Replay real saved calls through both versions.
  • Gate CI on the compatibility report.

Build it on your machine

Each step above is meant to be built, not only read. The source repository ships a starter and the checks for every step, and its test runner grades your own folder step by step:

Write the step, run its checks, then move to the next step. The checks for each step are also shown above, under that step, so you can see what is expected before you start.

Exercises

Questions to test what you built. Try each one before you open the solutions.

  1. How would you make adding api_key a compatible change?
  2. Why separate "already invalid" calls from broken ones?
  3. Where do saved calls come from in a real system?

Solutions

Solution
  1. A compatible version

Add api_key as optional with a server-side default or a transition period that accepts both, log calls that omit it, and make it required only after the logs show no caller depends on its absence.

Solution
  1. Already invalid calls

They failed before the change too. Counting them as broken would blame the migration for an existing problem and inflate the breaking rate.

Solution
  1. Saved calls

From tool-call logs (with secrets removed), from agent traces, and from test fixtures. Logged real calls matter most, because they show what agents actually send.

SolutionB1 · Testing only new calls

Replaying the calls agents already make. A newly written call naturally matches the new schema; the saved calls show the change breaks every existing caller.

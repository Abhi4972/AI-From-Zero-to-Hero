In plain words first
The idea in one line

Train a small model that guesses the country of a UFO sighting from its duration and location, save it with pickle, and put it behind a web form.

The problem

Most models end up inside an application. This project keeps the model deliberately simple so the focus is on the steps around it: cleaning, training, saving the trained model to a file, and loading that file in a web server that answers form submissions.

Step 1 · Clean the sightings data

Keep sightings that lasted 1 to 60 seconds and encode the country as a number.

Step 2 · Train the classifier

from sklearn.model_selection import train_test_split

Selected_features = ['Seconds','Latitude','Longitude']

X = ufos[Selected_features]
y = ufos['Country']


X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, classification_report 
from sklearn.linear_model import LogisticRegression
model = LogisticRegression()
model.fit(X_train, y_train)
predictions = model.predict(X_test)

print(classification_report(y_test, predictions))
print('Predicted labels: ', predictions)
print('Accuracy: ', accuracy_score(y_test, predictions))

CodeThe Flask app: load the pickled model once, predict on each form post: app.py
import numpy as np
from flask import Flask, request, render_template
import pickle

app = Flask(__name__)

model = pickle.load(open("../ufo-model.pkl", "rb"))


@app.route("/")
def home():
    return render_template("index.html")


@app.route("/predict", methods=["POST"])
def predict():

    int_features = [int(x) for x in request.form.values()]
    final_features = [np.array(int_features)]
    prediction = model.predict(final_features)

    output = prediction[0]

    countries = ["Australia", "Canada", "Germany", "UK", "US"]

    return render_template(
        "index.html", prediction_text="Likely country: {}".format(countries[output])
    )


if __name__ == "__main__":
    app.run(debug=True)

Exercises

  1. Add input validation to the Flask route so a missing or non-numeric field returns a friendly message instead of a server error.
  2. Replace pickle with joblib and measure the file size and load time of each.
  3. Accuracy is high mostly because one country dominates. Print the class balance and the per-class recall, and explain why this model is less useful than its accuracy suggests.
Recap
What to keep
  • Train, save, load, serve: the four steps around any model.
  • Load the model once at start-up, not on every request.
  • Check class balance before trusting accuracy.

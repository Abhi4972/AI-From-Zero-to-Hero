LLM fundamentals

JuniorWhat is a token, and why do engineers care about tokenization?

A token is the unit a model reads and writes: usually a word piece produced by byte-pair encoding (BPE) or a similar algorithm. English averages roughly four characters per token; Hindi, code and numbers often take more tokens per word. Engineers care because tokens set the price, the context limit and the latency, and because tokenization explains odd failures such as miscounting letters or mangling long numbers. Always measure with the provider's tokenizer or the usage field rather than counting words.

JuniorWhat do temperature and top-p control?

Both shape how the next token is sampled from the model's probability distribution. Temperature rescales the distribution: low values make the most likely token dominate (more deterministic), high values flatten it (more varied). Top-p (nucleus sampling) keeps only the smallest set of tokens whose probabilities add up to p. For extraction, classification and tool callinglater · 14.56, use low temperature; for brainstorming, higher. Some reasoning models fix or ignore these settings, so check the model's documentation.

MidWhy do LLMs hallucinate, and what actually reduces it?

The model is trained to produce plausible continuations, not verified facts, so when it lacks knowledge it still produces fluent text. Training also rewards guessing over saying "I don't know" in many benchmarks. What reduces it in products: grounding answers in retrieved sources and requiring citations, giving the model permission and a format to say it does not know, tools for facts that change (prices, order status), structured outputlater · 11.21 with validation, and a faithfulnesslater · 14.72 check before answering. Measure the hallucination rate on your own eval set; it varies a lot by task.

MidWhat is the KV cache, and why does it matter for cost and latency?

During generation, each layer stores the attention keys and values of every previous token so they are not recomputed for each new token. It makes generation fast but uses GPU memory proportional to context length times concurrent users, which is what limits how many conversations one GPU serves. Providers expose its benefit as prompt cachinglater · 11.23: a repeated prefix is billed at a discount and returns its first token faster. Keep prompts' stable parts first to exploit it.

MidWhat are reasoning models, and when are they worth the cost?

Models trained (often with reinforcement learning) to produce an internal chain of thoughtlater · 11.26 before answering, with a controllable effort or thinking budget. They do much better on multi-step problems: maths, planning, debugging, complex tool use. They cost more tokens and add latency, sometimes many seconds. Use them for hard steps such as planning or root-cause analysis, and fast non-reasoning models for routing, extraction and formatting. Decide per step with evals, not per application.

Deep learning and transformer internals

JuniorExplain gradient descent and backpropagation in two minutes.

Training needs one number to reduce, the loss (for LLMs, cross-entropy on the next token). The gradient says how the loss changes as each weight changes. Gradient descent repeatedly moves every weight a small step against its gradient, scaled by the learning rate. Backpropagation is how the gradient is computed cheaply: run the network forward, keep intermediate values, then apply the chain rule backward from the loss, layer by layer, reusing each result. A backward pass costs about twice a forward pass regardless of the number of weights. In practice gradients come from mini-batches, and the optimizer is usually AdamW with warmup and cosine decay (Lesson 3.18).

JuniorWhy do neural networks need activation functions, and which ones do LLMs use?

Without a non-linearity, stacked layers collapse into one linear map, so depth adds nothing. ReLU was the long-time default; GPT-2 and BERT use GELU, a smooth ReLU; Llama, Mistral, Qwen and most current LLMs use SwiGLU, a gated unit in the feed-forward layers. Softmax at the output turns scores over the vocabulary into probabilities.

MidHow do you detect and fix overfitting?

The sign is a gap: training loss keeps falling while validation loss stalls or rises. Fixes: more or cleaner data, weight decay, dropout, early stopping at the best validation step, a smaller model or fewer epochs, and for fine-tuning a lower learning rate or LoRAlater · 3.24. Keep a test set you touch once. The same logic applies to prompts: a prompt tuned on 20 examples overfits them, so keep a held-out eval set.

MidWalk through scaled dot-product attention. Why divide by √d_k?

Each token's vector is projected into a query, a key and a value. Scores are query-key dot products; a softmax turns each row into weights; the output is the weighted sum of values: softmax(QKᵀ/√d_k)V. A causal mask blocks future tokens in decoders. Dot products of d-dimensional vectors grow like √d, so without the division the softmax saturates onto one token and its gradients vanish; scaling keeps it soft and trainable. Multi-head attention runs several of these in parallel subspaces and concatenates the results.

MidWhy does attention cost O(n²), and what do production systems do about it?

Every token is compared with every other, so the score matrix is n × n. For prefill, compute and memory grow with the square of the context; during generation the KV cache grows linearly with context and concurrency. Remedies: the KV cache itself, grouped-query or multi-query attention to shrink it, FlashAttention to compute exact attention in fast on-chip memory, sliding-window or local attention layers, PagedAttentionlater · 14.137 for memory management, KV-cache quantization, and hybrid architectures with state-space layers. At the application level: retrieval and context engineeringlater · 11.27 instead of stuffing the window.

MidHow do transformers know word order? Explain RoPE.

Attention alone is order-blind, so position must be injected. The original transformer added fixed sinusoids; BERT and GPT-2 learned one vector per position. RoPE, used by Llama, Mistral, Qwen and Gemma, rotates each pair of dimensions in the query and key by an angle proportional to the position. The dot product of a rotated query and key then depends only on the distance between them, so attention sees relative position. Context-extension methods such as position interpolation and YaRN rescale the rotation frequencies so a model can be fine-tuned to longer windows. ALiBi instead subtracts a distance penalty from scores.

MidEncoder-only, decoder-only, encoder-decoder: what is the difference and when do you use each?

Encoders (BERT) see the whole input in both directions and are trained by masked-word prediction; they suit embeddings, classification, rerankerslater · 5.38 and entity extraction, and they are small and fast. Decoders (GPT, Llama, Claude) see only earlier tokens and predict the next one; they generate, and they are what chat and agent models are. Encoder-decoders (T5, Whisper, the original transformer) encode input fully and decode output with cross-attention; they suit translation, summarization and speech recognition. Decoder-only won general-purpose LLMs because one objective scales to all text and every task can be phrased as continuation.

MidWhat are the residual stream, LayerNorm and RMSNorm for?

Each sublayer adds its output to its input (x = x + sublayer(norm(x))), so a per-token vector, the residual stream, flows through every layer. It lets gradients reach early layers and makes deep stacks trainable. Normalization keeps activations in a stable range: LayerNorm centers and scales; RMSNorm only scales by the root mean square, which is cheaper and works as well, so Llama-family models use it. Modern models normalize before each sublayer (pre-norm), which trains more stably than post-norm.

SeniorEstimate the memory to serve an 8B model with 50 concurrent 16,000-token conversations.

Weights in bf16: about 2 bytes per parameter, so 16 GB. KV cache per token is 2 (key and value) × layers × KV heads × head dimension × bytes: for Llama 3 8B, 2 × 32 × 8 × 128 × 2 = 128 KiB. 50 × 16,000 tokens × 128 KiB is about 98 GiB. Total around 115 GB plus activations and overhead, so two 80 GB GPUs, or one with an 8-bit KV cache and 8-bit weights. Without GQA (32 KV heads) the cache would be four times larger. Then say what you would measure: real context lengths are usually far below the maximum, and PagedAttention allocates only what is used.

SeniorHow does a mixture-of-experts model work, and what are its trade-offs?

Each feed-forward layer is replaced by many experts and a router that sends each token to the top few (often 2 of 8, or 8 of 256). Total parameters store knowledge; only active parameters cost compute per token: Mixtral 8x7B has 46.7B total and about 12.9B active, DeepSeek-V3 671B and 37B. Trade-offs: all experts must sit in memory, so memory cost follows the total; routing needs a load-balancing loss; serving needs expert parallelism and can be uneven across GPUs; fine-tuning is trickier. The win is quality per unit of compute, which is why most large open models are MoE.

SeniorWhat is speculative decoding, and does it change the output?

A small draft model (or extra prediction heads, or n-gram lookup from the prompt) proposes several tokens; the large model scores all of them in one forward pass and accepts the longest run consistent with its own distribution, then adds one token. With acceptance rate α and k draft tokens, each large-model pass yields (1 − α^(k+1)) / (1 − α) tokens on average, over three at α = 0.8 and k = 4. With the standard acceptance rule the output distribution is exactly the large model's, so quality is unchanged; only latency improves. It helps most when decode is memory-bound and drafts are often right, such as code and structured output.

SeniorWhat are state-space models such as Mamba, and will they replace transformers?

They process a sequence with a fixed-size running state updated per token, so cost grows linearly with length and there is no growing KV cache; Mamba makes the state update depend on the input (selective). Pure SSMs are weaker at exact recall of something far back in context, which attention does well. The practical direction is hybrids that interleave a few attention layers with many SSM or linear-attention layers (Jamba, IBM Granite 4, NVIDIA Nemotron-H), trading a little recall for much cheaper long context. For agent builders the impact is on serving cost and context length, not on how you build.

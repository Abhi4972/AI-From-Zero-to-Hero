Why this came about

In 1943 Warren McCulloch and Walter Pitts described an idealised brain cell as a tiny calculator that adds up its inputs and fires if the total passes a threshold. In 1958 Frank Rosenblatt built the perceptron, a machine that learned such weights from examples. In 1969 Marvin Minsky and Seymour Papert showed that a single layer cannot learn even simple patterns like "exactly one of two switches is on" (XOR), and interest collapsed for over a decade. The fix was known in principle (stack several layers with a bend between them), but training them needed backpropagationlater · 3.16, popularised in 1986, and real power needed the data and GPUslater · 3.20 that arrived around 2012. Every language model is this same idea, scaled up enormously.

In plain words first
Many small voters, organised in rows

Think of a neuron as a small committee member who looks at a few numbers, weighs some more than others, adds them up, and gives an opinion. One member can only draw one simple dividing line. Put many members side by side (a layer), each looking for something different, and pass their opinions to another row of members, and the group can recognise complicated shapes no single member could. Nobody tells the members what to look for: training adjusts every weight until the group's final answer is right.

Step 1 · One neuron

A neuron does three things: multiply each input by a weight, add them up together with a bias, then pass the total through an activation function. With a sigmoid as the activation, that is exactly logistic regression from Lesson 2.24.

import numpy as np

x = np.array([7.5, 3.0, 1.0])     # inputs: km, items, raining
w = np.array([0.4, 0.8, 2.0])     # one weight per input
b = -3.0                          # the bias

z = x @ w + b                     # weighted sum: 7.5*0.4 + 3*0.8 + 1*2.0 - 3
print("weighted sum z =", z)
print("after ReLU     =", max(0.0, z))
What you should see
weighted sum z = 4.4
after ReLU     = 4.4

The weighted sum z is sometimes called the pre-activation. ReLU ("rectified linear unit") is the simplest useful activation: keep positive numbers, turn negative ones into 0. The neuron "fires" only when its weighted evidence passes the threshold set by the bias.

Step 2 · A layer is a matrix multiplication

A layer is many neurons looking at the same inputs, each with its own weights. Put each neuron's weights in a column of a matrix W, put several examples in the rows of X, and one matrix multiplication (Lesson 1.24) computes every neuron for every example at once.

X = np.array([[7.5, 3, 1],        # 4 deliveries (rows), 3 features each (columns)
              [2.0, 1, 0],
              [12., 6, 1],
              [4.0, 2, 0]])
W = np.array([[0.4, -0.2],        # 3 inputs (rows) x 2 neurons (columns)
              [0.8,  0.1],
              [2.0,  0.5]])
b = np.array([-3.0, 0.5])         # one bias per neuron

Z = X @ W + b                     # (4, 3) @ (3, 2) -> (4, 2), and b is added to every row (broadcasting)
print(X.shape, "@", W.shape, "->", Z.shape)
print(Z)
print("after ReLU:")
print(np.maximum(0, Z))
What you should see
(4, 3) @ (3, 2) -> (4, 2)
[[ 4.4 -0.2]
 [-1.4  0.2]
 [ 8.6 -0.8]
 [ 0.2 -0.1]]
after ReLU:
[[4.4 0. ]
 [0.  0.2]
 [8.6 0. ]
 [0.2 0. ]]
Reading this output
  • Each row of the result is one delivery; each column is one neuron's output for it. The first column is the neuron from Step 1 (4.4 for the first delivery).
  • The shapes tell the whole story: (examples × inputs) @ (inputs × neurons) gives (examples × neurons). The inner sizes must match; Lesson 1.24's picture applies directly.
  • Adding b to a (4, 2) array adds the two biases to every row. That is NumPy broadcasting (Lesson 0.21).
  • np.maximum(0, Z) applies ReLU to every number at once. The layer's output is a new set of features, two per delivery here, which the next layer takes as its input.

A network with layers between the input and the output is called a multi-layer perceptron (MLP) or a feed-forward networklater · 7.19. The layers in the middle are hidden layers, because you never see their values directly in the data. Each one turns its input into new, more useful features.

Step 3 · Why the bend matters

What if you skip the activation? Two layers without one are (x @ W1) @ W2, and matrix multiplication lets you regroup that as x @ (W1 @ W2): a single layer with the matrix W1 @ W2.

rng = np.random.default_rng(0)
W1 = rng.normal(size=(2, 3))
W2 = rng.normal(size=(3, 1))
x = np.array([[0.5, -1.0]])

print("two layers, no activation:", (x @ W1) @ W2)
print("one layer with W1 @ W2:   ", x @ (W1 @ W2))
What you should see
two layers, no activation: [[0.4190748]]
one layer with W1 @ W2:    [[0.4190748]]

Identical. Without a non-linear activation, a hundred layers are no more powerful than one, and the whole network can only ever draw straight lines (flat surfaces) to separate classes. The activation is what lets depth add power.

import math

def gelu(z):                         # the smooth ReLU used in GPT-2 and BERT (a standard approximation)
    return 0.5 * z * (1 + math.tanh(math.sqrt(2 / math.pi) * (z + 0.044715 * z ** 3)))

print("   z   ReLU  sigmoid   tanh   GELU")
for z in [-2, -1, 0, 1, 2]:
    print(f"{z:>4}   {max(0, z):>4}   {1 / (1 + math.exp(-z)):.3f}  {math.tanh(z):>6.3f}  {gelu(z):>6.3f}")
What you should see
   z   ReLU  sigmoid   tanh   GELU
  -2      0   0.119  -0.964  -0.045
  -1      0   0.269  -0.762  -0.159
   0      0   0.500   0.000   0.000
   1      1   0.731   0.762   0.841
   2      2   0.881   0.964   1.955
Activation What it does Where you meet it
ReLU negative → 0, positive unchanged the default in most networks since about 2011: cheap, and trains well
sigmoid squeezes to between 0 and 1 the output of yes/no classifiers; "gates" inside some layers
tanh squeezes to between −1 and 1 older recurrent networks (Lesson 5.35)
GELU a smooth ReLU that lets small negatives through BERTlater · 7.22, GPT-2 and many transformerslater · 7.19 (Lesson 7.19)
SwiGLU a gated variant the feed-forward layers of Llama, Mistral, Qwen and most current LLMs
softmax turns a vector of scores into probabilities the very last step of a classifier or language model

Step 4 · Solving what a straight line cannot: XOR by hand

The problem that stalled the field in 1969: output 1 when exactly one of two inputs is 1. No single straight line separates the 1s from the 0s, but two hidden ReLU neurons can. Here are weights chosen by hand:

inputs = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])

W1 = np.array([[1, 1],          # both hidden neurons add up the two inputs...
               [1, 1]])
b1 = np.array([0, -1])          # ...but the second one only fires when both are on
W2 = np.array([1, -2])          # output = first neuron minus twice the second

hidden = np.maximum(0, inputs @ W1 + b1)
print("hidden layer:\n", hidden)
print("output:", hidden @ W2)
What you should see
hidden layer:
 [[0 0]
 [1 0]
 [1 0]
 [2 1]]
output: [0 1 1 0]

The first hidden neuron counts how many inputs are on; the second detects "both on". Subtracting twice the second from the first gives 0, 1, 1, 0: XOR. Each hidden neuron drew one simple line; the output layer combined them into something no single line can express. In a real network, nobody chooses these weights: training finds them (Lesson 3.16).

Step 5 · See a network learn a shape

The dots below belong to two classes in a ring: inside and outside. Train the network with different settings and watch the shaded prediction change.

Things to try:

  1. Ring, activation "none", 8 units: whatever you do, the boundary stays a straight line. Many units without a bend are still one straight-line model.
  2. Ring, tanh or ReLU, 1 unit, then 2, then 4: with too few units the network cannot wrap around the ring; around 3 or 4 it can.
  3. Spiral: hard. Small networks fail; 8 units and several rounds of training do much better. Harder problems need bigger networks.

The same experiment with scikit-learn's MLPClassifier, on 600 points:

from sklearn.linear_model import LogisticRegression
from sklearn.neural_network import MLPClassifier

rng = np.random.default_rng(0)
X = rng.uniform(-1, 1, size=(600, 2))
y = ((X ** 2).sum(axis=1) < 0.45).astype(int)          # 1 = inside the ring
X_train, y_train, X_val, y_val = X[:400], y[:400], X[400:], y[400:]

print(f"always 'outside' baseline : {1 - y_val.mean():.3f}")
print(f"logistic regression       : {LogisticRegression().fit(X_train, y_train).score(X_val, y_val):.3f}")
print(f"8 units, no activation    : {MLPClassifier((8,), activation='identity', max_iter=3000, random_state=0).fit(X_train, y_train).score(X_val, y_val):.3f}")
for units in [2, 4, 8, 16]:
    net = MLPClassifier(hidden_layer_sizes=(units,), activation="relu", max_iter=3000, random_state=0)
    net.fit(X_train, y_train)
    print(f"{units:>2} ReLU units              : {net.score(X_val, y_val):.3f}")
What you should see
always 'outside' baseline : 0.645
logistic regression       : 0.645
8 units, no activation    : 0.645
 2 ReLU units              : 0.505
 4 ReLU units              : 0.940
 8 ReLU units              : 0.975
16 ReLU units              : 0.980
Reading this output
  • Logistic regression scores exactly the baseline: a straight line cannot do better than calling everything "outside".
  • A network with 8 units but no activation also scores exactly the baseline, as Step 3 predicted.
  • With ReLU, 2 units are not enough (this run even does worse than the baseline), 4 units get 94%, and 8 to 16 units 97 to 98%.
  • hidden_layer_sizes=(8,) means one hidden layer of 8 neurons; (64, 32) would mean two hidden layers.

There is a famous result behind this, the universal approximation theorem (1989): a network with one hidden layer and enough units can approximate any reasonable function as closely as you like. It says nothing about how many units you need or whether training will find the weights. In practice, deeper networks (more layers) learn complicated patterns with far fewer units than one very wide layer, which is why modern networks are deep: "deep learning".

Step 6 · Counting parameters

A layer with n_in inputs and n_out neurons has n_in × n_out weights plus n_out biases. Model sizes ("an 8-billion-parameter model") are this count, summed over every layer.

def count_params(sizes):
    """sizes = [inputs, hidden1, hidden2, ..., outputs]"""
    total = 0
    for n_in, n_out in zip(sizes[:-1], sizes[1:]):
        total += n_in * n_out + n_out
    return total

print("the network in the picture  [4, 6, 6, 3]:", count_params([4, 6, 6, 3]))
print("a digit classifier   [64, 128, 64, 10]:", count_params([64, 128, 64, 10]))
print("one GPT-2 feed-forward block [768, 3072, 768]:", f"{count_params([768, 3072, 768]):,}")
print("GPT-2 small has 12 of those:", f"{12 * count_params([768, 3072, 768]):,}")
What you should see
the network in the picture  [4, 6, 6, 3]: 93
a digit classifier   [64, 128, 64, 10]: 17226
one GPT-2 feed-forward block [768, 3072, 768]: 4,722,432
GPT-2 small has 12 of those: 56,669,184

GPT-2 small (2019) has 124 million parameters in total, and about 57 million of them sit in these simple two-layer feed-forward networks, one inside each of its 12 transformer blocks. The rest are mostly in the attention layers and the embeddinglater · 3.19 table (the Transformers, step by step section). A transformer is, to a large extent, this lesson's MLP, repeated, with attention added between the copies.

The same idea as a formula
  • one neuron: a = φ(w · x + b), where φ is the activation
  • one layer for a batch: A = φ(XW + b), with X of shape (n, d_in), W of shape (d_in, d_out)
  • a two-layer network: ŷ = φ₂(φ₁(XW₁ + b₁)W₂ + b₂)
  • without activations: (XW₁)W₂ = X(W₁W₂), a single linear layer
  • parameters of a layer: d_in · d_out + d_out
Check your mental model
  • ✗ "A neural network works like a brain."
    ✓ It was loosely inspired by brain cells, but it is arithmetic: weighted sums and simple bends, with weights tuned by calculus.
  • ✗ "More neurons without activations make a more powerful network."
    ✓ Without non-linear activations, any number of layers equals one linear layer.
  • ✗ "The hidden layers store the training examples."
    ✓ They hold weights that compute new features. The examples shaped those weights during training but are not stored as such.

Exercises

Predict before you run

In Step 4, what does the network output for the input [2, 0], which was never part of the XOR problem? (Solution P1.)

Make it your own

In the playground, set the data to XOR, the activation to ReLU, and find the smallest number of hidden units that reaches 100% accuracy. Then try tanh. (Solution M1.)

Practice
Apply it

How many parameters does a network with sizes [784, 256, 10] have (a classic network for 28 × 28 pixel digit images)? Work it out by hand first, then check with count_params. (Solution X1.)

Solutions

SolutionP1 · An input outside the training data

Hidden layer: [2 + 0 + 0, 2 + 0 - 1] = [2, 1], both positive, so ReLU keeps them. Output: 2 - 2 × 1 = 0. The hand-made network only "means" XOR for inputs that are 0 or 1; for other inputs it computes whatever its arithmetic gives. Networks do not know when they are outside the data they were designed or trained for, a theme that returns with distribution shift (Lesson 2.26) and hallucinationlater · 10.38 (Lesson 10.38).

SolutionM1 · XOR in the playground

Two ReLU or tanh units can solve XOR in principle (Step 4 shows one solution), but training from a random start does not always find it; 3 or 4 units reach 100% much more reliably. Extra units give training more ways to succeed. This is one reason networks are usually made larger than the bare minimum.

SolutionX1 · Counting by hand

First layer: 784 × 256 + 256 = 200,960. Second layer: 256 × 10 + 10 = 2,570. Total 203,530. Almost all parameters sit in the first layer, because it connects every pixel to every hidden neuron.

Recap
  • A neuron computes a weighted sum of its inputs plus a bias, then applies an activation function.
  • A layer is many neurons at once: one matrix multiplication plus a bias, then the activation; shapes go (examples × inputs) @ (inputs × neurons).
  • Without non-linear activations, stacked layers collapse into one linear layer; ReLU, GELU and friends make depth useful.
  • Hidden layers create new features; combining simple ones lets networks represent shapes no straight line can, like XOR or a ring.
  • Model size is the number of weights and biases; a transformer contains many copies of a simple two-layer MLP.

Check your understanding

Q1What does a layer of neurons compute for a batch of examples?

Q2Why do neural networks need non-linear activation functions?

Q3How many parameters does a layer with 10 inputs and 5 neurons have?

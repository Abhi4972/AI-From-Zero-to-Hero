In plain words first
The idea in one line

What it does

If you have a folder full of modules that you want to import from your app, than the trick from Multiple python files won't work -- you can't just put a whole folder to the stage and then import from it.

Instead, you can create a zip folder, put that to the stage, and then import from that zip directly.

  1. Create an app with the code from streamlit_app.py. Note the important step of adding utils.zip to sys.path
  2. Put several python modules in the utils folder, or another similar
  3. Zip the utils folder

sh zip -r utils.zip utils/*.py

  1. Create the app in SiS, either through the web UI, or through the snowcli

sh snow streamlit create --file streamlit_app.py GREAT_NAME_FOR_MY_STREAMLIT snow streamlit deploy --file streamlit_app.py GREAT_NAME_FOR_MY_STREAMLIT

  1. Upload utils.zip to the stage

sh snow stage put utils.zip GREAT_NAME_FOR_MY_STREAMLIT_STAGE

  1. Profit!

Read the code

Start with the first file: it is the entry point. The others are the pieces it calls.

Codestreamlit_app.py (9 lines)
import sys

sys.path.append("utils.zip")

# If the folder 'utils' exists, then this will import from that folder. Otherwise
# it will import from the zip file.
from utils.plotting import this_is_a_cool_function

Run it on your machine

git clone --depth 1 --filter=blob:none --sparse https://github.com/Snowflake-Labs/sf-samples
cd sf-samples
git sparse-checkout set samples/streamlit-in-snowflake/import-from-folder
cd samples/streamlit-in-snowflake/import-from-folder

Install the dependencies (pip install -r requirements.txt if the folder has one), put your keys in a .env file, then start the entry point shown above.

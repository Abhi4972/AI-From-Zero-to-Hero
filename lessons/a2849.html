The recipe

Model note: this notebook uses claude-haiku-4-5, a legacy model, because assistant-message prefill (the continuation technique shown below) is only accepted on Claude Haiku 4.5. All current models (Claude Opus 5.5, Claude Sonnet 5.5, Claude Fable 5.1, and Claude Haiku 5.5) return a 400 for a request that ends with an assistant message. Current models also accept much larger max_tokens values (up to 128K output tokens; see the models overview), so a single request usually suffices. If a response is still cut off on a current model, continue with a new user turn such as "Continue exactly where you left off." rather than an assistant prefill.

This notebook illustrates how to get Claude to give responses longer than the max_tokens limit of a single request by using a prefill with the content of the previous message.

First, we'll set max_tokens=4096 and prompt Claude to write something longer than that.

import anthropic

# Reads ANTHROPIC_API_KEY from the environment
client = anthropic.Anthropic()
# See the model note at the top: the prefill continuation below is only accepted on the
# legacy Claude Haiku 4.5; current models, including Claude Haiku 5.5, return a 400 for it.
MODEL_NAME = "claude-haiku-4-5"

message = client.messages.create(
    model=MODEL_NAME,
    max_tokens=4096,
    messages=[
        {
            "role": "user",
            "content": """
Please write five stories. Each should be at least 1000 words. Number the words to make sure you don't lose track. Make each story about a different animal.
Put them in <story_1>, <story_2>, ... tags
""",
        },
    ],
)

Solution? We put the partially completed response, which was cut off in its prime, in an Assistant message to Claude, who then continues sampling and completes the story. You can see that Claude seamlessly picks up in mid-sentence.

message2 = client.messages.create(
    model=MODEL_NAME,
    max_tokens=4096,
    messages=[
        {
            "role": "user",
            "content": """
Please write five stories. Each should be at least 1000 words. Number the words to make sure you don't lose track. Make each story about a different animal.
Put them in <story_1>, <story_2>, ... tags
""",
        },
        {
            "role": "assistant",
            "content": message.content[0].text,  # The text of Claude's partially completed message.
        },
    ],
)
print(message2.content[0].text)

Please be advised that this approach unfortunately entails being "double-charged" for reading the input tokens in your prompt and single-charged for reading the output tokens of Claude's 4096-token response as input tokens. However, they will not be double-charged as output tokens.

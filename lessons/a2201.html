In plain words first
The idea in one line

Pick one feature of a patient, fit a straight line to it, and see how well that line predicts how a disease progresses.

The problem

scikit-learn ships a small medical dataset: ten measurements (age, BMI, blood pressure and six blood serum values) for 442 diabetes patients, and a number that says how far the disease progressed a year later. The question is the simplest one regression can ask: if you know only a patient's BMI, how well can a straight line predict that progression?

Step 1 · Load the dataset and choose one feature

Each row of X is one patient; column 2 is BMI. scikit-learn expects a 2-D array of features even when there is only one, hence the reshape.

Import needed libraries

import matplotlib.pyplot as plt

Load the diabetes dataset, divided into X data and y features

X, y = datasets.load_diabetes(return_X_y=True)

Step 2 · Train and predict

A third of the patients are held back as a test set the model never sees while it fits.

Split the training and test data for both X and y

X_train, X_test, y_train, y_test = model_selection.train_test_split(X, y, test_size=0.33)

Select the model and fit it with the training data

model = linear_model.LinearRegression()
model.fit(X_train, y_train)
What you should see
LinearRegression()

Use test data to predict a line

y_pred = model.predict(X_test)

Step 3 · Plot the line against the test patients

Black dots are real test patients; the blue line is what the model predicts for each BMI.

Display the results in a plot

plt.scatter(X_test, y_test,  color='black')
plt.plot(X_test, y_pred, color='blue', linewidth=3)
plt.show()

Exercises

  1. Repeat the fit with each of the ten features in turn and print the R² score (model.score) for each. Which single feature predicts progression best?
  2. Fit on all ten features at once. How much does the test R² improve over the best single feature?
  3. Remove test_size=0.33's randomness by passing random_state=0, then change the seed. How much does the score move between seeds, and what does that say about a 442-row dataset?
Recap
What to keep
  • A regression model maps features to a number.
  • Keep a test set aside to judge the model honestly.
  • One feature gives a straight line; more features give a better fit only if they carry signal.

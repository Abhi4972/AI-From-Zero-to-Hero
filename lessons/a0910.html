In plain words first
The idea in one line

Single-agent RL assumes the environment is stationary. Put two learning agents in the same world and that assumption breaks: each agent is part of the other's environment, and both are changing. Multi-agent RL is the set of tricks to make learning converge when the Markov assumption no longer holds.

Terms you'll hear
Term What people say What it actually means
Markov game "Multi-agent MDP" $(S, A_1, \ldots, A_n, P, R_1, \ldots, R_n)$; each agent has its own reward.
CTDE "Centralized training, decentralized execution" Joint critic at training time; each agent's policy uses only local obs.
IPPO "Independent PPO" Each agent runs PPO separately. Simple baseline; often underrated.
MAPPO "Multi-agent PPO" PPO with a centralized value function conditioned on global state.
QMIX "Monotonic value decomposition" $Q_{\text{tot}} = f_{\text{monotone}}(Q_1, \ldots, Q_n)$ allows decentralized argmax.
COMA "Counterfactual multi-agent" Advantage = my Q minus expected Q marginalizing over my action.
Self-play "Agent vs past self" Single agent, two roles; standard for zero-sum games.
League play "Population training" Cache past policies, sample opponents from the pool; handles strategy cycles.

The problem

In plain words first

With one learner, the world stays the same while the agent improves. With several learners, every agent is part of every other agent's world, and that world keeps changing as they all learn. An action that was good yesterday can be bad today because a teammate or an opponent has changed. Multi-agent RL deals with three questions: how to learn when the others keep changing, how to tell which agent deserves credit for a shared reward, and how to train against opponents without going round in circles. This lesson runs the lesson's two-agent grid world, shows on tiny games where independent learners settle for less, how much noise a shared reward adds, and why self-play has to remember old opponents, and then uses OpenSpiel and PettingZoo, two standard multi-agent libraries. No neural network is trained.

A robot learning to navigate a room is a single-agent RL problem. A soccer team is not. AlphaStar vs StarCraft opponents is not. A marketplace of bidding agents is not. Two cars negotiating a four-way stop is not. Many-on-many real-world problems are not.

In every multi-agent setting, from the perspective of any one agent, the other agents are part of the environment. As they learn and change their behavior, the environment becomes non-stationary. The Markov property — "next state depends only on current state and my action" — gets violated because the next state also depends on what the other agents chose, and their policies are moving targets.

This breaks tabular convergence proofs (Q-learning's guarantee assumes a stationary environment). It breaks naive deep RL too: agents chase each other in loops, never converge to a stable policy. You need multi-agent-specific techniques: centralized training / decentralized execution, counterfactual baselines, league play, self-play.

Applications: robot teams, traffic control, fleets of vehicles, market simulations, multi-agent LLM systems (Phase 16), and any game with more than one intelligent player.

The idea

Formalism: Markov Game. A generalization of MDP: states S, a joint action a=(a1​,…,an​), transition P(s′∣s,a), and per-agent rewards Ri​(s,a,s′). Each agent i maximizes its own return under its own policy πi​. If rewards are identical, it is fully cooperative. If zero-sum, it is adversarial. If mixed, it is general-sum.

Core challenges:

  • Non-stationarity. P(s′∣s,ai​) from agent i's view depends on π−i​, which is changing.
  • Credit assignment. With a shared reward, which agent caused it?
  • Exploration coordination. Agents must explore complementary strategies, not redundantly explore the same state.
  • Scalability. The joint action space grows exponentially in n.
  • Partial observability. Each agent sees only its own observation; the global state is hidden.

Four dominant regimes:

1. Independent Q-learning / independent PPO (IQL, IPPO). Each agent learns its own Q or policy, treating others as part of the environment. Simple, sometimes it works (especially with experience replay acting as a smoothing agent-modeling trick). Theoretical convergence: none. In practice: fine for loosely-coupled tasks, bad for tightly-coupled ones.

2. Centralized training, decentralized execution (CTDE). Most common modern paradigm. Each agent has its own policy πi​ that conditions on local observation oi​ — standard decentralized execution at deployment. During training, a centralized critic Q(s,a1​,…,an​) conditions on the full global state and joint action. Examples: - MADDPG (Lowe et al. 2017): DDPG with a centralized critic per agent. - COMA (Foerster et al. 2017): counterfactual baseline — ask "what would my reward have been if I'd taken action a′ instead?" — isolates my contribution. - MAPPO / IPPO with shared critic (Yu et al. 2022): PPO with a centralized value function. A strong, widely used baseline for cooperative MARL. - QMIX (Rashid et al. 2018): value decomposition — Qtot​(s,a)=f(Q1​(s,a1​),…,Qn​(s,an​)) with monotonic mixing.

3. Self-play. Two copies of the same agent play each other. The opponent's policy is my policy from a past snapshot. AlphaGo / AlphaZero / MuZero. OpenAI Five. Works best for zero-sum games; the training signal is symmetric.

4. League play. An extension of self-play to general-sum / adversarial environments: keep a population of past and current policies, sample an opponent from the league, train against them. Adds exploiters (specialize in beating the current best) and main exploiters (specialize in beating exploiters). AlphaStar (StarCraft II). Needed when the game admits "rock-paper-scissors" strategy cycles.

Communication. Allow agents to send learned messages mi​ to each other. Works in cooperative settings. Foerster et al. (2016) showed that differentiable inter-agent communication can be trained end-to-end. Today's LLM-based multi-agent systems (Phase 16) essentially communicate in natural language.

The same idea as a formula

Why the world stops being stationary. For agent 1, the transition it experiences averages over what agent 2 does:

P1​(s′∣s,a1​)=a2​∑​π2​(a2​∣s)P(s′∣s,a1​,a2​)

so whenever π2​ changes, agent 1's environment changes. Q-learning's convergence proof assumes this does not happen.

Equilibrium. A joint policy (π1​,…,πn​) is a Nash equilibrium when no agent can gain by changing only its own policy: Ji​(πi​,π−i​)≥Ji​(πi′​,π−i​) for all i and πi′​. A cooperative game can have several, some much worse than others.

Exploitability of a policy π in a two-player zero-sum game: what a best-responding opponent wins against it, maxπ′​J(π′,π) minus the game's value. It is zero exactly at a Nash equilibrium, which is why it is the standard score for self-play.

Credit assignment. With a shared reward R, agent i's policy-gradient term ∇logπi​(ai​)R carries the noise of every other agent's choices. COMA's counterfactual advantage compares the joint action with what agent i alone could have done instead:

Ai​(s,a)=Q(s,a)−ai′​∑​πi​(ai′​∣s)Q(s,(ai′​,a−i​))

Regret matching (CFR). Each decision point keeps the cumulative regret Rt(a) for not having played a, and plays πt+1(a)∝max(Rt(a),0). In two-player zero-sum games the average policy converges to a Nash equilibrium; the current one need not.

Worked example
Why independent learners play safe, by hand

The climbing game: two agents, actions 0, 1, 2, shared reward

partner 0 partner 1 partner 2
me 0 11 −30 0
me 1 −30 7 6
me 2 0 0 5

An independent learner's Q-value for its own action averages over the partner's behaviour. Early on the partner is close to uniform:

  • Q(0)=(11−30+0)/3=−6.33, Q(1)=(−30+7+6)/3=−5.67, Q(2)=(0+0+5)/3=1.67.
  • Action 2 looks best, so both agents drift to it. Once there, switching to action 1 would pay 6, but action 1 risks −30 whenever the partner explores action 0, and with a learning rate of 0.1 each such hit knocks its estimate down by about 3.6. Action 2 can never lose, so its estimate sits steadily near 5. In the runs below that end at (2,2), the first agent's estimate for action 1 averages 2.2 against 4.8 for action 2.

The best joint action (0,0) pays 11, but each agent only sees it if the other is already playing 0. A learner over joint actions, Q(a1​,a2​), sees 11 directly.

Counterfactual credit. Ten agents each pick 0 or 1 with probability ½; the team reward is the number of 1s. Agent 0 picked 1 and the team scored 6. Its counterfactual baseline is the average over its own two choices with the others fixed: 21​⋅6+21​⋅5=5.5, so its advantage is +0.5, whatever the other nine did. With the shared reward, its signal would have been 6, mostly the others' work.

Check your mental model
  • ✗ "If every agent learns well, the team will find the best joint behaviour."
    ✓ Independent learners often settle on a safe equilibrium; in the climbing game 80 of 100 runs end on reward 5 instead of 11.
  • ✗ "Self-play gets better every iteration."
    ✓ Beating only the newest version can cycle forever (rock beats scissors beats paper); it is the average over past versions that converges.
  • ✗ "A shared reward is fair, so it is a good learning signal."
    ✓ It is fair but noisy: each agent's gradient carries every other agent's luck, and the noise grows with the number of agents.

Step 1 · the multi-agent env

This lesson uses a 5×5 GridWorld with two cooperative agents (main.py; the snippet in Step 1 sketches the same world at 6×6). They start in opposite corners and must reach a shared goal. Shared reward: -1 per step while either agent is still moving, +10 when both arrive. See code/main.py.

class CoopGridWorld:
    def __init__(self):
        self.size = 6
        self.goal = (5, 5)

    def reset(self):
        return ((0, 0), (5, 0))  # two agents

    def step(self, state, actions):
        a1, a2 = state
        new1 = move(a1, actions[0])
        new2 = move(a2, actions[1])
        done = (new1 == self.goal) and (new2 == self.goal)
        reward = 10.0 if done else -1.0
        return (new1, new2), reward, done

The joint action space is |A|² = 16. The global state is two positions.

Step 2 · independent Q-learning

Each agent runs its own Q-table keyed on joint state. At each step: both pick ε-greedy actions, collect joint transition, each updates its own Q with the shared reward.

def independent_q(env, episodes, alpha, gamma, epsilon):
    Q1, Q2 = defaultdict(default_q), defaultdict(default_q)
    for _ in range(episodes):
        s = env.reset()
        done = False
        while not done:
            a1 = epsilon_greedy(Q1, s, epsilon)
            a2 = epsilon_greedy(Q2, s, epsilon)
            s_next, r, done = env.step(s, (a1, a2))
            if done:
                Q1[s][a1] += alpha * (r - Q1[s][a1])
                Q2[s][a2] += alpha * (r - Q2[s][a2])
                break
            target1 = r + gamma * max(Q1[s_next].values())
            target2 = r + gamma * max(Q2[s_next].values())
            Q1[s][a1] += alpha * (target1 - Q1[s][a1])
            Q2[s][a2] += alpha * (target2 - Q2[s][a2])
            s = s_next

Works on this task because rewards are dense and aligned. Fails on tightly-coupled tasks (e.g., where one agent has to wait for the other).

Step 3 · centralized Q with decomposed-value update

Use one Q over joint actions Q(s,a1​,a2​). Update from shared reward. Decentralize at execution by marginalizing: πi​(s)=argmaxai​​maxa−i​​Q(s,a1​,a2​). Trades exponential joint action space for a correct global view.

Both methods solve this task. The best possible return is 3.0 (agent 1 needs 8 steps to the goal, each costing −1 until both have arrived, then +10: −7+10), and both greedy policies reach exactly 3.0. Independent Q-learning even learns faster at first (−55 against −99 in the first 150 episodes), because each agent's table has 4 actions per state while the joint table has 16 and needs more exploration. That is why independent learners are a reasonable first try: when the agents barely interact (here they only need to end up on the same square), treating the partner as part of the environment is enough. The exploring curves stay near 0 to 1 rather than 3 because of ε-greedy random moves during training. The next run shows a game where the coupling is tight and independent learning fails.

Settling for less, and the noise of a shared reward

A: the climbing game, 100 runs each of two independent Q-learners and of one learner over joint actions. B: agent 0's policy-gradient estimate in a team of n agents, with the shared reward and with a counterfactual baseline, from 200,000 samples (a few seconds).

import numpy as np
from collections import Counter

# A. The climbing game (Claus & Boutilier 1998): two agents, three actions each, one shared reward
G = np.array([[11, -30, 0],
              [-30,  7, 6],
              [  0,  0, 5]], dtype=float)
def independent(seed, steps=5000, alpha=0.1, eps=0.1):
    rng = np.random.default_rng(seed); Q1, Q2 = np.zeros(3), np.zeros(3)
    for _ in range(steps):
        a = rng.integers(3) if rng.random() < eps else int(Q1.argmax())
        b = rng.integers(3) if rng.random() < eps else int(Q2.argmax())
        r = G[a, b]; Q1[a] += alpha * (r - Q1[a]); Q2[b] += alpha * (r - Q2[b])   # each sees only its own action
    return int(Q1.argmax()), int(Q2.argmax())
def joint(seed, steps=5000, alpha=0.1, eps=0.1):
    rng = np.random.default_rng(seed); Q = np.zeros((3, 3))
    for _ in range(steps):
        a, b = (rng.integers(3), rng.integers(3)) if rng.random() < eps else np.unravel_index(Q.argmax(), Q.shape)
        Q[a, b] += alpha * (G[a, b] - Q[a, b])
    return tuple(int(x) for x in np.unravel_index(Q.argmax(), Q.shape))
print("A. climbing game: where 100 runs end (greedy joint action -> shared reward)")
for name, f in (("independent Q-learners", independent), ("one learner over joint actions", joint)):
    c = Counter(f(s) for s in range(100))
    print(f"  {name:<31}" + "  ".join(f"{a}->{G[a]:+.0f}: {n}" for a, n in c.most_common()))

# B. Credit assignment: n agents each choose 0 or 1 with p = 0.5; the team reward is the number of 1s, plus noise.
# Agent 0's REINFORCE estimate of d(team reward)/d(logit_0) with the shared reward versus a counterfactual baseline.
rng = np.random.default_rng(0); S = 200_000
print("\nB. noise in agent 0's gradient estimate (true gradient 0.25 in every case)")
print("  agents | shared reward   | counterfactual baseline (COMA-style)")
print("         |                 | exact critic   | critic off by +/-0.5")
for n in (2, 5, 10, 20, 50):
    a = rng.random((S, n)) < 0.5
    R = a.sum(1) + rng.normal(0, 1, S)
    score = a[:, 0] - 0.5                                   # d log pi(a_0) / d logit_0
    g_shared = score * R
    R_cf = R - a[:, 0] + 0.5                                 # E over agent 0's own action, others held fixed
    g_cf = score * (R - R_cf)
    g_cf_noisy = score * (R - R_cf - rng.normal(0, 0.5, S))  # a learned critic is never exact
    print(f"  {n:>6} | {g_shared.mean():.3f} +/- {g_shared.std():5.2f} | {g_cf.mean():.3f} +/- {g_cf.std():.2f} | {g_cf_noisy.mean():.3f} +/- {g_cf_noisy.std():.2f}")

Reading this output

A. The learner over joint actions finds the best joint action, (0,0) with reward 11, in all 100 runs. Independent learners find it in only 13; 80 end on (2,2) with reward 5 and 7 on (1,2) with 6. Nothing is wrong with each agent's learning rule: each one correctly estimates what its own action is worth given how the partner currently behaves, and the partner's exploration makes the high-paying actions risky. This is why cooperative methods give agents a centralised critic or value decomposition during training (QMIX, MAPPO) while keeping separate policies for execution.

B. All the estimators are unbiased (about 0.25 every time), but with the shared reward the noise grows with the team: a standard deviation of 0.75 with 2 agents, 2.7 with 10, 12.6 with 50, so a team of 50 needs roughly (12.6/0.75)2≈280 times as many samples for the same accuracy as a team of 2. The exact counterfactual baseline removes all of it, because it subtracts exactly the part of the reward that agent 0 did not cause; a critic with errors of ±0.5 still keeps the noise at 0.25 regardless of team size. This is the argument for COMA-style counterfactual advantages and, more generally, for per-agent credit.

Step 4 · simple self-play (adversarial 2-agent)

Same agent, two roles. Train agent A against agent B; after K episodes, copy A's weights into B. Symmetric training, consistent progress. The AlphaZero recipe in miniature.

Self-play that cycles, and self-play that converges

A: rock-paper-scissors, where each new policy is either the best response to the latest policy (naive self-play) or to the average of all past policies (fictitious play). B: two players in matching pennies following their exact policy gradients at the same time.

import numpy as np

# Rock-paper-scissors, payoff to the row player; zero-sum, the only Nash equilibrium is (1/3, 1/3, 1/3)
A = np.array([[0, -1, 1], [1, 0, -1], [-1, 1, 0]], dtype=float)
def exploitability(p): return float((A @ p).max())       # what a best-responding opponent wins against p
def br(p): e = np.zeros(3); e[(A @ p).argmax()] = 1; return e

print("A. rock-paper-scissors, two kinds of self-play")
print("   iteration | latest policy (best response to the latest) | exploitability | fictitious play: average policy | exploitability")
latest = np.array([1.0, 0, 0]); avg = latest.copy(); hist = latest.copy()
for t in range(1, 1001):
    latest = br(latest)                                   # naive self-play: beat the newest version only
    hist = hist + br(hist / t); avg = hist / (t + 1)      # fictitious play: beat the average of all past versions
    if t in (1, 2, 3, 10, 100, 1000):
        print(f"   {t:>9} | {np.array2string(latest, precision=2):>42} | {exploitability(latest):>14.2f} | "
              f"{np.array2string(avg, precision=2):>31} | {exploitability(avg):.3f}")

# Matching pennies: two independent learners following their exact policy gradients at the same time
print("\nB. matching pennies, simultaneous exact policy-gradient steps (learning rate 0.1), start at P(heads) = 0.6 / 0.5")
x, y = np.log(0.6 / 0.4), 0.0                             # logits of P(heads) for player 1 and player 2
sig = lambda z: 1 / (1 + np.exp(-z)); path = []
for t in range(3001):
    p, q = sig(x), sig(y); path.append((p, q))
    if t in (0, 100, 500, 1000, 2000, 3000):
        P = np.array(path)
        print(f"   step {t:>4}: P1(heads) {p:.2f}  P2(heads) {q:.2f}  distance from Nash (0.5, 0.5) {np.hypot(p - .5, q - .5):.2f}"
              f"  | time-average {P[:, 0].mean():.2f} {P[:, 1].mean():.2f}")
    # player 1 wins on a match, player 2 on a mismatch: u1 = (2p-1)(2q-1) = -u2
    gx = (2 * q - 1) * 2 * p * (1 - p); gy = -(2 * p - 1) * 2 * q * (1 - q)
    x, y = x + 0.1 * gx, y + 0.1 * gy

Reading this output

A. Naive self-play goes round in circles: rock is beaten by paper, paper by scissors, scissors by rock, and after 1,000 iterations the latest policy is a pure strategy that loses one chip per game to the right counter (exploitability 1.00), exactly as bad as at the start. Fictitious play responds to the average of all past policies, and that average approaches (31​,31​,31​): exploitability 0.18 after 10 iterations, 0.07 after 100, 0.014 after 1,000. The individual best responses are still pure strategies; it is the population that converges. League training (AlphaStar) and the average policy in CFR rest on the same fact.

B. Two policy-gradient learners in matching pennies chase each other: when player 1 leans heads, player 2 moves towards tails, which pushes player 1 to tails, and so on. With simultaneous steps the orbit spirals outwards, from a distance of 0.10 from the equilibrium to 0.22 after 3,000 steps, so the policies never settle, while their time-averages sit at 0.50, 0.50. Each learner is doing the right thing for itself; the joint dynamics do not converge.

Pitfalls

  • Non-stationary replay. Experience replay with independent agents is worse than single-agent because old transitions were generated by now-obsolete opponents. Fix: relabel or weight by recency.
  • Credit assignment ambiguity. Shared reward after a long episode; no clear way to say which agent contributed. Fix: counterfactual baselines (COMA), or reward shaping per agent.
  • Policy drift / chasing. Each agent's best response changes with each other's update. Fix: centralized critic, slow learning rates, or freeze-one-at-a-time.
  • Reward hacking via coordination. Agents find coordinated exploits the designer did not anticipate. Q-learning pricing agents in simulated markets learn to keep prices high together without communicating (Calvano et al. 2020). Fix: careful reward design, behavioral constraints.
  • Exploration redundancy. Both agents explore the same state-action pairs. Fix: entropy bonuses per-agent, or role-conditioning.
  • League cycles. Pure self-play can get stuck in a dominance cycle. Fix: league play with diverse opponents.
  • Sample explosion. n agents × state space × joint actions. Approximate with function approximation; factored action spaces (one policy output head per agent).

Use it: the same idea with real libraries

Where multi-agent methods are used:

Domain Method Notes
Cooperative navigation / manipulation MAPPO / QMIX CTDE; shared critic + decentralized actors.
Two-player games (chess, Go, poker) Self-play with MCTS (AlphaZero); regret minimisation (CFR) for poker Zero-sum; symmetric training.
Complex multiplayer (Dota, StarCraft) League play + imitation pretraining OpenAI Five, AlphaStar.
Autonomous-vehicle fleets CTDE MAPPO / PPO with attention Partial obs; variable team sizes.

Much current interest is in systems of language-model agents that negotiate, debate or build software together. There, coordination is mostly done with prompts and tool protocols; RL, where it is used, is usually applied to whole trajectories of one agent at a time (Phase 16 · 03).

A: OpenSpiel's counterfactual regret minimisation on Kuhn poker, a three-card poker game whose equilibrium is known exactly (tabular, about a second). B: PettingZoo's cooperative-navigation task with random actions, to see what a decentralised actor and a centralised critic each get to use.

# needs the open_spiel, pettingzoo and mpe2 packages
import numpy as np, pyspiel
from open_spiel.python.algorithms import cfr, exploitability, expected_game_score

# A. OpenSpiel: counterfactual regret minimisation (self-play for imperfect-information games) on Kuhn poker
game = pyspiel.load_game("kuhn_poker")       # 3 cards, 2 players, 1 betting round: 12 decision points per player
solver = cfr.CFRSolver(game)
print("A. CFR self-play on Kuhn poker (tabular, about a second); exploitability = chips per hand a perfect opponent wins")
print("   iteration | latest policy | average policy | average policy's value for player 1")
for t in range(1, 1001):
    solver.evaluate_and_update_policy()
    if t in (1, 10, 100, 1000):
        avg = solver.average_policy()
        v = expected_game_score.policy_value(game.new_initial_state(), [avg] * 2)[0]
        print(f"   {t:>9} | {exploitability.exploitability(game, solver.current_policy()):>13.4f} | "
              f"{exploitability.exploitability(game, avg):>14.4f} | {v:+.4f}")
print(f"   game value of Kuhn poker for player 1: -1/18 = {-1 / 18:+.4f}")

    obs, rew, term, trunc, _ = env.step(acts); rewards.append(list(rew.values()))

Reading this output

A. CFR is self-play with a specific update (regret matching at every decision point), and it shows the same split as fictitious play. The average policy's exploitability falls from 0.46 to 0.07 after 10 iterations and 0.0009 after 1,000, and its value for player 1 converges to −0.0556, exactly the known game value −1/18: the first player loses about one chip every 18 hands against perfect play. The current policy is still exploitable by 0.05 after 1,000 iterations. CFR variants are what poker systems such as Libratus and Pluribus are built on.

B. In the navigation task each actor sees 18 numbers (its own position and velocity, the relative positions of the landmarks and the other agents, and their communication channel) and picks one of 5 actions; a centralised critic can see the 54-number global state and the joint action, one of 125 combinations. With 10 agents the joint action would have 510≈10 million combinations, which is why centralised critics take actions as inputs instead of enumerating them. In this random episode all three agents received the same reward on every step: no one collided, so only the shared team term was non-zero, and no agent could tell from the reward whether its own moves helped.

Break it on purpose

In the fictitious-play half of the self-play run, replace the average over all past policies with a recency-weighted one, as a league that mostly keeps recent opponents would:

avg = 0.9 * avg + 0.1 * br(avg)

Industry practice
What's current (2024–2026)
  • Cooperative MARL. MAPPO/IPPO with a centralised value function and QMIX-style value decomposition are the standard baselines, run at scale in JAX environment suites (JaxMARL) and libraries such as RLlib, BenchMARL and EPyMARL.
  • Self-play and populations. Self-play with search (AlphaZero lineage) for board games, CFR-family solvers for poker, and league or population training for large multiplayer games; driving-policy research trains with self-play in simulation (for example GIGAFLOW).
  • Tooling. PettingZoo is the standard multi-agent API (with MPE2 for particle environments), and OpenSpiel collects games and algorithms such as CFR, fictitious play and exploitability.

Sources: MAPPO, JaxMARL, PettingZoo, OpenSpiel, Superhuman AI for multiplayer poker (Pluribus), Robust autonomy from self-play (GIGAFLOW).

Recap
What to keep from this lesson
  • Other learning agents make the environment non-stationary; single-agent guarantees no longer apply.
  • Independent learners can settle on a safe but poor equilibrium; joint or centralised critics see the coordinated optimum.
  • Shared rewards are noisy credit; counterfactual baselines isolate each agent's own contribution.
  • In zero-sum games, score policies by exploitability; the average of self-play converges, the latest policy can cycle.
  • Leagues keep old opponents for this reason; CTDE trains with global information and acts with local information.

Solutions

SolutionP1 · Few

Few: 13 of 100 runs end on the best joint action. Each independent learner estimates the value of its own actions averaged over its partner's current behaviour, exploration included. Actions 0 and 1 each risk −30 when the partner picks the "wrong" partner action, so their estimates stay low and unstable, while action 2 never loses. Both agents settle on the safe action, reward 5 (80 runs), sometimes 6 (7 runs). A learner over joint actions sees that (0,0) pays 11 and finds it in all 100 runs.

SolutionB1 · It stalls

No. With weight 0.1 on the newest best response, exploitability falls to about 0.15 and then stays between about 0.12 and 0.17 for good; with weight 0.02 it stalls between about 0.06 and 0.07. A recency-weighted average forgets old strategies at a fixed rate, so it can never settle on the mixture (31​,31​,31​); it keeps circling near it, at a distance set by how fast it forgets. The plain average gives the t-th policy weight 1/t, which shrinks over time, and that shrinking step is what lets it converge. A league that only plays against recent versions of itself can therefore be beaten by a strategy it once knew how to handle; AlphaStar's league kept past players and added exploiters for this reason.

In plain words first
The idea in one line

If you have a folder full of python files that you want to import into your app, you can create a zip folder, put the zipped folder in the stage, and then import from that zip directly.

What it does

If you have a folder full of python files that you want to import into your app, you can create a zip folder, put the zipped folder in the stage, and then import from that zip directly.

Create the zip module

Put python files in the utils folder and Zip the utils folder

sh zip -r utils.zip utils/*.py

Using snowcli

Create the app

sh snow streamlit create --file streamlit_app.py GREAT_NAME_FOR_MY_STREAMLIT snow streamlit deploy --file streamlit_app.py GREAT_NAME_FOR_MY_STREAMLIT

Upload utils.zip to the stage

sh snow stage put utils.zip GREAT_NAME_FOR_MY_STREAMLIT_STAGE

Using snowsql

Create the stage and upload the files to it

```sql CREATE STAGE my_stage; PUT file://path-to-code-directory/streamlit_app.py @my_stage auto_compress=false overwrite=true;

PUT file://path-to-code-directory/utils.zip @my_stage auto_compress=false overwrite=true; ```

Create the app

```sql CREATE STREAMLIT my_test_app ROOT_LOCATION = @..my_stage MAIN_FILE='/streamlit_app.py' QUERY_WAREHOUSE=

```

Read the code

Start with the first file: it is the entry point. The others are the pieces it calls.

Codestreamlit_app.py (8 lines)
import streamlit as st
import zipimport

importer = zipimport.zipimporter('utils.zip')

module=importer.load_module('utils/helper')

module.helper_function()

Run it on your machine

git clone --depth 1 --filter=blob:none --sparse https://github.com/Snowflake-Labs/sf-samples
cd sf-samples
git sparse-checkout set samples/streamlit-in-snowflake/import-python-modules
cd samples/streamlit-in-snowflake/import-python-modules

Install the dependencies (pip install -r requirements.txt if the folder has one), put your keys in a .env file, then start the entry point shown above.

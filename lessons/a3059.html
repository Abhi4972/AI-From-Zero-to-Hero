In plain words first
The idea in one line

Forward and reverse geocoding built entirely inside Snowflake on the Overture Maps Marketplace share — no external geocoding APIs.

What it does

Forward and reverse geocoding built entirely inside Snowflake on the Overture Maps Marketplace share — no external geocoding APIs. All objects live in the GEOCODING.PUBLIC schema.

  • Forward - free-text address -> GEOGRAPHY point. US plus 14 European countries
  • Reverse - lat/lon -> nearest address (worldwide)
  • Tester app - GEOCODING_TESTER, a Snowflake App Runtime app to try forward, reverse and normalization with results on a map
  • International parsing - worldwide address parsing via libpostal on SPCS

Data source

Overture Maps "Addresses" (Carto), imported from the Marketplace as:

OVERTURE_MAPS__ADDRESSES.CARTO.ADDRESS

Columns: ID, STREET, NUMBER, UNIT, POSTCODE, POSTAL_CITY, COUNTRY, GEOMETRY (GEOGRAPHY).

The installer auto-acquires this listing (free, GZT0Z4CM1E9NQ) — no manual Marketplace step. If a copy already exists under either OVERTURE_MAPS__ADDRESSES or the DS_-prefixed name, it is reused. A stable view GEOCODING.PUBLIC.OVERTURE_ADDRESS is created over whichever share resolves, so you never edit the physical share name. Geocoding itself needs no external access integration; only the tester app uses one, to proxy its CARTO basemap.

Pause or remove

The libpostal service and its compute pool are billed while they run. The service suspends itself after 30 minutes without calls (AUTO_SUSPEND_SECS = 1800), and the pool suspends 10 minutes after that. The next PARSE_ADDRESS_INTL call, or a European forward geocode, wakes both: about 16 s if only the service was suspended and about 100 s if the pool was too. The function tester has Start and Stop buttons for this. To pause by hand:

ALTER SERVICE GEOCODING.PUBLIC.LIBPOSTAL_SVC SUSPEND;
ALTER COMPUTE POOL GEOCODING_LIBPOSTAL_POOL SUSPEND;

Re-running the installer resumes both. To free the about 19.7 GB of EU index storage but keep US and reverse geocoding:

DROP TABLE IF EXISTS GEOCODING.PUBLIC.OVERTURE_ADDRESS_EU_LOC;
DROP TABLE IF EXISTS GEOCODING.PUBLIC.OVERTURE_ADDRESS_EU;
DROP TABLE IF EXISTS GEOCODING.PUBLIC.EU_LOCALITY_ALIAS;
DROP TABLE IF EXISTS GEOCODING.PUBLIC.EU_LOCALITY;

To remove everything the installer created (service, compute pool, image repository, functions, procedures and index tables), run the uninstall script. It shows the plan first and only drops with --yes:

bash .cortex/skills/install-geocoding/scripts/uninstall_geocoding.sh --connection <conn>        # dry run
bash .cortex/skills/install-geocoding/scripts/uninstall_geocoding.sh --connection <conn> --yes

--keep-eu-index keeps the database, --drop-shares also drops the Overture Marketplace databases, and --keep-warehouses keeps the build warehouses. The equivalent SQL:

`GEOCODING_TESTER` is a small Snowflake App Runtime app (Next.js, deck.gl and
MapLibre) in `GEOCODING.PUBLIC`. It has three tabs, and every result is drawn on a map:

- **Forward geocode**: one address per line, up to 200. A country dropdown
  sets the default. Prefix a line with `CC |` (for example
  `DE | Unter den Linden 77, 10117 Berlin`) to mix countries in one batch.
  Points are colored by `MATCH_LEVEL`.
- **Reverse geocode**: one `lat, lon` per line, up to 200. Clicking the map
  adds a point. Each input is linked to its nearest address, and search radii
  are drawn for batches of 25 points or fewer. "Any country" searches worldwide.
- **Normalize address**: runs `PARSE_ADDRESS`, `STANDARDIZE_STREET`,
  `PARSE_ADDRESS_INTL`, `EXPAND_STREET_INTL` and `NORMALIZE_STREET_EU` on each
  line (up to 200, `CC |` prefix as on Forward), then geocodes them onto the
  map. One address shows the functions side by side; several show a table, and
  clicking a row shows that record's full output.

A **Sample** dropdown on each tab loads a test sample, grouped into single
records and multiple records:

| Tab | Multiple-record samples |
|-----|-------------------------|
| Forward | 10 US, 10 DE, 10 FR, 20 across six countries, 50 across six countries |
| Reverse | 10 Berlin, 10 Paris, 2

"""libpostal service for Snowflake SPCS service functions.

Implements the Snowflake service-function protocol:
  request  : {"data": [[row_idx, arg1], ...]}
  response : {"data": [[row_idx, result], ...]}

Endpoints:
  POST /parse   -> RETURNS OBJECT  (libpostal parse_address, mapped to normalized fields)
  POST /expand  -> RETURNS ARRAY   (libpostal expand_address normalized variants)
  GET  /healthcheck -> readiness probe
"""
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
from postal.parser import parse_address
from postal.expand import expand_address

app = FastAPI()

# libpostal parse labels we surface, mapped to friendly keys. suburb /
# city_district / state_district / island matter for Europe: libpostal often
# labels the town people write there ("Mengede", "lanciano") as one of them.
_LABEL_MAP = {
    "house_number": "house_number",
    "road": "road",
    "unit": "unit",
    "postcode": "postcode",
    "suburb": "suburb",
    "city_district": "city_district",
    "city": "city",
    "island": "island",
    "state_district": "state_district",
    "state": "state",
    "country": "country",
}


@app.get("/healthcheck")
def healthcheck():
    return {"status": "ok"}


def _parse_one(raw):
    if raw is None:
        return None
    text = str(raw).strip()
    if not text:
        return None
    result = {v: None for v in _LABEL_MAP.values()}
    result["parse_error"] = False
    try:
        for value, label in parse_address(text):
            key = _LABEL_MAP.get(label)
            if key and result.get(key) is None:
                result[key] = value
    except Exception:
        result["road"] = text
        result["parse_error"] = True
    return result


def _expand_one(raw):
    if raw is None:
        return None
    text = str(raw).strip()
    if not text:
        return []
    try:
        return list(expand_address(text))
    except Exception:
        return [text]


@app.post("/parse")
async def parse(request: Request):
    body = await request.json()
    out = [[row[0], _parse_one(row[1] if len(row) > 1 else None)] for row in body["data"]]
    return JSONResponse({"data": out})


@app.post("/expand")
async def expand(request: Request):
    body = await request.json()
    out = [[row[0], _expand_one(row[1] if len(row) > 1 else None)] for row in body["data"]]
    return JSONResponse({"data": out})

// Runs a request through /api/job and polls, so batches that take longer than
// the App Runtime ingress timeout (about a minute) still return.
async function post(path: string, body: unknown): Promise<Resp> {
  const kind = path.replace("/api/", "")
  const start = await fetch("/api/job", {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({ kind, body }),
  })
  const { id, error } = await start.json()
  if (!id) return { error: error ?? "could not start job" }
  for (;;) {
    await new Promise((r) => setTimeout(r, 1500))
    const r = await fetch(`/api/job?id=${id}`)
    const job = await r.json()
    if (job.status === "done") return job.result as Resp
    if (job.error) return { error: job.error }
  }
}

const num = (v: unknown) => (v == null ? NaN : Number(v))

function toPoints(rows: Row[] = []): MapPoint[] {
  return rows
    .filter((r) => Number.isFinite(num(r.LAT)) && Number.isFinite(num(r.LON)))
    .map((r) => ({
      lat: num(r.LAT),
      lon: num(r.LON),
      id: num(r.INPUT_ID),
      kind: "result" as const,
      level: (r.MATCH_LEVEL as string) ?? "ADDRESS",
      label: [r.RAW_ADDRESS ?? r.FULL_ADDRESS, r.MATCH_LEVEL, r.MATCH_SCORE != null && `score ${r.MATCH_SCORE}`, r.DISTANCE_M != null && `${Math.round(num(r.DISTANCE_M))} m`]
        .filter(Boolean)
        .join(" | "),
    }))
}

function parseForward(text: string) {
  return text
    .split("\n")
    .map((l) => l.trim())
    .filter(Boolean)
    .map((l) => {
      const m = l.match(/^([A-Za-z]{2})\s*\|\s*(.+)$/)
      return m ? { address: m[2], country: m[1].toUpperCase() } : { address: l }
    })
}

function parsePoints(text: string) {
  return text
    .split("\n")
    .map((l) => l.split(/[,\s]+/).filter(Boolean).map(Number))
    .filter((p) => p.length >= 2 && p.every(Number.isFinite))
    .map(([lat, lon]) => ({ lat, lon }))
}

/**
 * Display formatters for Snowflake query results.
 *
 * The Node.js driver returns NUMBER as number (or string for large values),
 * TIMESTAMP as Date, and NULL as null. These helpers accept any of those and
 * always return a display string, using "—" for null/empty/invalid input.
 *
 * Numeric strings go through Number(), so integers above
 * Number.MAX_SAFE_INTEGER round. formatNumber keeps them exact; the compact,
 * currency and percent formatters are approximate by design.
 */

export const EMPTY = "—"

function toNumber(value: unknown): number | null {
  if (value === null || value === undefined || value === "") return null
  const n = typeof value === "number" ? value : Number(value)
  return Number.isFinite(n) ? n : null
}

/** 1234567.891 → "1,234,567.89". Large integer strings stay exact. */
export function formatNumber(value: unknown, maximumFractionDigits = 2): string {
  if (typeof value === "string" && /^-?\d+$/.test(value.trim()) && !Number.isSafeInteger(Number(value))) {
    return BigInt(value.trim()).toLocaleString("en-US")
  }
  const n = toNumber(value)
  return n === null ? EMPTY : n.toLocaleString("en-US", { maximumFractionDigits })
}

/** 1234567 → "1.2M", 1500 → "1.5K" */
export function formatCompact(value: unknown): string {
  const n = toNumber(value)
  return n === null
    ? EMPTY
    : n.toLocaleString("en-US", { notation: "compact", maximumFractionDigits: 1 })
}

/** 1234.5 → "$1,234.50" */
export function formatCurrency(value: unknown, currency = "USD"): string {
  const n = toNumber(value)
  return n === null ? EMPTY : n.toLocaleString("en-US", { style: "currency", currency })
}

/** Ratio in, percent out: 0.1234 → "12.3%" */
export function formatPercent(value: unknown, maximumFractionDigits = 1): string {
  const n = toNumber(value)
  return n === null
    ? EMPTY
    : n.toLocaleString("en-US", { style: "percent", maximumFractionDigits })
}

function toDate(value: unknown): Date | null {
  if (value === null || value === undefined || value === "") return null
  const d = value instanceof Date ? value : new Date(value as string | number)
  return Number.isNaN(d.getTime()) ? null : d
}

/** → "Oct 23, 2026" */
export function formatDate(value: unknown): string {
  const d = toDate(value)
  return d === null ? EMPTY : d.toLocaleDateString("en-US", { dateStyle: "medium" })
}

/** → "Oct 23, 2026, 10:50:46 AM" */
export function formatDateTime(value: unknown): string {
  const d = toDate(value)
  return d === null
    ? EMPTY
    : d.toLocaleString("en-US", { dateStyle: "medium", timeStyle: "medium" })
}

/** Generic cell formatter for rows of unknown shape. */
export function formatValue(value: unknown): string {
  if (value === null || value === undefined || value === "") return EMPTY
  if (value instanceof Date) return formatDateTime(value)
  if (typeof value === "number") return formatNumber(value)
  if (typeof value === "boolean") return value ? "true" : "false"
  if (typeof value === "object") return JSON.stringify(value)
  return String(value)
}

/** True for values that should be right-aligned in a table column. */
export function isNumeric(value: unknown): boolean {
  return typeof value === "number" || (typeof value === "string" && value.trim() !== "" && Number.isFinite(Number(value)))
}

/** Milliseconds in, short duration out: 850 → "850 ms", 4200 → "4.2 s", 125000 → "2m 5s" */
export function formatDuration(ms: unknown): string {
  const n = toNumber(ms)
  if (n === null || n < 0) return EMPTY
  if (n < 1000) return `${Math.round(n)} ms`
  if (n < 60_000) return `${(n / 1000).toFixed(1)} s`
  const minutes = Math.floor(n / 60_000)
  if (minutes < 60) return `${minutes}m ${Math.round((n % 60_000) / 1000)}s`
  return `${Math.floor(minutes / 60)}h ${minutes % 60}m`
}

/** 1536 → "1.5 KB" */
export function formatBytes(bytes: unknown): string {
  const n = toNumber(bytes)
  if (n === null || n < 0) return EMPTY
  const units = ["B", "KB", "MB", "GB", "TB", "PB"]
  let v = n
  let i = 0
  while (v >= 1024 && i < units.length - 1) {
    v /= 1024
    i++
  }
  return `${v.toLocaleString("en-US", { maximumFractionDigits: i === 0 ? 0 : 1 })} ${units[i]}`
}

/** Time since a date: "just now", "5 min ago", "3 h ago", "2 d ago". Future dates: "in 5 min", then a date. */
export function formatRelative(value: unknown, now: Date = new Date()): string {
  const d = toDate(value)
  if (d === null) return EMPTY
  const s = Math.round((now.getTime() - d.getTime()) / 1000)
  if (s < -45) {
    if (s > -3600) return `in ${Math.round(-s / 60)} min`
    if (s > -86_400) return `in ${Math.round(-s / 3600)} h`
    return formatDate(d)
  }
  if (s < 45) return "just now"
  if (s < 3600) return `${Math.round(s / 60)} min ago`
  if (s < 86_400) return `${Math.round(s / 3600)} h ago`
  return `${Math.round(s / 86_400)} d ago`
}

This repo ships a project-local Cortex Code skill, install-geocoding, that deploys the whole solution with one command. Open this folder in Cortex Code and say "install geocoding", or run the orchestrator directly:


**full install: core + libpostal SPCS + EU index + tester app**

bash .cortex/skills/install-geocoding/scripts/install_geocoding.sh \
  --connection <your-snow-connection> [--warehouse <wh>] --eu-warehouse GEOCODING_BUILD_WH

**US forward + worldwide reverse only (no Docker needed)**

bash .cortex/skills/install-geocoding/scripts/install_geocoding.sh \
  --connection <your-snow-connection> --no-intl

Opt-outs: --no-intl (skips libpostal and the EU index), --no-eu (keeps libpostal, skips the index), --no-app (skips the tester app). The old --intl and --eu flags are still accepted.

The EU step calls BUILD_EU_INDEX, which builds the European candidate tables once. The first build reads about 140M addresses and runs a spatial join, so pass an X-Large warehouse with --eu-warehouse. If you have none, create one first: CREATE WAREHOUSE IF NOT EXISTS GEOCODING_BUILD_WH WAREHOUSE_SIZE = XLARGE AUTO_SUSPEND = 60 INITIALLY_SUSPENDED = TRUE COMMENT = '{"origin":"sf_sit-is-geocoding","name":"oss-geocoding","version":{"major":1,"minor":0},"attributes":{"is_quickstart":1,"source":"sql"}}'; Later runs find the tables and skip the build. The libpostal step needs a running Docker daemon or Podman machine to build the linux/amd64 image.

The installer is idempotent (re-runnable), auto-acquires the Overture listing, and tags every object with a JSON tracking COMMENT (see Tracking). See .cortex/skills/install-geocoding/SKILL.md.

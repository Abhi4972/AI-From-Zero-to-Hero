In plain words first
The idea in one line

Look at which ingredients mark each of five cuisines, then even out the classes so a classifier is not biased towards the biggest one.

The problem

The dataset lists recipes from five cuisines (Korean, Indian, Chinese, Japanese and Thai) as rows of 0s and 1s, one column per ingredient. There are nearly three times as many Korean recipes as Thai ones, so a model trained as-is would lean towards Korean.

What are the top ingredients by class

def create_ingredient_df(df):
    # transpose df, drop cuisine and unnamed rows, sum the row to get total for ingredient and add value header to new df
    ingredient_df = df.T.drop(['cuisine','Unnamed: 0']).sum(axis=1).to_frame('value')
    # drop ingredients that have a 0 sum
    ingredient_df = ingredient_df[(ingredient_df.T != 0).any()]
    # sort df
    ingredient_df = ingredient_df.sort_values(by='value', ascending=False, inplace=False)
    return ingredient_df

Step 3 · Drop shared ingredients and balance the classes

Rice, garlic and ginger appear in every cuisine, so they do not help tell them apart. SMOTE then creates synthetic examples of the smaller cuisines until every class has as many rows as the largest.

Drop very common ingredients (common to all cuisines)

feature_df= df.drop(['cuisine','Unnamed: 0','rice','garlic','ginger'], axis=1)
labels_df = df.cuisine #.unique()

Balance data with SMOTE oversampling to the highest class. Read more here: https://imbalanced-learn.org/dev/references/generated/imblearn.over_sampling.SMOTE.html

oversample = SMOTE()
transformed_feature_df, transformed_label_df = oversample.fit_resample(feature_df, labels_df)

print(f'new label count: {transformed_label_df.value_counts()}')

Exercises

  1. Undersample instead of oversample (RandomUnderSampler). How many rows are left, and what is lost?
  2. Print the ten ingredients that best separate Japanese from Chinese recipes (difference in frequency between the two classes).
  3. SMOTE creates points between real neighbours. Why can that produce recipes that make no culinary sense, and why might it still help the classifier?
Recap
What to keep
  • Look at class counts before training.
  • Features shared by every class carry no signal.
  • SMOTE balances classes with synthetic minority examples.

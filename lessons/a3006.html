In plain words first
The idea in one line

Create AI Agents on Snowflake with Lang.ai: a project built with Python.

What it does

Overview

This repository contains files essential for setting up and running a Retention AI Agent using Lang.ai's Native App on Snowflake.

For prerequisites, environment setup, step-by-step guide and instructions, please refer to the QuickStart Guide.

Important Note

The dataset included in this repository is artificially generated for demonstration purposes. While it accurately represents the structure and type of data you'll work with, it should not be considered real customer data.

Read the code

Start with the first file: it is the entry point. The others are the pieces it calls.

Run it on your machine

git clone --depth 1 --filter=blob:none --sparse https://github.com/Snowflake-Labs/sf-samples
cd sf-samples
git sparse-checkout set samples/create_ai_agents_on_snowflake_with_lang_ai
cd samples/create_ai_agents_on_snowflake_with_lang_ai

Install the dependencies (pip install -r requirements.txt if the folder has one), put your keys in a .env file, then start the entry point shown above.

Exercises

  1. Add a limit on the number of tool calls per run and make the agent say so when it hits the limit.
  2. Log every tool call with its arguments and result, then read one full run. Where does the agent waste steps?
  3. Give the agent a tool that fails half the time. Does it retry, give up, or invent a result?

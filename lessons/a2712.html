In plain words first
The idea in one line

A Streamlit app that tells you what an upgrade will break before you run it.

What it does

A Streamlit app that tells you what an upgrade will break before you run it. Paste a requirements.txt or package.json, tick the packages you want to upgrade, and get a short report per package: what changes between your version and the target, what to change in your code, and how to check it.

One agent does the work, built with the Strands Agents SDK, and it reads two public MCP servers:

MCP server Used for Needs
Context7 (https://mcp.context7.com/mcp) Up-to-date library documentation, migration guides and code examples No account. Anonymous use has lower rate limits; Context7 offers a free API key for higher ones
DeepWiki (https://mcp.deepwiki.com/mcp) Questions answered from a public GitHub repository's code and docs No account

What the report contains

For each package:

  • Verdict: Safe, Needs changes or Risky, with the exact versions compared.
  • What breaks: renames, removals and behavior changes, each with its source.
  • What to change: short code snippets when the sources have them.
  • How to check: a test, a command or a warning to look for.

The agent is told to report only what the tools returned and to say which part of the version range the sources do not cover.

How it works

 dependency file ──> parse_dependencies() ──> table ──> one Agent run per ticked package
                                                          │
                                         ┌────────────────┴────────────────┐
                                    Context7 MCP                      DeepWiki MCP
                          (resolve-library-id, query-docs)        (ask_wiki_question)
  • parse_dependencies() reads requirements.txt (pins and ranges, skipping comments, -r, -e and URLs; only ==, ===, ~=, >= and > count as the current version) and package.json (dependencies and devDependencies).
  • build_agent() returns a plain Strands Agent that holds both MCP clients. Strands opens and closes the MCP connections; the app calls agent.cleanup() at the end.
  • tool_filters allow-list only the read-only tools of each server.
  • Each package starts from a clean conversation (agent.messages.clear()), and the expander title shows which tools were used.

Adapt it

  • Use another model provider: build_model() is the only place that picks the provider. Return a different Strands model, for example AnthropicModel(model_id=...) from strands.models.anthropic (install strands-agents[anthropic]), and update the sidebar label.
  • Add a source: add a function that returns an MCPClient (for example a package-registry or changelog MCP server), add it to tools=[...] in build_agent(), and mention it in SYSTEM_PROMPT.
  • Change the report: edit the sections at the end of SYSTEM_PROMPT.

Limits

  • The report is only as good as the sources. Context7 and DeepWiki can lag behind the newest release, and DeepWiki answers are generated from a repository index. Treat the report as a checklist, then run your tests.
  • DeepWiki covers public GitHub repositories only.
  • The app does not read your code, so it cannot tell which breaking changes actually affect you. The How to check section tells you what to search for.

"""Dependency Upgrade Advisor: paste a requirements.txt or package.json, get an upgrade report.

For each package you pick, one agent reads two public MCP servers and writes a short report:
what breaks between your current version and the target, what to change, and how to check it.

    Context7  -> up-to-date library documentation and code examples (resolve-library-id, query-docs)
    DeepWiki  -> questions answered from a GitHub repository's code and docs (ask_wiki_question)

Neither server needs an account or a token. The agent is a plain Strands `Agent`; the model
provider is your choice (see `build_model`).

The agent code is at the top and the Streamlit app is in `main()`, so you can import
`parse_dependencies` and `build_agent` from another script without starting the UI.

SPDX-License-Identifier: Apache-2.0
"""

import asyncio
import json
import os
import re
from dataclasses import dataclass, field
from typing import Any

import streamlit as st
from strands import Agent
from strands.hooks import AfterToolCallEvent
from strands.models.openai import OpenAIModel
from strands.tools.mcp import MCPClient

DEFAULT_MODEL = "gpt-5.4-mini"

SAMPLE_REQUIREMENTS = """\
pydantic==1.10.13
requests==2.25.1
sqlalchemy==1.4.49
"""

SYSTEM_PROMPT = """\
You are a careful release engineer. You are given one package, the version a project uses today
and the version it wants to move to. Find out what breaks between the two and what the project
has to change.

Tools:
- Context7 (resolve-library-id, then query-docs): the library's documentation, migration guides
  and code examples. Resolve the library id first, and ask for a specific version when the
  resolve result lists one.
- DeepWiki (ask_wiki_question): answers about the library's GitHub repository, for example its
  release notes, deprecations and migration steps. Use owner/repo as the repository name.

Rules:
- Every breaking change, rename and removal you report must come from a tool result. Never add
  details from memory, even if you are sure of them.
- If the target is "latest", use the newest stable version that the tools list, and say which
  version that is. If you cannot find it, say so instead of guessing.
- If you cannot find notes for part of the version range, say which part is not covered.
- Name the source of each point (the Context7 library id or the GitHub repository).
- Do not use any other tool, and do not run or edit code.

Answer in Markdown, under 250 words, with exactly these sections:
**Verdict:** one of Safe / Needs changes / Risky, then one sentence why. Name the exact
versions you compared, for example "1.10.13 to 2.14.1".
**What breaks:** a bullet list. Each bullet is the old thing, the new thing and the source.
**What to change:** a bullet list with a short code snippet when the sources have one.
**How to check:** one or two concrete checks (a test, a command or a warning to look for).
"""


# --------------------------------------------------------------------------------------
# Reading a dependency file
# --------------------------------------------------------------------------------------


@dataclass(frozen=True)
class Dependency:
    name: str
    version: str  # "" when the file does not pin one
    ecosystem: str  # "PyPI" or "npm"


_REQ_LINE = re.compile(r"^([A-Za-z0-9][A-Za-z0-9._-]*)(?:\[[^\]]*\])?\s*(.*)$")
# A specifier such as `>=4.4` or `!=5.0`. Only some operators say which version is used today.
_SPECIFIER = re.compile(r"(===|==|~=|>=|<=|!=|>|<)\s*([^\s,;#]+)")
_CURRENT_OPERATORS = {"==", "===", "~=", ">=", ">"}  # `!=`, `<` and `<=` exclude or cap versions
_MAX_NAME_LENGTH = 214  # PyPI and npm both cap package names near this length
_NAME_OK = re.compile(r"^[A-Za-z0-9@][A-Za-z0-9._/@-]*$")
# One npm comparator: an optional operator, then a version number.
_NPM_COMPARATOR = re.compile(r"(<=|>=|<|>|=|\^|~)?\s*v?(\d+(?:\.[0-9A-Za-z*+-]+)*)")
# The Target field goes straight into the prompt, so it must look like a version (or "latest").
TARGET_OK = re.compile(r"^[A-Za-z0-9][A-Za-z0-9._+-]{0,63}$")


def _pypi_version(spec: str) -> str:
    """First version in a requirement specifier that says what is used today ("" if none)."""
    for op, version in _SPECIFIER.findall(spec):
        if op in _CURRENT_OPERATORS:
            return version
    return ""


def _npm_version(spec: str) -> str:
    """First version number in an npm range ("" for "latest", "workspace:*", URLs, upper bounds only)."""
    spec = spec.strip()
    if not re.match(r"^[\^~<>=v\s]*\d", spec):
        return ""
    for op, version in _NPM_COMPARATOR.findall(spec):
        if op not in ("<", "<="):
            return version
    return ""


def parse_dependencies(text: str) -> list[Dependency]:
    """Read a requirements.txt or a package.json (dependencies and devDependencies).

    Lines such as comments, `-r other.txt`, `-e .` and URLs are skipped. A range such as
    `>=1.0,<2` keeps its first version number, because that is the lower bound in use. `!=` and `<`
    do not say which version is in use, so those packages count as unpinned.
    """
    text = text.lstrip("\ufeff").strip()  # drop a BOM so `{` is detected
    if not text:
        return []

    if text.startswith("{"):
        try:
            data = json.loads(text)
        except json.JSONDecodeError as exc:
            raise ValueError(f"This looks like package.json but is not valid JSON: {exc}") from exc
        if not isinstance(data, dict):
            raise ValueError("package.json must be a JSON object.")
        found: dict[str, str] = {}
        for section in ("dependencies", "devDependencies"):
            value = data.get(section)
            if value is None:
                continue
            if not isinstance(value, dict):
                raise ValueError(f'"{section}" in package.json must be an object of name: version pairs.')
            for name, spec in value.items():
                if len(name) <= _MAX_NAME_LENGTH and _NAME_OK.match(name):
                    found[name] = str(spec)
        # Specs such as "workspace:*", "latest" or a URL count as unpinned.
        return [Dependency(n, _npm_version(spec), "npm") for n, spec in found.items()]

    deps: list[Dependency] = []
    for raw in text.splitlines():
        line = raw.split(" #")[0].strip()
        if not line or line.startswith(("#", "-", "git+", "http")):
            continue
        match = _REQ_LINE.match(line)
        if match and len(match.group(1)) <= _MAX_NAME_LENGTH:
            deps.append(Dependency(match.group(1), _pypi_version(match.group(2)), "PyPI"))
    return deps


# --------------------------------------------------------------------------------------
# The agent
# --------------------------------------------------------------------------------------


def context7_client() -> MCPClient:
    # Hosted, works without an API key (Context7 applies a rate limit to anonymous use).
    return MCPClient(
        url="https://mcp.context7.com/mcp",
        tool_filters={"allowed": ["resolve-library-id", "query-docs"]},
    )


def deepwiki_client() -> MCPClient:
    # Hosted, no account needed, public repositories only.
    return MCPClient(
        url="https://mcp.deepwiki.com/mcp",
        tool_filters={"allowed": ["ask_wiki_question"]},
    )


def build_model(model_id: str = DEFAULT_MODEL, api_key: str | None = None) -> OpenAIModel:
    """The one place that picks the model provider.

    To use another provider, return a different Strands model here, for example
    `AnthropicModel(model_id=...)` from `strands.models.anthropic`, and install the
    matching extra (`strands-agents[anthropic]`).
    """
    return OpenAIModel(client_args={"api_key": api_key or os.environ.get("OPENAI_API_KEY")}, model_id=model_id)


@dataclass
class ToolTrail:
    """Which MCP tools the agent used while answering one package."""

    calls: list[str] = field(default_factory=list)

    def record(self, event: AfterToolCallEvent) -> None:
        self.calls.append(event.tool_use["name"])


def build_agent(model: Any) -> tuple[Agent, ToolTrail]:
    """A plain Strands Agent holding both MCP clients. Call `agent.cleanup()` when done."""
    trail = ToolTrail()
    agent = Agent(
        model=model,
        system_prompt=SYSTEM_PROMPT,
        tools=[context7_client(), deepwiki_client()],
        callback_handler=None,  # the UI does the streaming
    )
    agent.add_hook(trail.record, AfterToolCallEvent)
    return agent, trail


def question_for(dep: Dependency, target: str) -> str:
    current = dep.version or "an unpinned (unknown) version"
    return f"Package: {dep.name} ({dep.ecosystem})\nCurrent version: {current}\nTarget version: {target or 'latest'}"


# --------------------------------------------------------------------------------------
# Streamlit app
# --------------------------------------------------------------------------------------


async def advise(agent: Agent, trail: ToolTrail, dep: Dependency, target: str, status, box) -> str:
    """Stream the report for one package into the page."""
    agent.messages.clear()  # every package starts from a clean conversation
    trail.calls.clear()
    text = ""
    async for event in agent.stream_async(question_for(dep, target)):
        tool = event.get("current_tool_use")
        if tool and tool.get("name"):
            status.update(label=f"{dep.name}: using {tool['name']}...")
        if "data" in event:
            text += event["data"]
            box.markdown(text)
    return text


def main() -> None:
    st.set_page_config(page_title="Dependency Upgrade Advisor", page_icon="📦", layout="wide")
    st.title("📦 Dependency Upgrade Advisor")
    st.caption(

Setup

You need Python 3.10+ and an OpenAI API key. No other account or token is needed.

pip install -r requirements.txt
export OPENAI_API_KEY=sk-...        # or type it in the sidebar
streamlit run dependency_upgrade_advisor.py

Then:

  1. Paste your dependency file (a sample is pre-filled).
  2. In the table, tick the packages and set Target to a version number or latest. Keep it to a few packages per run: each one is a separate agent run with several tool calls.
  3. Click Check upgrades.

Exercises

  1. Connect the server to a second MCP client (Claude Desktop, an IDE or the MCP Inspector) and list its tools.
  2. Add input validation to one tool and return a clear error the model can recover from.
  3. Decide which tools should need human approval, and add that check.

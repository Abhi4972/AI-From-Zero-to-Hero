Why this came about

Python was created by Guido van Rossum and first released in 1991, with one main goal: code that is easy for people to read. It became the language of data and AI because the key libraries were written for it: NumPylater · 0.14 for fast arithmetic on large arrays (2006), pandas for tables of data (2008), scikit-learn for machine learninglater · 2.2 (around 2010) and PyTorchlater · 3.16 for neural networks (2016). Today nearly every AI library, tutorial and research paper's code is in Python, so it is the one language this course uses.

In plain words first
A program is a recipe

A program is a list of instructions, like a recipe. Python reads it from the top, one line at a time, and does exactly what each line says, nothing more. Most instructions work with values: a number such as 499, a piece of text such as "tea", or True. You can give a value a name, called a variable, so you can use it later. print(...) shows a value on the screen so you can see what your program is doing.

Step 1 · Your first program

Start with the smallest program that does something you can see. print is a function: a named action. Whatever you put inside its brackets is shown on the screen. Type these three lines into a file, or into the box below, and run them:

print("Hello, ShopKart!")
print("Orders today:", 42)
# A line that starts with # is a comment. Python ignores it; it is a note for people.
What you should see
Hello, ShopKart!
Orders today: 42

Two ways to run this:

  • As a script. Save the three lines in a file called hello.py inside your course folder and run uv run hello.py in the terminal. Python runs the whole file from top to bottom and prints the results.
  • In a notebook. Paste the lines into a notebook cell (VS Code or Colab) and press Shift+Enter. The output appears under the cell. Notebooks are handy for trying things; scripts are what you ship.

print is a function: a named action you call by writing its name followed by brackets. What you put inside the brackets are its arguments. print accepts several arguments separated by commas and prints them with a space between. The text "Hello, ShopKart!" is in quotes so Python knows it is text, not an instruction.

Step 2 · Values have types

Every value has a type, which decides what you can do with it. The built-in function type(...) tells you which:

print(type(42), type(4.99), type("tea"), type(True), type(None))
What you should see
<class 'int'> <class 'float'> <class 'str'> <class 'bool'> <class 'NoneType'>
Type Name in Python Examples Used for
Whole number int (integer) 42, -7, 0 Counts, quantities, IDs
Decimal number float (floating-point) 4.99, 0.5, -1.0 Prices, probabilities, measurements
Text str (string) "tea", 'Pune', "SK-1042" Names, messages, anything written
True or false bool (boolean) True, False Answers to yes/no questions
Nothing NoneType None "No value here yet"

Text can use double or single quotes: "tea" and 'tea' are the same string. True, False and None are written with a capital letter and no quotes.

Step 3 · Arithmetic

Python works as a calculator. Most symbols mean what you expect. Three are new: // divides and throws away the remainder, % gives only the remainder, and ** raises to a power. The third line shows a surprise that every programmer meets sooner or later; predict what 0.1 + 0.2 prints before you run it.

print(7 + 3, 7 - 3, 7 * 3, 7 / 3)
print(7 // 3, 7 % 3, 2 ** 10)
print(0.1 + 0.2)
print(round(0.1 + 0.2, 2))
What you should see
10 4 21 2.3333333333333335
2 1 1024
0.30000000000000004
0.3
Reading this output
  • 7 / 3 is division and always gives a float: 2.3333333333333335.
  • 7 // 3 is floor division: divide and drop the remainder, giving 2. 7 % 3 (read "7 modulo 3") is the remainder, 1. Together they answer "how many full boxes of 3, and how many left over?"
  • 2 ** 10 is a power: 2 to the 10th, 1024.
  • 0.1 + 0.2 prints 0.30000000000000004, not 0.3. Computers store decimal numbers in binary, and most decimals (like 0.1) cannot be stored exactly, so tiny errors appear. This is normal in every programming language. Round when you display results, and never compare floats with == (Step 7).

Step 4 · Variables: names for values

A variable is a name you attach to a value with =, the assignment sign. Read price = 499 as "let price be 499", not as "price equals 499".

price = 499
qty = 2
total = price * qty
print(total)
qty = 3              # point qty at a new value
print(total)         # total does not change by itself: it was computed earlier
total = price * qty  # compute it again
print(total)
count = 10
count += 1           # shorthand for count = count + 1
print(count)
What you should see
998
998
1497
11

The second print(total) still shows 998: changing qty later does not reach back and update total. Python ran total = price * qty once, when it reached that line, and stored the result. This surprises many beginners; spreadsheets update automatically, programs do not.

Naming rules. Names may contain letters, digits and underscores, but cannot start with a digit (2nd_price is not allowed). They are case-sensitive: Price and price are different variables. By convention Python code uses snake_case, lowercase words joined by underscores: order_total, delivery_days. Choose names that say what the value means; days_to_deliver beats d. Avoid names Python already uses, such as print, list, str or type: you would hide the built-in function.

Step 5 · Text: strings

A piece of text is called a string, written between quotes. Strings come with built-in actions, called methods, that you call with a dot: name.upper() asks the string name for an upper-case copy of itself. The lines below join strings, measure them, clean them, split them and pick characters out of them. These few operations are most of what you will do to text for the rest of the course.

name = "Asha"
greeting = "Hello, " + name + "!"   # + joins strings
print(greeting)
print(len(name), name.upper(), name.lower())
message = "   Refund approved   "
print("[" + message.strip() + "]")
print("tea,rice,soap".split(","))
print("I love tea".replace("tea", "coffee"))
print(name[0], name[-1], name[1:3])
What you should see
Hello, Asha!
4 ASHA asha
[Refund approved]
['tea', 'rice', 'soap']
I love coffee
A a sh
Reading this output
  • len(name) is the length: how many characters, 4.
  • .upper(), .lower(), .strip(), .split(",") and .replace(...) are methods: functions that belong to a value and are called with a dot after it. .strip() removes spaces at both ends; .split(",") cuts the text at each comma and gives back a list of pieces (Lesson 0.10).
  • name[0] is the first character. Positions start at 0, not 1. name[-1] counts from the end: the last character. name[1:3] is a slice: from position 1 up to, but not including, position 3, so "sh".
  • Strings never change in place: name.upper() gives back a new string and leaves name as it was.

The neatest way to build text from values is an f-string: put f before the opening quote and write any expression inside {}.

item, price, qty = "tea", 249.5, 3          # three assignments in one line
print(f"{qty} x {item} = {price * qty} rupees")
print(f"Total: {price * qty:.2f}")           # :.2f means 2 decimal places
print(f"{'Item':<8}|{'Price':>8}")           # < left-align, > right-align, in 8 characters
print(f"{item:<8}|{price:>8.2f}")
What you should see
3 x tea = 748.5 rupees
Total: 748.50
Item    |   Price
tea     |  249.50

You will build prompts for language models this way throughout the course, so f-strings are worth getting comfortable with.

Step 6 · Converting between types

Text that looks like a number is still text. Convert it before doing arithmetic:

typed = "42"
print(typed + "1")       # two strings: joined
print(int(typed) + 1)    # converted to a number first: added
print(str(3.5) + " stars")
print(float("4.99") * 2)
print(int(4.99))         # int() cuts off the decimals; it does not round
print(bool(0), bool(7), bool(""), bool("no"))
What you should see
421
43
3.5 stars
9.98
4
False True False True

The last line shows Python's idea of "truthiness": 0, empty text "" and None count as false; any other number or any non-empty text counts as true. Even the text "no" is true, because it is not empty.

Tip
Text from the keyboard is always a string

answer = input("How many? ") waits for the user to type something and gives it back as text, even if they typed 3. Convert with int(answer) before doing arithmetic. (The course code never waits for typing, so you will not see input in a runnable block.)

Step 7 · True and false: comparisons

Programs make decisions by asking yes/no questions. A comparison gives back True or False:

price = 499
print(price > 300, price == 499, price != 499)
in_stock, prime_member = True, False
print(in_stock and prime_member, in_stock or prime_member, not in_stock)
print("tea" in "green tea", 300 <= price < 1000)
print(abs((0.1 + 0.2) - 0.3) < 1e-9)       # the safe way to compare floats
What you should see
True True False
False True False
True True
True
Operator Means Example
==, != equal, not equal qty == 0
<, <=, >, >= less than, at most, greater than, at least price >= 500
and, or, not both true, at least one true, the opposite in_stock and paid
in contained in "tea" in "green tea"

= and == are different: one = assigns (puts a value in a variable), two == compares. Mixing them up is one of the most common beginner mistakes. The last line shows how to compare decimals safely: check that they are very close (1e-9 means 0.000000001), not exactly equal.

Check your mental model
  • ✗ "x = 5 means x equals 5, like in algebra."
    ✓ It means: put the value 5 in the box named x, now. Later lines can change it.
  • ✗ "If I change a variable, everything computed from it updates."
    ✓ Python computes each line once, when it reaches it. Recompute if inputs change.
  • ✗ ""42" and 42 are the same."
    ✓ One is text, one is a number. "42" + "1" is "421"; 42 + 1 is 43.
  • ✗ "Positions in text start at 1."
    ✓ They start at 0. The first character of name is name[0].

Exercises

Predict before you run

What do these print? print(10 / 4), print(10 // 4), print(10 % 4), print("5" * 3). Write your four answers, then run them. (Solution P1.)

Break it on purpose

Run this and read the error message. Then fix it in two different ways.

total = 998
print("Total: " + total)

(Solution B1.)

Make it your own

A customer buys 3 packs of tea at INR 249.50 and 2 bags of rice at INR 89. Write code that computes the subtotal, adds 5% GST, and prints a line such as Subtotal: 926.50 | GST: 46.33 | Total: 972.83. (Solution M1.)

Solutions

SolutionP1 · Division and repetition

10 / 4 is 2.5 (division always gives a float). 10 // 4 is 2 (floor division). 10 % 4 is 2 (the remainder: 4 goes into 10 twice, with 2 left). "5" * 3 is "555": multiplying text by a number repeats it.

SolutionB1 · Joining text and a number

Python stops with TypeError: can only concatenate str (not "int") to str. It will not guess whether you meant to add numbers or join text. Fix 1: convert, print("Total: " + str(total)). Fix 2 (usually better): an f-string, print(f"Total: {total}"). A third option is print("Total:", total), letting print put a space between its arguments.

SolutionM1 · A small bill
tea, rice = 3 * 249.50, 2 * 89
subtotal = tea + rice
gst = subtotal * 0.05
print(f"Subtotal: {subtotal:.2f} | GST: {gst:.2f} | Total: {subtotal + gst:.2f}")

This prints Subtotal: 926.50 | GST: 46.33 | Total: 972.83. Formatting with :.2f rounds only the display; the variables keep their full precision.

Recap
  • Python runs a program top to bottom; print shows values; # starts a comment.
  • Values have types: int, float, str, bool, None. The type decides what you can do.
  • = assigns a value to a name; variables do not update themselves when other variables change.
  • Strings have methods (.upper(), .split()), positions start at 0, and f-strings build text from values.
  • Comparisons give True or False; == compares, = assigns.

Check your understanding

Q1What does print(type(3.0)) show?

A number with a decimal point is a float, even when the decimal part is zero.

Q2After a = 2, b = a * 10, a = 5, what is b?

b was computed when a was 2; changing a afterwards does not change b.

Q3What is "ShopKart"[1:4]?

A slice starts at position 1 and stops before position 4: characters 1, 2 and 3.

Q4Which line compares two values?

Two equals signs compare; one assigns.

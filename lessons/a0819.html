Visual Autoregressive Modeling (VAR): Next-Scale Prediction

In plain words first
The idea in one line

Diffusion models sample iteratively in time (denoising steps). VAR samples iteratively in scale — it predicts a 1x1 token, then 2x2, then 4x4, up to the final resolution, each scale conditioning on the previous. The 2024 paper showed VAR matches GPT-style scaling laws for image generation and beats DiT at the same compute budget. This lesson builds the core mechanism.

Terms you'll hear
Term What people say What it actually means

Next-scale prediction "Predict coarser, then finer" The model predicts tokens at increasing resolution scales, conditioning on all previous scales
Multi-scale VQ tokenizer "Residual VQ" VQ-VAE that produces K token grids of increasing resolution, with decoder summing all scales

Causal-across-scales "Scale-ordered attention" Token at scale $k$ can attend to all of scales $1 \ldots k$ but not scales $k+1 \ldots K$

The problem

In plain words first

Language models write text one token at a time, and that recipe scales beautifully. Applied to images, it means generating a grid of image tokens one by one in reading order, which is slow and forces the top-left corner to be decided before the model knows what the picture will be. VAR, visual autoregressive modelling, changes the order: first predict a single token summarising the whole image, then a 2 × 2 grid, then 3 × 3, and so on up to the final grid, each step adding detail to everything at once. Every token of a scale is predicted in the same pass, so a 256 × 256 image takes ten passes. This lesson runs the lesson's toy VAR, counts the passes and tokens of the real one, and then runs the authors' released VAR model on this page's CPU: a real photo decoded after more and more scales, and new images generated scale by scale. Nothing is trained.

Autoregressive generation dominated language modeling because it scales predictably: more compute, more parameters, lower perplexity, better outputs. Image generation had two main AR attempts before 2024: PixelRNN/PixelCNN (pixel-by-pixel) and DALL·E 1 / Parti (token-by-token on VQ-VAE codes).

Both suffered from a generation-order problem. Pixels and tokens are arranged in a 2D grid, but the AR model has to visit them in a 1D raster order. An early corner pixel has no idea what the image eventually becomes. Generation quality scaled worse than GPT-on-text and never reached diffusion-model quality at matched compute.

VAR fixes the generation-order problem by changing what is being generated. Instead of predicting image tokens one by one in space, VAR predicts a whole image at increasing resolutions. Step 1: predict a 1x1 token (the overall image "summary"). Step 2: predict a 2x2 grid of tokens (coarser features). Step 3: predict a 4x4 grid. Step K: predict the final (H/8)x(W/8) grid.

Each scale attends to all previous scales (causally in "scale order") and parallel within its own scale. The order problem disappears: the whole image at scale k is produced in one transformer pass.

Idea 1 · VQ-VAE Multi-Scale Tokenizer

VAR needs a multi-scale discrete tokenizer. For an image x, it produces a sequence of progressively higher-resolution token grids:

x -> encoder -> latent f
f -> tokenize at 1x1: token grid z_1 of shape (1, 1)
f -> tokenize at 2x2: token grid z_2 of shape (2, 2)
...
f -> tokenize at (H/p)x(W/p): token grid z_K of shape (H/p, W/p)

Each zk​ uses the same codebook (typical size 4096-16384). The tokenization at each scale is not independent — it is trained so that summing the residuals at each scale reconstructs f:

f≈upsample(embed(z1​),target_size)+⋯+upsample(embed(zK​),target_size)

This is a residual VQ variant. Scale k captures what scales 1…k−1 missed. Decoder takes the sum of all scale embeddings and produces the image.

The multi-scale VQ tokenizer is trained once (like VQGAN) and then frozen. All the generative work is done by the autoregressive model on top.

Idea 2 · Next-Scale Prediction

The generative model is a transformer that sees tokens from all previous scales and predicts the tokens at the next scale.

Input sequence structure:

[START, z_1 tokens, z_2 tokens, z_3 tokens, ..., z_K tokens]

Position embeddings encode both scale index and spatial position within the scale. Attention is causal in scale order and block-wise inside a scale: token at scale k, position (i,j) can attend to all tokens at scales 1…k, including every position of scale k itself. There is no intra-scale order and no intra-scale causality, so all positions within a scale are predicted in parallel.

Training loss: at each scale k, predict the tokens zk​ given all prior-scale tokens. Cross-entropy loss on the discrete VQ codes. Same structure as GPT except the "sequence" is now scale-structured.

Idea 3 · Generation

At inference:

generate z_1 = sample from p(z_1)                    # 1 token
generate z_2 = sample from p(z_2 | z_1)              # 4 tokens in parallel
generate z_3 = sample from p(z_3 | z_1, z_2)         # 16 tokens in parallel
...
decode: f = sum of embed-and-upsample scales 1..K
image = VAE_decoder(f)

For K=10 scales, generation is 10 transformer forward passes. Each pass produces its entire scale in parallel — no per-token autoregression within a scale. For a 256x256 image this is 10 passes, against DiT's 25–250 sampling steps and 256 passes for a raster-order token model.

The same idea as a formula

Next-token (raster) factorisation of a token grid z with n positions: p(z)=∏i=1n​p(zi​∣z<i​), n sequential passes.

Next-scale factorisation. With token maps r1​,…,rK​ of sizes hk​×wk​:

p(r1​,…,rK​)=k=1∏K​p(rk​∣r1​,…,rk−1​),p(rk​∣r<k​)=(i,j)∏​p(rk(i,j)​∣r<k​)

The second product says the tokens within a scale are sampled independently given the coarser scales: K passes instead of ∑k​hk​wk​.

Multi-scale residual quantisation. With encoder output f, codebook C and up/down-sampling ↑,↓:

rk​=Q(↓hk​​(f−f^​k−1​)),f^​k​=f^​k−1​+↑(C[rk​]),f^​0​=0

Each scale quantises what the coarser ones missed; the decoder turns f^​K​ into the image.

Attention mask. Token at scale k may attend to every token of scales 1,…,k (block-causal), never to finer scales.

Cost. Tokens: N=∑k​hk​wk​ (680 for VAR's ten scales up to 16×16). With a KV cache, pass k processes only the hk​wk​ new tokens.

Idea 4 · Why Next-Scale Wins Over Next-Token

Three structural wins: 1. Coarse-to-fine aligns with natural image statistics. Human visual perception and image datasets both exhibit scale-dependent regularities: low-frequency structure is stable and predictable; high-frequency detail is conditional on low-frequency content. Next-scale prediction exploits this. 2. Parallel generation within scale. Unlike GPT-style token AR, VAR produces all tokens at a scale in one step. Effective generation length is log-scale instead of linear. 3. No generation order bias. Tokens at scale k see all of scale k-1; there is no "left-of" or "above" bias that forces early tokens to commit before late context is available.

Idea 5 · Scaling Law

Tian et al. demonstrated that VAR follows a power-law scaling curve for FID on ImageNet — just like GPT does for perplexity. The fitted exponents are small, as for language models: each doubling of compute lowers the loss by a modest but predictable fraction. This was the first image-generative model to exhibit this kind of scaling behavior as cleanly as language models. The result is that VAR-scale predictions become predictable from compute, not empirical guesses per architecture.

Idea 6 · Relationship to Diffusion

VAR and diffusion share the same data-compression story: both break the generation problem into a sequence of easier subproblems.

  • Diffusion: gradually add noise, learn to undo one step.
  • VAR: gradually add resolution, learn to predict the next scale.

They are different axes through the problem. Both yield tractable conditional distributions. Empirically VAR is faster at inference (fewer passes, all parallel within a scale) and matches or beats DiT on class-conditional ImageNet. Text-to-image versions followed: HART (MIT and NVIDIA), Infinity (ByteDance) and Switti bring next-scale prediction to text-to-image generation at up to 1024 × 1024.

Industry practice
What's current (2024–2026)
  • Next-scale text-to-image. Infinity (ByteDance, bitwise tokens), HART (MIT and NVIDIA, hybrid discrete plus continuous tokens) and Switti apply next-scale prediction to text-to-image generation with open code and weights.
  • Autoregressive image generation in multimodal LLMs. OpenAI's GPT Image models and other "native" image generators inside multimodal models are reported to generate autoregressively, often with a diffusion decoder; open examples include Janus-Pro and Lumina-mGPT.
  • Diffusion still dominates open image models. FLUX.2, Qwen-Image and Z-Image are flow-matching transformers; next-scale and token models remain the main alternative.

Refuse separate per-scale codebooks unless V is calibrated to the smaller scale's pixel count and codebook collapse is mitigated. Refuse next-scale prediction at all when K x average-scale-area exceeds the LM's max sequence length minus headroom for text conditioning.

Exercises

  1. Scale count ablation. Train VAR with 4, 6, 8, 10 scales. Measure reconstruction quality vs number of autoregressive passes. More scales = finer residuals = better quality but more passes.

  2. Codebook size. Train tokenizers with codebook sizes 512, 4096, 16384. Larger codebooks give better reconstruction but harder prediction. Find the knee.

  3. Parallel-within-scale check. For a trained VAR, measure the attention pattern explicitly. Within scale k, does the model attend to cross-scale positions but not intra-scale? Verify the mask implementation.

  4. VAR vs DiT scaling. For the same ImageNet class-conditional task, train VAR and DiT at matched param budgets (e.g., 33M, 130M, 458M). Plot FID vs compute. VAR should pull ahead of DiT at each size — reproduce the paper's result at small scale.

  5. Text conditioning. Extend VAR to take a text embedding (CLIP pooled) as an extra conditioning input via adaLN. This is the HART recipe. How much does FID improve on text-aligned sampling?

Solutions

SolutionP1 · Around six to eight scales

Around six to eight scales. After one scale the decoded image is a flat grey; after four it is a blurry pale blob; after six the dog's dark ears and white chest are in place; after eight (the 10×10 grid) it is clearly the photo, and the last two scales, which hold more than half of all tokens, add only fine detail. Each scale stores the residual of the coarser ones, so composition and colour are settled early with few tokens. That is the property VAR exploits: decisions about the whole picture are made first, while a raster model must commit to its top-left corner before anything else.

SolutionB1 · Training and sampling disagree

With a causal mask inside a scale, every training prediction of token (i,j) is made knowing the true tokens before it in raster order, and the model learns to rely on them, for example copying a neighbour's colour. At generation time the whole scale is sampled in one pass, so those neighbours do not exist yet: the inputs at their positions are not the tokens the model learned to expect. Its predictions are made in a situation it never trained on, and neighbouring tokens no longer agree with each other, giving blotchy, incoherent textures. Either sample the scale token by token (losing VAR's speed) or, as VAR does, train with the same block mask used at generation, so that tokens within a scale depend only on coarser scales.

Interview questions

Try answering out loud first, then open one answer at a time.

Questions from real AI engineering interviews that this lesson prepares you for. Answer out loud first, then open the worked answer.

Explain the mechanismToken-by-token image generation used to mean predicting one code after another in raster order. A newer method predicts whole grids at increasing resolution instead. Explain what it predicts at each step, why that fixes the old method's main weakness, and how it compares with diffusion in the number of network passes.

Level 2 of 4 · about 10 minutes to answer well.

Short answer. Next-scale prediction tokenizes an image into a pyramid of grids, from one code up to the full latent resolution, with a residual quantizer so that the sum of the scales reconstructs the image. The transformer is causal across scales and parallel within a scale: given all coarser grids, it predicts every code of the next grid in one pass. That removes the raster-order problem, where an early corner code had to commit before any context existed. For a 256 by 256 image the reference uses about 10 scales, so generation is about 10 passes against 28 to 50 for a diffusion transformer, and all codes of a scale come out together.

The tokenizer.

A multi-scale residual quantizer: encode the image to a latent, quantize it at 1 by 1, then at 2 by 2, then 4 by 4, up to the full latent grid, with one shared codebook. Each scale encodes what the coarser scales missed, and the decoder takes the sum of all upsampled scale embeddings. The codebook is typically 4096 to 16384 entries. Train it once and freeze it.

The model.

The input for scale 1 is a start token. The input for each later scale k is a grid built from the coarser scales only, upsampled to the size of scale k. The codes of scale k are the targets at those positions, and they enter the input only for the scales after k. Position embeddings carry the scale index and the position within the scale. The attention mask is block-causal: a code at scale k attends to every code of scales 1 to k, including all positions of its own scale, and to nothing finer. Training is cross-entropy on the codes at each scale given the coarser scales.

Why it beats raster order.

  1. Coarse to fine matches image statistics: low-frequency structure is stable and predictable, and detail is conditional on it.
  2. Parallel within a scale: the generation length is logarithmic in the pixel count instead of linear.
  3. No order bias: nothing is left of or above anything inside a scale, so no early code commits before the late context exists.

The scaling result.

The paper reports a power law of image quality against compute, the way language models scale in perplexity, and a better quality than a diffusion transformer at matched compute on a class-conditional benchmark.

Relation to diffusion.

Both break generation into easier conditional steps. Diffusion adds noise and learns to remove one step of it; next-scale prediction adds resolution and learns to predict one more scale. The scale method needs fewer passes and parallelizes inside each pass; text-conditioned variants were an open research direction at the time of the lesson.

Plausible wrong answers.

  • "It is diffusion with a different name." Diffusion iterates over noise levels on continuous latents; this iterates over resolution on discrete codes and predicts a whole grid per pass.
  • "Within a scale the codes still go one by one." The mask is bidirectional inside a scale, so one forward pass produces the whole grid.
  • "Raster order only costs speed." It also biases generation: an early code commits before the context that should condition it exists, which capped quality below diffusion at matched compute.

Follow-ups an interviewer may ask.

  • (level 2) Why does the residual structure matter for the tokenizer? Expected: each scale encodes only what the coarser scales missed, so the sum reconstructs the latent and the scales are not redundant.
  • (level 2) What does a code at scale k see, and what may it not see? Expected: all codes at scales 1 to k, its own scale's positions included; nothing at finer scales.
  • (level 3) What happens to quality and cost as you add scales? Expected: finer residuals and better reconstruction, at the cost of one more pass per scale; the lesson's exercise sweeps 4 to 10 scales to find the knee.
  • (level 3) How would you add text conditioning? Expected: feed a pooled text embedding through adaptive normalization, as the hybrid variant in the lesson does, and measure the gain on text-aligned samples.

Where it is taught. The visual autoregressive lesson builds the multi-scale tokenizer and the scale-ordered mask.

Frameworks

MidCompare LangGraph, OpenAI Agents SDK, Strands, Google ADK and Microsoft Agent Framework.

LangGraph is a low-level graph runtime with checkpoints, interrupts and durable state: maximum control. The OpenAI Agents SDK is a small set of primitives (agents, tools, handoffs, guardrailslater · 15.23, sessions, tracing), quick to start. Strands is model-driven with hooks, steering and native AWS integration. ADK is Google's code-first framework with workflow agents and graph workflows, deployable to Agent Runtime. Microsoft Agent Framework merges Semantic Kernel and AutoGen with typed workflows and Azure integration. All support MCPlater · 16.26 and OpenTelemetrylater · 14.145; choose by control needed, ecosystem, team language and where you deploy.

MidWhen would you choose CrewAI, Pydantic AI, LlamaIndex or DSPy?

CrewAI for role-based multi-agent crews and event-driven flows with a gentle learning curve. Pydantic AI for type-safe Python agents with validated structured outputs, dependency injection and a strong testing story. LlamaIndex when the application is document-heavy: parsing, indexing and query engines, plus agent workflows on top. DSPy when you want to optimize prompts and few-shot examples programmatically against a metric instead of hand-tuning them. None of these is wrong; the deciding factors are control, team familiarity and how much of the work is retrieval versus orchestration.

MidHow do you avoid lock-in to an agent framework?

Keep the framework thin: tools as plain functions or MCP servers, prompts in files or a registry, models behind a gateway with an OpenAI-compatible API, traces in OpenTelemetry, evals independent of the framework, and state in your own database. Then switching frameworks means rewriting the orchestration layer only. Record the choice in a short decision record with the criteria, so it can be revisited.

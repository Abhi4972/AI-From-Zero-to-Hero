The problem

In plain words first

An executable file is not a mystery box; it has a documented layout. Linux uses ELF, Windows uses PE/COFF, macOS uses Mach-O, and each says where the code is, which parts are writable, which functions it calls from shared libraries and where execution starts. This project builds a static inspector for all three, written defensively because binary files are untrusted input.

It is a bridge from phase 13's reverse-engineering lessons to a working tool: read headers; list sections with permissions and entropy; resolve symbols and demangle C++ names; read imports, exports, relocations and macOS chained fixups; recover strings and function starts even from stripped binaries; and publish a JSON report, an HTML byte map and a diff between two builds.

A static inspector that reads ELF, PE/COFF, and Mach-O files you compiled and reports their layout, names, links, and function starts.

You give it an ELF64 object, a COFF object, a PE32+ image, or a Mach-O 64 file. It reports the format, the architecture, and the sections and segments with permissions and entropy. It also reports symbols with demangled C++ names, imports, exports, relocations, Mach-O chained fixups, strings with their section, and function starts. With the unstripped build of the same source, it scores each function start method with precision and recall. It writes a JSON report, a standalone HTML report with a byte map, and a diff between two builds.

Python 3.10 or later and the standard library only. The grader also uses Python. The fixtures are already built, so you need clang only to rebuild them.

Where it stops: Check the contents of a build before a release: which sections are writable and executable, which libraries it imports, and which names strip removed. Compare two builds of your own program and see which sections grew, which symbols moved, and which strings changed.

Step 1 · Detect the format and parse the header

Step 1 of 6 · about 1.5 hours · Python

Read the magic bytes and identify ELF64, a COFF object, a PE32+ image, or Mach-O 64. Parse the file header of each into one shape: format, architecture, kind, entry point, and the raw fields. Read the Mach-O load commands in sequence. Refuse 32-bit, big-endian, universal, and truncated files with a FormatError that names the reason.

Read the project README first. This stage applies the ELF header reader of lesson 32. It adds COFF, PE32+, and Mach-O with the tables of lesson 40.

What you build. You write three functions in the formats module:

  • detect_format(data) reads the first bytes and returns "elf64", "coff", "pe", or "macho64".
  • parse_header(data) returns one dictionary shape for all four formats.
  • load_commands(data) returns the Mach-O load commands in file order.

Every later stage calls parse_header first. If the header is wrong, every section, symbol, and fixup after it is wrong too.

Why it matters. A file extension does not identify a binary. A .o file from clang can be ELF or Mach-O. A .obj file is a COFF object and has no magic number at all. The inspector must decide from the bytes, and it must refuse a file it cannot read correctly. A tool that guesses and continues prints tables that look correct and are not.

All four formats in this project are little-endian. The supplied unpack(fmt, data, offset) helper reads one record with struct.unpack_from and raises FormatError when the record runs past the end of the file. Use it for every read, so a truncated file always fails with a message that names the offset.

Work through one concrete case. The first 32 bytes of the stripped arm64 build are:

cf fa ed fe 0c 00 00 01 00 00 00 00 02 00 00 00
12 00 00 00 a8 05 00 00 85 00 20 00 00 00 00 00

Read them as eight little-endian 32-bit fields (<IiiIIIII):

Field Bytes Value Meaning
magic cf fa ed fe 0xfeedfacf Mach-O 64, little-endian
cputype 0c 00 00 01 0x0100000c arm64 (CPU_TYPE_ARM with the 64-bit flag)
filetype 02 00 00 00 2 MH_EXECUTE, so kind is "executable"
ncmds 12 00 00 00 18 18 load commands follow
sizeofcmds a8 05 00 00 1448 they occupy bytes 32 to 1480
flags 85 00 20 00 0x00200085 MH_NOUNDEFS, MH_DYLDLINK, MH_TWOLEVEL, MH_PIE

The load commands start at offset 32. Each starts with cmd and cmdsize. The first is LC_SEGMENT_64 (0x19). The next starts at 32 plus its cmdsize. One of the 18 is LC_MAIN (0x80000028), whose entryoff is 0x5e8. The __TEXT segment starts at virtual address 0x100000000, so the entry point is 0x1000005e8. That is the address of _main in the unstripped build.

The other formats follow the same pattern:

  • ELF: 7f 45 4c 46, then EI_CLASS 2 (64-bit) and EI_DATA 1 (little-endian). e_type 1 is relocatable. e_machine 62 (0x3e) is x86-64. The tally object has e_shnum 13 and e_shstrndx 1.
  • COFF object: no magic. Bytes 64 86 are machine 0x8664, then 0a 00 is 10 sections. SizeOfOptionalHeader is 0, which is what makes it an object.
  • PE image: MZ at offset 0, e_lfanew at 0x3c is 0x40, and PE\0\0 is at 0x40. The optional header starts at 0x58 with magic 0x20b (PE32+). AddressOfEntryPoint 0x1000 plus ImageBase 0x140000000 gives entry 0x140001000.

Pick a format in the lab and change the fields. The lab computes the same decision that detect_format makes and shows which check fails first.

Implement the contract. detect_format(data: bytes) -> str

  • Fewer than 4 bytes: raise FormatError.
  • \x7fELF: require EI_CLASS 2 and EI_DATA 1, else raise FormatError that says "ELF64" or "little-endian". Return "elf64".
  • MZ: read e_lfanew at 0x3c and require PE\0\0 there. Return "pe".
  • 0xfeedfacf read as a little-endian word: return "macho64". Raise for 0xfeedface ("32-bit") and for ca fe ba be ("universal").
  • Otherwise, if the first 20 bytes parse as a COFF file header with a machine in COFF_MACHINES, SizeOfOptionalHeader 0, and 1 to 96 sections, return "coff".
  • Anything else: raise FormatError("unknown format: ...").

parse_header(data: bytes) -> dict returns:

{
    "format": "elf64" | "coff" | "pe" | "macho64",
    "arch": "x86_64" | "arm64" | ...,
    "bits": 64,
    "endian": "little",
    "kind": "relocatable" | "executable" | "shared" | ...,
    "entry": int | None,
    "fields": {...},
}

Required fields keys, which later stages and the tests read:

  • ELF: e_type, e_machine, e_flags, e_phoff, e_phnum, e_shoff, e_shnum, e_shstrndx. Raise when a header table runs past the end of the file. Also raise when an entry size is not 64 (sections) or 56 (program headers), or when e_shstrndx is not below e_shnum. entry is None for a relocatable file.
  • COFF and PE: machine, number_of_sections, time_date_stamp, pointer_to_symbol_table, number_of_symbols, size_of_optional_header, characteristics, and section_table (the file offset of the first section entry).
  • PE adds magic, entry_rva, image_base, section_alignment, file_alignment, size_of_image, size_of_headers, subsystem, dll_characteristics, dll_flags (names from DLL_CHARACTERISTICS), and data_directories, a dictionary from the names in PE_DIRECTORIES to {"rva", "size"} for nonzero entries only. Refuse magic 0x10b (PE32). kind is "shared" when characteristics bit 0x2000 (DLL) is set.
  • Mach-O: cputype, filetype, ncmds, sizeofcmds, flags, flag_names, and load_commands (the list of names).

load_commands(data: bytes) -> list[dict] returns one {"cmd", "name", "offset", "size"} per command. Use LOAD_COMMANDS for names and LC_0x... for unknown values. Raise when sizeofcmds runs past the file, or when a cmdsize is below 8, not a multiple of 8, or runs past sizeofcmds.

Verify and inspect. A fresh workspace fails with not implemented yet: stage 1: implement parse_header. The tests check all four formats, the 18 Mach-O load commands in otool -l order, the PE fields that llvm-objdump -p prints, five rejected variants, and the held-out program.

Investigate the failure boundary.

  • Set the ELF e_shoff to a value near the end of the file. parse_header must raise before any section is read.
  • Set the first cmdsize of the Mach-O file to 0. Without the size check, the loop reads the same command forever.
  • Set e_lfanew past the end of the PE file. The unpack bounds check must name the offset.
  • Feed a C source file. The last COFF check must refuse it, because the machine field does not match.

Extensions.

  • Add ELF32 and PE32 by reading the 32-bit field layouts. Keep the output shape the same.
  • Read one slice of a universal Mach-O: the fat header lists each architecture with an offset and a size.
  • Decode LC_BUILD_VERSION into a platform and minimum OS version.

Step 2 · Sections, segments, permissions, and entropy

Step 2 of 6 · about 1.5 hours · Python

List the sections of each format with name, address, file offset, size, and bytes in the file. Add an r/w/x permission string from the flags of the format. List ELF program headers and Mach-O segments. Compute Shannon entropy in bits per byte over the bytes each region holds in the file, so zero-fill regions report 0.

This stage uses the section header table from lesson 32 and the segment and section tables of the three formats from lesson 40.

What you build. You write five functions in the layout module:

  • shannon_entropy(data) returns bits per byte, rounded to 4 decimal places.
  • sections(data) lists every section with a permission string and the entropy of its bytes.
  • segments(data) lists ELF program headers and Mach-O segments.
  • section_at_offset(section_list, offset) and section_at_address(section_list, address) find the owner of a file offset or a virtual address. Stages 4, 5, and 6 use them.

Why it matters. Sections tell you what the link editor made. Segments tell you what the loader maps and with which permissions. A section that is writable and executable, or a data section with entropy near 8, is a fact a reviewer must see before a release. Entropy measures how evenly the byte values spread. The maximum is 8 bits per byte, when all 256 values occur equally often, and zero padding is 0. In the fixtures, the code sections measure from 5.5 to 5.9 and the string sections from 4.0 to 4.7. The padding between segments measures 0.0. Compressed or encrypted data comes close to 8.

Each format stores permissions in a different place:

Format Where Bits
ELF section sh_flags SHF_WRITE 0x1, SHF_ALLOC 0x2, SHF_EXECINSTR 0x4
ELF segment p_flags PF_X 0x1, PF_W 0x2, PF_R 0x4
COFF and PE section Characteristics MEM_EXECUTE 0x20000000, MEM_READ 0x40000000, MEM_WRITE 0x80000000
Mach-O segment initprot, maxprot VM_PROT_READ 1, VM_PROT_WRITE 2, VM_PROT_EXECUTE 4

An ELF section without SHF_ALLOC is not loaded, so its string is "---". A Mach-O section has no permission bits of its own. It takes initprot of the segment with the same name. In a Mach-O object the only segment has an empty name, so use the instruction attributes (0x80000400) for "r-x" and the table MACHO_SEGMENT_PERMS for the rest.

Work through one concrete case. The ELF object for the tally program has 13 section headers of 64 bytes at e_shoff 1320. Entry 2 is .text. Its sh_flags is 0x6, so SHF_ALLOC and SHF_EXECINSTR are set and SHF_WRITE is clear: "r-x". Its sh_offset is 64 and sh_size is 0x13c (316). Entry 5 is .bss with type SHT_NOBITS (8). Its size is 4, but it holds no bytes in the file. So file_size is 0 and its entropy is 0.0.

Now compute entropy for the 15-byte string tally report v3. Count each byte value:

Byte Count p p log2(1/p)
t, l, r, space 2 each 2/15 0.3876 each
a, y, e, p, o, v, 3 1 each 1/15 0.2605 each

The sum is 4 × 0.3876 + 7 × 0.2605 = 3.3736 bits per byte. The bytes aabb give exactly 1.0, and the 256 values 0 to 255 once each give exactly 8.0.

On the arm64 executable, __TEXT,__text is 768 bytes with entropy 5.8595, __TEXT,__cstring is 4.6413, and __DATA,__common is zerofill with file_size 0. The __PAGEZERO segment maps 4 GiB with no file bytes and permission "---".

Move the sliders to set how many distinct byte values a region holds and how often the most common one appears. The lab computes the entropy and the permission string from the flag bits you select.

Implement the contract. shannon_entropy(data: bytes) -> float: return 0.0 for empty input. Otherwise H = sum over byte values of p × log2(1/p), with p = count / length, rounded with round(value, 4).

Key ELF COFF object PE image Mach-O
index header index (skip index 0) 1-based 1-based 1-based across all segments
name from .shstrtab 8-byte name, or /n into the string table same sectname
segment None None None segname
type ELF_SECTION_TYPES name "code", "initialized", "uninitialized", "other" same MACHO_SECTION_TYPES name
addr sh_addr 0 ImageBase + VirtualAddress addr
offset sh_offset PointerToRawData, or 0 with no file bytes same offset, or 0 for zerofill

file_size 0 for NOBITS, else sh_size 0 for uninitialized data min(SizeOfRawData, VirtualSize) 0 for zerofill types

Raise FormatError when the file bytes of a section run past the end of the file. Also raise when a Mach-O LC_SEGMENT_64 is too small for its nsects entries of 80 bytes.

segments(data: bytes) -> list[dict] returns {"name", "addr", "size", "offset", "file_size", "perms", "max_perms", "entropy"}. ELF names come from ELF_SEGMENT_TYPES and max_perms is None. Mach-O uses segname, vmsize, initprot, and maxprot. Relocatable ELF, COFF objects, and PE images return [], because a PE image maps each section directly.

section_at_offset(section_list, offset) returns the section with the smallest file_size whose file range holds the offset, or None. section_at_address(section_list, address) returns the first section whose [addr, addr + size) holds the address, or None.

What you build. You write five functions in the linkage module:

  • relocations(data) lists ELF, COFF, and Mach-O relocation records and PE base relocations.

Why it matters. The bytes of a call or a pointer in an object file are often zero. The relocation record says what the link editor writes there. In a linked image, the loader fills import slots before the program runs. On current macOS, the fixup information sits inside the pointer slots themselves, as chained 64-bit words. A disassembler that reads one of those slots without decoding it reports a pointer to an address that does not exist. Lesson 20.40 opens with that exact mistake.

Mach-O relocation_info <iI, 8 bytes address, then symbolnum:24, pcrel:1, length:2, extern:1, type:4

PE imports. The import directory of the small PE image is at RVA 0x2000, which the .rdata section maps to file offset 0x400. The 20-byte descriptor reads: lookup table 0x2028, time stamp 0, forwarder 0, name 0x2096, address table 0x2048. The name RVA gives kernel32.dll. The lookup table holds three 64-bit entries and a zero. Bit 63 is clear in each, so each is the RVA of a hint and a name: hint 0 GetStdHandle, hint 1 WriteConsoleA, hint 2 ExitProcess. Cell 7 is the zero padding at the end of __TEXT. The lengths add up to the file size, and each cell starts where the previous one ends.

def extract_strings(data, section_list, segment_list=(), min_length=4):
    if min_length < 1:
        raise ValueError("min_length must be at least 1")
    found = []
    start = None
    for index in range(len(data) + 1):
        if index < len(data) and data[index] in PRINTABLE:
            if start is None:
                start = index
            continue
        if start is not None and index - start >= min_length:
            found.append((start, data[start:index].decode("ascii"), "ascii"))
        start = None
    index = 0
    while index + 1 < len(data):
        end = index
        while end + 1 < len(data) and data[end] in PRINTABLE and data[end + 1] == 0:
            end += 2
        if (end - index) // 2 >= min_length:
            found.append((index, data[index:end].decode("utf-16-le"), "utf-16le"))
            index = end
        else:
            index += 1
    result = []
    for offset, text, encoding in sorted(found):
        section, segment = _region(section_list, segment_list, offset)
        result.append({"offset": offset, "text": text, "encoding": encoding, "section": section, "segment": segment})
    return result

    return [section for section in section_list
            if section["code"] and section["file_size"] and section["name"] not in STUB_SECTIONS]


def lc_function_starts(data, header):
    if header["format"] != "macho64":
        return []
    found = linkedit_data(data, "LC_FUNCTION_STARTS")
    if not found:
        return []
    text = next((segment for segment in segments(data) if segment["name"] == "__TEXT"), None)
    address = text["addr"] if text else 0
    blob = data[found[0]:found[0] + found[1]]
    result, cursor = [], 0
    while cursor < len(blob):
        delta, cursor = uleb128(blob, cursor)
        if delta == 0:
            break
        address += delta
        result.append(address)
    return result


def prologue_scan(data, header, section_list):
    result = []
    for section in _code_sections(section_list):
        code = data[section["offset"]:section["offset"] + section["file_size"]]
        if header["arch"] == "arm64":
            for position in range(0, len(code) - 3, 4):
                word = int.from_bytes(code[position:position + 4], "little")
                if (word & 0xFF0003FF) == 0xD10003FF or (word & 0xFFC07FFF) == 0xA9807BFD:
                    result.append(section["addr"] + position)
        elif header["arch"] == "x86_64":
            for pattern in (b"\x55\x48\x89\xe5", b"\xf3\x0f\x1e\xfa"):
                position = code.find(pattern)
                while position >= 0:
                    result.append(section["addr"] + position)
                    position = code.find(pattern, position + 1)
    return sorted(set(result))


def call_targets(data, header, section_list):
    if header["kind"] == "relocatable":
        return []
    code_sections = _code_sections(section_list)

    def inside(address):
        return any(s["addr"] <= address < s["addr"] + s["size"] for s in code_sections)

    result = set()
    for section in code_sections:
        code = data[section["offset"]:section["offset"] + section["file_size"]]
        if header["arch"] == "arm64":
            for position in range(0, len(code) - 3, 4):
                word = int.from_bytes(code[position:position + 4], "little")
                if (word & 0xFC000000) == 0x94000000:
                    immediate = word & 0x3FFFFFF
                    if immediate & 0x2000000:
                        immediate -= 1 << 26
                    target = section["addr"] + position + immediate * 4
                    if inside(target):
                        result.add(target)
        elif header["arch"] == "x86_64":
            for position in range(len(code) - 4):
                if code[position] == 0xE8:
                    displacement = int.from_bytes(code[position + 1:position + 5], "little", signed=True)
                    target = section["addr"] + position + 5 + displacement
                    if inside(target):
                        result.add(target)
    return sorted(result)


def symbol_starts(data, section_list):
    code_sections = _code_sections(section_list)
    names = {section["name"] for section in code_sections}
    result = set()
    for symbol in symbols(data):
        if symbol["kind"] != "func" or not symbol["defined"] or symbol["section"] not in names:
            continue
        owner = [s for s in code_sections if s["name"] == symbol["section"]]
        if any(s["addr"] <= symbol["value"] < s["addr"] + s["size"] for s in owner):
            result.add(symbol["value"])
    return sorted(result)


def function_starts(data):
    header = parse_header(data)
    section_list = sections(data)
    methods = {
        "symbols": symbol_starts(data, section_list),
        "function_starts_table": lc_function_starts(data, header),
        "prologues": prologue_scan(data, header, section_list),
        "call_targets": call_targets(data, header, section_list),
        "entry": [header["entry"]] if header["entry"] else [],
    }
    methods["recovered"] = sorted(set(methods["function_starts_table"]) | set(methods["call_targets"]) | set(methods["entry"]))
    return methods


def score_starts(found, truth):
    found, truth = set(found), set(truth)
    hits = found & truth
    return {
        "found": len(found),
        "truth": len(truth),
        "true_positives": len(hits),
        "false_positives": sorted(found - truth),
        "missed": sorted(truth - found),
        "precision": round(len(hits) / len(found), 4) if found else 0.0,
        "recall": round(len(hits) / len(truth), 4) if truth else 1.0,
    }

            raise FormatError("only little-endian ELF (EI_DATA 1) is supported")
        return "elf64"
    if data[:2] == b"MZ":
        (lfanew,) = unpack("<I", data, 0x3C)
        if unpack("<4s", data, lfanew)[0] != b"PE\0\0":
            raise FormatError(f"MZ header points at {lfanew:#x}, which has no PE signature")
        return "pe"
    magic = int.from_bytes(data[:4], "little")
    if magic == 0xFEEDFACF:
        return "macho64"
    if magic == 0xFEEDFACE:
        raise FormatError("32-bit Mach-O is not supported")
    if data[:4] == b"\xca\xfe\xba\xbe":
        raise FormatError("universal (fat) Mach-O: extract one slice with lipo first")
    if len(data) >= 20:
        machine, count, _, _, _, optional, _ = unpack("<HHIIIHH", data, 0)
        if machine in COFF_MACHINES and optional == 0 and 0 < count <= 96:
            return "coff"
    raise FormatError(f"unknown format: first bytes {data[:4].hex()}")


def _elf_header(data):
    fields = unpack("<16sHHIQQQIHHHHHH", data, 0)
    _, e_type, machine, _, entry, phoff, shoff, flags, _, phentsize, phnum, shentsize, shnum, shstrndx = fields
    if shnum and shentsize != 64:
        raise FormatError(f"section header entry size {shentsize}, expected 64")
    if phnum and phentsize != 56:
        raise FormatError(f"program header entry size {phentsize}, expected 56")
    if shoff + shnum * 64 > len(data):
        raise FormatError("section header table runs past the end of the file")
    if phoff + phnum * 56 > len(data):
        raise FormatError("program header table runs past the end of the file")
    if shnum and shstrndx >= shnum:
        raise FormatError(f"e_shstrndx {shstrndx} is not below e_shnum {shnum}")
    kind = ELF_KINDS.get(e_type, f"type {e_type}")
    return {
        "format": "elf64",
        "arch": ELF_MACHINES.get(machine, f"machine {machine:#x}"),
        "bits": 64,
        "endian": "little",
        "kind": kind,
        "entry": entry if kind in ("executable", "shared") and entry else None,
        "fields": {
            "e_type": e_type, "e_machine": machine, "e_flags": flags,
            "e_phoff": phoff, "e_phnum": phnum, "e_shoff": shoff, "e_shnum": shnum, "e_shstrndx": shstrndx,
        },
    }

def _pe_header(data):

def load_commands(data):
    _, _, _, _, ncmds, sizeofcmds, _, _ = unpack("<IiiIIIII", data, 0)
    if 32 + sizeofcmds > len(data):
        raise FormatError("load commands run past the end of the file")
    commands, offset = [], 32
    for _ in range(ncmds):
        cmd, size = unpack("<II", data, offset)
        if size < 8 or size % 8 or offset + size > 32 + sizeofcmds:
            raise FormatError(f"load command at {offset:#x} has invalid size {size}")
        commands.append({"cmd": cmd, "name": LOAD_COMMANDS.get(cmd, f"LC_{cmd:#x}"), "offset": offset, "size": size})
        offset += size
    return commands

def shannon_entropy(data):
    if not data:
        return 0.0
    total = len(data)
    value = -sum(count / total * math.log2(count / total) for count in Counter(data).values())
    return round(value + 0.0, 4)

def _cstring(data, start, end):

def uleb128(data, offset):
    value = shift = 0
    for count in range(10):
        if offset + count >= len(data):
            raise FormatError(f"uleb128 at {offset:#x} runs past the end of its data")
        byte = data[offset + count]
        value |= (byte & 0x7F) << shift
        shift += 7

def _elf_relocations(data, header):

    for section in section_list:

            continue

                pending = number - (1 << 24) if number & 0x800000 else number
                continue
            if external:
                if number not in table:
                    raise FormatError(f"relocation {item} in {section['sectname']} names missing symbol {number}")
                symbol = table[number]
            else:
                if not 1 <= number <= len(raw_sections):
                    raise FormatError(f"relocation {item} in {section['sectname']} names missing section {number}")
                symbol = raw_sections[number - 1]["sectname"]
            result.append(_relocation(section["sectname"], address, prefix + names.get(kind, str(kind)), symbol, pending))
            pending = None
    return result

def library_name(libraries, ordinal):
    if ordinal == 0:
        return "self"
    if ordinal in (0xFF, -1):
        return "main-executable"
    if ordinal in (0xFE, -2):
        return "flat-lookup"

def linkedit_data(data, name):
    for command in load_commands(data):
        if command["name"] == name:
            dataoff, datasize = unpack("<II", data, command["offset"] + 8)
            if dataoff + datasize > len(data):
                raise FormatError(f"{name} points past the end of the file")
            return dataoff, datasize
    return None


def chained_fixups(data):
    header = parse_header(data)
    empty = {"header": None, "imports": [], "fixups": []}
    if header["format"] != "macho64":
        return empty
    found = linkedit_data(data, "LC_DYLD_CHAINED_FIXUPS")
    if not found:
        return empty
    base, size = found
    blob = data[base:base + size]
    version, starts, imports_offset, symbols_offset, count, imports_format, symbols_format = unpack("<7I", blob, 0)
    if version != 0:
        raise FormatError(f"chained fixups version {version} is not supported")
    if symbols_format != 0:
        raise FormatError("compressed chained fixup symbol names are not supported")
    libraries = dylibs(data)
    width = {1: 4, 2: 8, 3: 16}.get(imports_format)
    if width is None:
        raise FormatError(f"chained imports format {imports_format} is not supported")
    imports = []
    for index in range(count):
        if imports_format == 3:
            word, addend = unpack("<QQ", blob, imports_offset + 16 * index)
            ordinal, weak, name_offset = word & 0xFFFF, (word >> 16) & 1, word >> 32
            ordinal = ordinal - 0x10000 if ordinal >= 0xFFF0 else ordinal
        else:
            (word,) = unpack("<I", blob, imports_offset + width * index)
            addend = unpack("<i", blob, imports_offset + width * index + 4)[0] if imports_format == 2 else 0
            ordinal, weak, name_offset = word & 0xFF, (word >> 8) & 1, word >> 9
            ordinal = ordinal - 0x100 if ordinal >= 0xF0 else ordinal
        imports.append({
            "index": index, "name": read_cstring(blob, symbols_offset + name_offset),
            "library": library_name(libraries, ordinal), "weak": bool(weak), "addend": addend,
        })
    segments = macho_segments_raw(data)
    image_base = next((segment["vmaddr"] for segment in segments if segment["name"] == "__TEXT"), 0)
    section_list = sections(data)
    (seg_count,) = unpack("<I", blob, starts)
    if seg_count > len(segments):
        raise FormatError(f"chained starts list {seg_count} segments, file has {len(segments)}")
    fixups = []
    for segment_index in range(seg_count):
        (start_offset,) = unpack("<I", blob, starts + 4 + 4 * segment_index)
        if not start_offset:
            continue
        where = starts + start_offset
        _, page_size, pointer_format, _, _, page_count = unpack("<IHHQIH", blob, where)
        if pointer_format not in POINTER_FORMATS:
            raise FormatError(f"chained pointer format {pointer_format} is not supported")
        segment = segments[segment_index]
        for page in range(page_count):
            (first,) = unpack("<H", blob, where + 22 + 2 * page)
            if first == 0xFFFF:
                continue
            if first & 0x8000:
                raise FormatError("multi-start chained pages are not supported")
            page_start = segment["fileoff"] + page * page_size
            offset = page_start + first
            for _ in range(page_size // 4 + 1):
                if offset + 8 > page_start + page_size:
                    raise FormatError(f"fixup chain leaves its page at {offset:#x}")
                (raw,) = unpack("<Q", data, offset)
                step = (raw >> 51) & 0xFFF
                address = segment["vmaddr"] + offset - segment["fileoff"]
                owner = section_at_address(section_list, address)
                fixup = {"offset": offset, "address": address, "section": owner["name"] if owner else None,
                         "raw": raw, "next": step}
                if raw >> 63:
                    ordinal = raw & 0xFFFFFF
                    if ordinal >= len(imports):
                        raise FormatError(f"bind at {offset:#x} uses import {ordinal}, table has {len(imports)}")
                    fixup.update(kind="bind", ordinal=ordinal, name=imports[ordinal]["name"],
                                 library=imports[ordinal]["library"], addend=(raw >> 24) & 0xFF)
                else:
                    target = raw & 0xFFFFFFFFF
                    high8 = (raw >> 36) & 0xFF
                    if pointer_format == 6:
                        target += image_base
                    fixup.update(kind="rebase", target=target | (high8 << 56))
                fixups.append(fixup)
                if not step:
                    break
                offset += step * 4
            else:
                raise FormatError("fixup chain does not terminate inside its page")
    return {
        "header": {"version": version, "imports_count": count, "imports_format": imports_format,
                   "pointer_formats": sorted({POINTER_FORMATS[f] for f in _formats(blob, starts, seg_count)})},
        "imports": imports,
        "fixups": fixups,
    }


def _formats(blob, starts, seg_count):
    result = []
    for index in range(seg_count):
        (start_offset,) = unpack("<I", blob, starts + 4 + 4 * index)
        if start_offset:
            result.append(unpack("<H", blob, starts + start_offset + 6)[0])
    return result


def _pe_imports(data, header):
    fields = header["fields"]
    directory = fields["data_directories"].get("import")
    if not directory:
        return []
    section_list = sections(data)
    base = fields["image_base"]
    offset = rva_to_offset(section_list, base, directory["rva"])
    result = []
    for _ in range(4096):
        ilt, _, _, name_rva, iat = unpack("<IIIII", data, offset)
        if not (ilt or name_rva or iat):
            return result
        library = read_cstring(data, rva_to_offset(section_list, base, name_rva))
        thunk = rva_to_offset(section_list, base, ilt or iat)

    if fixups["header"]:
        slots = {}
        for fixup in fixups["fixups"]:

        return [{"name": item["name"], "library": item["library"], "slots": slots.get(item["index"], []),
                 "hint": None, "ordinal": item["index"]} for item in fixups["imports"]]

def exports_trie(blob, image_base):
    result, stack, visited = [], [(0, "")], set()
    while stack:
        node, prefix = stack.pop()
        if node in visited:
            raise FormatError(f"exports trie revisits node {node:#x}")
        visited.add(node)
        size, cursor = uleb128(blob, node)
        children_at = cursor + size
        if size:
            flags, cursor = uleb128(blob, cursor)
            if flags & 0x08:
                ordinal, cursor = uleb128(blob, cursor)
                result.append({"name": prefix, "address": None, "flags": flags, "reexport": ordinal})
            else:
                offset, cursor = uleb128(blob, cursor)
                result.append({"name": prefix, "address": image_base + offset, "flags": flags, "reexport": None})
        if children_at >= len(blob):
            raise FormatError(f"exports trie node {node:#x} runs past the end of the trie")
        count, cursor = blob[children_at], children_at + 1
        children = []
        for _ in range(count):
            stop = blob.find(b"\0", cursor)
            if stop < 0:
                raise FormatError("exports trie edge has no terminating NUL")
            edge = blob[cursor:stop].decode("utf-8", "replace")
            child, cursor = uleb128(blob, stop + 1)
            if not 0 < child < len(blob):
                raise FormatError(f"exports trie child offset {child:#x} is outside the trie")
            children.append((child, prefix + edge))
        stack.extend(reversed(children))
    return sorted(result, key=lambda item: item["name"])


def _pe_exports(data, header):
    fields = header["fields"]
    directory = fields["data_directories"].get("export")
    if not directory:
        return []
    section_list = sections(data)
    base = fields["image_base"]
    offset = rva_to_offset(section_list, base, directory["rva"])
    values = unpack("<IIHHIIIIIII", data, offset)
    ordinal_base, functions, names, eat, enpt, eot = values[5], values[6], values[7], values[8], values[9], values[10]
    if names > functions:
        raise FormatError("export directory has more names than addresses")
    result = []
    for index in range(names):
        (name_rva,) = unpack("<I", data, rva_to_offset(section_list, base, enpt + 4 * index))
        (slot,) = unpack("<H", data, rva_to_offset(section_list, base, eot + 2 * index))
        if slot >= functions:
            raise FormatError(f"export ordinal index {slot} is outside the address table")
        (target,) = unpack("<I", data, rva_to_offset(section_list, base, eat + 4 * slot))
        name = read_cstring(data, rva_to_offset(section_list, base, name_rva))
        forwarder = None
        if directory["rva"] <= target < directory["rva"] + directory["size"]:
            forwarder = read_cstring(data, rva_to_offset(section_list, base, target))
        result.append({"name": name, "address": None if forwarder else base + target,
                       "ordinal": ordinal_base + slot, "forwarder": forwarder})
    return result

def _covering(items, start, end):
    best, best_overlap = None, 0
    for item in items:
        if not item["file_size"]:
            continue
        overlap = min(end, item["offset"] + item["file_size"]) - max(start, item["offset"])
        if overlap > best_overlap or (overlap == best_overlap and overlap > 0 and item["file_size"] < best["file_size"]):
            best, best_overlap = item, overlap
    return best


def byte_map(data, section_list, segment_list=(), cells=128):
    if cells < 1:
        raise ValueError("cells must be at least 1")
    cells = min(cells, len(data)) or 1
    first = min((s["offset"] for s in section_list if s["file_size"]), default=len(data))
    result = []
    for index in range(cells):
        start = index * len(data) // cells
        end = (index + 1) * len(data) // cells
        section = _covering(section_list, start, end)
        if section:
            region = section["name"]
        elif end <= first:
            region = "headers"
        else:
            segment = _covering(segment_list, start, end)
            region = segment["name"] if segment else "unmapped"
        result.append({"index": index, "offset": start, "length": end - start, "region": region,
                       "entropy": shannon_entropy(data[start:end])})
    return result

def validate_report(report):
    errors = []
    if not isinstance(report, dict):
        return ["report must be an object"]
    for key, kind in REPORT_FIELDS.items():
        if key not in report:
            errors.append(f"missing key {key}")
        elif not isinstance(report[key], kind):
            errors.append(f"{key} must be {kind.__name__}")
    if report.get("schema") not in (None, REPORT_SCHEMA) and isinstance(report.get("schema"), str):
        errors.append(f"schema must be {REPORT_SCHEMA}")
    for key, fields in ITEM_FIELDS.items():
        for position, item in enumerate(report.get(key) or []):
            if not isinstance(item, dict):
                errors.append(f"{key}[{position}] must be an object")

            for field in fields:
                if field not in item:

    for field in ("name", "size", "sha256"):

def read_cstring(data, offset, end=None):
    end = len(data) if end is None else min(end, len(data))
    if offset < 0 or offset >= end:
        raise FormatError(f"string offset {offset:#x} is outside its table")
    stop = data.find(b"\0", offset, end)
    if stop < 0:
        raise FormatError(f"string at {offset:#x} has no terminating NUL inside its table")
    return data[offset:stop].decode("utf-8", "replace")


class _Demangler:
    def __init__(self, text):
        self.text = text
        self.pos = 0
        self.subs = []

    def peek(self, count=1):
        return self.text[self.pos:self.pos + count]

    def take(self, count=1):
        if self.pos + count > len(self.text):
            raise ValueError("unexpected end")
        value = self.text[self.pos:self.pos + count]
        self.pos += count
        return value

    def number(self):
        start = self.pos
        while self.peek().isdigit():
            self.pos += 1
        if start == self.pos:
            raise ValueError("expected a length")
        return int(self.text[start:self.pos])

    def source_name(self):
        length = self.number()
        if length == 0 or self.pos + length > len(self.text):
            raise ValueError("bad source name")
        return self.take(length)

    def substitution(self):
        self.take()
        if self.peek() == "t":
            self.take()
            return ["std"], False
        if self.peek() == "_":
            self.take()
            index = 0
        else:
            digits = ""
            while self.peek() and self.peek() != "_":
                digits += self.take()
            self.take()
            index = int(digits, 36) + 1
        if index >= len(self.subs):
            raise ValueError("substitution out of range")
        return self.subs[index], True

    def nested(self, is_function):
        self.take()
        const = False
        if self.peek() == "K":
            self.take()
            const = True
        parts = []
        while self.peek() != "E":
            if not self.peek():
                raise ValueError("unterminated nested name")
            if self.peek() == "S":
                value, _ = self.substitution()
                parts = list(value)
            elif self.peek().isdigit():
                parts.append(self.source_name())
            elif self.peek() in ("C", "D"):
                code = self.take(2)
                if code[1] not in "123" or not parts:
                    raise ValueError("unsupported constructor form")
                parts.append(("~" if code[0] == "D" else "") + parts[-1])
            else:
                raise ValueError("unsupported nested component")
            if self.peek() != "E" or not is_function:
                if list(parts) not in self.subs:
                    self.subs.append(list(parts))
        self.take()
        return parts, const

    def type(self):
        code = self.peek()
        if code in BUILTINS:
            self.take()
            return BUILTINS[code]
        if code in ("P", "R", "O", "K"):
            self.take()
            inner = self.type()
            text = {"P": inner + "*", "R": inner + "&", "O": inner + "&&", "K": inner + " const"}[code]
            self.subs.append([text])
            return text
        if code == "N":
            parts, _ = self.nested(False)
            return "::".join(parts)
        if code == "S":
            value, _ = self.substitution()
            if value == ["std"]:
                name = "std::" + self.source_name()
                self.subs.append([name])
                return name
            return "::".join(value)
        if code.isdigit():
            name = self.source_name()
            self.subs.append([name])
            return name
        raise ValueError(f"unsupported type code {code!r}")

    def encoding(self):
        const = False
        if self.peek() == "N":
            parts, const = self.nested(True)
        elif self.peek() == "S" and self.peek(2) == "St":
            self.take(2)
            parts = ["std", self.source_name()]
        elif self.peek().isdigit():
            parts = [self.source_name()]
        else:
            raise ValueError("unsupported name")
        if self.pos == len(self.text):
            return "::".join(parts)
        params = []
        while self.pos < len(self.text):
            params.append(self.type())
        if params == ["void"]:
            params = []
        return "::".join(parts) + "(" + ", ".join(params) + ")" + (" const" if const else "")

def elf_symbol_table(data, section_list, table_index):
    by_index = {section["index"]: section for section in section_list}
    table = by_index.get(table_index)
    if table is None or table["type"] not in ("SYMTAB", "DYNSYM"):
        raise FormatError(f"section {table_index} is not a symbol table")
    header = parse_header(data)
    (link,) = unpack("<I", data, header["fields"]["e_shoff"] + 64 * table_index + 40)
    strtab = by_index.get(link)
    if strtab is None:
        raise FormatError(f"symbol table {table['name']} links to missing string table {link}")
    if table["size"] % 24:
        raise FormatError(f"symbol table {table['name']} size {table['size']} is not a multiple of 24")
    result = []
    for index in range(1, table["size"] // 24):
        name, info, _, shndx, value, size = unpack("<IBBHQQ", data, table["offset"] + 24 * index)
        text = read_cstring(data, strtab["offset"] + name, strtab["offset"] + strtab["size"])
        if shndx == 0:
            section = None
        elif shndx == 0xFFF1:
            section = "*ABS*"
        elif shndx == 0xFFF2:
            section = "*COMMON*"
        elif shndx in by_index:
            section = by_index[shndx]["name"]
        else:
            raise FormatError(f"symbol {index} names missing section {shndx}")
        kind = ELF_KINDS.get(info & 0xF, f"type {info & 0xF}")
        if kind == "section" and not text and section:
            text = section
        result.append(_symbol(index, text, value, size, kind, ELF_BINDINGS.get(info >> 4, f"binding {info >> 4}"),
                              section, "dynsym" if table["type"] == "DYNSYM" else "symtab"))
    return result

            section = "*ABS*"
        elif number == -2:
            section = "*DEBUG*"
        elif storage == 2 and value:
            section = "*COMMON*"
        else:
            section = None

            symbol_kind = "file"
        elif storage == 3 and aux and value == 0 and section == name:
            symbol_kind = "section"
        elif kind >> 4 == 2:
            symbol_kind = "func"
        elif number > 0:
            symbol_kind = "object"
        else:
            symbol_kind = "notype"

        raise FormatError("auxiliary records run past the end of the symbol table")
    return result

def rel32(target_rva, next_rva):
    return struct.pack("<i", target_rva - next_rva)


def build():
    text_rva, rdata_rva, data_rva, reloc_rva = 0x1000, 0x2000, 0x3000, 0x4000
    text_off, rdata_off, data_off, reloc_off = 0x200, 0x400, 0x600, 0x800

    rdata = bytearray()

    def place(blob, align=1):
        while len(rdata) % align:
            rdata.append(0)
        start = rdata_rva + len(rdata)
        rdata.extend(blob)
        return start

    descriptor_rva = place(bytes(40))
    ilt_rva = place(bytes(8 * (len(IMPORTS) + 1)), 8)
    iat_rva = place(bytes(8 * (len(IMPORTS) + 1)), 8)
    hint_rvas = [place(struct.pack("<H", index) + name + b"\0", 2) for index, name in enumerate(IMPORTS)]
    dll_rva = place(DLL_NAME)
    export_dir_rva = place(bytes(40), 4)
    eat_rva = place(bytes(4), 4)
    enpt_rva = place(bytes(4), 4)
    eot_rva = place(bytes(2), 2)
    image_name_rva = place(IMAGE_NAME)
    export_name_rva = place(EXPORT_NAME)
    message_rva = place(MESSAGE + b"\0")
    export_size = message_rva - export_dir_rva

    struct.pack_into("<IIIII", rdata, descriptor_rva - rdata_rva, ilt_rva, 0, 0, dll_rva, iat_rva)
    thunks = b"".join(struct.pack("<Q", rva) for rva in hint_rvas) + bytes(8)
    rdata[ilt_rva - rdata_rva:ilt_rva - rdata_rva + len(thunks)] = thunks
    rdata[iat_rva - rdata_rva:iat_rva - rdata_rva + len(thunks)] = thunks
    struct.pack_into("<IIHHIIIIIII", rdata, export_dir_rva - rdata_rva, 0, 0, 0, 0, image_name_rva, 1, 1, 1, eat_rva, enpt_rva, eot_rva)
    struct.pack_into("<I", rdata, eat_rva - rdata_rva, text_rva)
    struct.pack_into("<I", rdata, enpt_rva - rdata_rva, export_name_rva)
    struct.pack_into("<H", rdata, eot_rva - rdata_rva, 0)

    code = bytearray()
    code += b"\x48\x83\xec\x28"
    code += b"\xb9\xf5\xff\xff\xff"
    code += b"\xff\x15" + rel32(iat_rva, text_rva + len(code) + 6)
    code += b"\x48\x89\xc1"
    code += b"\x48\x8d\x15" + rel32(message_rva, text_rva + len(code) + 7)
    code += b"\x41\xb8" + struct.pack("<I", len(MESSAGE))
    code += b"\x4c\x8d\x4c\x24\x20"
    code += b"\x48\xc7\x44\x24\x20\x00\x00\x00\x00"
    code += b"\xff\x15" + rel32(iat_rva + 8, text_rva + len(code) + 6)
    code += b"\x31\xc9"
    code += b"\xff\x15" + rel32(iat_rva + 16, text_rva + len(code) + 6)
    code += b"\xcc"

    data = struct.pack("<Q", IMAGE_BASE + message_rva)
    reloc = struct.pack("<IIHH", data_rva, 12, (REL_BASED_DIR64 << 12) | 0, 0)

    sections = [
        (b".text", len(code), text_rva, text_off, SCN_CODE | SCN_MEM_EXECUTE | SCN_MEM_READ),
        (b".rdata", len(rdata), rdata_rva, rdata_off, SCN_INITIALIZED_DATA | SCN_MEM_READ),
        (b".data", len(data), data_rva, data_off, SCN_INITIALIZED_DATA | SCN_MEM_READ | SCN_MEM_WRITE),
        (b".reloc", len(reloc), reloc_rva, reloc_off, SCN_INITIALIZED_DATA | SCN_MEM_READ | SCN_MEM_DISCARDABLE),
    ]

    image = bytearray(reloc_off + FILE_ALIGN)
    image[0:2] = b"MZ"
    struct.pack_into("<I", image, 0x3C, 0x40)
    image[0x40:0x44] = b"PE\0\0"
    struct.pack_into("<HHIIIHH", image, 0x44, MACHINE_AMD64, len(sections), 0, 0, 0, 240,
                     FILE_EXECUTABLE_IMAGE | FILE_LARGE_ADDRESS_AWARE)
    struct.pack_into(
        "<HBBIIIIIQIIHHHHHHIIIIHHQQQQII", image, 0x58,
        PE32_PLUS, 14, 0, FILE_ALIGN, 3 * FILE_ALIGN, 0, text_rva, text_rva, IMAGE_BASE, SECTION_ALIGN, FILE_ALIGN,
        6, 0, 0, 0, 6, 0, 0, 0x5000, 0x200, 0, SUBSYSTEM_CUI,
        DLL_HIGH_ENTROPY_VA | DLL_DYNAMIC_BASE | DLL_NX_COMPAT | DLL_TERMINAL_SERVER_AWARE,
        0x100000, 0x1000, 0x100000, 0x1000, 0, 16,
    )
    directories = 0x58 + 112
    struct.pack_into("<II", image, directories + 8 * DIR_EXPORT, export_dir_rva, export_size)
    struct.pack_into("<II", image, directories + 8 * DIR_IMPORT, descriptor_rva, 40)
    struct.pack_into("<II", image, directories + 8 * DIR_BASERELOC, reloc_rva, len(reloc))
    struct.pack_into("<II", image, directories + 8 * DIR_IAT, iat_rva, len(thunks))
    table = directories + 16 * 8
    for index, (name, virtual_size, rva, offset, characteristics) in enumerate(sections):
        struct.pack_into("<8sIIIIIIHHI", image, table + 40 * index, name, virtual_size, rva, FILE_ALIGN, offset,
                         0, 0, 0, 0, characteristics)
    image[text_off:text_off + len(code)] = code
    image[rdata_off:rdata_off + len(rdata)] = rdata
    image[data_off:data_off + len(data)] = data
    image[reloc_off:reloc_off + len(reloc)] = reloc
    return bytes(image)


if __name__ == "__main__":
    OUTPUT.write_bytes(build())
    print(f"wrote {OUTPUT.name}: {OUTPUT.stat().st_size} bytes")
Break it on purpose

A quick parser reads a section's offset from the header and slices data[offset:offset+size] without checks. A crafted file sets size to 4 GB. What happens, and what is this project's rule? (Solution B1.)

Recap
What to keep from this project
  • Identify the format by magic bytes; refuse what you do not support.
  • Sections carry permissions and entropy measured over stored bytes.
  • Read symbols, imports, exports and fixups with bounds checks everywhere.
  • Recover function starts with several methods and score them.
  • Publish a versioned report, a byte map and a build diff.

Exercises

Questions to test what you built. Try each one before you open the solutions.

  1. Why refuse big-endian and universal (fat) Mach-O files instead of guessing?
  2. Why might a prologue scan find fewer functions at -O2 than at -O0?
  3. What would a build diff show if a new dependency were linked in?

Solutions

Solution
  1. Refusing unsupported formats

Parsing them with assumptions made for little-endian 64-bit files would produce plausible but wrong numbers. A clear refusal tells the user what to do (extract one architecture first) instead of misleading them.

Solution
  1. Prologues at -O2

Optimizing compilers skip frame setup in small leaf functions and interleave instructions, so the familiar "save registers, set frame pointer" pattern is often missing. At -O0 nearly every function has it.

Solution
  1. A new dependency

New imports (library and symbol names), likely growth in __text and __stubs, new strings, and new function starts, each listed in the diff with sizes.

SolutionB1 · An unchecked size

Python would silently return a short slice (or a huge allocation in other languages), and later code would misread it as the section's content. The project checks every offset and size against the file length and reports a format error instead.

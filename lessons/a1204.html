In plain words first
The idea in one line

DeepMind's Flamingo (2022) did two things before anyone else. It showed a single model could process arbitrarily interleaved sequences of images, videos, and text. And it showed VLMs could learn in-context — give a few-shot prompt with three example (image, caption) pairs and the model captions a new image without any gradient step. The mechanism: gated cross-attention layers, inserted between the frozen LLM's existing layers, with a learned tanh gate that starts at zero so the LLM's text capability is preserved at initialization. The problem

In plain words first

Flamingo (DeepMind, 2022) gives a frozen language model eyes without changing what it already knows. It leaves the text stream untouched and inserts new layers between the existing ones. In these, the text tokens look at image features through cross-attention. Each new layer's contribution is multiplied by a gate, tanh(α), and α starts at zero, so on day one the model is exactly the original language model. Training opens the gates gradually. A Perceiver resampler squeezes each image to a fixed 64 tokens, and a mask makes every word look only at the most recent image, so prompts can interleave many images and texts. This lesson explains the design, then inserts zero-gated cross-attention into a real frozen 0.5B language model to show that nothing changes until the gates open. No model is trained.

BLIP-2 feeds 32 visual tokens into a frozen LLM's input layer. Works for one image per prompt. But what if you want to feed many images interleaved with text, as in "here is image A, caption it; here is image B, caption it; now here is image C, caption it"? The LLM's self-attention would need to handle image tokens and text tokens in a single stream, and the question of which positions can attend to which images gets fussy.

Flamingo's answer: do not change the LLM's input stream at all. Insert extra cross-attention layers between existing LLM blocks. Text tokens still flow through the LLM's causal self-attention as always. Between every few LLM blocks, text tokens also cross-attend to image features via a new gated layer. The gate (initialized to zero) means at step zero the new layers are no-ops — the model behaves exactly like the pretrained LLM. As training progresses the gate opens and visual information starts flowing.

The second question Flamingo answered: how do you handle a variable number of images (0, 1, or many) per prompt? A Perceiver resampler — a small cross-attention module that takes whatever number of patches you have and produces a fixed number of visual latent tokens per image. The total grows with the image count, but each text token reads only one image's latents, so what any single text token sees in cross-attention has the same shape regardless of how many images are in the prompt.

Idea 1 · The frozen LLM

Flamingo starts with a frozen Chinchilla 70B LLM. All 70B weights untouched. The existing text self-attention and FFN operate normally.

Idea 2 · Perceiver resampler

For each image in the prompt, the ViT produces N patch tokens. The Perceiver resampler has K fixed learnable latents (Flamingo uses K=64). Each resampler block is two sub-steps:

  1. Cross-attention: the K latents attend over the N patch tokens (Q from latents, K/V from patches).
  2. Self-attention + FFN within the latents.

After 6 resampler blocks, the output is K=64 visual tokens of dim 1024, regardless of how many patches the ViT produced. A 224x224 image (196 patches) and a 480x480 image (900 patches) both exit as 64 resampler tokens.

For video, the resampler is applied temporally: each frame's patches produce 64 latents, and a temporal positional encoding lets the model distinguish t=0 from t=N. The full video becomes T⋅64 visual tokens.

Idea 3 · Gated cross-attention

Between every M layers of the frozen LLM, insert a new gated cross-attention block. Flamingo-3B uses M=1 (a block before every layer), Flamingo-9B M=4, and Flamingo-80B M=7, trading visual capacity against added parameters:

x_after_llm_block = llm_block(x_before)
cross = cross_attn(x_after, resampler_output)
gated = tanh(alpha) * cross + x_after
x_before_next_block = gated
  • alpha is a learnable scalar initialized to zero.
  • tanh(0) = 0, so at init the gated branch contributes zero.
  • As alpha moves away from zero, the cross-attention contribution grows smoothly.
  • The residual connection means even a fully-open gate does not overwrite the LLM's text representation; it just adds visual information on top.

This is the single most important design choice in Flamingo: visual conditioning is additive, gated, and zero at initialization. A Flamingo at step 0 is a perfect Chinchilla 70B on text-only inputs.

Idea 4 · Masked cross-attention for interleaved inputs

In a prompt like " caption A caption B ?", each text token should only see images that came before it in the sequence. The cross-attention mask enforces: text token at position t attends only to the resampler tokens of image i_t, where i_t is the most recent image before position t; tokens from every other image are masked. "Sees only the last preceding image" or "sees all preceding images" are both valid choices; Flamingo chose the former.

The same idea as a formula

A gated cross-attention block after LLM layer ℓ, for text hidden states x and the latents V of the image the token may see:

x←x+tanh(αattn​)CA(x,V),x←x+tanh(αffn​)FFN(x),αattn​,αffn​ initialised to 0.
At α=0 both updates vanish exactly, so the model computes the frozen LLM's function. The gradient with respect to α at 0 is CA(x,V)⊤∂x∂L​, which is not zero, so the gate can open.

The interleaving mask. For text position t with most recent image i(t):

maskt,j​={10​if latent j belongs to image i(t)otherwise.​

Perceiver resampler: K learned latents cross-attend to N visual features, giving K×d whatever N is (K=64 in Flamingo).

Worked example
A gate at 0, 0.1 and 0.96
  • Block output at tanh(α)=0: x+0⋅CA(x,V)=x, bit for bit. The model's text predictions are unchanged.
  • At tanh(α)=0.1, a cross-attention output of size comparable to x shifts the hidden state by a tenth of it in each of the 6 blocks of the run below. That is enough to move logits by more than 1 unit.
  • At tanh(α)≈1, the untrained visual branch adds noise at full strength in every block, and the language model's predictions degrade. That is what a randomly initialised, ungated insertion would do from step 0.
  • The mask for "⟨img⟩ cat ⟨img⟩ dog ⟨img⟩ ?" with 3 images: each token reads 64 of the 192 latents, a third of the cross-attention matrix.

Predict before you run

Six gated cross-attention blocks with random weights are inserted into a frozen Qwen2.5-0.5B, fed random "image" latents. With every gate at tanh(α) = 0, how much do the logits change? And at tanh(α) ≈ 0.96, what happens to the perplexity of an ordinary English sentence? (Solution P1.)

See it drawn
Zero-gated cross-attention in a real frozen LLM

Qwen2.5-0.5B-Instruct, frozen, with 6 Flamingo-style blocks (gated cross-attention plus gated feed-forward), one after every 4 of its 24 layers, attached with forward hooks. The "visual" input is 64 random latents standing in for one image's resampler output. For gate values from 0 to 0.96: the largest change in any logit, and the perplexity of a fixed English sentence. Nothing is trained. About 20 seconds.

import math, torch, torch.nn as nn
from transformers import AutoModelForCausalLM, AutoTokenizer, logging
logging.set_verbosity_error()
torch.manual_seed(0)

# Flamingo's trick on a real frozen LLM: insert tanh-gated cross-attention blocks between Qwen2.5-0.5B's layers
name = "Qwen/Qwen2.5-0.5B-Instruct"
tok = AutoTokenizer.from_pretrained(name)
lm = AutoModelForCausalLM.from_pretrained(name, dtype=torch.float32).eval()
D, EVERY = lm.config.hidden_size, 4

class GatedXAttn(nn.Module):                       # x + tanh(alpha) * CrossAttn(x, visual), then the same for an FFN
    def __init__(self, d, heads=14):
        super().__init__()
        self.attn = nn.MultiheadAttention(d, heads, batch_first=True)
        self.ffn = nn.Sequential(nn.LayerNorm(d), nn.Linear(d, 4 * d), nn.GELU(), nn.Linear(4 * d, d))
        self.norm = nn.LayerNorm(d)
        self.alpha_attn = nn.Parameter(torch.zeros(1)); self.alpha_ffn = nn.Parameter(torch.zeros(1))
    def forward(self, x, visual):
        x = x + torch.tanh(self.alpha_attn) * self.attn(self.norm(x), visual, visual, need_weights=False)[0]
        return x + torch.tanh(self.alpha_ffn) * self.ffn(x)

layers = lm.model.layers
blocks = nn.ModuleList([GatedXAttn(D) for _ in range(0, len(layers), EVERY)])
visual = torch.randn(1, 64, D)                     # stand-in for 64 Perceiver-resampler tokens of one image

def run_with_gates(ids, gate):
    for b in blocks:
        b.alpha_attn.data.fill_(gate); b.alpha_ffn.data.fill_(gate)
    hooks = []
    for k, b in enumerate(blocks):                 # run block k right after LLM layer EVERY*k + EVERY-1
        def hook(mod, inp, out, b=b):
            h = out[0] if isinstance(out, tuple) else out
            h = b(h, visual)
            return (h,) + tuple(out[1:]) if isinstance(out, tuple) else h
        hooks.append(layers[EVERY * k + EVERY - 1].register_forward_hook(hook))
    with torch.no_grad():
        out = lm(ids, labels=ids)
    for h in hooks: h.remove()
    return out

text = "The Eiffel Tower is a wrought-iron lattice tower in Paris, France. It is named after the engineer Gustave Eiffel."
ids = tok(text, return_tensors="pt").input_ids
with torch.no_grad():
    base = lm(ids, labels=ids)
added = sum(p.numel() for p in blocks.parameters())
print(f"frozen LLM: {sum(p.numel() for p in lm.parameters()) / 1e6:.0f}M parameters, {len(layers)} layers; "
      f"added {len(blocks)} gated cross-attention blocks (one after every {EVERY} layers): {added / 1e6:.0f}M new parameters\n")
print(f"{'gate tanh(alpha)':>16}{'max logit change':>18}{'perplexity on the text':>24}")
print(f"{'(no blocks)':>16}{0:>18.4f}{math.exp(base.loss):>24.2f}")
for a in [0.0, 0.01, 0.1, 0.5, 2.0]:
    out = run_with_gates(ids, a)
    print(f"{math.tanh(a):>16.3f}{(out.logits - base.logits).abs().max():>18.4f}{math.exp(out.loss):>24.2f}")

Reading this output

At a closed gate nothing changes, exactly. With 6 new blocks inserted and 58M new random parameters (12% of the 494M frozen LLM), the logits differ from the original model by 0.0000 and the sentence's perplexity is still 3.91. This is not "almost the same": multiplying by tanh(0) = 0 removes the new branch entirely. Training can start from the pretrained language model with no damage, which is the point of Flamingo's design.

Opening the gate injects whatever the branch carries. At tanh(α) = 0.01 the logits move by up to 0.16 and perplexity is unchanged at two decimals (3.92). At 0.1 they move by 1.6 and perplexity rises to 4.05. At 0.46 it is 5.47, and at 0.96 it is 17.58: the untrained branch, fed random "visual" latents, is now overwriting the language model's computation.

What training does. The gate gives the optimiser a dial for how much of the visual branch to let in. The gradient on α is non-zero even at 0, so as the cross-attention learns to extract useful image information, opening the gate lowers the loss and α grows. The Flamingo paper reports that the learned gates open to different degrees at different depths.

Where the blocks go. Here one block follows every 4th layer, as in Flamingo-9B. More blocks give the image more influence and add more parameters. With 70B frozen parameters, Flamingo-80B's blocks add about 10B.

The interleaving mask, token by token

The prompt "⟨image⟩ A photo of a cat. ⟨image⟩ A photo of a dog. ⟨image⟩ A photo of a" in the Qwen tokenizer, with 64 latents per image. The table shows which image each text token may cross-attend to under Flamingo's rule, and how much more the "all preceding images" variant would read. Instant.

import torch
# uses tok from the run above (Qwen2.5 tokenizer)
# Flamingo's interleaved masking: each text token cross-attends only to the latents of the most recent image before it
prompt = "<image> A photo of a cat. <image> A photo of a dog. <image> A photo of a"
pieces = prompt.split("<image>")[1:]
tokens, last_img = [], []
for i, piece in enumerate(pieces):
    for t in tok(piece).input_ids:
        tokens.append(tok.decode([t])); last_img.append(i)
K = 64                                                   # latents per image from the Perceiver resampler
n_img = len(pieces)
mask = torch.zeros(len(tokens), n_img * K, dtype=torch.bool)  # True = may attend
for r, i in enumerate(last_img):
    mask[r, i * K:(i + 1) * K] = True
print(f"{len(tokens)} text tokens, {n_img} images x {K} latents = {n_img * K} visual keys\n")
print("token        sees image   (# = attends to that image's 64 latents)")
for r, (t, i) in enumerate(zip(tokens, last_img)):
    print(f"{t!r:<12} {i + 1:>6}       " + "".join("#" if mask[r, j * K] else "." for j in range(n_img)))
print(f"\nallowed entries: {mask.sum().item():,} of {mask.numel():,} ({mask.float().mean():.0%})")
cum = torch.zeros_like(mask)
for r, i in enumerate(last_img): cum[r, : (i + 1) * K] = True
print(f"'all preceding images' variant: {cum.sum().item():,} allowed ({cum.float().mean():.0%}); "
      f"the final ' a' would read {cum[-1].sum().item()} latents instead of {K}")

Reading this output

Each caption reads only its own image. The tokens of "A photo of a cat." cross-attend to image 1's 64 latents, "A photo of a dog." to image 2's, and the final unfinished "A photo of a" to image 3's. Self-attention in the LLM still lets every token read all earlier text. So when the model completes the third caption, it can copy the pattern of the first two from the text, while its visual evidence comes only from image 3. That combination is what makes Flamingo's few-shot prompting work.

The mask is sparse. Only 33% of the cross-attention entries are allowed. The variant where each token sees all preceding images would allow 61%, and the last token would read 192 latents instead of 64. Flamingo chose the simpler rule: it performed better in the paper's ablations than seeing all previous images, and the LLM's self-attention still carries information about earlier images forward through the text.

Text before the first image (not in this prompt) has no image to see. Flamingo handles it by letting the gated block contribute nothing for those positions.

Idea 5 · In-context few-shot learning

A Flamingo prompt looks like:

<image1> A photo of a cat. <image2> A photo of a dog. <image3> A photo of a

The model sees the completion pattern and outputs "bird" (or whatever image3 shows). No gradient steps. The frozen LLM's in-context learning capability carries through the gated cross-attention — this is the punchline of the paper and why it matters.

Idea 6 · Training data

Flamingo trained on three datasets:

  1. MultiModal MassiveWeb (M3W): 43M web pages with interleaved images and text, reconstructing reading order.
  2. Image-Text Pairs: ALIGN (1.8B pairs) plus LTIP (312M pairs), about 2.1B pairs in total.
  3. Video-Text Pairs (VTP): 27M short video clips.

OBELICS (2023) is an open reproduction of the interleaved web corpus, which Idefics, Idefics2, and most open "Flamingo-like" models train on.

Idea 7 · OpenFlamingo and Otter

OpenFlamingo (2023) is the open reproduction. Architecture identical (Perceiver resampler + gated cross-attention on frozen LLaMA or MPT). Checkpoints at 3B, 4B, 9B. Quality lags Flamingo due to smaller base LLM and less data.

Otter (2023) builds on OpenFlamingo with instruction tuning on MIMIC-IT (a dataset of multimodal instructions), showing gated cross-attention works for instruction following too.

Idea 8 · The descendants

  • Idefics / Idefics2 / Idefics3: Hugging Face's line. Idefics (2023) was an open Flamingo-style model with gated cross-attention. Idefics2 dropped the cross-attention layers and fed 64 perceiver-resampler tokens per image into the LLM's input. Idefics3 replaced the resampler with pixel shuffle.
  • Flamingo-to-Chameleon transition: by 2024 many teams moved to early-fusion (Lesson 12.11); Flamingo-style gated cross-attention remains in production where backbone freezing is required.
  • Gemini's interleaved input: conceptually inherits Flamingo's interleaved-format flexibility, though the exact mechanism is proprietary.

Break it on purpose

Initialise the gates at α = 1 instead of 0, keep the LLM frozen, and start training on image–text data. What happens to the model's text ability in the first steps, and what does the training then have to do? (Solution B1.)

Industry practice
What's current (2024–2026)
  • Input-token fusion won for most models: since 2024 most open VLMs (LLaVA family, Qwen-VL, InternVL, Idefics2/3) place projected visual tokens in the LLM's input instead of adding cross-attention layers.
  • Cross-attention survives where the LLM must stay unchanged: Meta's Llama 3.2 Vision (2024) added cross-attention adapter layers to a Llama 3.1 text model and kept the text model's weights fixed, so text behaviour was preserved.
  • Interleaved data keeps its value: OBELICS and later interleaved web corpora (such as MINT-1T) are standard in VLM pretraining, because they teach multi-image and in-context use.
  • Zero-initialised gates and adapters are a general technique: ControlNet's zero convolutions and LoRA's zero-initialised B (Lesson 11.8) use the same "start as identity" idea.

Sources: Flamingo (arXiv 2204.14198), Idefics2 (arXiv 2405.02246), Llama 3.2 announcement, OBELICS (arXiv 2306.16527), MINT-1T (arXiv 2406.11271).

Recap
What to keep from this lesson
  • Flamingo keeps the LLM frozen and inserts gated cross-attention blocks between its layers.
  • tanh(α) gates start at 0, so the model starts as the original LLM, exactly.
  • A Perceiver resampler turns each image into a fixed 64 latents.
  • A mask lets each text token see only the most recent image: interleaved prompts work.
  • In-context few-shot learning carries over from the frozen LLM.

Solutions

SolutionP1 · Exactly nothing, then a large loss of fluency

At tanh(α) = 0 the logits change by exactly 0.0000 and the perplexity stays 3.91, the frozen model's own value, even though 58M random parameters were inserted. At tanh(α) ≈ 0.96 the untrained branch dominates: the perplexity of the same English sentence rises to 17.58, more than four times worse. The gate decides how much of the new branch reaches the language model, so starting it closed protects the pretrained model completely.

SolutionB1 · The model starts damaged

At α = 1 the gate is tanh(1) ≈ 0.76 open from the first step, so the randomly initialised cross-attention and feed-forward branches add large, meaningless updates in every block. The run above shows the effect: at a gate of 0.46 the perplexity of plain English had already risen from 3.91 to 5.47, and at 0.96 to 17.58. The frozen LLM cannot adapt. All repair must come from the new layers: they first have to learn to cancel their own noise, or the gates have to close again, before they can learn anything useful about images. Training is slower and less stable, and the early gradients through a damaged language model are poor. Zero-initialised gates avoid all of this. The same reasoning is behind LoRA's zero-initialised B and ControlNet's zero convolutions.

Read the block and the decode loop and find the problems. python def causal_mask(n): return torch.tril(torch.ones(n, n, dtype=torch.bool)) class DecoderBlock(nn.Module): def forward(self, text, image, mask): text = text + self.self_attn(self.ln1(text), mask=None) text = text + self.cross_attn(self.ln2(text), image, mask=mask) text = text + self.ffn(self.ln3(text)) return text def generate(model, image, prompt_ids, steps): ids = prompt_ids for _ in range(steps): memory = model.encode_image(image) mask = causal_mask(ids.shape[1]) logits = model.decode(ids, memory, mask) ids = torch.cat([ids, logits[:, -1].argmax(-1, keepdim=True)], dim=1) return ids

Level 2 of 4 · about 12 minutes to answer well.

Short answer. The masks are swapped. Self-attention over the text runs with no mask, so every position sees the future during training, and the model learns to copy the next token instead of predicting it, which breaks as soon as it must generate. Cross-attention gets the causal text mask, which is square over the text length and cannot apply to scores that span text by image, hence the shape error with 197 image tokens. The decode loop also re-encodes the image on every step; encode once, cache the image keys and values, and reuse them.

The mask discipline.

Attention Query Key Mask
Self-attention over text text, length Nt text, length Nt causal, lower-triangular Nt by Nt
Cross-attention into the image text, length Nt image, length Nv none

Text may not look ahead during autoregression. The image is fully observed before any text exists, and its patches have no order, so every text position may attend to every patch.

Bug 1: no mask on self-attention.

With mask=None, position i attends to the positions after it. Under teacher forcing the target of position i is the token at i plus one, which is now visible, so the loss falls fast and the model learns to look it up. At inference the future does not exist, and from the second token the captions fall apart. That is the symptom in the report.

Bug 2: the causal mask on cross-attention.

The scores of cross-attention have the shape Nt by Nv. A causal mask of shape Nt by Nt fits only when Nv equals Nt, and then it silently hides part of the image from the early text tokens. With a 197-token image memory and a shorter text, the shapes do not broadcast and the forward pass raises. The capstone adds one shape-validation function, so that this mistake raises a clear error instead of corrupting a loss curve.

Observation 3: no key and value cache.

The image does not change during decoding. Encoding it on every step and projecting its keys and values again multiplies the cost of the heavy encoder by the number of generated tokens. Encode once, project once, store the keys and values, and pass them to every step. The capstone tests that the cached and the uncached paths give identical logits.

The fixed block.

def forward(self, text, image_kv, text_mask):
    text = text + self.self_attn(self.ln1(text), mask=text_mask)
    text = text + self.cross_attn(self.ln2(text), image_kv, mask=None)
    text = text + self.ffn(self.ln3(text))
    return text

Plausible wrong answers.

  • "Use the causal mask on both attentions to be safe." Cross-attention scores are text by image, so a square text mask either raises or hides part of the image; the image needs no mask.
  • "The captions are wrong because the image encoder is weak." A model that is right on the first token and wrong from the second leaked the future in training; the mask is the cause.
  • "Recomputing the image each step is fine, the encoder is small." The encoder is the heaviest part per call, and the image never changes; the cache is what makes captioning fast.

Follow-ups an interviewer may ask.

  • (level 2) Why does the training loss look fine with the first bug? Expected: teacher forcing puts the target token in the input one position later, and an unmasked attention can read it; the loss measures a lookup, not a prediction.
  • (level 2) When does cross-attention need a mask? Expected: with several images and text segments interleaved, where a segment may see only the images before it; for one image and one caption, none.
  • (level 3) What does the gate from the Flamingo design add to this block, and why? Expected: a learned scalar through a hyperbolic tangent on the cross-attention residual, starting at zero, so that a frozen language model keeps its text behavior at initialization and mixes the image in gradually.
  • (level 3) How do you test the cache path? Expected: run the same prompt with and without the cache and assert that the logits match to float tolerance; the capstone ships that test.

Debug a failureYou fine-tune a model built like Flamingo, with a gated cross-attention block after every few layers of a frozen language model, on a small captioning dataset. Captions improve, but text-only quality degrades: the model rambles on plain prompts and loses facts it knew. What is the likely cause, how do you confirm it, and how do you fix it?

Level 3 of 4 · about 12 minutes to answer well.

Short answer. The gates opened too wide too fast. Each gated layer adds the hyperbolic tangent of a learned scalar times the cross-attention output to the residual stream; at zero the layer is a no-op and the model is the pretrained text model. A high learning rate on the gates, or no regularization, lets visual noise flood the residual stream even when the prompt has no image. Confirm it by reading the gate values per layer against the base and by running a text-only eval with the gates forced to zero; fix it with a lower rate or a schedule on the gates, a text-only data mix, and a check that the layers add nothing when no image is present.

The mechanism.

x_after = llm_block(x_before)
cross   = cross_attn(x_after, visual_latents)
x_next  = tanh(alpha) * cross + x_after

At initialization alpha is zero, so the model is exactly the frozen language model. As alpha grows, visual information is added on top of the text representation. The residual means that even a fully open gate does not erase the text path, but a large gate adds a large term at every fourth block. If the cross-attention output is noise, that noise reaches the output.

Why a fine-tune breaks it.

  • The gates are the cheapest parameters to move, so a learning rate chosen for the cross-attention weights pushes them fast.
  • A caption-only dataset never shows a text-only prompt, so nothing penalizes gates that add visual terms when there is no image to attend to.
  • With few images per prompt, the masked cross-attention has little to read, and an open gate still adds its output.

Confirm.

  1. Log the gate value per layer. Compare it with the base checkpoint and with the step at which text quality fell.
  2. Run the text-only eval with the gates forced to zero. If the quality returns, the gates are the cause.
  3. Send a text-only prompt through the model and measure the norm of the gated term per layer. It should be near zero when no image is present.

Fix.

  • A lower learning rate or a warm-up schedule for the gate scalars, so that they open over the run rather than in the first steps.
  • A text-only mix in the fine-tuning data, so that the loss covers the case the product sees.
  • A regularizer on the gates, or a cap on their magnitude.
  • A mask check: text tokens with no preceding image must attend to nothing, and the gated term must add nothing.
  • Fewer gated layers, if the task does not need one every fourth block.

Why the design is still right.

The gate is what let the original work keep a frozen 70B language model intact while it learned to read images. The failure here is in the schedule, not in the architecture.

Plausible wrong answers.

  • "The captioning data is too small; add more images." More caption data with no text-only prompts pushes the gates further the same way; the fix is the gate schedule and the data mix.
  • "Unfreeze the language model so that it can adapt to the visual input." That trades a schedule problem for catastrophic forgetting of the text model, which the frozen design exists to prevent.
  • "Replace gated cross-attention with the simpler concatenation design." The symptom is a schedule problem; the gate is the mechanism that protects the text model, and the simpler design has no such protection.

Follow-ups an interviewer may ask.

  • (level 3) What does the residual connection buy once the gate is open? Expected: the text representation is never overwritten, only added to; even a fully open gate leaves the text path intact, which is why the fix is the schedule and not a redesign.
  • (level 3) How would you spot the same damage in a model that concatenates image tokens instead? Expected: there is no gate to read; the damage shows as a shift in the language model weights, so compare the text-only eval before and after, and freeze the language model or limit it to adapters.
  • (level 4) Design a unit test that catches this before training. Expected: build the block with alpha at zero and assert that the output equals the block output exactly for a text-only input, then set a large alpha and assert that a text-only input with an empty mask still equals the block output.
  • (level 4) How do you decide how many gated layers to keep? Expected: ablate the insertion frequency against caption quality and text-only quality on one eval; every fourth block is the reference, and fewer layers mean fewer places for noise to enter.

Where it is taught. The Flamingo lesson explains why the gate starts at zero and names an over-fast gate as the cause of degraded text performance, and the cross-attention fusion capstone builds the block and the gate exercise.

Explain the mechanismA model must take a prompt with any number of images, some small and some large, interleaved with text, and then caption the last image from a few in-context examples. Explain the module that makes the number and the size of the images manageable, and how a text token knows which image to look at.

Level 2 of 4 · about 12 minutes to answer well.

Short answer. A resampler with a fixed set of learned latent vectors turns the patch tokens of each image into a fixed number of visual tokens. In the reference design, 64 latents attend over however many patches the encoder produced, 196 for a small image or 900 for a large one, through six blocks of cross-attention and self-attention, and every image exits as 64 tokens of one width. Text tokens then read those tokens through gated cross-attention layers inserted between the frozen language model blocks, and a mask lets each text token attend only to the latents of the most recent image before it in the sequence.

The resampler.

Each block does two things. The K latents cross-attend to the N patch tokens, with queries from the latents and keys and values from the patches; then the latents run self-attention and a feed-forward layer among themselves. After six blocks the output is K tokens of width 1024, whatever N was. For video the resampler runs on each frame, with a temporal position encoding, so the frame count times 64 is the token count of the clip.

Why fixed matters.

Interleaved prompts have zero, one or many images. With a fixed count per image, what any one text token sees in cross-attention has the same shape whatever the prompt. The total grows with the image count, but each text token reads one image's latents.

The gated bridge.

Between every fourth block of the frozen language model sits a new cross-attention layer with a residual gate: the output equals the block output plus the hyperbolic tangent of a learned scalar times the cross-attention. The scalar starts at zero, so at initialization the new layers do nothing, and the model is exactly the pretrained text model.

The mask.

In a sequence like image A, caption A, image B, caption B, image C, question, a text token attends only to the resampler tokens of the most recent image before it; the other images are masked. Attending to all preceding images is a valid alternative; the reference design chose the most recent one.

In-context few-shot.

Three image and caption pairs followed by a new image form a prompt that the frozen language model already knows how to complete. The gated layers feed it image content, and its in-context learning carries over without a gradient step. That is the point of keeping the language model frozen and the gate at zero.

Against the single-input bridge.

The query-based bridge from the earlier lesson also uses learned queries, but once, at the input layer, with 32 queries. The resampler plus gated cross-attention reads the latents every few layers, which costs more parameters and compute and buys interleaving and few-shot behavior.

Plausible wrong answers.

  • "Pad every image to the same number of patches." Padding wastes compute on large images and loses detail on small ones; the resampler gives a fixed count without either.
  • "Let the text tokens attend to all image patches directly." The count then varies per image and per prompt, and a prompt with many images floods the attention; the latents keep it fixed.
  • "Initialize the gate open so that the model learns faster." An open gate at step zero destroys the frozen language model's text behavior; a start at zero is what preserves it.

Follow-ups an interviewer may ask.

  • (level 2) Why does the latent side supply the query vectors and the patch side the rest, not the other way around? Expected: the output has one row per query, so queries from the latents give a fixed number of rows; the reverse would give one row per patch again.
  • (level 2) What does the temporal encoding do for video? Expected: each frame gives the same 64 latents, so without a time signal the model cannot tell the first frame from the last; the encoding marks the frame index.
  • (level 3) Why mask to the most recent image instead of all preceding images? Expected: it keeps the shape each text token sees constant and matches the interleaved reading order, where a caption describes the image before it; seeing all images is the alternative with a different trade-off.
  • (level 3) A fine-tune of a model like this lost text-only quality. Where do you look? Expected: the gate; if it opened too wide too fast, visual noise overwrote the text residual stream, so compare the gate values by layer with the base.

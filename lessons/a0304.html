The idea in one line

Without nonlinearity, your 100-layer network is a fancy matrix multiply. Activations are the gates that let neural networks think in curves.

Terms you'll hear
Term What people say What it actually means
Activation function "The nonlinear part" A function applied to each neuron's output that breaks linearity, enabling the network to learn nonlinear mappings
Vanishing gradient "Gradients disappear in deep networks" Gradients shrink exponentially through layers when the activation's derivative is less than 1, making early layers untrainable
Exploding gradient "Gradients blow up" Gradients grow exponentially through layers when the effective multiplier exceeds 1, causing unstable training
Dead neuron "A neuron that stopped learning" A ReLU neuron whose input is permanently negative, producing zero output and zero gradient
Sigmoid "Squishes values to 0-1" The logistic function $1/(1+e^{-x})$, historically important but causes vanishing gradients in deep networks
ReLU "Clips negatives to zero" $\max(0, x)$ -- the activation that made deep learning practical by preserving gradient magnitude
GELU "The transformer activation" Gaussian Error Linear Unit, a smooth activation that weights inputs by their probability of being positive
Swish/SiLU "Self-gated ReLU" $x \cdot \text{sigmoid}(x)$, discovered through automated search, used in EfficientNet
Softmax "Turns scores into probabilities" Normalizes a vector of logits into a probability distribution where all values are in (0,1) and sum to 1
Leaky ReLU "ReLU that doesn't die" $\max(\alpha x, x)$ where $\alpha$ is small (0.01), preventing dead neurons by allowing small negative gradients
Saturation "The flat part of sigmoid" Regions where an activation's derivative approaches zero, blocking gradient flow
Logit "The raw score before softmax" The unnormalized output of the final layer before applying softmax or sigmoid

The problem

In plain words first

An activation function is the small bend applied to every neuron's output. Without it, any stack of layers collapses into one straight-line transformation. Which bend you choose decides how gradients travel backwards: sigmoid squashes them, ReLU passes them through unchanged when the neuron is on and blocks them when it is off, and smooth modern choices such as GELU sit in between. Hidden layers use ReLU or GELU today; the output layer uses whatever turns scores into the answer you need (softmax for classes, sigmoid for a probability, nothing for a number).

Stack two linear transformations: y=W2​(W1​x+b1​)+b2​. Expand it: y=W2​W1​x+W2​b1​+b2​. That's just y=Ax+c -- a single linear transformation. No matter how many linear layers you stack, the result collapses to one matrix multiply. Your 100-layer network has the same representational power as a single layer.

This is not a theoretical curiosity. It means a deep linear network literally cannot learn XOR, cannot classify a spiral dataset, cannot recognize a face. Without activation functions, depth is an illusion.

Activation functions break the linearity. They warp the output of each layer through a nonlinear function, giving the network the ability to bend decision boundaries, approximate arbitrary functions, and actually learn. But pick the wrong activation and your gradients vanish to zero (sigmoid in deep networks), explode to infinity (unbounded activations without careful initialization), or your neurons die permanently (ReLU with large negative biases). The choice of activation function directly determines whether your network learns at all.

Idea 1 · Why Nonlinearity Is Necessary

Matrix multiplication is composable. Multiplying a vector by matrix A then matrix B is identical to multiplying by AB. This means stacking ten linear layers is mathematically equivalent to one linear layer with one big matrix. All those parameters, all that depth -- wasted. You need something to break the chain. That's what activation functions do.

Here is the proof. A linear layer computes f(x)=Wx+b. Stack two:

Layer 1:hLayer 2:y​=W1​x+b1​=W2​h+b2​​

Substitute:

yyy​=W2​(W1​x+b1​)+b2​=(W2​W1​)x+(W2​b1​+b2​)=Ax+c​

One layer. Insert a nonlinear activation g() between layers:

hy​=g(W1​x+b1​)=W2​h+b2​​

Now the substitution breaks. W2​g(W1​x+b1​)+b2​ cannot be reduced to a single linear transformation. The network can represent nonlinear functions. Each additional layer with an activation adds representational capacity.

Check your mental model
  • ✗ "More linear layers give the network more power."
    ✓ Any number of linear layers equals one linear layer; the extra parameters buy nothing until an activation sits between them.
  • ✗ "In a deep sigmoid network the signal itself fades away."
    ✓ The forward values stay healthy: Step 3 shows them near 0.5 at every layer. What fades is the gradient on the way back, because each layer multiplies it by sigmoid's slope of at most 0.25.
  • ✗ "GELU cannot have dead neurons."
    ✓ GELU's slope is −0.012 at x=−3 and −0.0005 at x=−4. A neuron whose input stays below about −3 learns almost as little as a dead ReLU. GELU's real advantage is the smooth slope near zero, where ReLU's jumps from 0 to 1.

Idea 2 · Sigmoid

The original activation function for neural networks.

sigmoid(x)=1+e−x1​

Output range: (0, 1). Smooth, differentiable, maps any real number to a probability-like value.

The derivative:

sigmoid′(x)=sigmoid(x)⋅(1−sigmoid(x))

The maximum value of this derivative is 0.25, occurring at x=0. In backpropagation, gradients multiply through layers. Ten layers of sigmoid means the gradient gets multiplied by at most 0.25 ten times:

0.2510=0.000000953674

Less than one millionth of the original signal. This is the vanishing gradient problem. Gradients in early layers become so small that weights barely update. The network appears to learn -- loss decreases in later layers -- but the first layers are frozen. Deep sigmoid networks simply do not train.

Additional problem: sigmoid outputs are always positive (0 to 1), which means gradients on weights are always the same sign. This causes zig-zagging during gradient descent.

Idea 3 · Tanh

The centered version of sigmoid.

tanh(x)=ex+e−xex−e−x​

Output range: (-1, 1). Zero-centered, which eliminates the zig-zag problem.

The derivative:

tanh′(x)=1−tanh(x)2

Maximum derivative is 1.0 at x=0 -- four times better than sigmoid. But the vanishing gradient problem still exists. For large positive or negative inputs, the derivative approaches zero. Ten layers still crush the gradient, just less aggressively.

Idea 4 · ReLU: The Breakthrough

Rectified Linear Unit. Popularized for deep learning by Nair and Hinton in 2010 (the function itself dates to Fukushima's 1969 work), it changed everything.

relu(x)=max(0,x)

Output range: [0,∞). The derivative is trivially simple:

relu′(x)={10​if x>0if x≤0​

No vanishing gradient for positive inputs. The gradient is exactly 1, passed straight through. This is why deep networks became trainable -- ReLU preserves gradient magnitude across layers.

But there is a failure mode: the dead neuron problem. If a neuron's weighted input is always negative (due to a large negative bias or unfortunate weight initialization), its output is always zero, its gradient is always zero, and it never updates. It is permanently dead. In practice, 10-40% of neurons in a ReLU network can die during training.

Idea 5 · Leaky ReLU

The simplest fix for dead neurons.

leaky_relu(x)={xαx​if x>0if x≤0​

Where α is a small constant, typically 0.01. The negative side has a small slope instead of zero, so dead neurons still get a gradient signal and can recover.

Idea 6 · GELU: The Modern Default

Gaussian Error Linear Unit. Introduced by Hendrycks and Gimpel in 2016. Default activation in BERT, GPT, and most modern transformers.

gelu(x)=x⋅Φ(x)

Where Φ(x) is the cumulative distribution function of the standard normal distribution. The approximation used in practice:

gelu(x)≈0.5⋅x⋅(1+tanh(2/π​⋅(x+0.044715⋅x3)))

GELU is smooth everywhere, allows small negative values (unlike ReLU which hard-clips to zero), and has a probabilistic interpretation: it weights each input by how likely it is to be positive under a Gaussian distribution. This smooth gating outperforms ReLU in transformer architectures because it provides better gradient flow and avoids the dead neuron problem entirely.

Idea 7 · Swish / SiLU

Self-gated activation discovered by Ramachandran et al. in 2017 through automated search.

swish(x)=x⋅sigmoid(x)

Swish is formally x⋅sigmoid(x). Google discovered it through automated search over activation function space -- a neural network designing parts of neural networks.

Like GELU, it is smooth, non-monotonic, and allows small negative values. The difference is subtle: Swish uses sigmoid for gating while GELU uses the Gaussian CDF. In practice, performance is nearly identical. Swish is used in EfficientNet and some vision models. GELU dominates in language models.

Idea 8 · Softmax: The Output Activation

Not used in hidden layers. Softmax converts a vector of raw scores (logits) into a probability distribution.

softmax(xi​)=∑j​exj​exi​​

Every output is between 0 and 1. All outputs sum to 1. This makes it the standard final activation for multi-class classification. The largest logit gets the highest probability, but unlike argmax, softmax is differentiable and preserves information about relative confidence.

Worked example
Softmax by hand

Logits (2,1,0): e2=7.389, e1=2.718, e0=1, total 11.107. The probabilities are (0.665,0.245,0.090). Adding the same number to every logit changes nothing, because it multiplies every term and the total by the same factor. Real implementations use this: they subtract the largest logit first, so ex never overflows.

Step 1 · Implement All Activation Functions with Derivatives

Each function takes a single float and returns a float. Each derivative function takes the same input and returns the gradient.

import math

def sigmoid(x):
    x = max(-500, min(500, x))
    return 1.0 / (1.0 + math.exp(-x))

def sigmoid_derivative(x):
    s = sigmoid(x)
    return s * (1 - s)

def tanh_act(x):
    return math.tanh(x)

def tanh_derivative(x):
    t = math.tanh(x)
    return 1 - t * t

def relu(x):
    return max(0.0, x)

def relu_derivative(x):
    return 1.0 if x > 0 else 0.0

def leaky_relu(x, alpha=0.01):
    return x if x > 0 else alpha * x

def leaky_relu_derivative(x, alpha=0.01):
    return 1.0 if x > 0 else alpha

def gelu(x):
    return 0.5 * x * (1 + math.tanh(math.sqrt(2 / math.pi) * (x + 0.044715 * x ** 3)))

def gelu_derivative(x):
    phi = 0.5 * (1 + math.erf(x / math.sqrt(2)))
    pdf = math.exp(-0.5 * x * x) / math.sqrt(2 * math.pi)
    return phi + x * pdf

def swish(x):
    return x * sigmoid(x)

def swish_derivative(x):
    s = sigmoid(x)
    return s + x * s * (1 - s)

def softmax(xs):
    max_x = max(xs)
    exps = [math.exp(x - max_x) for x in xs]
    total = sum(exps)
    return [e / total for e in exps]

def gradient_scan(name, derivative_fn, start=-5, end=5, n=100):
    step = (end - start) / n
    near_zero = 0
    healthy = 0
    for i in range(n):
        x = start + i * step
        g = derivative_fn(x)
        if abs(g) < 0.01:
            near_zero += 1
        else:
            healthy += 1
    pct_dead = near_zero / n * 100
    print(f"{name:15s}: {healthy:3d} healthy, {near_zero:3d} near-zero ({pct_dead:.0f}% dead zone)")

Step 4 · Dead Neuron Detector

Create a ReLU network, pass random inputs through it, count how many neurons never fire.

def dead_neuron_detector(n_inputs=5, hidden_size=20, n_samples=1000):
    random.seed(0)
    weights = [[random.gauss(0, 1) for _ in range(n_inputs)] for _ in range(hidden_size)]
    biases = [random.gauss(0, 1) for _ in range(hidden_size)]

    fire_counts = [0] * hidden_size

    for _ in range(n_samples):
        inputs = [random.gauss(0, 1) for _ in range(n_inputs)]
        for neuron_idx in range(hidden_size):
            z = sum(w * x for w, x in zip(weights[neuron_idx], inputs)) + biases[neuron_idx]
            if relu(z) > 0:
                fire_counts[neuron_idx] += 1

    dead = sum(1 for c in fire_counts if c == 0)
    rarely_fire = sum(1 for c in fire_counts if 0 < c < n_samples * 0.05)
    healthy = hidden_size - dead - rarely_fire

    print(f"\nDead Neuron Report ({hidden_size} neurons, {n_samples} samples):")
    print(f"  Dead (never fired):     {dead}")
    print(f"  Barely alive (<5%):     {rarely_fire}")
    print(f"  Healthy:                {healthy}")
    print(f"  Dead neuron rate:       {dead/hidden_size*100:.1f}%")

    for i, c in enumerate(fire_counts):
        status = "DEAD" if c == 0 else "WEAK" if c < n_samples * 0.05 else "OK"
        bar = "#" * (c * 40 // n_samples)
        print(f"  Neuron {i:2d}: {c:4d}/{n_samples} fires [{status:4s}] {bar}")

Step 5 · Training Comparison -- Sigmoid vs ReLU vs GELU

Train the same two-layer network on the circle dataset (points inside a circle = class 1, outside = class 0) with three different activations. Compare convergence speed.

def make_circle_data(n=200, seed=42):
    random.seed(seed)
    data = []
    for _ in range(n):
        x = random.uniform(-2, 2)
        y = random.uniform(-2, 2)
        label = 1.0 if x * x + y * y < 1.5 else 0.0
        data.append(([x, y], label))
    return data


class ActivationNetwork:
    def __init__(self, activation_fn, activation_deriv, hidden_size=8, lr=0.1):
        random.seed(0)
        self.act = activation_fn
        self.act_d = activation_deriv
        self.lr = lr
        self.hidden_size = hidden_size

        self.w1 = [[random.gauss(0, 0.5) for _ in range(2)] for _ in range(hidden_size)]
        self.b1 = [0.0] * hidden_size
        self.w2 = [random.gauss(0, 0.5) for _ in range(hidden_size)]
        self.b2 = 0.0

    def forward(self, x):
        self.x = x
        self.z1 = []
        self.h = []
        for i in range(self.hidden_size):
            z = self.w1[i][0] * x[0] + self.w1[i][1] * x[1] + self.b1[i]
            self.z1.append(z)
            self.h.append(self.act(z))

        self.z2 = sum(self.w2[i] * self.h[i] for i in range(self.hidden_size)) + self.b2
        self.out = sigmoid(self.z2)
        return self.out

    def backward(self, target):
        error = self.out - target
        d_out = error * self.out * (1 - self.out)

        for i in range(self.hidden_size):
            d_h = d_out * self.w2[i] * self.act_d(self.z1[i])
            self.w2[i] -= self.lr * d_out * self.h[i]
            for j in range(2):
                self.w1[i][j] -= self.lr * d_h * self.x[j]
            self.b1[i] -= self.lr * d_h
        self.b2 -= self.lr * d_out

    def train(self, data, epochs=200):
        losses = []
        for epoch in range(epochs):
            total_loss = 0
            correct = 0
            for x, y in data:
                pred = self.forward(x)
                self.backward(y)
                total_loss += (pred - y) ** 2
                if (pred >= 0.5) == (y >= 0.5):
                    correct += 1
            avg_loss = total_loss / len(data)
            accuracy = correct / len(data) * 100
            losses.append(avg_loss)
            if epoch % 50 == 0 or epoch == epochs - 1:
                print(f"    Epoch {epoch:3d}: loss={avg_loss:.4f}, accuracy={accuracy:.1f}%")
        return losses

Recap
What to keep from this lesson
  • Without activations, depth collapses into one linear layer.
  • Sigmoid's slope is at most 0.25, so its gradients vanish in deep stacks; tanh is better but still saturates.
  • ReLU passes gradients unchanged where it is on and blocks them where it is off; neurons stuck off are dead.
  • GELU and Swish are smooth versions of ReLU and the default in transformers.
  • Softmax turns logits into class probabilities and belongs on the output layer.

Solutions

SolutionP1 · Tanh, surprisingly

Tanh: 41 of the 100 points have a slope below 0.01, against 9 for sigmoid. Tanh's slope falls below 0.01 once ∣x∣>2.65, sigmoid's only once ∣x∣>4.6. A higher peak slope does not mean a wider useful range; that is why the scale of the inputs to each activation (initialisation, normalisation) matters as much as the choice of function.

SolutionB1 · Neurons that hardly ever fire

2 neurons never fire in 1,000 samples, 14 fire on fewer than 5 percent of them, and only 4 stay healthy, against 20 healthy with the original biases. A neuron that rarely fires rarely gets a gradient, so it has little chance to recover. Fixes: Leaky ReLU or GELU, a lower learning rate, and initialising biases at zero.

SolutionM1 · Tanh

Tanh ends at a loss of 0.0157: better than sigmoid's 0.0319, behind ReLU's 0.0102 and GELU's 0.0056. Its zero-centred output and steeper slope help; its saturation still slows it down compared with the ReLU family.

Use it: the same idea with real libraries

PyTorch provides all of these as both functional and module forms:

import torch
import torch.nn as nn
import torch.nn.functional as F

x = torch.randn(4, 10)

relu_out = F.relu(x)
gelu_out = F.gelu(x)
sigmoid_out = torch.sigmoid(x)
swish_out = F.silu(x)

logits = torch.randn(4, 5)
probs = F.softmax(logits, dim=1)

model = nn.Sequential(
    nn.Linear(10, 64),
    nn.GELU(),
    nn.Linear(64, 32),
    nn.GELU(),
    nn.Linear(32, 5),
)

Hidden layers in a transformer: GELU. Hidden layers in a CNN: ReLU. Output layer for classification: softmax. Output layer for regression: none (linear). Output layer for probabilities: sigmoid. That's it. Start with these defaults. Change them only when you have evidence.

RNNs and LSTMs use tanh for hidden state and sigmoid for gates, but if you're building from scratch today, you're probably not using RNNs. If neurons are dying in your ReLU network, switch to GELU. Don't reach for Leaky ReLU unless you have a specific reason -- GELU solves the dead neuron problem and gives better gradient flow.

Industry practice
What's current (2024–2026)
  • Gated activations in LLMs. SwiGLU (Llama, Qwen, Mistral, DeepSeek) and GeGLU (Gemma) multiply a SiLU or GELU branch by a linear "gate" branch; they replaced ReLU in large language models.
  • GELU in encoders, ReLU on the edge. BERT-style encoders and ViTs use GELU; ReLU and its cheap variants (ReLU6, hard-swish) remain common in mobile CNNs because they quantise well.

Sources: GLU variants, Gemma report, MobileNetV3 (hard-swish).

medium35 mintrain

A network with one hidden layer of tanh units can bend a straight line into a smooth curve. In this task you train a 1-16-1 tanh network to fit sin(x) from noisy samples. The checks then compare the trained network with the true curve at new points that your code never sees.

Task

Write two functions.

  1. train(x, y, rng) trains a network and returns the trained model.
  2. predict(model, x) returns the network output for each value in x.

The data comes from make_sine(n, rng) in support.py. Each x is uniform from −π to π, and y=sin(x)+ε with Gaussian noise of standard deviation 0.1.

Use 1 input, 16 tanh hidden units and 1 linear output: y^​=tanh(xW1​+b1​)W2​+b2​. Train it on the mean squared error N1​∑i​(y^​i​−yi​)2 with full-batch gradient descent. Adam reaches the target with the least tuning.

During training, call report(step, loss) from practice_check once for each update step. The first step is 0. The page draws these values as a live loss curve, and the checks count them.

Input and output

Name Type Shape Meaning
x float array (N,) the training inputs, from −π to π
y float array (N,) the noisy targets
rng np.random.Generator the only source of random numbers
model any the value that train returns
  • train returns the model. The model can be any Python value, for example a list of weight arrays.
  • predict returns a float array of shape (M,) for an input of shape (M,).

Constraints

  • Budget: at most 1500 update steps, so at most 1500 calls to report.
  • Target: a mean squared error of at most 0.01 against the true curve sin(x), at 2000 new values of x from −π to π. This page does not give their seed.
  • Take every random number from rng. The same seed must give the same model.
  • Do not change x or y, and do not change their shape.
  • predict must work for one value, shape (1,).
  • Use numpy only. One full submit has a limit of 20 seconds.

Your code
Common mistakes the checks catch
  • Forgets the factor 1 - h ** 2 when it sends the gradient back through the tanh layer.
  • Uses t - out as the output gradient, so Adam climbs the loss instead of descending it.
  • Starts both weight matrices at zero, so no gradient reaches the first layer and the output stays flat.
  • Draws the first-layer weights from np.random and not from the rng argument, so two runs with one seed differ.
  • Sets x.shape = (-1, 1) on the caller's array, so the input changes shape.
  • Trains for 2500 steps, more than the budget of 1500.
Hint 1

Reshape x and y to column vectors of shape (N, 1) with reshape. That makes a new view and keeps the caller's arrays as they are. Then X @ W1 has shape (N, 16).

Hint 2

Draw W1 from rng.normal with the scale 1, so that the 16 tanh units bend at different values of x. Draw W2 with the scale sqrt(1 / 16). Start the biases at zero. Zero weights give no gradient to the first layer.

Hint 3

The gradient of the mean squared error at the output is 2 * (out - t) / N. Send it back with @ W2.T and multiply by 1 - h ** 2, the derivative of tanh.

Hint 4

Use Adam on the four arrays: keep m and v for each, correct them with 1 - beta ** (step + 1), and step with lr * m_hat / (sqrt(v_hat) + eps). The learning rate 0.01 reaches the target in about 1000 steps.

Reference solution and notes
import numpy as np

from practice_check import report
from support import make_sine

HIDDEN = 16
STEPS = 1500
LR = 0.01
BETA1 = 0.9
BETA2 = 0.999
EPS = 1e-8


def init_params(rng):
    W1 = rng.normal(scale=1.0, size=(1, HIDDEN))
    W2 = rng.normal(scale=np.sqrt(1.0 / HIDDEN), size=(HIDDEN, 1))
    return [W1, np.zeros(HIDDEN), W2, np.zeros(1)]


def forward(params, X):
    W1, b1, W2, b2 = params
    h = np.tanh(X @ W1 + b1)
    return h, h @ W2 + b2


def train(x, y, rng):
    params = init_params(rng)
    m = [np.zeros_like(p) for p in params]
    v = [np.zeros_like(p) for p in params]
    X = x.reshape(-1, 1)
    t = y.reshape(-1, 1)
    n = X.shape[0]
    for step in range(STEPS):
        W1, b1, W2, b2 = params
        h, out = forward(params, X)
        loss = np.mean((out - t) ** 2)
        report(step, float(loss))
        d_out = 2.0 * (out - t) / n
        d_h = d_out @ W2.T * (1.0 - h ** 2)
        grads = [X.T @ d_h, d_h.sum(axis=0), h.T @ d_out, d_out.sum(axis=0)]
        for i, g in enumerate(grads):
            m[i] = BETA1 * m[i] + (1.0 - BETA1) * g
            v[i] = BETA2 * v[i] + (1.0 - BETA2) * g ** 2
            m_hat = m[i] / (1.0 - BETA1 ** (step + 1))
            v_hat = v[i] / (1.0 - BETA2 ** (step + 1))
            params[i] = params[i] - LR * m_hat / (np.sqrt(v_hat) + EPS)
    return params


def predict(model, x):
    _, out = forward(model, np.asarray(x, dtype=float).reshape(-1, 1))
    return out[:, 0]

How tanh units build a curve

Each hidden unit gives a smooth step tanh(wx+b). Its center is at x=−b/w and its width depends on w. The output layer adds the steps with the weights W2​. A sine curve between −π and π needs about three bends, so 16 units are more than enough.

Why the check uses the true curve

The training targets have noise with variance 0.01. A model that copies every training point gets a training loss below 0.01 but a wrong curve between the points. The held-out check compares with sin(x) itself, so only a smooth fit passes.

Why tanh and not a step function

The derivative of tanh, 1−tanh2, is never 0, so each unit always gets some gradient. The activation functions lesson compares this with sigmoid and ReLU. A ReLU network also fits a sine, but it builds the curve from straight pieces.

Debug a failureAfter a few hundred steps at a high learning rate, a ReLU network's loss stops falling. You log the activations after each ReLU, and in two layers more than half of them are exactly zero on every batch. Explain what happened to those units, why they cannot come back on their own, and what you change.

Level 3 of 4 · about 12 minutes to answer well.

Short answer. First confirm that the units are dead and not only sparse: over a large sample, a dead unit is zero on every input. A ReLU unit whose pre-activation is negative for every input outputs zero and has a derivative of zero, so it receives no gradient and its weights never move again. A large update, driven by the high learning rate, pushed those units' weights and biases far enough negative that no input brings them back. Lower the learning rate, re-initialize the dead units or the dead layers, and move to an activation with a gradient on the negative side, such as a leaky variant or GELU.

What a dead unit is.

ReLU is max(0, x). Its derivative is 1 for positive inputs and 0 otherwise. A unit whose input is negative on every sample outputs 0, passes 0 gradient to its weights, and nothing else in the loss touches those weights. It is dead for the rest of training. The activation lesson reports that 10 to 40 percent of units can die in a ReLU network in practice. The debugging lesson's threshold is more than half zeros after a ReLU layer: at that point switch the activation or reduce the learning rate.

How the high learning rate did it.

One oversized step moves a unit's bias or weights far negative. After that step every input lands below zero. The debugging lesson's demo builds the state directly by filling weights with -1.0 and biases with -5.0 and shows a flat loss with most activations at zero. A high learning rate reaches the same state by accident.

Telling dead from sparse.

Some zeros are normal; ReLU is meant to be sparse. Count, over a large sample, the fraction of inputs on which each unit is positive. Dead means zero on all of them. The activation lesson's detector reports dead, barely alive and healthy units from that count.

What to change.

  1. Lower the learning rate, and add gradient clipping so one bad batch cannot produce the step again.
  2. Re-initialize the incoming weights of the dead units with a Kaiming draw and continue; the rest of the network keeps its progress. This is the debugging lesson's dead neuron resurrector exercise.
  3. Switch the activation. A leaky ReLU keeps a small slope on the negative side, so a unit can recover. GELU is smooth and avoids the failure entirely; the activation lesson prefers it over the leaky variant unless there is a specific reason.
  4. Check initialization. A Kaiming draw keeps pre-activations centered at the start, so fewer units begin life negative.

Plausible wrong answers.

  • "Half zeros is normal sparsity for ReLU." Some zeros are normal; a unit that is zero on every input is dead and contributes nothing, and the lesson flags a layer above half zeros.
  • "Raise the learning rate so the units jump back." The gradient is zero regardless of the rate; no step reaches them.
  • "Switch to sigmoid to avoid zeros." Sigmoid trades dead units for vanishing gradients through depth; a leaky variant or GELU keeps the benefits of ReLU.

Follow-ups an interviewer may ask.

  • (level 3) Why does the unit stay dead rather than drift back? Expected: zero output gives zero gradient to its weights, and nothing else in the loss touches them.
  • (level 3) How do you tell a dead unit from a sparsely active one? Expected: count the fraction of inputs on which it is positive over a large sample; dead is zero on all, sparse is positive on a small fraction.
  • (level 4) What links the high learning rate to the death? Expected: one large step moves the bias or weights far negative so every input lands below zero; clipping and a smaller rate limit the step.
  • (level 4) Can you revive the dead units without retraining from scratch? Expected: re-initialize their incoming weights with a Kaiming draw and continue; the rest of the network keeps its progress.

Explain the mechanismA junior engineer removes every activation function from a 10 layer network to make it faster and reports that training still runs and the loss still falls. What did they build, and why will it fail on XOR or on a spiral dataset?

Level 1 of 4 · about 5 minutes to answer well.

Short answer. Two linear layers compose into one: W2 (W1 x + b1) + b2 equals (W2 W1) x + (W2 b1 + b2), which is a single matrix and a single bias. Ten linear layers are one linear layer with extra parameters and the same decision boundary, a hyperplane. XOR and a spiral need a curved boundary, so the network cannot fit them at any width or depth.

The substitution.

h = W1 x + b1
y = W2 h + b2 = W2 W1 x + W2 b1 + b2 = A x + c

Matrix products compose, so a stack of linear maps is one linear map. Repeat the substitution and ten layers fold into one matrix A and one vector c. Depth without a nonlinearity is an illusion: the model has the capacity of a single linear layer, it only costs more to run.

What an activation changes.

Insert a nonlinear function g between the layers, so that h = g(W1 x + b1). The substitution fails, because W2 g(W1 x + b1) + b2 does not reduce to A x + c. Each extra layer with an activation adds representational capacity. That is what lets a network bend its boundary around a spiral or separate the XOR points.

What to add back.

The lesson's defaults: ReLU for a plain MLP or a CNN, GELU for a transformer, tanh inside recurrent cells. The output layer is the one place a missing activation is correct: a regression head emits any real number, a binary head uses a sigmoid, and a multi-class head uses a softmax.

Why the loss still fell.

A stack of linear layers only finds the best linear fit to the data. On XOR or a spiral that fit is close to chance, but it is better than random weights, so the loss moves. A falling loss is not evidence that the model can represent the target.

Plausible wrong answers.

  • "Ten layers are deeper, so they represent more." Without a nonlinearity the product of the matrices is one matrix; depth adds nothing.
  • "The biases make it nonlinear." A bias shifts the hyperplane; it does not bend it.
  • "The loss went down, so it is learning fine." It learns the best linear fit, which for XOR or a spiral is near chance.

Follow-ups an interviewer may ask.

  • (level 1) Which layer is allowed to have no activation? Expected: the output layer of a regression model, which must produce any real number.
  • (level 2) Does the deep linear network train faster than one layer? Expected: no; it computes the same function with more parameters and more matrix multiplies.
  • (level 2) Which activation would you add back for a plain MLP and for a transformer? Expected: ReLU for the MLP and GELU for the transformer.
  • (level 3) Why is the collapse not a proof that depth is useless? Expected: with a nonlinearity between layers the substitution fails and each layer adds capacity; deep networks fit the same functions with fewer parameters than wide shallow ones.

Check your understanding

Q1Why can't you build a useful deep network using only linear layers (no activation functions)?

y = W2(W1*x + b1) + b2 simplifies to y = Ax + c. No matter how many linear layers you stack, the result is equivalent to one linear layer. Activation functions break this composability.

Q2What is the output range of the ReLU activation function?

ReLU(x) = max(0, x). It outputs 0 for all negative inputs and passes positive inputs unchanged, giving a range of [0, infinity).

Q3What is the 'dead neuron' problem in ReLU networks?

If a ReLU neuron's weighted input is always negative (due to bad initialization or large negative bias), it outputs 0 with gradient 0. It can never recover because zero gradient means zero update.

Q4Which activation function is the default for hidden layers in modern transformers like GPT and BERT?

GELU (Gaussian Error Linear Unit) is the default activation in transformers. It provides smooth gradient flow, avoids dead neurons, and has been shown to outperform ReLU in language models.

Q5Why is softmax used only in the output layer and never in hidden layers?

Softmax normalizes a vector so all values are in (0,1) and sum to 1, creating a probability distribution. Hidden layers need to preserve and transform information, not compress it into probabilities.

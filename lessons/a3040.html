What it does

If you are already using multiple pages in your app, you might want to automatically trigger a page change for the app user when they take certain actions (e.g. when they click a button, or select a certain value of a widget for a multi-page form).

  1. Create an app with the code from streamlit_app.py
  2. Add extra pages
  3. Whenever you want to switch to a new page, just run

python switch_page("page name")

  1. Test locally to make sure you can see all the pages in the sidebar and that the pages switch when you expect them to.

sh streamlit run streamlit_app.py

  1. Create the app in SiS, either through the web UI, or through the snowcli

sh snow streamlit create --file streamlit_app.py GREAT_NAME_FOR_MY_STREAMLIT snow streamlit deploy --file streamlit_app.py GREAT_NAME_FOR_MY_STREAMLIT

  1. Upload all of the other pages to the stage associated with your app

sh snow stage put pages/page_1.py GREAT_NAME_FOR_MY_STREAMLIT_STAGE/pages snow stage put pages/page_2.py GREAT_NAME_FOR_MY_STREAMLIT_STAGE/pages

  1. Profit!

Codestreamlit_app.py (35 lines)
from __future__ import annotations

import streamlit as st


def switch_page(page_name: str):
    from streamlit.runtime.scriptrunner import RerunData, RerunException
    from streamlit.source_util import get_pages

    def standardize_name(name: str) -> str:
        return name.lower().replace("_", " ")

    page_name = standardize_name(page_name)

    pages = get_pages("streamlit_app.py")  # OR whatever your main page is called

    for page_hash, config in pages.items():
        if standardize_name(config["page_name"]) == page_name:
            raise RerunException(
                RerunData(
                    page_script_hash=page_hash,
                    page_name=page_name,
                )
            )

    page_names = [standardize_name(config["page_name"]) for config in pages.values()]

    raise ValueError(f"Could not find page {page_name}. Must be one of {page_names}")


if st.button("Switch to Page 1"):
    switch_page("Page 1")

if st.button("Switch to Page 2"):
    switch_page("Page 2")

Run it on your machine

git clone --depth 1 --filter=blob:none --sparse https://github.com/Snowflake-Labs/sf-samples
cd sf-samples
git sparse-checkout set samples/streamlit-in-snowflake/switch-pages
cd samples/streamlit-in-snowflake/switch-pages

Install the dependencies (pip install -r requirements.txt if the folder has one), put your keys in a .env file, then start the entry point shown above.

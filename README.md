# AI from Zero to Hero

A free, hands-on course from a dev environment and a little linear algebra to agents that plan, use tools and work in teams: **948 lessons in 20 phases**, with runnable Python, maths, interactive figures, quick checks, interview questions and a review queue, all in the browser.

**Open the course:** https://abhi4972.github.io/AI-From-Zero-to-Hero/

Everything is on one site: one menu for all 20 phases, one search across every lesson, one progress tracker. No account and no install are needed.

Each phase has up to three sections: its own lessons, **Cheat sheets** (one-page references) and companion lessons marked **From Zero to Agents**, grouped by topic and numbered after the phase's own lessons. Start with **Lesson 0.0**, which explains how the course works and suggests five routes through it.

## Using it

- **Progress** is saved in your browser. To move it to another device, use **Export progress** on the home page, then **Import progress** on the other device. Import merges, it never overwrites.
- **Python** runs in the page (Pyodide). The first run downloads about 10 MB; after that your browser usually has it cached.
- **Guided or Scroll**: show a lesson one step at a time, or as one page.
- Press **⌘K** / **Ctrl+K** (or `/`) to jump to any lesson, section or interview question.

## How the site is built

```
lessons/<id>.html     each lesson (edit these)
data/course.json      parts, phases and the lesson list: order, numbers, titles, minutes (edit this)
data/zxt.json         the one-line summaries the lesson player shows per section
data/diagrams/<id>.mmd  the step-through diagram of a lesson, as Mermaid source (edit these)
data/titles_src.py    this course's names for its phases, lessons and cheat sheets (edit this, then run tools/retitle.py)
engine/               the app: page shell, styles and scripts
img/ figs/ repo-assets/ src/   images and data used by lessons
shared/               Python runtime (Pyodide 0.26.4) and maths fonts
thumbs/               link-preview images
vol1/ … vol5/         old links from the five-volume version, redirected here

index.html, search/, meta/   generated by tools/build.py
```

After changing a lesson or `data/course.json`, run

```bash
python3 tools/renumber.py   # only if lesson numbers changed: updates every "Lesson N" reference
python3 tools/diagrams.py   # only if a diagram source changed: re-renders it into its lesson (needs mmdc)
python3 tools/retitle.py    # only if data/titles_src.py changed, or lessons were regenerated from the source repo
python3 tools/build.py
```

It rewrites `index.html` (the app plus a short summary of every lesson), the search files and the phase thumbnails, refreshes every lesson's Previous / Next footer, and stops with an error if any in-site link, image or listed lesson is missing.

`tools/migrate.py` is the one-time script that turned the five volume pages into this layout; the five-volume version is kept on the [`five-volumes`](https://github.com/Abhi4972/AI-From-Zero-to-Hero/tree/five-volumes) branch.

Served by GitHub Pages from `main`, root folder.

## Run it locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000. Opening `index.html` straight from disk will not work, because browsers block loading the lesson files that way.
